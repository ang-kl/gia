## 5. Map controller structure

- **Train** keeps its own wiring in `MrtMapPanel.jsx`. Station and stop taps are handled there.
- **Hawker and Cuisine** install `window.__giaStationSim` and `window.__giaStopBuses` hooks in their map panels.
  Their `mapOverlays.js` copies call the hooks, null-guarded. A shared controller and the shared stop layer do the
  work, and the hooks are removed on unmount.
- **Footer and header (v0.62.971):** `FooterRunButtons` sits in each app's existing footer row before back.
  `ResumeStrip` sits in the header band after each `SimCaptionStrip`.
