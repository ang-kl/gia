## 3. Storage keys added

| Key | TTL | Holds |
|---|---|---|
| `fr24:board:<icao>:<dir>` | 300 s | A board answer |
| `fr24:planes:<icao>` | 60 s | Planes near an airport |
| `fr24:flight:<fr24_id>` | 600 s | One flight summary |
| `fr24:locate:<callsign>` | 60 s | One live position |
| `fr24:gates:<ids, sorted>` | 300 s | Gate events |
| `fr24:track:<fr24_id>` | 120 s | A flown path |
| `fr24:eta:<callsigns>` | 300 s | ETAs |
| `fr24:credits:<YYYY-MM>` | month | Credits counted this Singapore calendar month |

Failures are not cached; in-flight requests are shared; a busy minute serves the last good answer marked `stale`,
never older than 30 days (FR24's storage rule, `STALE_MAX_MS`). Memory holds a copy when Redis is not open.

## 6. Constants that bound cost (`fr24.js:33-53`)

At most 8 FR24 requests a minute (`RATE_PER_MIN`); 20 results a request (`LIMIT`); credits counted from each answer,
including 40 a track (`TRACK_CREDITS`) and 8 an ETA call (`ETA_CREDITS`). A 402 from FR24 stops requests until the
month turns.
