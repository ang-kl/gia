## Note

Two things are worth carrying out of this entry, and neither is the code.

The first is that **one command closed a hole four phases of work had left open.** O-175 — "run `/cost` against the deployed build" — sat open from v0.62.716, cost nothing, needed no code, and was deferred through two API-key rotations while considerably more elaborate work went on around it. It found that the spend guard was blind to the priciest provider in the system. The cheapest available verification was also the highest-yield one, and it stayed undone because it was not interesting.

The second is X-5, which is the third repetition of one error in a single session: a stored observation read as live state. A header comment describing a file relationship (X-3), a CI status from a previous PR (X-4), a Redis key recording one call (X-5). Each was true when written and false when used. The operator caught the third one. The pattern is specific enough now to name: **anything the repo tells you about itself is evidence of a past moment, not a description of the present — re-measure before asserting.**
