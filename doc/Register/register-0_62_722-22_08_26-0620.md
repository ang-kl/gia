## Note

№ 195 closed by naming the pattern behind X-3, X-4 and X-5: *anything the repo tells you about itself is evidence of a past moment, not a description of the present — re-measure before asserting.* That note was written into a Register, and then the very next decision this session made — overruling the operator's model choice — violated it, **while citing it**. The rule had been learned as a phrase rather than as a habit, and a phrase can be recited in support of the thing it forbids.

What distinguishes X-7 from its three predecessors is that it was not a lapse. It was argued for, written into two source comments and a commit message as a principle, and used to override the only participant with live access to the running system. The three earlier instances were carelessness; this one was reasoning. That makes it the more expensive kind, and it is why every model name in this repo now resolves through one file whose comments cite Google's live 404 text as their evidence — not a repo comment, and not a recollection.

Two smaller things worth carrying forward. **X-8**: "the sandbox cannot verify this" was never tested, and cost three versions of estimated-rather-than-real cost data; one HTTP request settled it. **D-200**: the invariant test found an eleventh copy of the dead chain that three manual sweeps had missed, because `grep` silently skips files it deems binary — the sweep was not wrong about what it saw, it was wrong about what it had looked at.

And the item that matters most in this entry is the one the code cannot touch. **O-200** — depleted prepayment credits — means every fix here is necessary and none of it is sufficient. The model names are correct now; the calls still fail.
