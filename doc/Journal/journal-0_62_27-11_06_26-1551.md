### [HDR] #679 | 15:51 SGT 11-06-26 | v0.62.27 — Places cost: Michelin negative-cache + 7d success TTL | index.js (handleMichelinSearch resolveEntryPlace) | 1 PR | 0 build |

- **[INTENT]** Cut recurring Places spend on the Michelin walk without changing what the user sees.

- **[DELTA]** `index.js` `resolveEntryPlace`:
  - **(1) Negative cache.** The write was `if (placesData) setEx(...)` — misses were never cached,
    so an unresolvable entry re-billed a `places:searchText` (Atmosphere SKU) on every tap forever.
    Now the miss is cached under a sentinel `{ __michMiss: 1 }` for a 12h TTL; the read returns null
    for the sentinel without re-billing. A newly-indexed venue recovers within 12h.
  - **(2) Success TTL 24h → 7d.** The curated Michelin list is static and an established awardee's
    core Place data rarely moves (openNow is recomputed from regularOpeningHours client-side), so
    the meaningful staleness is negligible while cold re-fetches drop ~7×.

- **[VERIFICATION (sandbox)]** `node --check index.js` clean; full suite **3361/3361** green (no
  test delta — cache TTL/sentinel logic in a network-bound resolver). No web change.

- **[STATUS]** PR (rides the session branch). Railway on merge. No behaviour change for the user
  (same cards; fewer billed Places calls on repeat/unresolvable entries).

- **[KNOWN GAPS / declined this pass]**
  - **Discover Atmosphere over-fetch** (the biggest lever): the cuisine `DISCOVER_FIELD_MASK` pulls
    the full Enterprise+Atmosphere set (reviews/generativeSummary/priceRange/allowsDogs/
    accessibility) for every candidate across every page, though only ~12 show. Splitting into a
    cheap discover + lazy Atmosphere Place-Details for the shown set (cache-backed) is the highest-
    value change but a hot-path refactor — operator deferred it this pass.
  - **Autocomplete session tokens**: `/api/cuisine/place-autocomplete` bills each keystroke as a
    standalone Autocomplete request (5-min cache softens repeats); session tokens would fold
    keystrokes into the final Place-Details session. Operator deferred (needs a client+server change).
  - Worth adding per-SKU cost telemetry (api-cost.recordMapsCall tracks by endpoint string, not SKU)
    to measure these levers' impact before/after.
