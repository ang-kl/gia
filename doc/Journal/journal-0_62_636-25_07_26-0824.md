  Plan first"* (a long menu: Motion, Lenis, AutoAnimate, View Transitions API, NumberFlow, Rive/Lottie,

- **[AUDIT — plan turn, corrected premise]** The brief assumed "GSAP already in place" — it is **not**; all 7
  TMAs are bare React 18 + Tailwind + Vite with **zero** animation/UI libraries, and `prefers-reduced-motion`
  is respected **nowhere** in app code. Recommended **against** Lenis (fixed-shell map app — would fight the
  map-drag + bottom-sheet drag) and **against** 3D (we just fixed an iPad-mini WebGL/DOM freeze). Proposed a
  phased pilot: **C1** foundation → **C2** AutoAnimate → **C3** Motion + View Transitions. Operator chose
  Transport as the pilot and C1-C3 in one go.

- **[DELTA]** (Transport only; new deps `@formkit/auto-animate ^0.10` + `motion ^12.42`)
  - **C1 — foundation:**
    - `web/transport/src/styles.css` — a `@media (prefers-reduced-motion: reduce)` reset that neutralises the
      two infinite decorative animations (line-flash + marquee) and collapses transition/scroll durations; a
      `.gia-skeleton` shimmer; and `::view-transition-old/new(root)` timing (260 ms ease-out) for C3.
    - **NEW** `web/transport/src/components/LoadingSkeleton.jsx` — a skeleton shell (header + line-pill +
      map + card placeholders) replacing the bare `"Loading…"` line; wired into `App.jsx`'s `!data` return.
  - **C2 — AutoAnimate:** `useAutoAnimate()` on the LIST-mode station grid, so cards fade / slide as the
    focused line (and its station set) changes. Honours reduced-motion on its own.
  - **C3 — Motion + View Transitions:**
    - **NEW** `web/transport/src/lib/view-transition.js` — `withViewTransition()` (`flushSync` +
      feature-detect `document.startViewTransition` + reduced-motion guard), wrapping the footer view-swap
      toggles (carousel↔list, gmap↔png) for a native crossfade where supported, plain swap otherwise.
    - Motion spring on the **selected-card "pop"**: `StationCard` root is now `m.div` with
      `animate={{ scale: active ? 1.02 : 1 }}`, spring `420/30/0.7`, gated by `useReducedMotion()` (the
      ring/shadow still mark selection when motion is off). Loaded via `LazyMotion` + `domAnimation` in
      `main.jsx` — the ~⅓-size Motion bundle vs the full `motion` import.
