## New

### [HDR] v0.62.644 — uniform fixed-height carousel cards + Cuisine-style foot pill + a collapsed card worth reading

- **[INTENT]** Operator: *"Train TMA carousel cards collapsed should be within while the card height is the
  same as cuisine TMA, the collapse and expand is same effect as cuisine TMA."*

- **[READ of the Cuisine model (`IMG_1205`)]** A Cuisine `ResultCard` shows **a lot** while collapsed — name,
  type/rating/price, hours, price + crowd, Try-dish, Michelin, address — and hides only the *deep* detail
  behind a small pill at the card **foot** ("⌄ details, review & links"). The strip's cards are **one uniform
  box** and the content scrolls **inside**, so expanding never resizes the card. The Train card did the
  opposite: an almost-empty collapsed body (2 lines), a **▾ triangle up on the name strip**, and a `max-h` box
  that **grew** when expanded.

- **[DELTA]** (Train, 3 files)
  1. **Uniform box** — `web/transport/src/App.jsx`: the `StationCarousel` card box goes from `max-h-[42vh]` to
     a **fixed** `h-[34vh] sm:h-[27vh]` with `overflow-y-auto`, so every card in the strip is the **same** box
     (Cuisine's tidy look) and expanding **scrolls inside** it rather than resizing it.
  2. **Foot pill** — `StationCard.jsx`: the card-level triangle is **removed from the name strip** (the strip
     is now name-only, keeping every pixel for the name after v0.62.643) and replaced by a Cuisine-style
     **foot pill** "▾ details" / "▴ less", pinned with `mt-auto` (plus `min-h-full` on the card root so the
     pill lands on the card's bottom edge inside the fixed box; against an auto-height parent
     `min-height:100%` resolves to nothing, so the grid / drawer are unaffected).
  3. **Collapsed body is now informative** (Cuisine-like density): one compact row **per line** (line-code
     chip + 🚋 first · last, or the line name when there are no timings) plus a single **amenity-counts** row
     (🚪 exits · 🚌 stops · 🅿️ carparks · 🍜 nearest-hawker distance). The ▾ pill then reveals the full
     Around-the-station chips, the per-line direction detail, and the action pills.
  - i18n: added `mrt.detailsMore` / `mrt.detailsLess` (+ `mrt.exitsN` / `mrt.stopsN`, unused for now) in
    en + fr with English fallback.
