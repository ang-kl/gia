### [HDR] v0.62.629 — fix v0.62.628 regression: floating header hid the map controls

- **[ROOT CAUSE]** v0.62.628 floated the **header over** the full-bleed map (`absolute top-0`), which
  **covered the map's quick-access toggle row** (Monochrome / Train / Carpark / Bus Stop / Hawker, via
  `MapControls`) and the nav cluster — the "missing buttons." The carousel floated in the fixed shell at
  `bottom-14`, clipping tall cards. **Cuisine** actually keeps its header **above** the map (`sticky top-0
  z-30`) with the map **below** it (`sticky z-20`) and floats only the **cards** (`fixed z-30`) — *not* a
  header-over-map overlay.

- **[DELTA — `web/transport/src/App.jsx` CAROUSEL return]** Reverted the floating-header / full-bleed shell
  to a **flex-col**: header **in flow** (`px-3 pt-2 shrink-0 relative z-20`), map fills (`relative flex-1
  min-h-0`), and the carousel **floats over the MAP container's bottom** (`absolute inset-x-0 bottom-2 z-30
  pointer-events-none`) — so the map's toggle row + nav cluster (top of the map, below the header) stay
  visible. `mapBlock(true, true)` → `mapBlock(true)` (navInset off — the header no longer overlaps the
  map). `items-end` (v0.62.628, kept) gives natural card heights; floating **inside the bounded map
  container** (above the footer reserve) stops the clipping. The `MrtMapPanel` `z-[35]` expand overlay
  (v0.62.628) is kept. **Codex P2 (pre-merge review) fix:** the floating carousel (`z-30`) covered the
  map's **Overview / Back** control (`bottom-3 right-2 z-10`) exactly when a focused line enabled it —
  lifted that button to **`z-[36]`** (above the carousel) so it stays clickable.
