- **[INTENT]** Reduce the visual weight of bus-stop pins that sit far from the
  current map focus, so they no longer compete with primary search results.

- **[DELTA]**
  - **`mapOverlays.js`** (byte-identical ×3) —
    - new `liteBusNode()`: a half-size, translucent 🚏 marker (no № code, lighter
      fill, thinner border) used for de-emphasised bus stops.
    - new `BUS_DEEMPH_NEAR_M = 150` constant: stops within this of the **map
      anchor** render at full prominence; stops outside this but inside the
      `OVERLAY_RADIUS_M` (550 m) render as lite.
    - `buildBusMarkers` now pre-creates **both** content variants per marker and
      starts with the lite version.
    - `applyVisibility` (marker branch) swaps the marker's `content` between primary
      and lite based on the per-pan-anchor distance. Picking is re-evaluated on every
      `setAnchor` (i.e. every map `idle` event) — so panning the map shifts which
      stops are prominent.
  - **`package.json`** — `0.61.51` → `0.61.52` (PATCH).
