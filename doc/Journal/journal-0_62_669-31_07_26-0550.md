     coercion fix; those rows regained real file data on regeneration (1,644 rows).

     `data-theme` stamp had zero consumers (verified: no `var(--tg-`, no `getComputedStyle`, no
     `[data-theme]` selector, no `dark:` variants anywhere in clipboard). `applyTelegramTheme` renamed
     `initTelegramChrome` to match what it still does; header note added so the block doesn't get
     re-added. The fixed-light palette's single source of truth is now visibly `tailwind.config.js` (D-37).
  3. **`debe407` (P2-b)** — the invisible migrations:
     - **`tg-warn` role token** (cuisine tailwind config, fixed `#f59e0b` = amber-500): the audit's one
       genuine design-system gap — 11 advisory borders (8 App.jsx banners, 2 ResultPanel halts, the
       FunFactModal Stop) all documented as "amber per the operator's no-red rule" with no named token.
       Swap is pixel-identical; the name now holds the meaning. Deliberately NOT a theme var.
     - **`.gia-map-btn` role class** (cuisine/hawker/transport styles.css): the 15 map-nav buttons + the
       MapControls ⋮ trigger consolidate from the repeated `bg-white text-black border-gray-300` triad to
       one class with byte-identical values — encoding that map chrome is deliberately light in both
       themes (Google-Maps convention; the map tiles are its background, not the app theme).
     - **Search-FAB rings** (App.jsx + TellMePanel): `border-white/40` → `border-tg-accent-text/40` on the
       `bg-tg-accent text-tg-accent-text` FABs — identical on stock themes (button text is white), and on
       custom themes the ring now correctly matches the icon colour sharing the surface.
  4. **NOT changed — A-contradict handled as a decision, not a fix**: cuisine `BackFab.jsx` hard-codes the
     `#7FDBDB` teal while its own v0.60.91 comment documents the opposite operator intent (inverse theme

     later deliberate 4-app standardization, making the COMMENT the likely stale half. Auto-"fixing" the
     code would have visibly changed 1 of 4 apps on the strength of a stale comment. → Register O-85 item 1.
