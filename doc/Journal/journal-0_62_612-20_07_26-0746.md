# Journal — v0.62.612 (viewport: detect a touch tablet from the physical screen, so Cuisine stops reverting to the phone layout)

_(№ 956 — 20-07 '26 07:46 SGT)_

## New

### [HDR] v0.62.612 — a coarse-pointer device whose hardware short edge ≥ 768 is a tablet, even when Telegram's webview is collapsed

- **[INTENT]** Operator: *"we spend so many days doing the tablet and tablet mini and desktop. I run
  Cuisine TMA and it is revert to phone aspect ratio. why"* — confirmed (AskUserQuestion) on an
  **iPad / Android tablet (touch)**.

- **[ROOT CAUSE — investigation]** The responsive layout is gated by `isWide` from the **shared**
  `web/_shared/lib/use-viewport.js` `readViewport()`, which classified the device from the **live
  Telegram webview size** (`window.innerWidth` / `window.innerHeight`): a **tablet** required a coarse
  (touch) pointer **and** `min(innerW, innerH) ≥ 768`. But inside Telegram the webview is frequently
  **smaller than the physical screen** — a Mini App opens as a partial-height sheet, or a swipe collapses
  it — so `min(w, h)` drops below 768 and a **real tablet mis-read as `mobile`** → the phone layout, and
  could **"revert"** mid-session on a collapse/rotate. Meanwhile each `tg.js` fullscreen gate **already**
  keys off `window.screen` (the physical device), so the two decisions disagreed. **Not a regression**
  from the recent Hawker/Transport work — the hook is unchanged since v0.62.546 and Cuisine's App since
  v0.62.594; this is the pre-existing fragility, now surfaced.

- **[DELTA — 1 file]** `web/_shared/lib/use-viewport.js` `readViewport()`: a coarse-pointer device whose
  **physical short edge** (`min(window.screen.width, window.screen.height)`) is **≥ 768** is now a
  `'tablet'` **even if** the transient webview min-dimension is < 768 —
  `if (coarse && (minDim >= 768 || screenMin >= 768)) deviceClass = 'tablet'`. Once classified a tablet,
  it stays one (the physical screen is constant), so it can **never flip back to phone** on a resize. It
  **cannot** wrongly promote a phone (screen short edge < 768) or a desktop (`coarse` is false, so the
  branch is skipped). Affects **all three** TMAs (cuisine / hawker / transport share the hook) — a
  desirable consistency.
