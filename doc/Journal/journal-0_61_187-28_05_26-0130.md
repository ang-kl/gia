- **[INTENT]** OTHER region (Putrajaya / KL / Penang / Batam etc.)
  has effectively infinite candidate locations — a precinct
  dropdown or Places autocomplete is too broad to be useful.
  The anchor is set via chat `/location` (which lands on a
  curated precinct). For OTHER, the TMAs should display the
  anchor as a locked read-only label + skip the picker UI
  entirely. SG and JB keep their existing dropdown + free-text
  flows.
