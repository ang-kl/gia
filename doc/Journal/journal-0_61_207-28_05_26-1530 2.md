- **[INTENT]**
  1. Replace Google Places' bare-building-number `displayName.text`

- **[DELTA]**

  **NEW `smart-place-label.js`** (~110 lines, CommonJS):
  `smartPlaceLabel(displayName, formattedAddress)` returns the
  best label for the user. Pipeline:
  1. Split `formattedAddress` on commas; trim.
  2. Drop pure-digit postal-only pieces (SG's "238843", etc.).
  3. Drop country tail (Malaysia / Singapore / Indonesia / …).
  4. Pop a recognised STATE / federal-territory tail
     (Selangor / Wilayah Persekutuan / NSW / Victoria / …).
  5. Pop the CITY (postal-prefix-stripped + leading building-
     number-stripped).
  6. Pick the **first** piece:
     - `displayName` if it's not a pure building number
       (`/^[0-9]+[a-z]?$/i` or unit code).
     - Else the first remaining `formattedAddress` piece that
       matches a STREET keyword (`jl.`, `jalan`, `road`, `street`,
       `boulevard`, `soi`, `via`, `lorong`, etc.).
     - Else the last remaining piece (best-effort).
     - Else fall back to displayName or "Unnamed".
  7. Join `<First>, <City>, <State>` (skipping empty pieces),
     dedupe consecutive duplicates.

  Operator example test passes:
  ```
  displayName = "1"
  formatted   = "1, Jln Imbi, Imbi, 55100 Kuala Lumpur,
                 Wilayah Persekutuan Kuala Lumpur, Malaysia"
  → "Jln Imbi, Kuala Lumpur, Wilayah Persekutuan Kuala Lumpur"
  ```
