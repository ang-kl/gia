## New

### [HDR] #266 | 17:50:00 SGT 20-05-26 | v0.61.62 — HOTFIX: /healthz `pkg` → `pkgJson` | ~1 line | 2 files | 1 PR | 1 build |

- **[INTENT]** Restore the three Telegram Mini Apps (blank-screen outage).

- **[ROOT CAUSE]**
  - `GET /healthz` (`index.js:8495`) did `version: pkg.version`, but the
    `package.json` require is bound to **`pkgJson`** (`index.js:7`) — `pkg` is
    defined nowhere. Every `/healthz` hit threw `ReferenceError: pkg is not
    defined` → 500. Pre-existing since v0.59.30 (commit `53910df`, 2026-05-07) —
    the same commit that added both `/healthz` and the auto-fallback probe.
  - **The cascade:** `webhook-domain.js` probes `/healthz` every 60 s and counts
    the primary host (`soleat.net`) healthy *only* when the JSON carries
    `service: 'gia'`. A 500 → primary classified **unreachable** →
    `setActiveHost(FALLBACK)` → all TMA `web_app` button URLs switch from
    `soleat.net` to the fallback host (`soleat.up.railway.app`). The Mini Apps then
    open on the wrong domain and render blank.
  - Why it surfaced now and not since 2026-05-07: with **no** `WEBHOOK_FALLBACK_HOST`
    configured, `webhook-domain.js` keeps `activeHost = PRIMARY` even on a failed
    probe ("no fallback to switch to"). The fallback host became configured around
    the recent Railway redeploy, so the long-broken `/healthz` finally triggered
    the switch.

- **[DELTA]**
  - **`index.js`** — `/healthz` handler: `pkg.version` → **`pkgJson.version`** (the
    actual binding name). One-token fix.
  - **`package.json`** — `0.61.61` → `0.61.62` (PATCH — hotfix).

- **[VERIFICATION (sandbox)]**

  ```bash
  $ node --check index.js  → OK
  $ node -e 'require("./package.json")'  → healthz now returns version 0.61.62
  $ npm test  → 65 files / 1928 tests green
  ```

- **[STATUS]** DRAFT → PR (base `main`, branch `claude/review-gia4lunch-readme-3s798`).
  **Urgent:** merge → Railway redeploy → `/healthz` returns `{service:'gia',…}` →
  the webhook-domain probe re-classifies `soleat.net` as healthy on its next 60 s
