### [HDR] #244 | 19:30:00 SGT 19-05-26 | v0.61.40 — 🏥 Hospital overlay layer + one-shot fetcher | ~6 kb + data | 16 files | 1 PR | 1 build |

- **[INTENT]** Add a `🏥 Hospital` dropdown layer below `💊 Clinic / Pharmacy` on all
  three TMA maps, with a structured tap-popup, and a one-shot script that assembles the
  facility dataset from the curated name list + Google Places.

- **[DELTA]**
  - **`scripts/fetch-hospitals.js`** (new) — one-shot builder for `data/geo-hospitals.json`.
    Parses `data/Hospital_Sample.MD` for the canonical facility list (grouped into
    Acute / Psychiatric / Community hospitals, National specialty centres, Polyclinics)
    **and** the `# Example:` detail lines, which carry the curated extras Places cannot
    give — purpose-labelled appointment / urgent-care numbers, WhatsApp numbers,
    official website, operating-hours prose. Then one Google Places `searchText` call
    per facility supplies coordinates, formatted address, the main phone, a website
    fallback and `regularOpeningHours`. The two are merged per facility. Idempotent +
    resumable (`--dry` flag); needs `GOOGLE_MAPS_API_KEY`.
  - **`data/geo-hospitals.json`** (new) — 67 facilities (19 acute, 1 psychiatric, 10
    community, 9 national specialty, 28 polyclinics); 26 carry curated detail, 4 carry
    a WhatsApp number. Built by the operator-supplied funded key in this session.
  - **`index.js`** — `loadGeoOverlays()` reads `geo-hospitals.json` and serves it on
    `/api/geo/overlays` as `hospitals`.
  - **`mapOverlays.js`** (byte-identical ×3) — new `hospitalInfo()` popup builder
    (category line / `🏥 name` / `☎` purpose-labelled phones / `💬 WhatsApp` /
    `🌐` website / `📍` address / `🕒` hours — prefers the curated `hoursNote`, falls
    back to today's Places `hours` line / `Google Map ↗` via `infoCard`); `ensureLayer`
    `hospitals` branch builds teal `#00897B` 🏥 markers; `fetchOverlays` empty-default
    extended.
  - **`App.jsx`** (×3) — `overlayLayers` state gains `hospitals: false`.
  - **`i18n.js`** (×3) — `layer.hospitals` = `Hospital` / `Hôpital`.
  - **`MrtMapPanel.jsx` / `HawkerMapPanel.jsx` / `MapPanel.jsx`** — `applyOverlayLayers`
    pushes `hospitals`; `menuToggles` gains `{ key: 'hospitals', icon: '🏥' }` directly
    below `clinics`.
  - **`package.json`** — `0.61.39` → `0.61.40` (PATCH).
