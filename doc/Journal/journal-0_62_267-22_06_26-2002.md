- **[INTENT]** Operator polish on the Menu hub + Cuisine TMA: (1) the two food-icon line-art drawings read "faded" (thin pale-grey strokes) and small — make them navy + ~15% bigger; (2) the result-card eatery title looked oversized vs the rest of the card; (3) the location header's "tap to change" hint sat on its own second line — move it up beside the resting location. Titles (#asked) were already at the hero size and the button relabels were already live, so those two are no-ops this PR.

- **[MECHANISM]** The Menu tiles render a PNG via `Tile.jsx` `imgClass` inside a fixed `w-16 h-…` box. The v3 icons are anti-aliased grey line-art on transparency, so a CSS `filter: brightness(0)` collapses every stroke to a solid silhouette (higher-contrast = "brighter"), and the `invert→sepia→saturate→hue-rotate` chain re-tints that black to a deep navy (~#1e3a8a). Applied via a new `.icon-navy` class appended to the two food tiles' `iconImgClass` only — the landscape Train logo is untouched. Size +15% = `max-h-14`(56px)→`max-h-16`(64px) on the two icons + the shared box `h-14`→`h-16` so they fit. The Cuisine card title drops `text-sm`(14)→`text-[12px]` to match the card body (12–13px), weight kept for hierarchy. The SG/JB `LocationField` moves the `tap to change` hint inline after `{resting}` (shown only when a location is set), and the lower line now carries just the `{suffix}` places-nearby count.
