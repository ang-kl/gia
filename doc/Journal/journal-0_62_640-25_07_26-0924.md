## New

### [HDR] v0.62.640 — restore the card-level collapse, bring the carousel card down to Hawker height, clear the footer, finish the all-TMA header pass

- **[INTENT]** Operator (iPad mini; `IMG_1203` Menu hub v0.62.638 + `IMG_1204` Train v0.62.639): *"see the
  footer that covers the text. Why you don't follow the height in hawker and where is the collapse
  capability."*

- **[ROOT CAUSE — my own regression, two changes that backfired together]** v0.62.638 made the carousel render
  **full** cards (`collapsible=false`) to give them content weight; v0.62.639 then **squeezed** the width to
  22 %. Combined: a *narrow* **full** card re-flowed every meta item onto its **own line** (status / open /
  crowd / walk / hours / Around / line sub-card / action row), so cards grew to ~60 % of screen height, the
  bottom action row was clipped by `max-h` + the fixed footer dock (*"footer covers the text"*), and because
  `collapsible=false` there was **no card-level ▾ at all** (*"where is the collapse capability"*).

- **[DELTA]**
  1. **Collapse restored** — `web/transport/src/App.jsx`: the carousel renders
     `renderStationCard(…, compact=true, collapsible=TRUE)`, so the **▾ triangle is back** and a card opens
     **collapsed** (Hawker-like height).
  2. **Collapsed body = Hawker-height** — `StationCard.jsx`: the always-visible summary (which *is* the
     collapsed card's whole body) went from one row to **two tight `truncate` rows** — row 1 health dot +
     status + **Open now/Closed** + crowd glyph; row 2 **🕑 first–last** + **🚶 walk**. Every row is
     `truncate` + `min-w-0`, so a narrow card can **never** grow tall by wrapping (the v0.62.639 regression).
     `text-[10px] leading-tight`, `px-2 py-1`.
  3. **Footer clearance** — the carousel wrapper's fixed `bottom-14` replaced with
     `bottom: calc(3.25rem + env(safe-area-inset-bottom, 0px))`, so the dock can never overlap the card's last
     row on a device with a bottom inset; card `max-h` 46vh → **42vh**.
  4. **All-TMA header pass completed** — `IMG_1203` showed the Menu hub's first tile **under** Telegram's Back
     button. v0.62.638 wired the safe-area **var** app-wide, but the **Menu** and **Oversight** roots never
     **consumed** it: `web/menu/src/App.jsx` root gains
     `paddingTop: var(--tg-content-safe-area-inset-top, …)`; `web/oversight/src/App.jsx` **both** roots gain
     `calc(pad + var(…))`. (Cuisine already had it for `isWide`; Transport/Hawker use fixed shells that read
     it.)
