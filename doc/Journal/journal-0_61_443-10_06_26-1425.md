- **[CONTEXT — gate audit P4]** The /api/cuisine/search slug path ran **four overlapping inline
  geographic filters** back to back (the D1 duplication from the v0.61.441 Phase-0 audit): a 120 km
  hard gate, the JB-hybrid filter (+ its JB→OTHER graceful fallback), the OTHER country-keyword
  filter (+ its stale-pref floor), and the SG mention/proximity filter. Each was added for a
  separate incident; a venue had to survive all of them, and the `if/else` nesting made the
  interactions hard to read.

- **[DELTA]**
  - **`cuisine-geo-scope.js`** (new, IO-injected like `cuisine-special-mode-widen.js`) —
    `scopeVenuesByRegion({ venues, isJB, isOther, lat, lng, resolveCtxCountry, countryTextMatch,
    locationMode, demoteNeverEmpty })` → `{ venues, jbFallbackToOther, ctxCountry }`. Same
    thresholds (120 km / JB 60 km / SG 30 km), regexes (`\bjohor\b`, `singapore`), centroids, and
    logs (D703b/c/d) as the inline code; the OTHER stale-pref floor now routes through the shared
    `pool-floor.js demoteNeverEmpty`.
  - **`index.js`** — replaced the ~130-line inline block (old `15403–15537`) with one `await
    scopeVenuesByRegion(...)` call; `getUserCountryPref` is injected as `resolveCtxCountry`;
    `jbFilterFellBackToOther` is read off the result and still rides the payload (TMA amber banner).
    The `distanceM` haversine compute stays in index.js (used widely downstream).
  - **`__tests__/cuisine-geo-scope.test.js`** (new) — pins each branch: 120 km gate; SG
    text/proximity; JB hybrid; JB→OTHER fallback (restore + default ctxCountry=MY); OTHER country
    filter + stale-pref floor; SG-pref skip; defensive (null venues, thrown country-pref read).
  - **`package.json`** `0.61.442 → 0.61.443`; **`doc/.serial-state.yml`** commit 655 → 656,
    journal 641 → 642; re-anchored 14:25 SGT.

- **[BEHAVIOUR — zero change, by operator decision]** The audit found an accidental double-filter:
  in the inline code the SG rule is the trailing `else` of the OTHER `if`, so a JB-region search
  that did **not** fall back ran the JB filter **and then** the SG ≤30 km filter — silently dropping
  far-Johor venues (Pontian / Kulai / Mersing) >30 km from the SG centroid. A first cut of P4 fixed
  this (one rule per region, `else if (!isJB)`); the operator chose **"revert the JB delta, then
  merge"** so P4 ships as a **pure, zero-behaviour-change refactor** (`else`, preserving the JB+SG
  double-filter exactly as before). Collapsing that double-filter is **deferred to its own
  operator-smoked PR** (noted in the module + Register).
