  - **Country pick "saves first"** — mirrored the Cuisine TMA's `userChangedCountryRef` flow. An explicit
    country-dropdown pick now commits the new country's capital/centroid as the anchor (SG → new `SG_CENTROID`
    `1.3521,103.8198` since SG has no `cities.js` catalogue and uses the SG-mode free-text form whose
    autocomplete biases off `currentAnchor`; all other countries → `cities.js[0]` capital). The ref is set at

    (precinct sync) also calls that helper and a precinct pick must keep its own committed location.

    otherwise trigger (the v0.61.256 effect collapses on any `currentAnchor` coord change), so the user stays
    expanded to type the street.

    (mirror of Cuisine's v0.61.418) so a stale cross-country pin no longer snaps the city dropdown to a wrong
    nearest city.

    `text-sm → text-xs` (mirror v0.61.364), and wrapped country + city in a `gap-0` group so they butt
