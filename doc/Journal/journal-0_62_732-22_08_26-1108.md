# Journal — soleat / Gia4lunch v0.62.732

## New

### [HDR] The meaning pass: 402 corrections a structurally perfect file could not reveal

- **[INTENT]** Operator, verbatim: *"do a meaning pass on the six languages"*. Following
  v0.62.730, which shipped 1,509 machine translations across id/ru/de/zh/ja/es, and
  v0.62.731, where four of Codex's eight findings were semantic and every one of them had
  passed the structural gate cleanly.

- **[STATE BEFORE]** `i18n.js` carried 1,509 machine-translated variants that were
  *structurally* clean by the only check that existed. No one had read them. The operator
  does not read these six languages; nor did anything in the pipeline.

- **[WHAT WAS DONE]** Every one of the 1,509 shipped strings was read against its English
  source, in six passes of roughly 235 strings each. No API, no model call, no cost — the
  reading was done directly. Three kinds of defect came out, and they needed three
  different instruments.

- **[1 — THE FAMILIES THAT MUST NOT BE TRANSLATED AT ALL: 96 variants pruned]**

  `bot.lang.set.*` confirms a language switch **in the language you just switched to**;
  its `en` field already holds German for `bot.lang.set.de`. `language.btn.*` lists
  **endonyms** — 🇫🇷 Français, 🇨🇳 中文, 🇯🇵 日本語 — precisely so a reader who cannot read the
  current UI language can still find their own. Translating either family destroys the
  thing it exists to do, and **every single one of the 96 variants was wrong**:

  | Key | Language | What shipped | What it says |
  | :--- | :--- | :--- | :--- |
  | `bot.lang.set.id` | ru | Доставка в Индонезию (без мини-приложения) | *Delivery to Indonesia (without the Mini App)* |
  | `bot.lang.set.de` | ja | …を読み上げます | *…will be read aloud* |
  | `bot.lang.set.fr` | ru | Правовой язык по-французски | *The legal language in French* |
  | `bot.lang.set.zh` | ja | 説明文は中国語（小プログラム用）として設定されています | *The description text is set as Chinese* |
  | `language.btn.zh` | id | **CNY** 中文 | the 🇨🇳 flag was translated as a currency code |
  | `language.btn.ja` | id | 🇯ppa 日本語 | the flag's regional-indicator pair was corrupted |

  The fix is removal, not correction: `t()` already falls back to `entry.en` per key, and
  `entry.en` is the correct reader-facing value. `scripts/normalize-i18n-translations.mjs`
  prunes them; `__tests__/i18n-shipped-quality.test.js` fails if any comes back.

- **[2 — SLOT-PADDING ARTEFACTS: 377 lines repaired mechanically]** The slot-substitution
  translator wrapped every protected run in spaces and never took them back out:
  `* {n} *` (Telegram renders literal asterisks, not bold), `<i> {street} </i>`,
  `/buddy block<chat_id> ` (the delimiter moved off the command onto the far side of the
  argument), `{i} . {name}`, and 44 keys that lost a **leading space** they needed because
  they are fragments concatenated onto a preceding run.

  Every repair is derived from the English source for the same key — nothing is invented.
  The rule is **context-gated in both directions**: a space is collapsed only when the
  target's neighbouring non-space character is the one the source has flush against the
  token, and restored only when the character now touching the token is the one on the far
  side of the source's space. Ungated, the first draft turned a correct Indonesian
  `{target} diblokir` into `{target}diblokir` (English word order is `Blocked {target}.`)
  and a correct `<b>{n} tempat` into `<b> {n} tempat`. Both were caught by reading the
  dry-run diff, which is the only reason this entry can say the rule is gated.

  Chinese and Japanese additionally never set a space either side of full-width
  punctuation. Carrying the English spacing across gave `状态： {status}` in 72 places.

- **[3 — THE MEANING ERRORS: 402 hand-written corrections]** de 49 · id 49 · ru 82 · zh 70 ·
  ja 83 · es 69. Each is recorded in `scripts/i18n-meaning-fixes.json` with the string it
  replaced and a one-line reason. A representative sample, all of them structurally
  perfect and all of them wrong:

  | Key | Lang | Shipped | Means | Should be |
  | :--- | :--- | :--- | :--- | :--- |
  | `incident.type.MassDisruption` | de | Massenzerstörung | **mass destruction** | Großflächige Störung |
  | `incident.type.MassDisruption` | zh | 大规模破坏 | **large-scale destruction** | 大面积中断 |
  | `transport.bus.load.limited` | es | Reputación limitada | **limited reputation** | Plazas de pie limitadas |
  | `transport.bus.load.limited` | de | Beschränkte Berechtigung | **limited authorisation** | Begrenzte Stehplätze |
  | `transport.bus.load.limited` | ja | 限定的な立ち入り | **limited entry** | 立席わずか |
  | `forgetme.followup` | ja | 最近撮影した写真 | **recently taken photos** | 最近のおすすめ |
  | `transport.drive.unreachable` | de/ru/es/zh | Laufwerksansicht / отображение диска / vista de la unidad / 驱动器视图 | **disk-drive view**, in four languages | the driving view |
  | `transport.bus.noStopsCrowd` | ja | 試飲できるバス停 | bus stops where you can **taste-test** | サンプリングできる |
  | `wake.newBtn` | ja | 新店舗 | **a new store branch** | 新しい場所 |
  | `buddy.status.on` | ru/ja/es/zh/id | НА · の上 · EN · 在 · PADA | the **prepositions** "onto", "on top of", "in", "at", "at" | ВКЛ · ON · ACTIVADO · 开启 · AKTIF |
  | `buddy.on.body` | zh/ja | 飞行员 · パイロット | **airplane pilot**, for "Pilot" meaning a trial | 试运行功能 · 試験運用 |
  | `cuisine.chat.shareForAccurate` | zh | 选座结果 | **seat-selection** results | 准确的推荐 |
  | `incident.type.Diversion` | ja/ru/zh | 気晴らし · Отвлечение · 导流 | **amusement · distraction · fluid flow** | 迂回 · Объезд · 改道 |

  Four categories recur across all six languages, which is what makes them a *class* and
  not a list of one-offs:

  - **False friends on transport vocabulary.** "Lines" became text rows in four languages
    (Zeilen / Строки / 行数 / Baris) while the sibling key three lines down had it right.
    "Standing" became authorisation, reputation, entry rights and eligibility. "Drive"
    became a disk drive in four. "min" became *minimum* in three (`最小ピーク値`,
    "min peak") — and Japanese read "Frequency" as **周波数**, radio frequency.
  - **Buttons rendered as statements.** `hawker.openTmaBtn` — "Open Hawker Centre" — came
    back as *an open hawker centre* in five languages (Offenes, Pusat Kuliner Buka,
    开放式, オープン, abierto). Same for `cuisine.chat.openBtn`.
  - **Meaning reversals and outright breakage.** German `transport.train.network.low` said
    0 platforms *show* low density where the source says 0 are *above* it. Japanese
    `place.outsideHeader` said **周辺** (around) where the source says **outside** — the
    one word that distinguishes it from its sibling key. Spanish `place.outsideHeader`
    lost its opening bracket and stranded `{n}` mid-sentence. Chinese
    `transport.train.network.high` dropped both the words "high" and "moderate", leaving
    bare numbers. German `loc.desktopNudge` moved the placeholder behind the full stop and
    appended a stray "Die".
  - **One feature, three or four names.** The Cuisine Picker was 美食精选 / 美食选择器 /
    菜系选择器 in Chinese, 料理選び / 料理選択ツール / "Cuisine Picker" in Japanese,
    Выбор кухни / выбор блюд / меню выбора блюд / "Cuisine Picker" in Russian. Harmonised.

- **[THE GATE WAS POINTED AT THE WRONG FILE — D-205]** `validate-i18n-translations.mjs`
  reads `scripts/i18n-audit-jobs/` — the translator's **output**, before anything was
  pruned, repaired or corrected. It could never see the file the bot loads. That is how
  1,509 shipped strings sat behind a green check. Added
  `scripts/validate-i18n-live.mjs`, which walks `i18n.js` itself and compares every
  non-English variant against its own `en`. It found 8 failures the job-file gate could
  not see, and it now reports **1,686 of 1,687 safe** (the one remaining is a pre-existing
  `fr` `start.intro` count difference on a literal `>` the French renders as "plus de").

- **[TWO GATE RULES NARROWED, AND WHY THAT IS NOT LOOSENING]** `cmd-spacing` counted only
  whitespace as a closing boundary, so correct Russian `просто /weather, чтобы` failed;
  `cmd-delimited` treated any non-ASCII character as glue, so correct Chinese
  `请尝试 /hidden，` failed. Both now accept sentence punctuation, ASCII and full-width, as
  a boundary. Telegram ends a `bot_command` entity at the first character outside
  `[A-Za-z0-9_]`, so those commands stay tappable. **The cases each check was written for
  still fail** — verified directly: `/l<place>` still trips `cmd-spacing`, `/cuisineで`
  still trips both. A rule that rejects correct target-language punctuation is not strict,
  it is wrong about its subject.

- **[A GATE THAT CANNOT FAIL IS NOT A GATE — the D-204 lesson, applied]**
  `__tests__/i18n-shipped-quality.test.js` was checked by breaking the file on purpose:
  reverting `incident.type.MassDisruption` to *Massenzerstörung* and `carpark.row` to
  `{lots} lots` fails two of its six assertions by name, and restoring the file turns them
  green again. It also caught a bug in itself on first run — `\blots\b` matched the
  **placeholder name** `{lots}` and failed every correct translation, so the check now
  strips placeholders before looking at prose.

- **[VERIFICATION (sandbox)]**
  - `node --check i18n.js` — clean, after every one of the four write passes.
  - `node scripts/validate-i18n-live.mjs` — 1,687 shipped variants, 1,686 structurally
    safe, 1 failing (pre-existing `fr`).
  - `npx vitest run` — **174 files / 4,214 tests, all passing** (173/4,208 before, plus
    this entry's six).
  - Negative control on the new test: 2 of 6 assertions fail on a deliberate regression,
    all 6 pass on restore.
  - The fix applier is **fail-closed**: each entry carries the string it replaced and the
    run aborts without writing if any does not match byte for byte. Re-running it is a
    no-op (402/402, file unchanged).

- **[STATUS]** DRAFT → PR. Deploys to Railway on merge to `main`, as every i18n change does.

- **[TEST]** `__tests__/i18n-shipped-quality.test.js` — six assertions over the shipped

  unpruned-of-`en`-only, no slot-padding artefacts survive, no English `lots` / `min ago`

- **[KNOWN GAPS]**
  - **Register is inconsistent and only partly fixed.** German mixes du and Sie *within
    single messages*; Spanish mixes tú and usted. The worst instances were harmonised —
    every one where the two forms collide inside one string, and every button phrased as a
    command at the user rather than as the user's own choice — but a whole-file sweep is a
    style decision for the operator, not a defect to be quietly settled here.
  - **Example search terms remain translated in zh/ja.** `freetext.questionDeclined` was
    restored to Latin dish names in both, because the user is meant to type them back. But
    `cuisine.chat.webhookOnly` still says 「ラーメンを探して」 and "找拉面". Whether the free-text
    matcher resolves those has not been tested and is not asserted anywhere.
  - **This pass is one reader's judgement.** It found what a careful reading finds. It is
    not a native review, and it is not claimed as one.
  - **`scripts/i18n-audit-jobs/` is now stale** relative to `i18n.js` — 30 of its 1,590
    items still fail the job-file gate, and those job files no longer describe what ships.
  - Still due from earlier arcs: `i18n-audit.js`, `scripts/audit-i18n-translations.mjs`
    and `__tests__/i18n-audit.test.js` are orphaned by the O-197 route deletion and were
    left in place pending the operator's word (G2 — destructive).
