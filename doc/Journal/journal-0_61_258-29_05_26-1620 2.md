  **1. `scripts/durian-variance.js`** — three additions:

  - Two new CLI flags:
    - `--json` — also dump the structured report to stdout after
      the human-readable logs.
    - `--json-out=PATH` — write the same report to disk; parent
      directories are created with `mkdir -p` semantics.
  - `REGIONS` gains a 4th entry — **Kuala Lumpur** `(3.1390, 101.6869)`
    so the run covers all four cities the operator's <20% accuracy
    complaint named (was just SG / JB / Putrajaya). Cost rises

    ~$0.40-0.55 USD per mode.
  - Per-query record schema:
    ```json
    {
      "lang": "en",
      "query": "durian puff",
      "placesReturned": 8,
      "keptCount": 3,
      "rejectedCount": 5,
      "precision": 0.375,
      "kept":     [{"name": "Emicakes", "primaryType": "cake_shop", "formattedAddress": "..."}, ...],
      "rejected": [{"name": "Bob Cafe", "primaryType": "food",      "formattedAddress": "..."}, ...]
    }
    ```
  - Per-region totals + `primaryTypeFrequency` map.
  - Cross-region rollup printed at the end:
    ```
    Singapore      kept=23/96   precision=0.240
    Johor Bahru    kept=18/96   precision=0.188
    Kuala Lumpur   kept=21/96   precision=0.219
    Putrajaya     kept=11/96   precision=0.115
    ALL            kept=73/384  precision=0.190
    ```
    (illustrative — actual numbers land when the operator runs it).
  - Final report shape:
    ```json
    {
      "schemaVersion": 1,
      "scriptVersion": "0.61.258",
      "mode": "durian-pastry",
      "ranAtIso": "2026-05-29T16:20:00.000Z",
      "apiKey": { "hashSha256First16": "<16-hex>" },
      "regions": [{ ... }, ...],
      "seeds": { ... },
      "config": { "LIMIT_PER_QUERY": 8, "RADIUS_M": 8000 },
      "totals": { "placesReturned": ..., "kept": ..., "rejected": ..., "precision": ... }
    }
    ```
    Note: only the SHA-256 hash prefix of the API key is recorded
    (for run identification); the raw key is never written.

- **[KNOWN GAPS]**
  - Adding Kuala Lumpur lifts the per-mode cost from ~32 calls /
    $0.11 to ~120-160 / $0.40-0.55. If the operator prefers a
    cheaper run, drop `LIMIT_PER_QUERY` from 8 to 5 OR trim

    identification. Hash collisions are not a meaningful
    concern; the truncation to 16 hex chars (64 bits) is
    deliberately lossy so the recorded value can't be brute-
    forced back to the key.
