# Journal — soleat v0.61.208 (custom country dropdown: closed = flag+CC, open = flag+Name)

> Operator: *"Cuisine TMA, the dropdown should spell out the country
> name but after selection is back to `<flag>` + `<two characters>`.
> … same as the Menu TMA."* Native `<select>` renders the selected
> option's text identically whether closed or open, so the existing
> `{c.flag} {c.code}` options always showed "🇲🇾 MY" — even when the
> dropdown was open. Replaced with a custom button + popover in
> both TMAs.
>
> Commit 421 / journal 409 / build 211, on branch
> `claude/v0.61.208-country-dropdown-ux` off `main` at v0.61.207.

## New

### [HDR] #409 | 16:30 SGT 28-05-28 | v0.61.208 — custom country dropdown | 4 files | 1 PR | 1 build |

- **[INTENT]** Asymmetric closed-vs-open dropdown display:
  - **Closed button**: `🇲🇾 MY ▾` (compact, fits the existing 4.5 rem
    slot beside the search input).
  - **Open list**: each row shows `🇲🇾 Malaysia` (descriptive).
  - Click-outside / Escape closes; selected row highlighted.

- **[DELTA]**

  **`web/cuisine/src/v2/components/LocationField.jsx`**:
  - Imports: added `useRef`.
  - **NEW `<CountryDropdown>` component** (~55 lines, defined
    just above `OtherLocationPicker`):
    - State: `open` (bool).
    - useEffect: while open, registers `mousedown` (click-outside)
      and `keydown` (Esc) handlers on `document`. Cleanup on
      close.
    - Render:
      - `<button>` with `aria-haspopup="listbox"`, `aria-expanded`.
        Shows flag + CC + a "▾" hint.
      - When `open`, an absolutely-positioned `<ul role="listbox">`
        with `OTHER_COUNTRIES.map(c => …)`. Each `<li>` is a
        button with `flag + name` and selected styling
        (`bg-tg-bg/60 font-semibold` when `c.code === value`).
        `z-30`, `max-h-72 overflow-y-auto`, shadow.
  - The previous inline `<select>{…}</select>` is replaced by
    `<CountryDropdown value={country.code} onChange={…}
    ariaLabel={tr('loc.other.country', lang)} />`.

  **`web/menu/src/components/LocationFieldMenu.jsx`**:
  - Imports: added `useRef`.
  - **NEW `<CountryDropdownMenu>`** — near-duplicate of
    `CountryDropdown` but styled to match the Menu TMA's chrome
    (`text-[13px]`, `bg-tg-bg border border-tg-border rounded
    px-1 py-1.5`).
  - The OTHER-region `<form onSubmit={onOtherSearch}>`'s inline
    `<select>` is replaced by `<CountryDropdownMenu …>`.

  Both implementations share the same data (`OTHER_COUNTRIES`,
  `findCountry`, `DEFAULT_OTHER_COUNTRY` from each TMA's
  countries.js) and the same pick semantics. They are not yet
  extracted to a shared package — Cuisine + Menu TMAs ship as
  independent Vite builds with their own `node_modules`. Future
  shared package extraction is possible but out of scope here.

  - **`package.json`** — `0.61.207 → 0.61.208`.
  - **`doc/.serial-state.yml`** — commit 420 → 421, build 210 →
    211, journal 408 → 409; re-anchored 28-05 '26 16:30 SGT.
