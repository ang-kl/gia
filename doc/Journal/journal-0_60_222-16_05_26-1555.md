Plus a separate operator item: drop the Menu TMA footer's brand line.

- **[DELTA]**
  - **`venue-templates.js` — `formatOrderLine`:**
    - Glyph `🧾 {dishes}` → `🍽️ Try · {dishes}` (FR `🍽️ Essayez · …`). The function now takes `lang`; the `formatVenueBlock` caller passes it.
    - Venue-name guard: after the `filterDishNames` pass, any dish entry that contains — or is contained by — the venue's own name (case-insensitive) is dropped. Kills "Restaurant Fiz and what" and the bare "Restaurant Fiz" leak.
  - **`dish-name.js` — `TRAILING_STOPWORD_RE`** extended with the interrogatives `what / whats / why / how / who / whom / whose`. A captured fragment ending in one of these ("…and what") is no longer accepted as a dish name — closes the other half of the "Restaurant Fiz and what" leak at the shared guard.
  - **`web/menu/src/App.jsx`** — the footer's `Soleat <v> · 2026` brand line removed; the footer is now just the `experimental · v<build>` tag line.
  - **Tests** — `__tests__/venue-templates.test.js` updated (`🧾` → `🍽️ Try ·`, three assertions); `__tests__/dish-name.test.js` — two new fragment assertions (`Restaurant Fiz and what`, `the noodles how`).
