# Journal — v0.62.692 (URGENT: Hawker TMA white-screened on every load)

_(№ 1,032 — 01-08 '26 16:45 SGT)_

## New

### [HDR] v0.62.692 — `isShort` was used but never declared; every centre card threw

- **[INTENT]** Operator: *"urgent fix: Hawker TMA is crashed"*.

- **[SYMPTOM]** The Hawker TMA rendered its header, footer and map chrome, then went **blank the
  moment centre data arrived**. Not a slow load, not an empty state — a React render throw that
  unmounts the whole tree.

- **[ROOT CAUSE]** `web/hawker/src/App.jsx:502`:

  ```js
  const renderCentreCard = (c, i, glass = false, compact = false) => {   // ← no isShort
  ```

  The function **body** reads `isShort` in two places — the D-51 height tier at `:541`
  (`${isShort ? 'h-[5.5rem]' : 'h-[8rem]'}`) and the stalls/status row gate at `:550`
  (`{!isShort && …}`) — both added in **v0.62.686**. `CentreCarousel` duly passes it as the 5th
  argument (`:241`), but the parameter was never added to the signature, so inside the function
  `isShort` is an **undeclared identifier**. Reading one is a `ReferenceError`, not `undefined`.

  Every card threw, `Array.map` propagated it, and React tore down the tree — `document.getElementById('root').innerHTML.length === 0`.

- **[WHY IT SURVIVED EVERY GATE]** This is the uncomfortable part and worth stating plainly:
  - **The build passes.** Vite/esbuild transpiles JSX; it does not do scope analysis for undeclared
    identifiers. `✓ built` is not a claim that the code can run.
  - **`node --check` passes** — the syntax is perfectly valid.
  - **All 3,901 tests pass** — none of them render a React component (O-93, the standing gap).
  - **CI is green** on all four checks.
  - **Compiled-CSS greps passed** — `.h-[5.5rem]` and `.h-[8rem]` were both emitted, because Tailwind
    scans the *source text*, which contains the class strings regardless of whether the identifier
    guarding them resolves.
  Every verification this project runs is satisfied by code that cannot render a single card.
  - **It did not white-screen instantly**, which delayed detection: the crash needs centre data. On a
    slow network, or in a sandbox where `/api/hawker/centres-by-region` 404s, the app renders its
    shell and looks healthy. My own first reproduction attempt showed exactly that and nearly
    exonerated the build.

- **[HOW IT WAS ACTUALLY FOUND]** Static review had exhausted itself (build clean, route placement
  verified by brace depth, new modules confirmed tracked and loadable) without finding anything. The
  crash only surfaced by **running the built bundle in headless Chromium with the centres API
  mocked** — `pageerror` gave `ReferenceError: isShort is not defined` with a stack straight into the
  card `.map()`. Two harness mistakes had to be corrected first: serving under the app's `/app/`
  base path, and Playwright's route precedence (**last** registered wins, so an early catch-all
  `**/api/**` silently shadowed the specific centres mock and produced a *second* false all-clear).

- **[DELTA]** One parameter: `renderCentreCard = (c, i, glass = false, compact = false, isShort = false)`.
  Defaulted to `false` so the two-panel list call site — which passes only four arguments — keeps its
  existing behaviour exactly.

- **[SWEEP — is there another one?]** Ran `eslint --rule '{"no-undef":"error"}'` across
  `web/hawker/src`, `web/transport/src`, `web/cuisine/src` and `web/_shared`. The only remaining
  `no-undef` hits are **`__BUILD_VERSION__`** in three files — a Vite `define`, injected at build
  time, so a genuine false positive for an ad-hoc lint with no Vite globals configured. **No other
  undeclared identifier exists in any of the four app trees.** `isShort` was the only one.

- **[VERIFICATION (sandbox)]** Reproduced and fixed in a real browser, not by inspection:

  | | before fix | after fix |
  |---|---|---|
  | `#root` innerHTML | **0 chars** | **10,469 chars** |
  | centre cards render | **no** | **yes** |
  | uncaught page errors | `ReferenceError: isShort is not defined` | none |

  Cards render with name, 📇 address, 🍳 stall count, status and the ▸ toggle; region pills present.
  Hawker build green; full `npm test -- --run` **156 files / 3901 tests** green; version string
  rebuilt into the bundle (`0.62.692`).

- **[STATUS]** DRAFT — branch `claude/handover-july-11-49uzvf`, PR #1689. Deploys to prod on merge
  via Railway's main-branch build. `public/` is gitignored and rebuilt by `postinstall`, so the
  one-line source change is the whole fix.

- **[KNOWN GAPS]**
  - The reproduction used **mocked** centre data. The shape was modelled on the server route's own
    payload, but it is not the live dataset.
  - **The regression window is not established.** `isShort` entered `renderCentreCard`'s body in
    v0.62.686 (merged in PR #1682), so the crash has plausibly been live since then — through
    v0.62.689, .690 and .691 — and was reported only now. Nothing in this arc introduced it; the
    v0.62.689 Hawker work sat next to it without touching the signature.
  - No regression test guards this. A single smoke test that mounts each TMA with a fixture payload
    would have caught it, and would catch the next one; that is O-93 with a concrete, cheap shape.

- **[TIME ANCHOR]** Sovereign fetch, `api.data.gov.sg/v1/environment/air-temperature`:
  `items[0].timestamp = 2026-08-01T16:45:00+08:00` = **01-08 '26 16:45 SGT** (TF-6/TF-9).
