- **[DELTA]**

  **1. `web/menu/src/components/LocationFieldMenu.jsx`** — added
     `expanded` state (default `false` when `currentAnchor` is set,
     `true` otherwise). Inserted a compact-pill early return ahead
     of the existing expanded JSX:

     ```jsx
     if (currentAnchor && !expanded) {
       // flag derivation:
       //   region === 'SG'    → 🇸🇬 emoji
       //   region === 'JB'    → MY_Johor_flag.png img
       //   else (OTHER / MY-PUT)
       //                       → country.flag from findCountry(countryPref)
       return (
         <div className="rounded-md border border-tg-border bg-tg-card p-2 flex flex-col gap-1.5">
           <div className="text-[12px] font-semibold text-tg-text">{fieldLabel}</div>
           <div className="rounded-md border border-tg-accent bg-tg-card px-3 py-1.5">
             <div className="flex items-center gap-2">
               <span className="text-tg-accent">📍</span>
               <button onClick={() => setExpanded(true)}
                       className="flex-1 min-w-0 text-left text-sm inline-flex items-center gap-1.5">
                 {flagEl}
                 <span className="truncate">{composedLabel || currentAnchor.label}</span>
               </button>
               <span className="text-tg-hint text-xs flex-shrink-0">✏️</span>
             </div>
             <div className="text-[10px] text-tg-hint italic text-right leading-tight mt-0.5">
               {capStr ? `${capStr.replace(/^\s*·\s*/, '').trim()} · ` : ''}{tapStr} 🔝
             </div>
           </div>
           {disabledListLine && (
             <div className="text-[11px] text-tg-hint leading-snug">{disabledListLine}</div>
           )}
         </div>
       );
     }
     ```

     The compact pill mirrors v0.61.253 Cuisine TMA: row 1 with
     📍 + flag + label + ✏️, row 2 with right-flush meta + 🔝
     under ✏️.

  **2. Pick handlers** — `onCityPick`, `onPickerChange`,
     `pickOtherResult`, `pickSuggestion`, `onTextSubmit` all gain
     `setExpanded(false)` on successful set-location, so the
     operator always lands back on the compact pill after picking
     anything.

  **3. Expanded form** — added a small "↩︎ Collapse" link below
     the summary so the operator can dismiss the expanded form
     without committing a pick.

  **4. `package.json`** — `0.61.253 → 0.61.254`.

  **5. `doc/.serial-state.yml`** — commit 466→467, build 256→257,
