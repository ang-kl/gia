## New

### [HDR] #207 | 15:08:00 SGT 17-05-26 | v0.63.1 — custom map-control stack + Transport Overview reposition | 7 files | PR 1 of 4 | 1 build |

- **[INTENT]** Replace Google's native bottom-right zoom control with a small, discrete,
  theme-adaptive control stack in the top-right of every TMA map, and move the Transport TMA's
  "Overview" (reset-focus) button out of the banner into a floating bottom-right button.

- **[DELTA]**
  - **`web/cuisine/src/v2/components/MapPanel.jsx`**, **`web/hawker/src/components/HawkerMapPanel.jsx`**,
    **`web/transport/src/components/MrtMapPanel.jsx`** — the Google Map constructor now sets
    `zoomControl: false` (native control off). A custom top-right vertical control stack
    (`＋` / `－` zoom + the `⤢`/`⤡` expand toggle) is rendered as absolutely-positioned buttons
    over the map container. Buttons use `bg-tg-card/70` + `text-tg-text` Tailwind tokens — these
    flip with the Telegram light/dark theme, so the body is semi-transparent and the glyphs stay
    prominent (dark-on-light / white-on-dark) in either mode. Zoom buttons call
    `map.setZoom(map.getZoom() ± 1)`. The expand toggle (added v0.63.0) folds into this stack.
  - **`MrtMapPanel.jsx`** — the "Overview" button moved out of the focused-line banner into a
    small floating button at the map's bottom-right (shown only when a line is focused); the
    banner now carries just the "Showing <code> · N stations" text.
  - i18n: `map.zoomIn` / `map.zoomOut` (EN/FR) added to all three TMA i18n tables.
  - **`package.json`** — `0.63.0 → 0.63.1` (PATCH — map-control UI reposition).
