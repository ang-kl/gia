> 1. **`__tests__/jb-focus-points.test.js:15` — frozen-array sort.**
>    The v0.61.277 test wrote `expect(JB_FOCUS_KEYS.sort()).toEqual([...])`. `JB_FOCUS_KEYS` is `Object.freeze(Object.keys(JB_FOCUS_POINTS))`, so `.sort()` mutated a frozen array and threw `TypeError: Cannot assign to read only property '0'`. CI for PR #783 caught it; merged through anyway per operator pattern. Fix: spread before sort — `[...JB_FOCUS_KEYS].sort()`.
>
> 2. **`smart-place-label.js` restoration on origin/main.**
>    The blob on origin/main is the well-known empty-blob hash `e69de29bb2d1d6434b8b29ae775ad8c2e48c5391`. Locally the file is 164 lines and intact, but at some point it was committed with zero bytes (iCloud-stale-checkout: when Git read the file during a prior commit it returned 0 bytes; the working tree retained content but the blob was empty). PRs #781, #782, #783 all failed vitest on `smart-place-label.test.js` because the module exports nothing. v0.61.278 restores it by hash-objecting the real local content into the new tree.
>
> 3. **O-25 — JB→OTHER fallback toast.**
