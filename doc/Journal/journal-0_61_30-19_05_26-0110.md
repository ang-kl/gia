> Operator: *"Should the Instagram account button be placed next to the copy button for

## New

### [HDR] #234 | 01:10:00 SGT 19-05-26 | v0.61.30 — Instagram eatery button (gated, deferred data) | ~2 kb | 3 files | 1 PR | 1 build |

- **[INTENT]** Add an Instagram button next to the per-eatery copy button. Research found
  **no Instagram data exists anywhere in the repo** — no `instagram`/`ig`/`social` field
  on the venue object, in `data/` overlays, or in the pipeline; Google Places (the venue
  source) does not return handles. Operator decision (plan workstream A): **build the
  button + rendering now, gated on an `instagram` field that stays empty until a data
  source is wired in a separate future task**; surface on **both** the Cuisine Mini App
  card and the bot's text venue blocks.

- **[DELTA]**
  - **`web/cuisine/src/v2/components/ResultCard.jsx`** — new module-level `instagramUrl()`
    helper (normalises `@handle` / `handle` / `instagram.com/handle` / full URL → a
    profile URL); new `openInstagram()` handler mirroring `openMaps` (`tg().openLink`,
    `window.open` fallback); a third action button `📷 Instagram` after the Copy button,
    rendered **only when `venue.instagram` is truthy**; `instagram` added to the
    `copyOneToChat` payload so a copied block carries it.
  - **`venue-templates.js`** — matching `instagramUrl()` helper near `formatMapsLine`; the
    `includeContact` block now pushes a `📷 <url>` line after the `📞` phone line when
    `p.instagram` is set, `escapeHtml`-wrapped (the block renders with `parse_mode:'HTML'`).
  - **`package.json`** — `0.61.29` → `0.61.30` (PATCH).
  - No pipeline / `index.js` / search-response change — with no data source `instagram`
    is absent on every venue, so the button never renders and the bot line never appears.
    UI is byte-for-byte unchanged until the deferred data task populates the field.

- **[STATUS]** DRAFT → PR (base `main`, branch `claude/cuisine-instagram-button`).

- **[TEST]** With no data: no Instagram button on any Cuisine card, no `📷` line in bot
  venue blocks — identical to today. Stub `venue.instagram = 'soleat'` on a card → a
  `📷 Instagram` button appears next to Copy and opens `instagram.com/soleat`; the copied
  bot block shows the `📷` line.

- **[KNOWN GAPS]** The Instagram **data source** is not built — wiring an `instagram`
  field (curated `data/` JSON overlay matched by placeId, or LLM enrichment) is a
  deliberate separate task; until then the button/line are dormant. Plan **Workstream B**
  (low-visual-load greyscale-basemap map toggle) is **not** in this PR — it is blocked on
  a Google Cloud Map ID setup (`MAP_ID_GREYSCALE`) and ships separately.
