# Journal — soleat v0.61.205 (Putrajaya flag PNG wired to OTHER region pill)

> Operator uploaded `data/MY_Putrajaya_flag.PNG` to GitHub and
> asked it be used "for putrajaya flag in the button". Telegram
> inline buttons can't render custom images, so the meaningful
> surface is the Cuisine TMA region pill. v0.61.205 swaps the
> OTHER pill icon from 🌏 globe to the Putrajaya flag PNG when
> the active anchor is the IOI Resort City Putrajaya precinct.
>
> Commit 418 / journal 406 / build 208, on branch
> `claude/v0.61.205-putrajaya-flag-pill` off `main` at v0.61.204.

## New

### [HDR] #406 | 13:00 SGT 28-05-28 | v0.61.205 — Putrajaya flag on OTHER pill | 4 files | 1 PR | 1 build |

- **[INTENT]** Surface the operator-provided Putrajaya state
  flag in the TMA's region pill specifically when the active
  anchor is IOI Resort City. Other OTHER anchors (KL, Bangkok,
  Bali, Tokyo, etc.) keep the generic 🌏 globe — the Putrajaya
  flag is a city-state flag and shouldn't decorate non-Putrajaya
  picks.

- **[DELTA]**

  - **NEW asset** `data/MY_Putrajaya_flag.PNG` (70 KB, ~1:0.5
    aspect, blue field with yellow centre + crest). Downloaded
    from operator's GitHub blob via `gh api`.
  - **NEW** `web/cuisine/public/MY_Putrajaya_flag.png` (Vite
    static). Lowercase `.png` extension so the existing
    `endsWith('.png')` renderer picks it up.
  - **NEW** `public/cuisine/MY_Putrajaya_flag.png` (runtime
    mirror).

  - **`web/cuisine/src/v2/App.jsx`** (4 edits):
    1. **NEW `useState anchorPrecinctId`** (init `null`) — tracks
       the server-cached anchor's precinctId so the OTHER pill
       can pick the right flag.
    2. **`tryServerCache` success path** — `if (r.precinctId)
       setAnchorPrecinctId(r.precinctId)`.
    3. **Defensive follow-up `fetchUserLocation()` block** after
       the userLoc resolution chain (v0.61.203) — also calls
       `setAnchorPrecinctId(r.precinctId)`. Ensures the pill
       gets the right flag even when userLoc came from URL
       hash / Telegram initData / GPS / centroid.
    4. **v0.61.186 visibility-refresh useEffect** — also tracks
       precinctId (`setAnchorPrecinctId(r.precinctId || null)`).
       Handles the case where the user changes /location while
       the TMA is open in another tab.
    5. **Region toggle render** — OTHER pill `flag` is now
       dynamic:
       ```js
       flag: anchorPrecinctId === 'ioi-resort-putrajaya'
         ? 'MY_Putrajaya_flag.png'
         : '🌏'
       ```
       The existing 18×12 `<img>` renderer (extended in
       v0.61.204 to accept `.png` and `.svg`) renders the image
       with the rounded border styling used by the JB pill.

  - **`package.json`** — `0.61.204 → 0.61.205`.
  - **`doc/.serial-state.yml`** — commit 417 → 418, build 207 →
    208, journal 405 → 406; re-anchored 28-05 '26 13:00 SGT.
