## New

### [HDR] #254 | 01:30:00 SGT 20-05-26 | v0.61.50 — Cuisine location-field search-trigger + loading overlay rework | ~3 kb | 4 files | 1 PR | 1 build |

- **[INTENT]** Make the location-field's edit / search modes explicit and gate venue
  searches behind a clear control; and replace the one-shot first-load banner with a
  context-aware loading overlay (initial / rotating / refresh).

- **[DELTA]**
  - **`web/cuisine/src/v2/components/LocationField.jsx`** —
    - new optional `onSearch` prop fired by a new right-side **`🔍`** button that
      appears whenever the field is in **search mode** (closed). In **edit mode**
      (open input) the right icon is **`✏️`** (visual indicator, not clickable).
    - while open, a **2.5 s keystroke-inactivity timer** auto-closes the field back to
      search mode (so the `🔍` reappears without the user having to blur the input).
      Each `query` change re-arms the timer.
    - picking an autocomplete suggestion still commits the anchor only — venue search
      remains explicit per the v0.60.166 contract (no auto-search on pick).
  - **`web/cuisine/src/v2/App.jsx`** —
    - new `loadingReason` state (`'initial' | 'rotating' | 'refresh'`) and
      `rotatingIndex` driven by a `useEffect` that **cycles the 6 rotating titles
      every 1.5 s** while `loading && loadingReason === 'rotating'`.
    - new `triggerSearch()` helper: sets `loadingReason` to `'refresh'` when a prior
      search exists and the criteria are unchanged (`lastRunSnap !== null && !dirty`),
      `'rotating'` otherwise; then calls `runSearch(state)`.
    - the three search controls — the floating 🔍 FAB, the big "🔍 Search · Show me
      places to eat" button, and the LocationField's new 🔍 — now all call
      `triggerSearch` (was `runSearch(state)` for two of them; the third didn't exist).
    - the first-load overlay (`firstLoadPending && loading`) is broadened to **every**
      `loading` and renders one of three messages depending on `loadingReason`:
      - `initial` → **"⏳ Please wait while loading random eateries…"** (renames the
        previous "Please wait while loading list…");
      - `rotating` → a "Loading…" head plus the cycling title;
      - `refresh` → **"📑 Refreshing results with the same filters…"**.
  - **`web/cuisine/src/v2/lib/i18n.js`** — new keys: `loading.initial`,
    `loading.refresh`, `loading.head`, `loading.rotating.1`…`6`, `loc.searchHere`.
    FR translations added best-effort.
  - **`package.json`** — `0.61.49` → `0.61.50` (PATCH).
