- **[VERIFICATION (sandbox)] — and the bug in it.** The first verification of the #1760
  merge reported **`0 / 1677` notes at six locales on `origin/main`**, which would have
  been a merged PR that shipped nothing. It was wrong, and the way it was wrong is the
  point. The tables wrap each note as `{ local, note: { en, fr, … } }`; the throwaway
  script read `entry[lang]` on the **wrapper** instead of `entry.note[lang]`, so every
  row failed and the failure looked uniform enough to be believable. The corrected
  measurement, through the evaluated merge per D-199:

  | Tree | Notes | All six extra locales | All eight |
  | :--- | ---: | ---: | ---: |
  | `origin/main` (32932abb, #1760) | 1,677 | 50 | 50 |
  | branch `claude/handover-july-11-49uzvf` | 1,677 | 195 | 195 |

  The reusable form now lives at `scratchpad/coverage.mjs` rather than being retyped per
  check. **A confident zero and a real zero are not distinguishable by eye** — this is the
  same class as the `agents_total: 0` case recorded in `CLAUDE-protocol.md` §4, where
  matching one of two tool names reported nothing on a corpus that really contained
  subagent calls.

- **[THE GATES, AND WHY THEY EXIST]** Four of the six contamination rules exist because a
  specific error walked past the previous five. In this arc the rules earned their keep
  again, on errors that no amount of re-reading would have found:

  | Rule | What it caught |
  | :--- | :--- |
  | Mixed-script word | Four `кueh` — a Cyrillic **к** inside a Latin word — and one `неjareными`, a Latin **j** and **a** wedged inside a Russian one. |
  | Han leak outside zh/ja | 笋 in `SG::soon kueh` and 炖 in `peranakan::itek tim`, carried over from the English source into id/ru/de/es. Romanised, as いづう → Izuu and 油揚げ → abura-age were before them. |
  | Untranslated English stopword | A song title, `Black or White`, sitting in Russian, Chinese and Japanese strings. Here the rule was **right about the shape and wrong about the case**; the fix was to localise the title («Чёрное или белое», 《黑或白》, 「ブラック・オア・ホワイト」) rather than to weaken the rule with an exemption. An exemption list is how a gate gets switched off. |
  | 140-character cap | Not script-neutral: id/ru/de/es overflow where zh/ja never do. 34 strings in a single 25-row batch. The cap check moved into the batch validator so it fires where the string is written, not only at CI. |
