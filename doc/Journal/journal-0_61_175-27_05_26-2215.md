- **[KNOWN GAPS]**
  - **Railway redeploy delay** (operator's "didn't move up to
    v0.61.174" remark). The Railway redeploy on PR merge takes
    typically 2-3 min. PR #675 merged at 22:04 SGT; the live bot
    should report v0.61.174 within a few minutes of that. No
    code surface for the operator to inspect the running version
    in chat — only `/v` (owner health check) prints it. If a
    visible "running version" hint would be useful in the chat
    UI, that's a small follow-up (~10 lines in `runHealthCheck`).
  - **Set-all-off applies even to items the operator hadn't yet
    configured.** A first-time operator who's never set any
    cadence has every item at the default 'manual'; tapping
    "Set all off" overwrites those with 'off'. Behaviour-wise
    that's identical (neither manual nor off auto-runs), but
    semantically the operator may not expect it to touch items
    they hadn't customised. Could be filed as a follow-up to add
    a "only flip items that already have a non-manual cadence"
    flag, but probably overkill for the current operator (single
    owner).
  - **No "Set all 4M" / "Set all Yr" bulk-on switch.** If the
    operator wants to bulk-enable a cadence, they'd have to tap
    into each item. A follow-up could add three quick buttons:
    [Set all M] [Set all 4M] [Set all Yr] [Set all off]. Held
    until operator asks.
