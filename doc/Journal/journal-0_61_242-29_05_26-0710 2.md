### [HDR] #443 | 07:10 SGT 29-05-29 | v0.61.242 — IATA table + cities.js audit | 4 files | 1 PR | 1 build |

- **[INTENT]** This is the *prerequisite* PR the operator explicitly
  asked for: collect every IATA-coded city across ASEAN + East/South/
  Central/West Asia + Australia / New Zealand / Pacific Oceania into
  a single reference table, plus a nearest-by-haversine helper. The
  downstream PR (v0.61.243) will wire the TMA mount handler to call
  `nearestIataCity(GPS.lat, GPS.lng)` and snap the region / country
  / cityPick / map / 5-place load to the result, with a Gemini
  fallback when GPS sits outside the table coverage. **No behaviour
  change in this PR** — pure data + helper + test gates.
  
  The audit is bundled in the same PR because the operator's
  "non inventive" rule applies equally to the existing
  `cities.js` dropdown source: ~39 entries used fabricated
  3-letter codes (HK district names, Brunei subdistricts,
  unmatched abbreviations like SML / KEE / HOI / AYU /
  TGT / SHG / UKY / NRA / YOK / DAJ / GJU / VVN / POL / HPA /
  KEP / KPT / KRG / CMS / DDT / SBN / MLK / KGR / PUT / SHA /
  PTY); these now point to the nearest real IATA in the new table.
