## New

### [HDR] v0.62.645 — five corrections that bring the Train card onto Cuisine's actual conventions

- **[INTENT]** Operator (iPad mini; `IMG_1212` action-pill crop + `IMG_1213` landscape v0.62.644): *"I don't
  think cuisine TMA use the word 'direction' for Google map external link as coded now in Train TMA. And be
  default show the station details (not collapse), and the height of the card in Portrait mode isn't the same
  as cuisine TMA. Expand is to expand the card. Reduce the station name font size by 2 px and standardised to
  use Google interface font."*

- **[VERIFIED THE CLAIM BEFORE ACTING]** `web/cuisine/src/v2/components/ResultCard.jsx` renders a literal
  **"📍 Maps"** button, and `web/hawker/src/i18n.js` defines `btn.maps = '📍 Maps'`. The operator is right —
  neither app says "Directions".

- **[DELTA]** (Train, 4 files)
  1. **Wording** — new i18n key `mrt.act.maps` ("Maps" / "Carte"); the card's first action pill is now
     **"📍 Maps"**, opening the **station on Google Maps** (`mapsLatLng`, or
     `mapsQ('<name> MRT Station Singapore')` without coords) instead of "🧭 Directions" opening the routing
     UI — matching Cuisine + Hawker exactly. `mrt.act.directions` is left **defined but unused** (deleting
     shipped translations is a G2 destructive action).
  2. **Opens expanded** — `bodyOpen` seeds to **`true`**, so a card shows the station details by default and
     the foot pill **collapses** it.
  3. **Expand grows the card** — the v0.62.644 model (fixed-height box + internal scroll) is inverted: the
     **card** owns its height — fixed `h-[14rem]` while **collapsed** (uniform boxes), **no** fixed height
     while **expanded** so it simply grows. The carousel wrapper drops its fixed `h-[34vh]`/`h-[27vh]` for a
     `max-h-[52vh]` cap that only scrolls an unusually rich station.
  4. **Portrait height** — the collapsed height is a **rem** (`14rem`), not a `vh`, so the card is the **same
     size in portrait and landscape**. The v0.62.644 `vh` grew with the taller portrait viewport — exactly
     what the operator saw.
  5. **Name** — **16 px → 14 px** ("reduce by 2 px") and a new **`.font-google`** utility
     (Roboto / Google Sans / system fallbacks), so the card title uses Google's interface face. The Maps JS
     API already injects the Roboto webfont into the page, so this costs **no extra network request**.
