## New

### [HDR] #208 | 15:20:00 SGT 17-05-26 | v0.64.0 — overlay UX: radius limiting, exits + train layers, attraction enrichment | 16 files | PR 2 of 4 | 1 build |

- **[INTENT]** Make the map overlays useful at a glance: chips above the map; overlay points
  limited to a 1 km radius of where the user is looking; a new MRT-exits layer; a Train layer
  on the food maps; attractions default to nearby-only with an "all" switch; richer attraction
  popups.

- **[DELTA]**
  - **`scripts/build-geo-overlays.js`** — new `exits` dataset → `data/geo-exits.json` (597 MRT/
    LRT exits from `geoloc/LTAMRTStationExitGEOJSON.geojson`). The `attractions` converter now
    emits `address` / `website` / `hours` / nearest-`station` (computed offline against
    `data/mrt-coords.json`); a `stripHtml` repair handles upstream STB mojibake.
  - **`index.js`** — `exits` added to `/api/geo/overlays`. `/api/transport/line-paths` now
    **always returns geometry**: the real `data/mrt-line-paths.json` when present, else a
    server-side derived fallback (`buildLinePaths`, dynamic-imported from the transport app's
    ESM module + cached) — so the Cuisine/Hawker Train overlay works without the file.
  - **`web/{cuisine,hawker,transport}/src/.../mapOverlays.js`** (×3, kept in sync) — rewritten:
    a `setAnchor(lat,lng)` anchor + 1 km radius clip on the carpark / taxis / attractions /
    exits layers and a 1.5 km clip on the new `train` line layer (parks stay unfiltered);
    `setAttractionsMode('nearby'|'all')`; new `exits` (🚆) and `train` (line polylines, LTA
    colours) layers; the attractions InfoWindow now shows 📇 address, 🕰 hours, 🚉 nearest
    station, 🌐 website link.
  - **`MapLayerChips.jsx`** (×3) — `🚆 Exits` chip; a `Nearby ▾ / All` toggle shown beside
    Attractions when it is on; a `🚇 Train` chip gated by a `showTrain` prop (Cuisine + Hawker
    only — the Transport map draws its own lines).
  - **`web/{cuisine,hawker,transport}/src/App.jsx`** — `<MapLayerChips>` moved **above** the
    map; `overlayLayers` gains `exits` (+ `train: true` default on Cuisine/Hawker); new
    `attractionsMode` state.
  - **`MapPanel.jsx` / `HawkerMapPanel.jsx` / `MrtMapPanel.jsx`** — feed the map-centre anchor
    to the controller on the `idle` event; drive `exits` / `train` / `attractionsMode`.
  - i18n: `layer.exits` / `layer.train` / `layer.nearby` / `layer.all` (EN/FR) in all three TMAs.
  - **`package.json`** — `0.63.1 → 0.64.0` (MINOR — new features).
