## New

### [HDR] #247 | 22:30:00 SGT 19-05-26 | v0.61.43 — SG street/building abbreviation expander | ~3 kb | 4 files | 1 PR | no build (server-only) |

- **[INTENT]** Expand the short-form street / building names in the Singapore
  open-data GEOJSONs and the LTA bus-stop catalogue (Rd, Ave, Sth, Opp, Blk …) for
  display, without touching the source files or any entity name.

- **[DELTA]**
  - **`sg-address.js`** (new) — `expandSgAbbrev(text)`: a token-exact, case-insensitive
    expander. Dictionary grounded in a scan of ~6,500 GEOJSON street/building strings
    (clinics, hospitals, police, attractions, hawker, healthier-eateries, red-light
    cameras, StreetAndPlaces). Covers `Rd/Ave/Av/Dr/Drv/Cres/Cl/Ter/Hts/Gdns/Lk/Hway/
    Lor/Lrg/Jln/Ctrl/Upp/Bt/Tg/Mt/Nth/Sth/Blk/Bldg/Ctr/Opp/Bef/Aft`. The `St` rule
    (confirmed by the scan: 148 of 150 are "Street"; only first-token `St` is
    Saint / a proper name) expands `St` → Street **except as the first word**.
  - **`transport.js`** — `nearestStops()` and `allStops()` pass each stop's
    `description` / `roadName` through `expandSgAbbrev` before returning, so the
    `/transport` bus list, the station-context pins and the `/api/geo/bus-stops`
    overlay all get full names.
  - **`index.js`** — `loadGeoOverlays()` expands the address-type fields of the served
    features: clinics `street`/`building`, hospitals/police/attractions `address`.
  - **`package.json`** — `0.61.42` → `0.61.43` (PATCH).
  - **Applied at the API boundary** — the `data/geo-*.json` files and the Redis
    bus-stop cache keep their short forms; only the served, human-facing strings are
    expanded, so no client / `mapOverlays.js` change was needed.

- **[VERIFICATION (sandbox)]**

  ```bash
  $ node --check sg-address.js / transport.js / index.js  → OK
  $ node -e expandSgAbbrev smoke test:

  ```
  No `web/` change → no TMA build required.

- **[STATUS]** DRAFT → PR (base `main`, branch `claude/review-gia4lunch-readme-3s798`).

- **[TEST]** Open a clinic / hospital / police / attraction / bus-stop map popup —
  the street, building and road names read in full ("Upper Serangoon Road", not "Upp
  Serangoon Rd"). The `/transport` nearby-bus-stop list shows expanded names too.

- **[KNOWN GAPS]** The dictionary is token-exact and conservative — a short form not
  in the table passes through unchanged (under-expand rather than mis-expand). `St`
  as a first word is always left as-is, which is correct for the two scanned cases
  (St George's, St Aerospace) but would also leave a genuine "St … Street" un-expanded
  if one existed (none in the data). New abbreviations are a one-line dictionary add.
  The 24 hours layer remains disabled; the `doc/Legal/` revision (journal #239) remains.
