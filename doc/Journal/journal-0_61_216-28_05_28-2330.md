  **5. `ownerPlaceSearchVarianceRun`** — handles `cfg.dynamic === 'current'`:
  - Reads cached user-location (`getUserLocation(redis, chatId)`).
  - Calls `psv.nearestCityForAnchor(lat, lng)` to pick the closest curated city.
  - Falls back to Kuala Lumpur when no anchor.
  - Prepends a `<i>Nearest curated city: <Name> (~N km from your cached anchor).</i>` line to the "starting" message so the operator sees what got picked.

  **6. NEW `/training` slash command** (~120 lines, owner-gated):
  - Parser: `<count> <arg1> [arg2] …`. Each arg is either a 2-letter ISO country code (MY/JP/KR/ID/TH) or a case-insensitive city name.
  - When exactly one country code is in the args, country acts as an AND filter; multiple countries fall back to "any country" + city filter only.
  - `psv.buildTestSet` previews the actual test count + estimated cost BEFORE firing.
  - On 0 matches: prints the curated city list so the operator can pick valid names.
  - Otherwise: progress pings + summary (same shape as the menu Run).

  Examples:
  ```
  /training 500 MY                — 500 across MY
  /training 300 JP Osaka          — Osaka-only (max ~150 actual)
  /training 200 Bali Jakarta      — both cities (max 300 actual)
  /training 100 KL Putrajaya      — two MY cities (max 200 actual)
  ```
