## New

### [HDR] v0.62.652 — the basis ladder AND the track cap were both holding the number down

- **[INTENT]** Operator, Telegram Desktop screenshot of the Train TMA beside a 1920 px Dell wallpaper: *"for
  the desktop are you able to increase the number of cards to see from current to another few more depending
  on aspect ratio of the desktop"*

- **[TWO SEPARATE CEILINGS]** Fixing only one would not have moved the number, which is worth recording:

  1. **The basis ladder stopped at `md` (768 px).** `basis-[60%] / sm:31% / md:22%` and nothing beyond — so a
     1920 px desktop showed the **same ~4.5 cards as a 768 px tablet**. Every extra pixel went into making
     each card *wider* rather than showing more of the line. Extended to `xl:17% / min-[1600px]:13.5% /
     min-[2000px]:11%` for the Train, and `xl:24% / min-[1600px]:19% / min-[2000px]:16%` for Hawker +
     Cuisine — their cards carry more content each, so they need more width each.
  2. **The track itself was capped.** Transport's carousel had `max-w-6xl` (**1152 px**) and Cuisine's
     `max-w-[1600px]`, so on a 2560 px ultrawide the carousel occupied less than half the screen and the
     ladder could not express itself. Now `xl:max-w-none` (Transport) and `min-[1800px]:max-w-none`
     (Cuisine). **This is the one that actually unlocked ultrawide** — before it, 1920 and 2560 both measured
     exactly 8.0 cards.

  Also added `min-w-[9rem]` as a **floor** on the Train card, so the top of the ladder can never squeeze a
  card below readable width; the track scrolls instead.

- **[ON "ASPECT RATIO" — said plainly, not silently substituted]** How many cards fit **across** is width ÷
  card width. Aspect ratio only enters via **height**, which changes how *tall* a card may be
  (`max-h-[52vh]`), not how many sit side by side. So the ladder is keyed to **width**, all the way to
  ultrawide — which is what the request actually needs. Recorded here because the operator asked for aspect
  ratio by name and deserves to know why the implementation keys off width.
