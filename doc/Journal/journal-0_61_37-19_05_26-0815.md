### [HDR] #241 | 08:15:00 SGT 19-05-26 | v0.61.37 — vertical semi-transparent map nav + /oversight label + base-map-only greyscale | ~5 kb | 11 files | 1 PR | 1 build |

- **[INTENT]** Match the operator's requested map-control layout: a vertical nav-button
  column (Reset on top), translucent buttons, a wider toggle-pill row; and correct the
  `/ver` keyboard's button label.

- **[DELTA]**
  - **`index.js`** — the `/ver` Admin-Commands inline keyboard button `🛡 /admin` is
    relabelled `🛡 /oversight` (the callback `v:oversight` is unchanged — it always
    launched the Oversight TMA; only the visible text was misleading).
  - **`MrtMapPanel.jsx` / `HawkerMapPanel.jsx` / `MapPanel.jsx`** — the top-right nav
    cluster changes from a horizontal row (`flex-row`) to a **vertical column**
    (`flex-col`), reordered top→bottom: **Reset · Zoom in (＋) · Zoom out (－) ·
    Expand/Collapse**. All four buttons are now **semi-transparent** (`bg-white` →
    `bg-white/70`).
  - **`MapControls.jsx`** (byte-identical ×3) — the in-map control row's right inset
    narrows `right-32` → `right-12`, since the nav cluster is now one button wide; this
    gives the Cuisine row room to show **✨ Attractions · 🅿️ Carpark · 🚌 Bus Stop ·
    🎨 Colour** on one line.
  - **`mapOverlays.js`** (byte-identical ×3) — new exported `ensureGreyscaleStyle()`
    injects a one-time `.gia-greyscale-map canvas{filter:grayscale(1)}` stylesheet. Each
    map panel adds that class to its container when 🎨 Colour is on, so the greyscale
    now desaturates **only the base-map `<canvas>`** — the DOM overlay pins
    (AdvancedMarkerElement) keep their colour. (Earlier the `filter` sat on the whole
    container, greying the pins too — operator: *"the greyscale … not the upper
    layer"*.) The CSS rule re-matches new canvases automatically on zoom/pan.
  - **`MrtMapPanel.jsx` / `HawkerMapPanel.jsx` / `MapPanel.jsx`** — import + call
    `ensureGreyscaleStyle()` in `initMap`; the container `<div>` carries the
    `gia-greyscale-map` class instead of an inline `filter`.
  - **`package.json`** — `0.61.36` → `0.61.37` (PATCH).
