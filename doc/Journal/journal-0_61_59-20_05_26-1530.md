## Deleted

### v0.61.41 — `MapControls.toggleStyle()` (local quick-toggle palette)

Removed from `MapControls.jsx` — the divergent local palette function:

> ```js
> function toggleStyle(active, disabled) {
>   return {
>     background: active ? '#F59E0B' : '#1F2937',
>     color: active ? '#111827' : '#D1D5DB',
>     border: '1px solid ' + (active ? '#FCD34D' : '#374151'),
>     boxShadow: '0 1px 4px rgba(0,0,0,0.45)',
>     opacity: disabled ? 0.5 : 1,
>     cursor: disabled ? 'default' : 'pointer'
>   };
> }
> ```

Rationale: this was a v0.61.41 copy of the quick-toggle palette that CR7 (v0.61.51)
failed to update when it made the shared `giaToggleStyle` theme-aware — leaving the
quick-row pills with a fixed dark-slate OFF background. `MapControls.jsx` now imports
and uses `giaToggleStyle` directly (single source of truth). The dropped `cursor`
field is cosmetic only — native `<button>` elements get the correct cursor from the
UA stylesheet.
