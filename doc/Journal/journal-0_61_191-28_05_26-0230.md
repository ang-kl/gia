- **[INTENT]** Replace the OTHER-region autocomplete dropdown with

  confirmation list. Fixes the "Times Square Kuala Lumpur → SG

- **[DELTA]**
  - **NEW `web/cuisine/src/v2/lib/countries.js`** — 16-entry
    frozen array: ASEAN-9 (MY/ID/TH/VN/PH/BN/KH/LA/MM) + Oceania-2
    (AU/NZ) + North Asia-5 (JP/KR/CN/HK/TW). SG omitted (it has
    its own pill). Each entry: `{ code, flag, name }`.
    `DEFAULT_OTHER_COUNTRY = 'MY'`. Helper `findCountry(code)`.
  - **`web/cuisine/src/v2/lib/state.js`** — `defaultState`
    gains `countryPref: 'MY'`. Only consumed when
    `region === 'OTHER'`.
  - **`web/cuisine/src/v2/lib/i18n.js`** — 7 new keys (EN + FR):
    - `loc.other.country` = `Country` / `Pays`
    - `loc.other.placeholder` = `Type a place name + 🔍`
    - `loc.other.searchBtn` = `🔍 Search`
    - `loc.other.searching` = `Searching {country}…`
    - `loc.other.noMatch` = `No places found in {country}…`
    - `loc.other.confirmHeader` = `Found in {flag} {country}:`
    - `loc.other.cancel` = `✕ Cancel · type again`
  - **`web/cuisine/src/v2/lib/api.js`** — NEW
    `placeSearchByCountry({ input, countryCode })` →
    POST `/api/cuisine/place-search-by-country`.
  - **`web/cuisine/src/v2/components/LocationField.jsx`** —
    imports the new module. After the existing hooks declare
    (Rules of Hooks safety: declare before any conditional
    return), branches on `region === 'OTHER'` → renders
    `<OtherLocationPicker>` (new sub-component at the file
    bottom, ~120 lines). The OtherLocationPicker:
    - Flag-only `<select>` on the left (fixed 4.5rem width)
      listing the 16 countries.
    - Free-text `<input>` (Enter submits).
    - 🔍 Search button.
    - On submit: `placeSearchByCountry({ input, countryCode })` →
      renders top 5 in a confirmation panel.
    - Tap row → `onSelect({ lat, lng, label })` → anchor moves.
    - `✕ Cancel · type again` resets.
  - **`web/cuisine/src/v2/App.jsx`** — `<LocationField>` gains
    `countryPref` + `onCountryChange` props. `onCountryChange`
    writes to `state.countryPref` so the next OTHER search uses
    the new country.
  - **`index.js`** — NEW endpoint
    `POST /api/cuisine/place-search-by-country` (~85 lines).
    - Validates `input` (2–200 chars) + `countryCode` (must be
      one of the 16 in the OTHER_COUNTRY_CODES set).
    - Calls Places New `searchText` with `regionCode=cc` +
      `includedRegionCodes=[cc]` + `pageSize=5` + minimal field
      mask.
    - 1-hour Redis cache (`placesearchbycountry:v1:<cc>:<text>`)
      so retypes don't burn API budget.
    - Rate-limited via `makeRateLimiter` (500/hr/chat — same
      tier as `/place-resolve` / `/place-autocomplete`).
    - Returns `{ results: [{placeId, primaryText, secondaryText,
      lat, lng}], countryCode, cached }`.
