- **[INTENT]** Produce a single canonical `data/stations.json` matching the agreed
  CR6 template, joining data already in the repo (no scraping, no new external
  fetches). Unblocks Phase 2 (LTA enrichments) and Phase 3 (UI card render).

- **[DELTA]**
  - **`scripts/build-station-info.js`** (new, ~120 lines) — pure Node, no new deps.
    Reads `data/mrt-coords.json` (canonical 143 operational + 41 future stations,
    with codes / lines / lat/lng) and `data/station-exits.json` (LTA MRT Station
    Exit GEOJSON, 183 station records, exit code + coords). Joins them into one
    record per operational station:
    - `station_name`, `lat`, `lng`
    - `lines: [{ operator, line_code, line_name, station_code, station_slug,
      more_info_url }]` — one entry per line for interchanges (Newton → NSL + DTL,
      different operators)
    - `exits: [{ label, lat, lng, nearest_bus_stop }]` — `label` strips the `Exit `
      prefix; `nearest_bus_stop` stubbed `null` for Phase 2
    - `first_last_train: []` — stubbed for Phase 2
    - `last_updated_at`, `data_quality_notes`
  - **URL rules** (rule-based, no scraping):
    - SMRT: `https://journey.smrt.com.sg/journey/station_info/<slug>/` where
      `slug = lowercase + hyphens` (e.g. `bukit-panjang`).
    - SBS Transit: generic `https://www.sbstransit.com.sg/Service/TrainInformation`
      (their per-station codes — e.g. `BKP` for Bukit Panjang — differ from LTA
      codes and aren't curated yet; flagged in `data_quality_notes`).
    - Line-code → operator / display name table per the CR6 brief: SMRT runs NSL /
      EWL / CGL / CCL / TEL / BPL; SBS Transit runs DTL / NEL / SLRT / PLRT.
  - **`data/stations.json`** (new, generated) — 180 operational stations; 175 carry
    exits; 118 carry SMRT links; 76 carry SBS links. Future-status stations skipped
    (29). `Newton` confirmed to emit both NSL (SMRT) and DTL (SBS Transit) line
    entries with the agreed display template values.
  - **`package.json`** — `0.61.54` → `0.61.55` (PATCH).
