## New

### [HDR] #288 | 05:55 SGT 22-05-26 | v0.61.89 — bottom-right zoom readout (Cuisine + Hawker) + camera-control / keyboard-shortcut parity (3 TMAs) | ~5 kb | 4 files | 1 PR | 1 build |

- **[INTENT]** (1) Add a tiny live zoom-level readout to the Cuisine + Hawker
  maps, bottom-right, as a troubleshooting aid for the per-TMA zoom behaviour;
  (2) streamline all three TMA maps onto one shared map-options block that
  keeps Google's native camera control (pan/tilt/rotate) + keyboard shortcuts
  enabled — previously only the Transport map carried them.

- **[DELTA]**
  - **`web/cuisine/src/v2/components/MapPanel.jsx`** — new `zoomLevel`
    `useState`, seeded in `initMap()` and tracked via a `zoom_changed` map
    listener. A tiny `z <level>` chip (black 55%, 10 px monospace,
    `pointer-events-none`) renders bottom-right, at `right-14` so it clears
    the 📍 recenter FAB. The map-options block gains `cameraControl: true`,
    `cameraControlOptions: { position: …LEFT_BOTTOM }` and
    `keyboardShortcuts: true`. (#1, #2)
  - **`web/hawker/src/components/HawkerMapPanel.jsx`** — same `zoomLevel`
    state + `zoom_changed` listener; the `z <level>` chip renders bottom-right
    at `right-3` (that corner is free here). Same camera-control /
    keyboard-shortcut additions to the map-options block. (#1, #2)
  - **`web/transport/src/components/MrtMapPanel.jsx`** — map-options
    normalised to the shared block: `disableDefaultUI: false` → `true`; the
    now-redundant `mapTypeControl` / `streetViewControl` / `fullscreenControl:
    false` lines dropped (all off under `disableDefaultUI: true`);
    `cameraControl: true` + `cameraControlOptions` (LEFT_BOTTOM) +
    `keyboardShortcuts: true` added. Net behaviour is unchanged — camera +
    keyboard were already on via `disableDefaultUI: false` — only the camera
    widget relocates from the default bottom-right to LEFT_BOTTOM, clearing
    the bottom-right Overview button. No zoom readout added (the operator
    scoped that to Cuisine + Hawker). (#2)
  - **`package.json`** — `0.61.88` → `0.61.89` (PATCH).
