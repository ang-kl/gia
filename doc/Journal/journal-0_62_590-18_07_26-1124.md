  the carousel, exactly as it already did on portrait tablets. `landscapeTablet`/`portraitTablet` (the
  `isWide`-gated booleans) are gone; `isWide` now only widens the list grid to 2 columns. Carried the
  `↻` refresh into the two-panel header so the phone keeps its stale-webview reload.

### [HDR] v0.62.590 (cont.) — Codex review fixes on #1598 (footer scroll + pin re-tap)

- **[REBASE]** #1598 was carrying the already-squash-merged v0.62.589 commit (I skipped the branch
  restart after #1597 merged), so its diff double-included the unified-tap-flow files — that's why Codex
  reviewed `MapPanel.jsx`. Rebased `--onto origin/main` to drop it; #1598's diff is now Hawker-only, plus
  these two review fixes.

- **[FIX 1 — Hawker footer scroll (Codex P2)]** `web/_shared/components/FooterNav.jsx` +
  `web/hawker/src/App.jsx`. The new two-panel is `fixed inset-0 overflow-hidden` with an inner
  `overflow-y-auto` list, so the **window never scrolls** — but `FooterNav`'s ⇣/⇡ used `window.scrollTo`
  and `atBottom` tracked `window` scroll, leaving the footer scroll control dead (the old phone
  stacked layout DID scroll the window, so this was a real regression). Added an optional **`scrollEl`**
  prop to `FooterNav` (defaults to `window`, so Menu/Transport are untouched); the two-panel now passes a
  `panelScrollRef` + its own `panelAtBottom` (computed from the container's `scrollTop/clientHeight/
  scrollHeight`). Also fixes the same latent gap on the portrait tablet.

- **[FIX 2 — Cuisine pin re-tap (Codex P2)]** `web/cuisine/src/v2/components/MapPanel.jsx` +
  `web/cuisine/src/v2/App.jsx`. After v0.62.589 a pin tap only sets `focusedPlaceId` and the focus effect
  opens the popup — but the in-card **✕** (`closeInfo`) cleared `openInfoIdRef` only, NOT `focusedPlaceId`,
  so re-tapping the **same** pin/card set state to the same value → the effect didn't re-run → the popup
  couldn't reopen. `closeInfo` now calls a new **`onInfoClose`** prop (App → `setFocusedPlaceId(null)`),
  so every re-tap is a fresh selection (fixes pin AND card re-tap). Side effect: the accent ring lifts
  when the popup closes, which reads as a deselect — acceptable, flagged in the PR.
