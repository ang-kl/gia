### [HDR] v0.62.590 — Hawker phone gets the tablet layout (carousel ↔ two-panel) + a 2-row zone selector

- **[INTENT]** Operator (IMG_3554, phone) on the Hawker TMA:
  1. *"this 5 zone as pills are awful. how to reduce to two rows and make it meaningful. the third row is
     the display message, is it useful?"*

- **[DELTA — item 1 (zone selector)]** `web/hawker/src/App.jsx`. The five zone chips wrapped raggedly
  (`flex flex-wrap`). Laid them out as a tidy **`grid grid-cols-3`** (a 3 + 2 **two-row** segmented
  control, chips centred/stretched to the cell) so the zone picker reads as one control. Dropped the
  redundant **"Central — 22 hawker centres (alphabetical)"** strip — the selected chip already shows the
  count, so the third row was noise.

- **[DELTA — item 2 (phone layout)]** Phones now use the **same responsive layout as tablet/desktop**
  instead of the old phone-only stacked scroll (where the map scrolled away with the list). The gate is
  now **orientation-driven for every device**: landscape (any) → full-bleed map + bottom **carousel**;
  portrait + map expanded → that carousel (collapsible via ⇱); portrait otherwise → the **two-panel**
  (top-fixed map + scrolling single-column list). The map's ⇲/⇱ toggles a phone between the listing and
  the carousel, exactly as it already did on portrait tablets. `landscapeTablet`/`portraitTablet` (the
  `isWide`-gated booleans) are gone; `isWide` now only widens the list grid to 2 columns. Carried the
  `↻` refresh into the two-panel header so the phone keeps its stale-webview reload.
