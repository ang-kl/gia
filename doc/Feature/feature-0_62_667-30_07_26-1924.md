implements via `awardsDiff()`'s `droppedAfter` (v0.62.666, Register D-34) — a dropped award is an ABSENCE of a

principle. Across both of this repo's Michelin data systems, "dropped" now means the same thing everywhere:
the venue stays in the data, its `awardYears` simply stops gaining new years.
