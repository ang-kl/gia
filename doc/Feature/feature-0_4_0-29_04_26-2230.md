### 3. Telegram Web App (TWA)

Served when the bot is in webhook mode (i.e. `RAILWAY_PUBLIC_DOMAIN` or `WEBHOOK_DOMAIN` set):

| Route | Auth | Returns |
| :--- | :--- | :--- |
| `GET /app` | none | `public/index.html` (the TWA shell) |
| `GET /static/*` | none | static assets (`app.js`, etc.) |
| `GET /maps-key` | `X-Telegram-Init-Data` HMAC | `{ key }` (Maps JS API browser key) |
| `GET /api/sanctuary?lat=X&lng=Y` | `X-Telegram-Init-Data` HMAC | `{ meal, label, venues: [{name, lat, lng, area, rating, openNow, placeId, vibe, url}] }` |

Frontend (`public/index.html` + `public/app.js`):
1. `tg.expand()`, fetches `/maps-key`, dynamically loads Google Maps JS.
2. Tries browser geolocation; falls back to Raffles Place if denied.
3. Calls `/api/sanctuary?lat=…&lng=…` with `X-Telegram-Init-Data: tg.initData`.
4. Renders 3 numbered venue markers + a user-position dot. Click → InfoWindow with name/area/vibe/Maps deep-link.

### 4. Pure-Gemini-then-Places-validation pipeline

`vibe-suggest.js`:
1. **`geminiCandidates(meal, lat, lng)`** asks Gemini (`responseMimeType: 'application/json'`) for 5 candidate `{name, area, vibe}` items. **Coordinates are not requested** — Gemini cannot fabricate them.
2. **`validateWithPlaces(candidate, near)`** issues `places:searchText` with the Gemini name + `locationBias` near the user. Accepts iff result is within **200 m** of the user. Authoritative coords come from Places.
3. **`pickValidated(lat, lng, count, fallback)`** orchestrates and returns up to `count` validated venues; falls back to cached `vibe:listings` if validation drops below `count`.

This keeps the user's structured-JSON pattern while preventing hallucination from corrupting the map.

### 5. Reply shape (chat-mode `/eat`)

```
[text]   Where are you for lunch? Tap to share once.
         [📍 Share my location] [⛔ Use Raffles Place default]

(user shares location)

[text]   Got it. Looking for lunch within 800m…
[text]   Gia's lunch sanctuary picks
         1. <Name> ⭐<rating> · Open now
         2. ...
         3. ...
[venue]  <card 1>
[text]   🌿 Sanctuary read for <Name 1>
         • Quiet: ...
         • Seating: ...
         • Vibe: ...
[venue]  <card 2>
[text]   🌿 Sanctuary read for <Name 2>
         ...
[venue]  <card 3>
[text]   🌿 Sanctuary read for <Name 3>
         ...
```

If no Sanctuary read available but Gemini supplied a `vibe` text, that line lands instead. If neither, only the venue card lands. Bot never crashes.
