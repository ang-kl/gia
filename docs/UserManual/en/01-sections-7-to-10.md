# Soleat User Manual — Sections 7 to 10

## 7. Main Ways to Use Soleat

Soleat can be used in several ways. You do not need to use every feature from the start.

Use the **Soleat Menu** when you prefer a visual entry point. It is useful for opening major features without remembering commands.

Use **Telegram commands** when you already know what you want to do. Commands are fast and direct.

Use **free-text search** when your request is more natural than a fixed menu choice. For example, you can type a dish, cuisine, cooking method, set-meal idea, or a place-based request.

Use **Cuisine Search** when you want more control over food criteria, filters, map results, dish suggestions, recognised venues, or local food discovery.

Use **Google Map View** when the surrounding context matters, such as nearby stations, exits, bus stops, car parks, hawker centres, attractions, clinics, police stations, or parks.

Use **Sketchbook / Clipboard** when you want to save, group, and plan possible eateries instead of deciding immediately.

## 8. Soleat Menu Overview

The Soleat Menu is the main launcher inside Telegram.

It is meant for users who want to tap into a feature instead of typing a command. From the menu, you can open the main Soleat surfaces and practical tools.

Depending on the available version and region, the menu may lead to features such as:

- Cuisine Search;
- Singapore Hawker Centres & Food Centres;
- Singapore Train Network / Transport;
- Sketchbook / Clipboard;
- Location;
- Singapore Car Parks;
- Weather;
- Recognised Venues; and
- other user-facing tools.

Use the menu when you are exploring Soleat or when you do not remember the command name.

Use commands when you already know the exact feature you want.

## 9. Command Overview

Telegram commands are shortcuts that begin with `/`.

They let you go directly to a Soleat feature from the chat.

### 9.1 Common user commands

| Command | Use it for |
|---|---|
| `/start` | Start or restart Soleat. |
| `/menu` or `/m` | Open the Soleat Menu. |
| `/cuisine` or `/c` | Open Cuisine Search. |
| `/search` or `/s` | Search using free text, such as dish, ingredient, cuisine, or cooking method. |
| `/recognised` | Find recognised venues and curated food sources. |
| `/hidden` | Look for hidden gems or lesser-known food places where supported. |
| `/hawker` | Open Singapore Hawker Centres & Food Centres. |
| `/transport` | Open transport-related information, including Singapore Train Network and nearby bus context where available. |
| `/carpark` | Check Singapore Car Parks where available. |
| `/weather` | Check weather. |
| `/location` or `/l` | Set or change location. |
| `/clipboard` or `/clip` | Open Sketchbook / Clipboard. |
| `/share` | Share saved or selected items where supported. |
| `/picks` | Recall recent venue picks where supported. |
| `/language` | Change language. |
| `/privacy` | Read privacy information. |
| `/forgetme` | Erase stored user data. |

### 9.2 Commands not covered in this manual

Some commands are owner-only, diagnostic, retired, or hidden from normal users. They are not part of the public user manual.

This manual focuses on commands meant for ordinary use.

### 9.3 When to use commands instead of the menu

Use commands when you know what you want.

For example:

```text
/weather
/carpark
/clipboard
```

Use the menu when you want to browse features first.

## 10. Location, Countries, Cities, and Saved Locations

Location is one of the most important parts of Soleat.

Soleat uses location to decide where to search, how to rank nearby places, and which practical context may be useful. Location can affect food results, map view, transport context, bus stops, car parks, hawker-centre results, recognised venues, hidden gems, and Sketchbook planning.

### 10.1 Main location choices

You can usually use location in three ways:

1. Share your current location.
2. Type a specific place.
3. Use country, city, and saved-location options where available.

### 10.2 Share current location

Use current location when you want nearby results from where you are now.

This is useful for quick decisions, such as:

- lunch nearby;
- dinner before travelling home;
- nearest bus or train context;
- nearby car parks;
- nearby hidden gems; or
- food options around your current area.

### 10.3 Type a specific place

Use a typed place when you are planning for somewhere else.

Better examples:

```text
Orchard MRT
Bugis Junction
Tanjong Pagar Plaza
Southkey Mid Valley
Tokyo Station
```

A station, mall, building, street, hotel, or neighbourhood is usually more useful than only typing a country name.

### 10.4 Countries and cities

Countries and cities help Soleat narrow the wider search context.

They are especially useful when you are planning outside Singapore, such as Malaysia, Johor Bahru, Japan, Australia, or other supported travel regions.

A country or city is usually not the final eating location. It gives Soleat the broader search area, but a specific place, saved location, or current location is usually better as the actual search anchor.

Example:

```text
Country: Malaysia
City: Johor Bahru
Place: Southkey Mid Valley
```

### 10.5 Saved locations

Saved locations are places you may want to reuse.

Examples:

```text
Home
Office
Church
Hotel
Orchard
Bugis
Johor Bahru hotel
Tokyo stay
```

Use saved locations when you often search from the same area or when you are planning a trip over several meals.

### 10.6 Country → City → Saved Location flow

A typical location flow is:

```text
Choose country
        ↓
Choose city
        ↓
Choose or enter saved location
        ↓
Use this location for search
        ↓
Review food, map, transport, bus, car park, and planning results
```

### 10.7 Location tips

Be specific when possible.

If results are too broad, add a clearer place name.

If results are too narrow, remove extra details or choose a broader area.

If you are planning a trip, save important locations first, then reuse them across food searches and Sketchbook planning.
