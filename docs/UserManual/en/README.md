# Soleat User Manual — English Master

This folder contains the English master copy for the Soleat User Manual.

## Status

Draft scaffold for Sections 1–6.

## Writing rules

- Write for users, not developers.
- Explain user goals before product surfaces.
- Use product terms consistently: Soleat, Soleat Menu, Cuisine Search, Eatery Cards, Google Map View, Singapore Train Network, Singapore Train Station Exits, Singapore Bus Information, Singapore Car Parks, Sketchbook / Clipboard.
- Do not include owner-only or admin commands in the public manual.
- Do not invent features.
- Mark uncertain feature behaviour as `Needs verification` outside the user-facing manual text.
- Keep the English master stable before translating.

## Translation plan

The English master should be locked before translation into the other supported languages:

- French
- Indonesian
- Russian
- German
- Chinese
- Japanese
- Spanish

Food terms, dish names, cuisine names, and local usage require meaning-aware review. They should not be treated as simple word-for-word translation.
