## What this snapshot is

A faithful mirror of the repository at v0.61.28 — all source (`index.js` + ~45 modules, `web/<app>/src`, `scripts/`), the curated datasets (`data/`), the open-data sources (`geoloc/`), the `__tests__/` suite (1,928 passing), and the full `doc/` documentation system **including the fresh v0.61.28 master document set** (`doc/Builder|Persona|Feature|Technical|Legal/…-0_61_28-…md`, `doc/Register/register-0_61_28-…md`) produced in the same pass.

It is bootable: a clean `npm install` reproduces the service.

| Excluded | Reason |
|---|---|
| `node_modules/` (root + every nested, incl. `web/*/node_modules`) | Reinstalled by `npm install` |
| `.git/` | History lives in the parent repository |
| `vault/` | Nested vaults forbidden (recursion) |
| `dist/`, `public/{cuisine,menu,hawker,transport,oversight}/` | Vite build artefacts — gitignored, regenerated by `npm run build` |
| `log/`, `*.log` | Transient logs |

| `.claude/settings.local.json` | Local session state |

## Boot instructions

```bash
cp -a vault/v0.61.28 /tmp/soleat-v0.61.28
cd /tmp/soleat-v0.61.28
npm install
npm test -- --run                       # 1,928 tests, expect 100% green
npm run build:geo                        # rebuild data/geo-*.json from geoloc/ (optional)
(cd web/cuisine && npm install && npx vite build)   # repeat per web/<app>/ to rebuild the TMAs
# provide a .env from .env.example, then: node index.js
```
