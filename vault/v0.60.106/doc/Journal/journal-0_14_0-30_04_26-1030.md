  - **All five Gemini modules** — `apiKey = process.env.GEMINI_API_KEY || process.env.GOOGLE_API_KEY` (was `GEMINI_API_KEY` only). Either env var works; existing config with `GEMINI_API_KEY` continues to function.
  - **`consultant.js`** — `fetchReviews` slice 5 → **3** (per spec §130.6). `geminiSanctuaryRead` prompt now includes `afternoon` in the keyword list and adds an `approach` field for building-level navigation cues. `findHiddenSanctuary` returns `approach` on each match.
  - **`vibe-summary.js` `summarizeVibe`** — added a fourth bullet `Approach:` to the structured output, asking Gemini to extract a building-level navigation cue from reviews if present (entrance / floor / alley / "tucked behind"), or "—" if none. Voice cue added: "polite, helpful, grounded" (matches existing Gia persona).
  - **`index.js`** — Hidden Sanctuary chat reply now includes the `Approach:` line when present.
  - **`package.json`** — version → 0.14.0.
- **[SPEC §130.8 NOTE]** "Reformed-Theological and Christ-modeled tone" interpreted as the secular virtues of polite / helpful / grounded — already encoded in the Gia persona. Explicit Christian doctrinal content not added to AI prompts; soleat targets religiously diverse Singapore users (Buddhist, Muslim, Hindu, Taoist, Christian, freethinker), and embedding a single faith tradition in the prompts would alienate the majority. Surfaced explicitly in the chat reply for transparency.
- **[RISK]** Low —
  - **Cost shift.** Pro is more expensive per token than Flash. Prior cost ~$0.0001 per call; Pro is ~$0.001–0.005 depending on payload. At single-user scale negligible. Per `/eat` worst-case: ~$0.05 input tokens × ~5 Gemini calls (gatekeeper, candidates, sanctuary read for 3 picks, hidden sanctuary, review screen) ~ $0.25. Up from prior $0.05.
  - **`approach` field** is best-effort. Reviewers often don't mention navigation cues; in those cases the field is `null` / `"—"` and no Approach line surfaces. No regression.
  - **Model switch ahead of GA.** `gemini-3-pro` may not yet be a valid identifier in production (was a hypothetical/preview name at session start). If `/ver` shows 🔴 Gemini after redeploy, fall back to `GEMINI_MODEL=gemini-2.5-pro` in Railway Variables.

### Spec §130.8 deviation logged
> **Spec ask:** "maintaining the Reformed-Theological and Christ-modeled tone of the bot."
>
> **Implementation:** secular virtues (polite, helpful, grounded) reinforced in prompt voice cues. No theological doctrinal content embedded in AI prompts.
>
> **Rationale:** soleat's audience is Singapore-CBD diners — religiously diverse. Embedding a single faith tradition in the assistant's reasoning prompts is poor product fit and excludes the majority of users. The "Christ-modeled" virtues most cleanly translatable into a public assistant — humility, helpfulness, dignity, groundedness — are all preserved in the existing Gia persona.
