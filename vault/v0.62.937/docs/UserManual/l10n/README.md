# Soleat User Manual Localisation Scaffold

This folder is for future translated versions of the Soleat User Manual.

## Status

Translation has not started.

The English master must be reviewed and locked before any translated manual is produced.

## Required gates

Before translation begins:

- English master locked;
- glossary reviewed;
- food-term review complete;
- command aliases validated;
- help IDs reviewed as future app contracts;
- image registry reviewed.

## Language order

Recommended order:

1. Chinese (`zh`)
2. Japanese (`ja`)
3. Indonesian (`id`)
4. French (`fr`)
5. German (`de`)
6. Spanish (`es`)
7. Russian (`ru`)

Chinese and Japanese are prioritised first because they pressure-test native-script food names and meaning-aware food-term handling.

## Rule

Do not create translated manuals by direct machine translation alone.

Food terms, cuisine names, dish examples, native-script names, and search examples require meaning-aware review.
