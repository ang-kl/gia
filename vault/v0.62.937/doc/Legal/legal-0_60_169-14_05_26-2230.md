## 1. Disclaimer (user-facing copy in `/legal`)

> _(reproduced verbatim from `legal-0_60_153-14_05_26-0200.md` — see §7 for the v0.60.169 amendment)_

> **soleat is a personal, non-commercial side project run from Singapore.** It surfaces public data (Google Places, LTA DataMall, NEA, data.gov.sg) and AI-mediated content (Anthropic Claude, Google Gemini) inside Telegram for **informational use only**. Listings, ratings, opening hours, and award statuses can be wrong, stale, or fabricated by the underlying LLMs despite our verification rules — please confirm critical details (open/close, halal certification, dietary safety) directly with the venue before acting. soleat does not collect, sell, or share personal data; see `/privacy` for retention. soleat is not affiliated with Google, Anthropic, the Singapore Government, or any of the rating bodies it references. Use at your own risk.

## 3. Jurisdiction & Privacy

> _(reproduced verbatim from `legal-0_60_153-14_05_26-0200.md`; no privacy/jurisdiction surface changes in the v0.60.154 → v0.60.169 arc — the new clauses in §7 are disclaimer-side, not data-handling-side.)_

- **Jurisdiction:** Singapore. Bot serves SG-specific data sets and complies with Singapore-side terms (LTA / NEA data licences, HDB carpark licence, IMDA Model AI Governance Framework alignment for AI-mediated output).
- **PDPA Section 13(c) / GDPR Article 17 alignment:** users can wipe every chatId-keyed Redis entry on demand via `/forgetme`. Returns a deletion summary so the user has a record.
- **No personal data sent to third parties.** Chat IDs are sha256-hashed before being used as Redis keys for location / processing / activity-tracking state. Telegram user IDs are visible only to the LLM providers when their APIs are called, and only as the bot's own request initiator (not as user attribution).
- **AI-mediated content disclaimers:** (unchanged from `legal-0_60_153` — `/hidden`, Tell-Gia, `/recognised`, Michelin narrate.)
- **Free-text search-term log (v0.60.131; retention 90 days v0.60.132).** (unchanged from `legal-0_60_153`.)
- **Aggregate-usage counters (v0.60.142; PR #379).** (unchanged from `legal-0_60_153`.)
