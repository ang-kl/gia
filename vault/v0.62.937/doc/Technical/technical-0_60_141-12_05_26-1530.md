## Free-text guard, dessert/drink steering, search-term log (v0.60.131)

### `freetext-classify.js` (new)

- `looksLikeQuestion(text)` → bool. True on: a trailing `?`; or a leading interrogative/auxiliary from a tight set (`does/do/did/is/are/can/could/will/would/what/which/who/why/how/should/has/have/may/might/…` — `where` excluded) AND ≥ 4 tokens; or ≥ 5 tokens containing an "asking verb" (`sell/sells/serve/serves/have/has/stock/carry/offer/make/…`) mid-sentence. Tokenisation is `[^\p{L}\p{N}']+`-split, lowercased. Deliberately conservative — short dish/brand names ("fish and chips", "char kway teow", "What The Burger") never trip it.

### `dessert-drink-keywords.js` (new)

- `DESSERT_DRINK_TERMS` — a `Set` of ~150 normalised SG-relevant dessert + drink dish names (curated `DESSERT_TERMS` + `DRINK_TERMS`, lowercased + diacritic-stripped on read). `looksLikeDessertOrDrink(text)` → `{ term, kind: 'dessert'|'drink', venueKeywords[], primaryTypes[] }` | null — matches the curated set, or a few fragments (`ice cream`, `kaya toast`, `bubble tea`, `teh tarik`, …), or a suffix (`…cake/tart/pie/pudding/cookie/waffle/pancake/macaron/eclair/kueh/bingsu/…` → dessert; `…latte/frappe/smoothie/milkshake/shake` → drink); bails on > 6 words / > 48 chars. `dessertDrinkQuery(hit, cuisineLabel)` → `"<cuisineLabel?> <term> bakery cafe Singapore"` (dessert) / `"… <term> cafe Singapore"` (drink), capped 80 chars. `venueKeywords` (bakery / patisserie / kueh / dessert / kopitiam-ish name fragments) + `primaryTypes` (`bakery` / `cafe` / `dessert_shop` / `ice_cream_shop` / `coffee_shop` / `tea_house` / `food_court` / …) drive the dessert-specific above/below ranking.

### `freetext-log.js` (new)

- `logFreeTextQuery(redis, text, meta = {})` — fire-and-forget; no-op when `!redis.isOpen` or `text` is blank. Builds `{ q: text.slice(0,80), ts: Date.now(), src: meta.src || 'chat', chip: meta.chip === true, m: meta.matchedKnownTerm || null, n: Number.isFinite(meta.resultCount) ? … : null }` and writes it to a global capped list `freetext:log` (`lPush` + `lTrim 0 4999` + `expire DAY_TTL_S`) **and** a per-day list `freetext:log:<YYYY-MM-DD>` (`rPush` + `expire DAY_TTL_S`). **No chatId / user identifier in the entry.** `DAY_TTL_S = 90 * 24 * 60 * 60` (v0.60.132 — was 30 d). `dumpFreeTextLog(redis, n = 50)` → `lRange freetext:log 0 n-1` parsed, newest first (`n` clamped 1–500). Swallows all errors.

## `cuisine-family.js` (new — v0.60.135; extended v0.60.136, v0.60.138)

- **Families**: `east-asian` / `southeast-asian` / `south-asian` / `european` / `middle-eastern` / `latin` / `american` / `african`.
- `RESTAURANT_TYPE_FAMILY` — Google Places (New) v1 *cuisine-specific* restaurant `primaryType` → family (`chinese_restaurant` → east-asian, `german_restaurant` → european, `mexican_restaurant` → latin, …). Non-cuisine types (`restaurant` / `cafe` / `bar` / `bakery` / `pizza_restaurant` / `seafood_restaurant` / `fine_dining_restaurant` / `meal_takeaway` / …) are deliberately absent → no family.
- `CUISINE_FAMILY_RULES` — `[needles[], family]` pairs; `cuisineFamily(name)` normalises (NFD + diacritic-strip + lowercase + `_-` → space) then returns the first matching needle's family (specific demonyms before broad umbrellas). `UMBRELLA_NO_FAMILY` (`fusion`/`modern`/`international`/`western`/`asian`/`continental`/`halal`/…) → null. So "European"/"Czech"/"Slavic"/"German" → european; "Cantonese"/"Sichuanese"/"Japanese" → east-asian; "Thai"/"Peranakan" → southeast-asian; "Fusion"/"Western" → null.
- `restaurantFamily(primaryType)` → family|null; `cuisineFamily(cuisineName)` → family|null; `isLikelyMismatch(primaryType, cuisineName)` → true ONLY when both families are known and differ.
- `GENERIC_DISH_WORDS` (food-component nouns + prep/method words + search boilerplate); `distinctiveDishWords(dishPhrase)` → normalised tokens ≥ 3 chars not in `GENERIC_DISH_WORDS`; `FAMILY_DEMONYMS` (derived from `CUISINE_FAMILY_RULES`, ≥ 4 chars, dropping `"american (new)"`-style parentheticals); `familyDemonyms(family)` → array.
- `BAKERY_CAFE_DISH_WORDS` (quiche / tart / pie / pastry / croissant / scone / éclair / macaron / cake / cookie / brownie / bread / bagel / sandwich / panini / crepe / pancake / waffle / donut / pretzel / custard / flan / pudding / …) + `BAKERY_CAFE_VENUE_TYPES` (`bakery` / `cafe` / `coffee_shop` / `dessert_shop` / `dessert_restaurant` / `donut_shop` / `chocolate_shop` / `candy_store` / `confectionery` / `ice_cream_shop` / `tea_house` / `sandwich_shop` / `bagel_shop` / `breakfast_restaurant` / `brunch_restaurant` / `cat_cafe`) + `BAKERY_CAFE_NAME_WORDS` (strong bakery/patisserie name fragments — `bakery` / `bakeshop` / `bakehouse` / `patisserie` / `boulangerie` / `konditorei` / `pastry` / `cakery` / `confectionery` / … — NOT bare `cafe`). `looksLikeBakeryCafeDish(dishPhrase)` → bool.
- `venuePlausiblyServes(venue, { cuisineName, dishPhrase })` → bool. `fam = cuisineFamily(cuisineName)`; if `!fam` → `true` (don't demote umbrella/unknown). Else true iff: `name.includes(normalisedCuisineName)` (≥ 4 chars); OR any `distinctiveDishWords(dishPhrase)` token is in `name`; OR `restaurantFamily(venue.primaryType) === fam`; OR any `familyDemonyms(fam)` token (≥ 4 chars) is in `name`; OR (`looksLikeBakeryCafeDish(dishPhrase)` AND (`venue.primaryType ∈ BAKERY_CAFE_VENUE_TYPES` OR `name` carries a `BAKERY_CAFE_NAME_WORDS` fragment)). `name = norm(venue.name)` only — not the address (avoids false matches like "Singapore German Centre").

### `index.js handleSearchTurn` — single-query path (uses `cuisine-family.js`)

- After the resolver chain (R.E.D / technique short-circuit / Gemini intent — see "R.E.D ordering" below) and the nation-overlay / cooking-method checks, the single-query path: `searchVenuesByDish(intent.searchTerm, intent.cuisine||null, …)` → up to 6 venues; `dishPhraseForCard = cleanDishPhrase(intent.searchTerm || userText) || userText`; `plausible = (v) => venuePlausiblyServes(v, { cuisineName: intent.cuisine||null, dishPhrase: dishPhraseForCard })`; `aboveVenues = venues.filter(plausible)`, `belowVenues = venues.filter(v => !plausible(v))`; `ordered = [...above, ...below].slice(0,6)`; `aboveShown = min(aboveVenues.length, ordered.length)`, `belowShown = ordered.length - aboveShown`. Render each card via `formatTechniqueVenueBlock` (per-card `try/catch` → `N. **Name**\n📇 area` fallback) with `dishPhrase: i < aboveShown ? dishPhraseForCard : ''`. If `aboveShown > 0 && belowShown > 0` → insert `tn('freetext.divider', lang, { dish: esc(dishPhraseForCard) })` between the above-cards and below-cards in the `'\n\n\n'`-joined block. If `aboveShown === 0 && belowShown > 0` → prepend `tn('freetext.allBelow', lang, { dish: esc(dishPhraseForCard) })` and render all cards with no `dishPhrase`.
