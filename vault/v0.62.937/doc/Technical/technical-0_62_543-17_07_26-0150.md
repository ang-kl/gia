## 1. `web/_shared/lib/distance-rings.js` — the ring module

**Rule M-1 — one self-contained copy, both TMAs.** The ring layer lives in the `web/_shared/` package
(created in the PR-2 consolidation, #1546) with **no per-TMA imports**, so Hawker and Cuisine each import the
same file (`createRingLayer`, `mrtTwoStopRadius`, `mrtReachRadius`, `farthestResultDist`, `formatDist`). This
deliberately sidesteps the triplicated `mapOverlays.js` (the PR-6 target) — the ring feature never forks it.
Cross-root relative import resolves at Rollup build time (cuisine·v2 is one level deeper:
`../../../../_shared/lib/…`; hawker `../../../_shared/lib/…`).

**Rule M-2 — rings are Polyline circles, not `Circle`.** Google's `google.maps.Circle` strokes **solid only**;
to honour the dashed reference the rings are `Polyline` circles (72 segments) with a repeating dash `Symbol`
via `icons` (shared grey `#5f6368`, 2 px). Labels are `AdvancedMarkerElement` DOM pills placed on the ring
edge — one at due-north normally, **all four cardinal sides when `radiusM > 8000 m`** (`LARGE_RING_M`) so a
big ring's label is never off the visible arc.

**Rule M-3 — the "2 MRT stops" radius is computed, region-gated.** `mrtTwoStopRadius` reads the bundled
operational station list (`web/_shared/lib/mrt-stations.generated.js`, emitted alongside the Cuisine copy by
`scripts/gen-cuisine-stations.mjs`), finds the nearest station, steps ±2 in each line's operational order
(line code = `[A-Z]+` prefix + number), and returns the mean straight-line distance. `draw(centre, results,
isSG, unit)` gates on `isSG`: **SG** → computed 2-stop ring + a capped (~6-stop) reach ring beyond it;
**non-SG** → a fixed 2 km ring + a ring at the farthest result (`farthestResultDist`), drawn only when a
result lies outside 2 km. `isSG` comes from `MapPanel` as `(region||'SG')==='SG'` — region-gating (not just
the distance gate) closes the SG–JB-border case where a JB anchor within 2 km of an SG station would else
borrow a train ring.

**Rule M-4 — units follow the searched country, not the device.** `formatDist(m, unit)` renders `'km'`
(`###m` / `#.#km`) or `'mi'` (`###ft` below 0.1 mi, else `#.#mi`). `MapPanel.distanceUnit(region, countryPref)`
returns `'mi'` iff `countryPref ∈ {US, GB, MM, LR}` (road-distance imperial countries), else `'km'`; SG is
always km. `countryPref` is threaded from `App` `state.countryPref` (the resolved anchor country) — the unit
tracks the place being searched, so Brisbane reads km and a US search reads miles. The imperial set is a
single `const` (Register O-53 — tunable).

**Rule M-5 — non-SG ring 3 auto-frame.** On a **new** result set, for non-SG with a ring 3
(`farthestResultDist(anchor, venues) > 2000`), `MapPanel.syncMarkers` `fitBounds` to the ring's extent
(anchor ± farthest in the 4 cardinal directions, 40 px pad) instead of the centroid/z12 frame, so all three
rings are visible; SG and the no-ring-3 case keep the centroid/z12 frame. A manual zoom-in can still crop it.

## 2. Cuisine map pin colours

**Pin colour = `MapPanel.pinColor(v)`**, precedence availability/urgency before prestige:
`openNow === false` → grey `#8E8E93`; else `closingSoonMinutes` 0–60 → pink `#DB2777`; else `michelinCategory`
→ red `#C6282D`; else green `#34C759`. `cuisinePinNode(number, background)` takes the colour; the droplet
shape/size are unchanged. Precedence is Register O-52 (flippable if Michelin red should win).
