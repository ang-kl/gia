## 0. Product overview

Soleat (*Gia4lunch* / "Gia") is a Singapore-focused dining + logistics assistant delivered as a Telegram bot, five Telegram Mini Apps (TMAs), and an Express server. A solo diner can discover where to eat — by cuisine, by dish, by cooking technique, by Michelin / Bib Gourmand recognition, or as a hidden gem — and then handle the practicalities: transport, carparks, weather. The whole interface is bilingual (English / French).

Features are grouped below into seven areas. §1 is the at-a-glance catalogue; §2 gives per-area detail.

## 2. Per-Feature Detail

### Feature A — Cuisine discovery (`/cuisine`, Cuisine TMA v2)

- **Surface:** `/cuisine` / `/c` slash command → Cuisine TMA (Vite + React 18).
- **Behaviour:** the user picks one or more cuisines (55+, organised SG / SE-Asian / East-Asian / China-regional / European / etc.), optionally applies quick filters (Halal, open-now, crowd, 🐾 Pet allowed, price tier, ♿️ accessibility), sets a location (current pin or typed place), and searches. Results render as venue cards on a list + an interactive Google Map with emoji pins. A client-side page-history (`⇠ Back` / `⇢ Next` FABs, ~17 pages of ~12 venues) lets the user scrub previous result sets without a server round-trip. Zero results trigger one silent auto-retry, then a `🔄 Reset filters & retry` CTA.
- **Region modes:** Singapore (20 km default radius, near-me focus) and Johor Bahru (30 km, whole-Johor-state geo-fence). Slider max 100 km.
- **Venue card:** name, cuisine-type label, area, hours, rating + crowd, price range (country-currency prefix + cross-border FX), 🐾 pet line, travel time, Maps link, Michelin / Bib Gourmand badge, and a Sanctuary read (`🌿 Quiet:` / `🌿 Seating:`).
- **Outputs:** in-app cards + map; `📋 Copy` (one venue) and `📋 Copy all` resend the picks into the Telegram chat as formatted messages.
- **Failure modes:** zero results → auto-retry + CTA; HTML send failure → plain-text retry; one malformed venue → name-only fallback card.
- **Cost:** ~15 Places `searchText` validates per search (capped); cached 30 s per criteria signature.

### Feature B — Free-text & cooking-method search (`/s`, free-text chat)

- **Surface:** `/s` slash command + plain free-text messages.
- **Behaviour:** the query is classified (dish / ingredient / cooking-tool-technique / cuisine / ambiguous) — deterministic dictionaries first, then a Gemini intent classifier. A dish resolves to a venue fan-out; a cooking technique resolves to a curated cuisine + a Gemini one-line explainer + a representative dish, rendered with a country flag and a "These places may have it. Please verify." caveat. `/s` also offers a guided **assistance sub-menu** (Authentic Dishes by cuisine + dish-type, and Others) for users who don't know what to type.
- **The "Try" line:** every recommendation line carries only a genuine dish/dessert name — never a generic category word — enforced by the shared `dish-name.js` guard; omitted when no real dish is known.
- **Outputs:** ranked venue cards (above/below a plausibility divider), each with the Sanctuary read + travel + Maps.
- **Failure modes:** no results → bilingual "try another dish" message; every render path wrapped so `/s` never goes silent.

### Feature C — Recognised venues (`/recognised`, Michelin chip)

- **Surface:** `/recognised` + a Cuisine TMA chip (SG-flag labelled; disabled in JB mode).
- **Behaviour:** searches the curated `michelin-2025.js` 130-entry Singapore Guide (3-star → 2-star → 1-star → Bib Gourmand), plus Asia 50/100 and Local-Produce lists. A criteria-scoped walk-through pages the curated pool 12 at a time; the seen-set self-resets on a filter change or after 1 h idle. Each entry is enriched (review extract, vibe, signature dish) and cross-referenced for the `✳️ Michelin · ⭐ · 2025` badge.
- **Cost-aware:** top-12-fresh per tap; per-entry 7-day enrichment cache.

### Feature D — Hidden gems (`/hidden`)

- **Surface:** `/hidden` (optionally with a free-text location).
- **Behaviour:** a Gemini grounded-search call proposes lesser-known venues near the anchor; the server verifies each against Google Places (live business status, real rating, haversine distance) and rewrites the card with corrected figures, dropping hallucinated or out-of-band venues. The "🍴 Try ·" line is filtered through the dish-name guard.
- **Failure modes:** all-dropped → a non-empty fallback message; model outage → graceful "try again".

### Feature E — Hawker centres (`/hawker`, Hawker TMA)

- **Surface:** `/hawker` → Hawker TMA.
- **Behaviour:** 100+ Singapore hawker centres (2025 dataset) on a map + list, with stall counts, status (operating / new / under-construction / proposed), and an InfoWindow per centre.

### Feature F — Transport, carpark & weather

- **`/transport` + Train TMA** — live MRT/LRT service status (LTA TrainServiceAlerts), an affected-lines ticker, a station map (toggle between a schematic PNG and an interactive Google Map of ~206 stations with line-coloured pins), engineering-closure schedule, and a you-are-here / nearest-station card. Future stations render greyed with an opening date.
- **`/carpark`** — the nearest five carparks with live availability (HDB / LTA).
- **`/weather`** — current conditions + the NEA 2-hour forecast.

### Feature G — Menu & utility

- **Menu TMA** — the app launcher / hub.
- **`/l` / `/location`** — share or set the current location, with a confirmation echo of the reverse-geocoded address.
- **`/clipboard`, `/share`, `/picks`** — copy / share / recall recent venue picks (share tokens, 7-day TTL).
- **`/legal`, `/privacy`** — operator-curated legal + privacy disclosures (EN/FR; see `doc/Legal/…`).
- **`/forgetme`** — immediate erasure of stored user data.
- **`/start`, `/language`** — onboarding intro + EN/FR locale toggle.
- **Owner-only (hidden, behind `isOwnerChat`, not in `setMyCommands`):** `/oversight` (+ Oversight TMA), `/ver`, `/ftlog` — diagnostics and version/health.
