### 2. Radial expansion (supersedes v0.8.1 fail-fast)

`pickValidated` now retries the first Gemini candidate at progressively larger radii: **200 m → 500 m → 1000 m**. The first radius at which the candidate validates becomes the "active radius"; subsequent candidates 2–N use that same radius to fill up to 3 picks. If all three radii fail, returns zero — caller falls through to Hidden Sanctuary then `handleNoResults`.

This is a **deliberate supersession** of the v0.8.1 fail-fast policy. Human Lead's latest spec explicitly requires retry expansion; the prior "max retry 1, no re-polling" decision is now superseded with full audit trail in the Deprecated table.

### 3. Hidden Sanctuary keyword sharpening

`consultant.js geminiSanctuaryRead` prompt updated to explicitly enumerate the keywords: **quiet, coffee, sanctuary, solo-friendly, calm, peaceful, study, work, single-seat, bar-seat, comfortable for one**. Gemini still returns structured JSON `{is_sanctuary, reason}`, but the reason should now anchor on these specific signals.

### 4. Afternoon snack scope

| Afternoon (15:00–16:59) | "desserts, cafés, coffee, tea spots" | "cafés, bakeries, **tea houses**, coffee bars, dessert spots" |

| | `restaurant, cafe, bar, bakery, food_court, meal_takeaway, point_of_interest` | `restaurant, cafe, **coffee_shop**, **tea_house**, bar, bakery, food_court, meal_takeaway` |

`point_of_interest` removed (too broad — was matching ATMs and bus stops). `coffee_shop` and `tea_house` added (real Places New types).

### 5. Vault 50 m fuzzy buffer

`vault.js queryVault` now adds a 50 m buffer to whatever radius is requested (`effectiveRadius = radiusM + 50`). At the default 300 m runtime call from `runFlow`, the underlying GEOSEARCH covers 350 m — handles GPS / coord drift between live tap and stored Vault entry.

### 6. `sync-vault.js` HTML-input mode

The importer now resolves its input list in priority order:

1. CLI flag `--html=<path>` — parse with cheerio for `<a href>` tags matching `maps.app.goo.gl`, `goo.gl/maps`, `(www.)?google.*/maps/`, or `maps.google.*`.
2. Auto-detect `data/Saved Places.html` — if it exists, parse same way.
3. Hardcoded URL list (the original 14 from the Architectural Spec) — fallback when no HTML present.

Cheerio added as a dependency. The hardcoded fallback ensures backward compatibility with existing run patterns.
