## 0. Product overview

Soleat (*Gia4lunch* / "Gia") is a Singapore-focused dining + logistics assistant delivered as a Telegram bot, five Telegram Mini Apps (TMAs), and an Express server. A solo diner can discover where to eat — by cuisine, by dish, by cooking technique, by Michelin / Bib Gourmand recognition, or as a hidden gem — and then handle the practicalities: transport, carparks, weather, and an interactive map of the surroundings. The interface is bilingual (English / French).

§1 is the at-a-glance catalogue; §2 gives per-area detail; §3 summarises the v0.61 arc.

## 2. Per-Feature Detail

### Feature A — Cuisine discovery (`/cuisine`, Cuisine TMA)

The user picks one or more cuisines (55+), optionally applies quick filters (Halal, open-now, crowd, 🐾 Pet allowed, price tier, ♿️ accessibility), sets a location (current pin or an editable typed place), and searches. Results render as venue cards on a list + an interactive Google Map with emoji pins. A client-side page-history (`⇠ Back` / `⇢ Next` FABs) scrubs previous result sets without a server round-trip. Zero results trigger one silent auto-retry, then a `🔄 Reset filters & retry` CTA. Region modes: Singapore (20 km default) and Johor Bahru (30 km, whole-state geo-fence). The venue card carries name, cuisine label, area, hours, rating + crowd, country-currency price (+ FX), 🐾 line, travel time, Maps link, Michelin badge, and the Sanctuary read.

### Feature B — Free-text & cooking-method search (`/s`, free-text chat)

The query is classified (dish / ingredient / cooking-technique / cuisine / ambiguous) — deterministic dictionaries first, then a Gemini intent classifier. A dish resolves to a venue fan-out; a cooking technique resolves to a curated cuisine + a Gemini explainer + a representative dish, rendered with a country flag and a "verify" caveat. `/s` offers a guided assistance sub-menu. Every "Try" line carries only a genuine dish name (the `dish-name.js` guard).

### Feature C — Recognised venues (`/recognised`, Michelin chip)

Searches the curated `michelin-2025.js` Singapore Guide (3-star → Bib Gourmand) plus Asia 50/100 and Local-Produce lists. A criteria-scoped walk-through pages the curated pool 12 at a time; the seen-set self-resets on a filter change or after 1 h idle. Each entry is enriched and badged `✳️ Michelin · ⭐ · 2025`.

### Feature D — Hidden gems (`/hidden`)

A Gemini grounded-search call proposes lesser-known venues near the anchor; the server verifies each against Google Places (live status, real rating, distance) and rewrites the card, dropping hallucinated or out-of-band venues.

### Feature E — Hawker centres (`/hawker`, Hawker TMA)

100+ Singapore hawker centres (2025 dataset) on a map + list, with stall counts, status, and an InfoWindow per centre. Each centre carries nearby-transit enrichment (nearest MRT station + nearby bus stops) and surrounding amenity pins via the shared overlay controller.

### Feature F — Transport, carpark & weather

- **`/transport` / `/train` + Transport TMA** — live MRT/LRT service status (LTA TrainServiceAlerts), an affected-lines ticker, an engineering-closure schedule, a you-are-here card listing the nearest 3 stations. Each nearest-station row shows the actual **station code** (e.g. `🟥 NS21 · 🟦 DT11 Newton`), coloured by line. The Transport TMA station map toggles between a schematic PNG and an interactive Google Map of ~206 stations.
- **`/carpark`** — the nearest five carparks with live availability.
- **`/weather`** — current conditions + the NEA 2-hour forecast.

### Feature G — Interactive map overlays (Cuisine / Hawker / Transport TMA maps)

The three map-bearing TMAs share one overlay controller (`mapOverlays.js`):

- **Overlay chip layers** — a chip strip toggles parks, attractions, carpark, exits, taxis, and (where applicable) the train-line layer. Point layers clip to a fixed radius around the map anchor.
- **Train-station-detail view** — tapping a train-overlay station marker enters a focus mode showing that station plus its line-neighbours one stop before/after; the Exits and Taxis chips then scope to those three stations, showing their exits / taxi stands + pick-up points.
- **Exit pins + Exit Template** — MRT/LRT exit pins show the exit letter/number as a pill coloured by the station's line. Tapping one opens the Exit Template popup: a line-coloured exit-code header, the station name, colour-coded station-code pills, and a 🎡 line of nearby named attractions.
- **Amenity pins** — venue / hawker-centre taps draw surrounding amenity pins (exits, bus stops with live arrivals, taxi stands, carparks) via the shared `attachAmenityPins` helper.
- **Map chrome** — theme-aware popup cards (light/dark via the Telegram colour scheme), an in-card ✕ close, a compact zoom row, an Overview viewport toggle.

### Feature H — Menu & utility

The Menu TMA is the app launcher. `/l` shares/sets location with a reverse-geocoded confirmation echo; `/clipboard` `/share` `/picks` copy/share/recall recent picks; `/legal` `/privacy` carry operator-curated disclosures; `/forgetme` erases stored data; `/start` `/language` onboard + toggle locale.

### Feature I — Owner / builder tools (hidden)

Behind `isOwnerChat`, off `setMyCommands`: `/v` opens an inline-keyboard builder menu firing the other hidden commands — `/ver` (health check), `/oversight` (Oversight TMA launcher), `/ftlog` (free-text-log dump), `/log on|off` (verbose logging).
