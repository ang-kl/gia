## §0.8.0 NEW CONTENT

### Walking-minute re-rank via Distance Matrix

Picks for `/eat /drink /groceries` are now **ranked by actual walking time** from the user's chosen centre (shared GPS, typed-place geocode, or Raffles default), not by Gemini's suggestion order or by straight-line distance.

| Surface | Before (v0.7.0) | After (v0.8.0) |
| :--- | :--- | :--- |
| Pick order | Gemini suggestion order, filtered by 200 m straight-line gate | **Ascending walking minutes** from origin |
| Header line | `1. <Name> ⭐4.4 · Open now` | `1. <Name> ⭐4.4 · Open now · 4 min walk` |
| API used | Places `searchText` only | Places `searchText` + Routes API `computeRouteMatrix` (mode `WALK`) |

If the Routes API call fails or `GOOGLE_MAPS_API_KEY` is missing, the function falls through silently — picks render in their pre-rank order without a walk-minute annotation. No regressions.
