- **[INTENT].** Make the focused (centered) horizontal result card show its **name** again — it was
  rendering white-on-white.

- **[NOT FROM THE RING PRs].** Verified against the diffs: #1548 / #1549 touched only `MapPanel.jsx` +
  the shared ring helper. The result card (`ResultCard.jsx`) was last changed in #1522 (v0.62.516); the
  bug itself dates to **v0.62.285** (when the focused card gained its forced-white background).

- **[ROOT CAUSE].** The app root (`App.jsx:3528`) sets `color: var(--tg-text)`, computed in the **dark**
  theme as light (`#f5f5f7`). The name row (`ResultCard.jsx:356`) had **no** text-colour class, so it
  merely *inherited* that already-computed light colour. In the horizontal strip the **focused** card is
  forced `bg-white` with a **local** `--tg-text: #1c1c1f` override — but a row that doesn't itself
  declare `color: var(--tg-text)` never re-resolves the local override → **light text on the white card
  = invisible**. Every other card-face row uses a `text-tg-*` class, so it re-resolves the var at the
  element and flips dark — which is exactly why *only* the name row vanished on *every* centered card.

    the focused card). Safe everywhere else: outside the focused card, `text-tg-text` resolves to the
