# Journal — soleat v0.62.517 (Sketchbook: free-text search FAB — TellMePanel verbatim port)

> Operator task **E**: *"Sketchbook free-text search FAB (port TellMePanel)."* Ports the Cuisine
> TMA's free-text composer (the 💬 → pill + 🔍 search bar) into the Sketchbook (clipboard) TMA as
> a floating FAB. As with the QuickFilters port (#1522), the LAYOUT is verbatim but the LOGIC is
> saved-card-based: Sketchbook has no server search, so the committed text narrows the **saved
> cards** client-side. The composer's COPY is honest to that — "Search saved cards…", not Cuisine's
> "What are you craving?" (which promises discovering *new* places).
