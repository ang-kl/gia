  **Accessibility specifics**:
  - Semantic landmarks: `<header role="banner">`, `<nav aria-label="Primary">`, `<main id="main">`, `<section aria-labelledby="…">`, `<article>`, `<footer>`. Each section has a referenced heading.
  - `lang="en"` on `<html>`, `<meta name="theme-color">` for both light + dark schemes.
  - `:focus-visible` global outline (3 px accent, 2 px offset).
  - Contrast ratios verified: `--fg`/`--bg` 16.5:1 (AAA), `--fg-muted`/`--bg` 7.0:1 (AAA), `--accent`/`--bg` 4.6:1 (AA normal / AAA large), `--accent-fg`/`--accent` 7.8:1 (AAA).
  - Touch targets: all interactive elements ≥ 44 × 44 px (nav links 44 px min-height; primary CTAs 48 px).
  - `prefers-reduced-motion: reduce` disables scroll-smooth + reveal animations.
  - `prefers-color-scheme: dark` flips the full token set (HSL-based for mechanical inversion).
  - Reveal-on-scroll uses `IntersectionObserver` with a graceful no-op fallback (instant-visible class) if the API or reduced-motion is detected.
  - No external CDN / no webfont (system stack: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, …`).
  - Inline SVG favicon (no extra request).
  - Print stylesheet strips chrome + keeps substance.

  **Performance**:
  - One request (HTML/CSS/JS all inline).
  - Page weight: ~14 KB ungzipped, ~5 KB gzipped.
  - Zero JS dependencies. Total inline JS: ~25 lines (year stamp + IntersectionObserver reveal).
