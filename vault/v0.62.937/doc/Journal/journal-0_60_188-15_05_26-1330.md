## New

### [HDR] #155 | 13:30:00 SGT 15-05-26 | v0.60.188 — Cuisine TMA: <12-result refresh hint + price-tier chips inline (no popover-in-popover) | 4 files, ~50 LOC | 1 PR |

- **[INTENT]**
  - **Item A**: When a search returns 1–11 venues, the seen-set has eaten into the next batch's headroom but the existing v0.60.115/117 exhausted-note path only fires at ≤2 venues. Add a hint above the result list when count `> 0 && < 12` AND `!exhaustedNote`: *"N result(s) for these criteria. Tap 🔍 to refresh results with same criteria."* The next 🔍 tap auto-arms `resetSeen: true` so the server wipes the per-criteria seen-set and the user gets a fresh first ~12 with the same criteria. Operator reported the existing refresh "didn't work" — root cause was that a normal 🔍 tap (without ↺ Start over) didn't pass resetSeen, so the dwindling seen-set kept the rotation stuck.
  - **Item B**: The `💲 Price ▾` chip in the overflow popover (v0.60.182) was unclickable because its `openPrice()` handler called `setFiltersOpen(false)` — which closes the **parent** overflow popover that **contains** the chip. Tap → parent collapses → chip disappears before its own state-change paints. Replace the dropdown with three direct toggle chips (`$`, `$$`, `$$$`) inline alongside the other overflow filters — no popover-in-popover, each tier toggles immediately on tap.
