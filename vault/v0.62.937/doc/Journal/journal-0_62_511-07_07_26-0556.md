## New

### [HDR] #867 | 05:56 SGT 07-07-26 | v0.62.511 — bot i18n 8-lang + Clipboard LocaleToggle | 4 files + 1 new | PR #(pending) |

- **[INTENT].** Operator: *"1, 2"* — (1) expand bot-side i18n to all 8 TMA locales, (2) add
  a locale toggle to the Clipboard TMA.

- **[CHANGE 1 — bot i18n.js].** `SUPPORTED` was `['en', 'fr']`; expanded to all 8
  (`en fr id ru de zh ja es`). The `t()` function already has `entry[l] || entry.en` fallback,
  so any string without a native translation silently returns English — **zero regression risk**.
  Added native translations for the 3 `/language` UI strings that users see when running the
  `/language` command: `language.current`, `language.cleared`, `language.fromTg` for
  id/ru/de/zh/ja/es. The `bot.lang.set.*` ack strings and `language.btn.*` button labels already
  existed for all 8 langs (v0.62.480). All other bot-chrome strings (open hours, crowd labels,
  venue templates) remain EN/FR only and fall back to EN.

    `web/menu/src/i18n.js`). Was missing; Clipboard could **read** the shared `gia.locale` pref
    but not **write** it (no toggle, no POST to `/api/cuisine/user-language`).

    header row between the brand title and the refresh button.
