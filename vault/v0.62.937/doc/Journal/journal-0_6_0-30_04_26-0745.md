## New

### [HDR] #9 | 07:45:00 SGT 30-04-26 | v0.6.0 | n/a kb | n/a lines
- **[INTENT]** Tranche A of the `instruction/02_Expand.MD` spec: brand rename to **soleat** (Gia persona voice retained), new `/drink` and `/groceries` commands, Topic Gatekeeper for free-text messages, walking radius 300 m, last-30-day review filter. Tranche B (Redis Vault, /BusArrivalv2, MRT-stop expansion) remains blocked on data inputs.
- **[DELTA]**
  - **`gatekeeper.js`** (new) — Gemini structured-JSON classifier. `gatekeep(redis, text)` → `{intent, reply}`. SHA-256 message hash (24 hex) cache for 60 s. Off-topic prompts get the Gia persona steer-back.
  - **`index.js`** —
    - + `bot.on('message')` gatekeeper handler at end of chain. Filters: ignores commands (`/`-prefixed or `bot_command` entity), keyboard texts (`'📍 Share my location'`, `'⛔ Use Raffles Place default'`), empty messages, and non-text updates.
    - + `bot.onText(/^\/drink…/)` and `bot.onText(/^\/groceries…/)` handlers wired to `startSanctuaryFlow(chatId, category, prompt)`.
    - `runEatFlow` → `runFlow(chatId, lat, lng, category)` generalised across categories. Seed fallback only loaded for `food`.
    - Default-button handler (`⛔ Use Raffles Place default`) now reads the pending category from Redis (was hard-coded to meal time).
    - Location handler reads pending category and routes to the right `runFlow`.
    - `setMyCommands` updated to include `eat`, `drink`, `groceries`, `status`. Menu button text "🌿 Gia Map" → "🌿 soleat Map". Boot banner "Gia4lunch" → "soleat".
  - **`vibe-suggest.js`** —
    - + `CATEGORIES` map for `food / drink / groceries`.
    - `pickValidated(...)` now accepts `opts.category`; non-food categories override `mealPeriodSGT()` with a category hint.
    - `SEARCH_RADIUS_M` 800 → 300 m per spec §3.1.
  - **`vibe-summary.js`** —
    - + `isRecentReview(review, now)` 30-day filter.
    - `fetchReviewText` filters by `publishTime` before sending to Gemini; falls back to the full pool if zero recent reviews are present.
  - **`package.json`** — `name` → `'soleat'`, `version` → `'0.6.0'`.
  - **`README.md`** — header, body sentence, banner snippet, footer ownership line all reflect the rename.
- **[RISK]** Med —
  - **G4 cost.** Free-text messages now trigger 1 Gemini call (cached 60 s by message hash). At single-user scale this is single-digit calls per day; at scale-out we'd want either a smarter cache or a regex-prefilter.
  - **Gatekeeper false positives.** Some short messages may classify as `off-topic` when they were a typo of a slash command (e.g. "eat" without the slash). Mitigation: the Gia persona reply still surfaces the menu, so the user sees the recovery path immediately.
  - **300 m radius reduces candidate count** in less dense areas. The seed-fallback path remains for sub-3 returns; expanding back to 500 m is a one-line change if results drop too low in practice.
- **[STATUS]** PROD — auto-deploys with the next Railway build.
- **[TEST]** Manual:
  1. Send a non-command message like "what should I eat?" → bot replies suggesting `/eat`.
  2. Send "hello" → warm greeting + menu.
  3. Send "what's the weather?" → off-topic steer-back.
  4. `/drink` → location share → 3 bar/coffee picks within 300 m of you.
  5. `/groceries` → location share → 3 supermarket/grocery picks within 300 m.
  6. `/eat` still works.
  7. Identical free-text message twice in 60 s → cached reply (logs show only one Gemini call in `[Gatekeeper]`).
- **[NEXT]** Tranche B —
  1. Redis Vault: import the curated 200+ locations (CSV/KML) the spec §5 references. Need source file from Human Lead.
  2. `/BusArrivalv2`: product call needed on UX path (nearest stop vs. user-shared bus stop code).
  3. `getTransitContext()` and "1 MRT stop away" expansion: needs MRT station coords dataset.
- **[ADVICE]** The Gatekeeper is the right shape for "warm-conversational" assistants but its cost grows with chat volume, not user count. The 60-second hash cache is cheap insurance; consider extending to 5 min if cost becomes a concern.
