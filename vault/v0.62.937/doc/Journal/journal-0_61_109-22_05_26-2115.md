## New

### [HDR] #309 | 21:15 SGT 22-05-26 | v0.61.109 — attraction enrichment + zoom doc | ~14 kb | 10 files | 1 PR | 1 build |

- **[INTENT]** (1) Document the Google-Maps zoom / overlay / pin
  behaviour across every embedded map surface in a `/UI` reference
  doc. (2) The STB tourist-attraction map popup was bare — only name,
  address, opening-hours prose, website and one nearest station. Add a
  scrape/enrichment pipeline so attractions gain star rating, contact,
  structured hours, a wheelchair flag, an Instagram link and the
  nearest two stations.

- **[DELTA]**
  - **`UI/Map_Zoom_Effects.MD`** (new) — reference doc: the shared
    zoom-tier algorithm (`trainTier` / `busTier` / `carparkSize` /
    `amenityTier` + `demoteByOverlap`), per-surface tables (buttons +
    dropdown, zoom levels, in-view vs not-in-view, pin clicks,
    search-criteria interaction) for Cuisine / Hawker / Transport-MRT /
    `/app/map`, and a summary matrix. Records that there are **4**
    interactive Google-Maps surfaces (+1 static `SystemMap`), not 8 —
    Menu and Oversight have no map.
  - **`scripts/fetch-attraction-details.js`** (new) — one Google Places
    (New) `searchText` call per attraction → rating + `userRatingCount`,
    `nationalPhoneNumber`, `regularOpeningHours.weekdayDescriptions`,
    `websiteUri`, `accessibilityOptions.wheelchairAccessibleEntrance`;
    then GETs each attraction's website and regexes for an
    `instagram.com/<handle>` profile link (reserved paths filtered).
    Writes a name-keyed `data/attraction-details.json`. Idempotent +
    resumable; mirrors `fetch-hospitals.js`. Needs `GOOGLE_MAPS_API_KEY`
    (~109 calls, <US$2).
  - **`data/attraction-details.json`** (new) — committed as an empty
    `{ details:{} }` scaffold; populated when the operator runs the
    fetcher.
  - **`scripts/build-geo-overlays.js`** — new `nearestStations(lat,lng,n)`;
    the attractions block now emits `stations` (nearest **two**, each
    with exits) instead of a single `station`, and does an **optional
    join** against `attraction-details.json` (`loadAttractionDetails`)
    merging rating / ratingCount / phone / hoursWeek / wheelchair /
    instagram when present — graceful when the file is absent/empty.
  - **`data/geo-attractions.json`** — regenerated by `build:geo`
    (`station` → `stations[2]`; the 8 other geo-*.json files were
    reverted — their only diff was the `_meta.lastUpdated` stamp).
  - **`attractionInfo` popup** — rewritten in
    `web/cuisine/src/v2/lib/mapOverlays.js`, copied byte-identical to
    the hawker + transport copies; and `attractionInfoHtml` added to
    `public/app.js` for the `/app/map` attraction popup. Renders
    ⭐ rating, 📇 address, 🕰 today's hours (structured Places week,
    STB prose fallback), ☎ contact, ♿ wheelchair line (only when
    Places reports an accessible entrance — minimal per operator),
    🚉 the nearest two stations + exits, 🌐 website, 📷 Instagram.
  - **`package.json`** — `0.61.107` → `0.61.109` (PATCH). `0.61.108`
    is PR #601 (concurrent); this branch is off `main` at v0.61.107.
