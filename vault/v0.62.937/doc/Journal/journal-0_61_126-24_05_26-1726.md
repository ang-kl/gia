## New

### [HDR] #327 | 17:26 SGT 24-05-26 | v0.61.126 — Fruits + Durian exclusive special modes (new module + drawer wiring + server override + 35-spec test file) | ~18 kb | 10 files | 1 PR | 1 build |

- **[INTENT]** Add two exclusive toggle modes to the Cuisine TMA:
  Fruits (fruit shops / juice stalls / fresh-fruit markets) and
  Durian (durian sellers / specialist shops / delivery). Per spec:
  mutually exclusive, grey out normal cuisine + Michelin + dessert
  filters when active, search seeds are mode-specific (no normal
  cuisine modifiers appended), results are post-filtered by mode
  keywords (English + Malay + Chinese), do NOT pad weak results
  with unrelated cuisines.

- **[DELTA]**
  - **`+ special-mode.js`** (~150 lines, new module) — single source
    of truth:
      - `SPECIAL_MODES` constants (FRUITS / DURIAN), `isSpecialMode`
        guard.
      - `SEED_TEMPLATES` per mode (fruit shop / fresh fruit stall /
        fruit juice stall / fresh fruit market / fruit seller; durian
        shop / stall / seller / delivery / specialist).
      - `KEYWORDS` per mode — English + variety names + Malay
        (`buah`, `jus buah`, `pasar buah`) + Chinese (`水果`, `果汁`,
        `榴莲`, `猫山王`, `红虾`).
      - `REJECT_PRIMARY_TYPES` per mode — Fruits rejects
        `meal_takeaway` (juice stalls are dine-in/counter); Durian
        keeps it (sellers commonly use it).
      - `buildSeeds(mode, { regionSuffix })` — region-suffixed seeds
        (`Singapore` / `Johor Bahru Malaysia` / `Putrajaya Malaysia`).
      - `filterByMode(venues, mode)` — drops anything without a mode
        keyword in name + area + primaryType + editorial summary +
        reviews, AND anything in the reject types list.
      - `isRelevant(venue, mode)` exposed for direct use.
  - **`+ __tests__/special-mode.test.js`** — 6 describes / 35 specs:
    mode guard, seeds suffix swap (SG / JB / Putrajaya), accept/reject
    (fruits + durian), filterByMode order preservation + null
    handling, multi-language signal matching, type rejection
    invariants.
  - **`index.js`** (`/api/cuisine/search`) —
      - Reads new `req.body.specialMode` (validated to `'fruits'` /
        `'durian'` / null).
      - `cuisineQueries` override when set — calls `sm.buildSeeds(mode,
        { regionSuffix: region === 'JB' ? 'Johor Bahru Malaysia' : 'Singapore' })`.
        Logs D778.
      - Short-circuits home-based + Tell-me qualifier + dessert
        detection blocks (`if (… && !specialMode)`).
      - Post-filter via `sm.filterByMode` after the existing
        `venueFilters.passesVenueFilter` pass. Logs D779.
      - Response payload echoes `specialMode` + sets
        `specialModeLimited: true` when `dedupedTop.length < 8`
        (the spec's "8-12 relevant" target).
  - **`web/cuisine/src/v2/lib/state.js`** — `defaultState` gains
    `specialMode: null`; carried through `clearAll`'s spread so the
    Clear / Reset button wipes it.
  - **`web/cuisine/src/v2/lib/api.js`** — `searchCuisine` accepts +
    forwards `specialMode`.
  - **`web/cuisine/src/v2/lib/i18n.js`** — 5 new keys (en+fr):
    `special.fruits.label`, `special.durian.label`,
    `special.activeNote` ({mode} interpolation),
    `special.fruits.limited`, `special.durian.limited`.
  - **`web/cuisine/src/v2/components/CuisineDrawer.jsx`** —
    new props `specialMode` + `onSpecialModeChange`. Two amber-
    bordered pill buttons above the catalogue grid (active state =
    `bg-tg-accent`, inactive = `border-amber-500/60`).
    `setSpecial(next)` toggles off if active, switches if other is
    active, wipes selected[] on activation (so chip badge doesn't
    ghost). Catalogue grid wrapped in `opacity-40
    pointer-events-none` when special mode is set. Italic
    activeNote line below the special row.
  - **`web/cuisine/src/v2/components/QuickFilters.jsx`** — new
    `specialModeActive` prop. When true the chip row +
    Filters popover go opacity-40 + pointer-events-none; toggle() +
    togglePrice() short-circuit defensively.
  - **`web/cuisine/src/v2/App.jsx`** — wires `state.specialMode` +
    setter to `CuisineDrawer`; passes `!!state.specialMode` to
    `QuickFilters`; forwards `specialMode` to `searchCuisine`. New
    `specialModeNotice` state populated from `r.specialMode` +
    `r.specialModeLimited`; renders the "🍉/🥥 Limited matches
    nearby" amber card between the misrep note and the
    cooking-method pivot.
  - **`package.json`** — `0.61.125 → 0.61.126`.
