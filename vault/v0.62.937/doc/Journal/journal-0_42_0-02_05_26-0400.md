### [HDR] #86 | 04:00:00 SGT 02-05-26 | v0.42.0 | n/a kb | n/a lines

- **[INTENT]** Operational hygiene release — close the four reliability gaps surfaced in the infrastructure audit (no tests, no CI, no structured logs, no error tracking). Invisible to end users, visible to the operator. Foundation for v0.43.0+ feature work.

- **[DESIGN]**

  1. **Vitest + 80 unit tests across 7 files**:
     - `__tests__/llm-client.test.js` — 13 tests: stripJsonFences fence/preamble/empty/null edges, DEFAULT_MODEL = `claude-sonnet-4-6` invariant, isReady() guard.
     - `__tests__/gemini-retry.test.js` — 11 tests: isRetryable for 408/429/500/502/503/504/529 + 400/401/403/404/422 + Anthropic.RateLimitError class + ECONNRESET; withRetry first-success / second-success / no-retry-on-400 / exhaust paths; makeFlashFallback no-op invariant.
     - `__tests__/pipeline-extract.test.js` — 9 tests: extractJsonArray on clean / fenced / object-wrapped {venues:[]} / {candidates:[]} / {results:[]} / prose-preamble / empty-null inputs.
     - `__tests__/pipeline-task-gates.test.js` — 13 tests: applySurpriseGates rating window 4.0-4.3, review-count <50, verifiedOpeningDate ≤90d soft gate, relaxed 180d override; applyTemporalGate day-mode (closesInHours ≥2) and night-mode (≥4 OR opens within 12h) with mocked SGT clock.
     - `__tests__/response-cache.test.js` — 12 tests: buildKey determinism (cuisine sort, lowercase normalization, geohash bucket, mealPeriod partition, dow partition); get/set roundtrip via in-memory redis-stub; safe null on closed redis; refuses empty venues write.
     - `__tests__/cuisine-search-helpers.test.js` — 11 tests: isFastFoodChain regex coverage (McDonald's variants, KFC, Coffee Bean & Tea Leaf, Domino's etc.); SG-local chains preserved (Toast Box, Ya Kun, Killiney); regex \b boundary stops false positives; clamp bounds.
     - `__tests__/surprise-helpers.test.js` — 11 tests: haversine identity / known-distance Raffles→Tanjong Pagar / symmetry; priceLevelToInt enum coverage; extractJsonObject fence/preamble/null edges.
     - `__tests__/redis-stub.js` — in-memory Redis mock (~80 lines, no external deps). Surfaces: get/set with EX, del, incr/incrBy, hSet/hGet/hGetAll/hDel, sAdd/sMembers, expire, exists, ping, connect/quit, isOpen.
     - `vitest.config.js` — Node-only env, `__tests__/**/*.test.js` glob, redis-stub excluded from collection.
     - `__tests__/package.json` — `{ "type": "module", "private": true }` so test files can use ESM `import`/`createRequire` to load CommonJS source.

  2. **GitHub Actions CI** — `.github/workflows/ci.yml` with three jobs:
     - `syntax`: `find . -name '*.js' -print0 | xargs -0 -n1 node --check` (excludes node_modules + web/*/dist + __tests__).
     - `test`: `npm test` (vitest run).
     - `build`: full `npm install` (triggers postinstall TMA build).
     - Triggers: push to main, all PRs. **Informative, not gating** — Railway still auto-deploys on push to main; CI tells you whether the deploy will break before users notice.

  3. **`logger.js`** — pino structured logger.
     - Production: JSON to stdout (Railway captures).
     - Development: pretty-printed via pino-pretty (when installed).
     - `forRequest(reqId, extra)` returns a child logger with `{reqId}` baked in for correlation across pipeline stages.
     - Redaction list covers `apiKey`, `token`, `authorization`, plus the three critical env-var names so they never leak into structured payloads.

  4. **Pino adopted in v0.41.0 hot path** (scope-cut: full sweep deferred to v0.43.0):
     - `pipeline-task.js` — three catch blocks now emit `forRequest(reqId, {kind, path}).error({err}, 'task failed')` and capture to Sentry with reqId tag.
     - `response-cache.js` — `console.warn` → `logger.warn({err}, '...')`.
     - `gemini-retry.js` — three console.warn/error sites → structured logger with `{label, attempt, total, waitMs, err}`.

  5. **`sentry.js`** — error tracking init.
     - `init()` reads `SENTRY_DSN`; no-op if unset (CI / dev / opt-out).
     - `captureWithReqId(err, reqId, extra)` tags scope with reqId and a sha256(chatId).slice(0,12) hash. **No PII**: no prompt content, no user names, no precise GPS beyond geoBucket precision.
     - `beforeSend` drops noise: `ETELEGRAM: 429`, `ETELEGRAM: 502`, `EFATAL.*AggregateError` polling-error storms.
     - Wired into `index.js` via `process.on('uncaughtException')` and `process.on('unhandledRejection')`. Pipeline-task catches forward errors via `captureWithReqId`. Bot polling/webhook error hooks deferred to v0.42.1 (B3).
