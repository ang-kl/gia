## New

### [HDR] #17 | 09:45:00 SGT 30-04-26 | v0.12.0 | n/a kb | n/a lines
- **[INTENT]** Per Human Lead instruction: `/ver` command to check the bot version and probe whether each upstream API is reachable from the deployed bot.
- **[DELTA]**
  - **`ver.js`** (new) — `runHealthCheck(bot, redis)` runs six probes in parallel:
    - **Telegram:** `bot.getMe()` (sanity that token is valid)
    - **Redis:** `PING`
    - **Google Places:** tiny `searchNearby` (1 result, 100 m around Raffles Place, FieldMask `places.id`)
    - **Routes API:** 1 origin × 1 destination `computeRouteMatrix` (FieldMask `duration`, walk mode)
    - **Gemini:** short `generateContent('Reply with just OK.')`
    - **LTA DataMall:** `/TrainServiceAlerts`
    - Each probe has a 5 s timeout. Failures return `{ok:false, ms, note: <error-snippet>}` instead of throwing. Results formatted as monospace block with 🟢/🔴 icons + latency + note.
  - **`index.js`** —
    - + `bot.onText(/^\/ver(?:@\w+)?$/)` handler. Sends "🩺 Running health check…" immediate ack, runs probes, sends `<pre>...</pre>` HTML-mode message with the report (falls back to plain text if HTML mode rejects).
    - + `/ver` row in `setMyCommands`.
  - **`package.json`** — version → 0.12.0.
- **[RISK]** Low — diagnostic-only command. Each probe is the cheapest possible call against its target API:
  - Places `searchNearby` 1 result ≈ $0.017
  - Routes API 1×1 element ≈ $0.005
  - Gemini ≈ negligible
  - Telegram `getMe` free
  - Redis PING free
  - LTA `TrainServiceAlerts` free (already used by cron)
  - Total ≈ $0.022 per `/ver` invocation.
- **[STATUS]** PROD — auto-deploys with the next Railway build.
- **[TEST]** Manual: send `/ver` → bot replies with monospace block:
  ```
  soleat v0.12.0

  🟢 Telegram        142ms  @soleat_bot
  🟢 Redis             3ms  PONG
  🟢 Google Places   210ms  searchNearby ok
  🟢 Routes API      180ms  computeRouteMatrix ok
  🟢 Gemini          720ms  OK
  🟢 LTA DataMall    340ms  TrainServiceAlerts ok
  ```
  Any 🔴 row tells you which upstream is broken.
- **[NEXT]** Tranche B remainder: `/BusArrivalv2` UX (Open #13), MRT-stop expansion (Open #14), run `sync-vault.js` (Open #17).
- **[ADVICE]** `/ver` is the right diagnostic for "is anything broken right now?" — pair it with the Railway log for full root-cause when something goes red. Because each probe is parallel, total latency is the slowest probe (usually Gemini at ~700–1500 ms).
