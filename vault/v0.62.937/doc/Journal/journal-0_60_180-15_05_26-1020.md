> Operator urgent: *"Keep the original Vibe-Journal layout for PR, I need to search and check how to improve. Similarly the register, technical, feature, vault are not properly structure and style to be readable, the tables etc."*

Two coupled fixes for the Vibe Journal:

1. **PR tab — restore the rich legacy view** with per-PR `<details>` cards (body excerpt + file list) + a search input. Operator's workflow is "search and check how to improve" — the bare table I shipped in v0.60.177 didn't support that. Reuses the legacy `doc/VibeCodingRecord/data/prs.ndjson` (200 records with full body text) + `pr-files.tsv` (PR# → file list) which the project already maintains.

My `renderMarkdownLite` previously just escaped the pipes — operator saw raw text walls. Now parses the GFM `| header | header |\n|---|---|\n| row | row |` block syntax into proper `<table>` markup with column headers + row hover + horizontal scroll on mobile.
