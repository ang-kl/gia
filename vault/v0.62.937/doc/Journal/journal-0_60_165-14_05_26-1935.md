  **`index.js` post-filter (`~line 9760`)** — strict mode + text-query fallback:
  ```js
  if (filters.petFriendly && venues.length > 0) {
    const strictPet = venues.filter((v) => v.allowsDogs === true);
    if (strictPet.length >= 3) {
      venues = strictPet;   // strict wins when Google data is present
    }
    // else: drop the strict filter, keep the text-query-biased pool
  }
  ```
  Logs `[Cuisine-Search] petFriendly strict: N/M venues tagged allowsDogs=true` (strict) OR `… strict yielded N/3 — falling back to text-query bias (M venues)` (fallback) so Railway-side `/log on` traces show which mode fired.

  **`index.js` cache-key slug (`~line 9367`)** — petFriendly bit `p` added to the filter slug so pet-friendly + non-pet-friendly variants of the same cuisine don't share a cached pool.
