### [HDR] #430 | 14:30 SGT 28-05-28 | v0.61.229 — Durian correction + variance suite | 5 files | 1 PR | 1 build |

- **[INTENT]** Make DURIAN return only venues that are actually
  durian-fruit sellers (per operator's Google Places primaryType
  catalogue), and DURIAN_PASTRY only durian-pastry venues; remove
  variety-name false positives entirely from the inclusion filter
  while keeping the 41-variety list available for review-snippet
  extraction.

- **[DELTA]**

  **1. `special-mode.js`** — three structural changes:

  - **`REJECT_PRIMARY_TYPES` → `ACCEPT_PRIMARY_TYPES` per mode.**
    Operator-supplied positive lists:

    | Mode | accept primaryTypes |
    |---|---|
    | DURIAN | `fruit_and_vegetable_store`, `fruit_and_vegetable_shop`, `grocery_store`, `supermarket`, `produce_market`, `food_market`, `wholesaler`, `wholesale_business`, `wholesale_supplier`, `fruit_parlor`, `fresh_fruit_store`, `bakery`, `cafe`, `juice_shop`, `juice_bar`, `dessert_shop`, `meal_takeaway` (v0.61.141 carve-out for specialists), `meal_delivery`, `store`, `food_store` |
    | DURIAN_PASTRY | `bakery`, `cafe`, `ice_cream_shop`, `dessert_shop`, `food_court`, `hawker_centre`, `hawker`, `fruit_parlor`, `juice_shop`, `juice_bar`, `wholesaler`, `wholesale_business`, `produce_market`, `food_market`, `restaurant`, `store`, `food_store` |
    | FRUITS | `fruit_and_vegetable_store/shop`, `grocery_store`, `supermarket`, `produce_market`, `food_market`, `wholesaler` / `wholesale_business`, `fruit_parlor`, `fresh_fruit_store`, `juice_shop`, `juice_bar`, `cafe`, `store`, `food_store` |

    `_acceptTypesFor(mode)` returns the right set. `isRelevant()`
    now does `if (pt && !accepts.has(pt)) return false` BEFORE the
    name / keyword loop. When `primaryType` is absent (Places
    returned no type), we fall through to keyword match.

  - **`KEYWORDS[DURIAN]` shrunk from ~60 to 4.** Only the core
    durian word (Latin singular + plural, Chinese simplified +
    traditional) drives inclusion. Every variety name moved out.

  - **NEW `DURIAN_VARIETY_TERMS` + `extractVarietyMentions(venue)`.**
    The 41-variety catalogue lives as a frozen list (with every
    "X or Y" alias split). The extractor uses word-bounded match
    for Latin terms (`\bd24\b` vs `\bd2\b`) and substring match for
    CJK (`\b` doesn't work on ideographs). The returned array is
    intended for a future result-card "Review mentions: Mao Shan
    Wang, D24" line. NOT used by the inclusion filter.

  **2. `__tests__/special-mode.test.js`** — five test-block edits:
  - Existing `isRelevant (Durian)` set: 3 cases flipped from
    expect:true to expect:false because variety-only names + non-
    accept-list primaryTypes no longer pass.
  - Existing `Durian narrowed to fruit-only (v0.61.141)` block:
    "accepts variety names without pastry tokens" flipped to
    "REJECTS variety-only names" (v0.61.229).
  - NEW v0.61.229 REGRESSION GUARD tests:
    - French restaurant + "Mao Shan Wang reduction" review → reject from DURIAN.
    - Italian restaurant + "durian dessert" review → reject from DURIAN.
    - Sushi restaurant + "durian on menu" review → reject from DURIAN_PASTRY.
  - NEW v0.61.229 `DURIAN_VARIETY_TERMS` block: shape check,
    word-bounded match, no-d2-inside-d24, Chinese script, empty
    venue.
  - v0.61.225 fruit-variety review-signal block (36 tests) and
    pastry-name catalogue block (16 + 14 tests) — all still pass
    unchanged because the test cases all carry "durian" in the
    venue name.

  **3. NEW `scripts/durian-variance.js`** (~140 lines):
  - CLI diagnostic. Iterates SG / JB / Putrajaya × en / zh-CN /
    zh-TW / ms × per-mode seed templates (4 + 3 + 2 + 2 ≈ 11
    queries per region for fruit; similar for pastry).
  - Hits Places searchText with operator-style locationBias.
    Field mask: id, displayName, formattedAddress, location,
    primaryType, primaryTypeDisplayName, reviews, editorialSummary.
  - Per query, logs `places=N kept=K rejected=R` + top-3 kept
    (with primaryType) + top-3 rejected (with primaryType).
  - Per region, logs the primaryType-frequency histogram so the
    operator can see which Google Places types Durian queries
    actually return — informs future accept-list tweaks.
  - Default mode `durian`; `--mode=durian-pastry` for pastry.
  - ~$0.11 per execution (33 calls × $0.0033 Essentials).
