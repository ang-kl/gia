- **[DIAGNOSTIC RUNBOOK]**
  When `/ver` shows green but `/cuisine` Search doesn't fire, the question is: bridge problem or pipeline problem?

  ```bash
  curl "https://<webhookDomain>/admin/test-pipeline?secret=<ADMIN_SYNC_SECRET>"
  ```
  Decision tree on the response:
  - `error.message` → pipeline crashed before completing. Stack trace top 5 frames included.
  - `steps.vault.n_vault === 0` → vault index is empty. Run `/admin/sync-vault` first.
  - `steps.pipeline.venuesCount === 0` → reason() returned no candidates OR Places validate filtered all of them. Check `pipelineDiagFirstFew` for the failing D-code.
  - `steps.pipeline.venuesCount > 0` → **pipeline is healthy**. The TMA bridge is the problem. User needs to: (a) confirm Header reads `v0.29.x`, (b) tap badge 5× quickly to open Diagnostics, (c) screenshot which D-code in 400-series fails.
- **[KNOWN GAPS]**
