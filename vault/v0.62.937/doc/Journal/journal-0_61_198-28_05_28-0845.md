- **[DELTA]**

  - **`index.js` (3 edits):**

    1. **JB area-text filter rewritten as a hybrid mirror of
       the SG branch** (index.js:12968).
       Was:
       ```js
       if (isJB) {
         venues = venues.filter((v) =>
           /\bjohor\b/i.test(`${v.area || ''} ${v.name || ''}`));
       }
       ```
       Now:
       ```js
       if (isJB) {
         const JB_CENTROID = { lat: 1.4927, lng: 103.7414 };
         venues = venues.filter((v) => {
           const text = `${v.area || ''} ${v.name || ''}`;
           if (/\bjohor\b/i.test(text)) return true;
           if (/singapore/i.test(text)) return false;
           const distFromJB = haversine(JB_CENTROID, v);
           return Number.isFinite(distFromJB) && distFromJB <= 60000;
         });
         if (venues.length !== beforeJb) {
           console.log(`[Cuisine-Search] D703b JB-hybrid-filter ${beforeJb} → ${venues.length}`);
         }
       }
       ```
       Effect: venues that Places returned with addresses like
       "Skudai, 81300, Malaysia" or "Iskandar Puteri, 79100" now
       pass via the 60 km centroid proximity check. 60 km from
       (1.4927, 103.7414) covers Pontian (west), Kulai (north),
       Desaru (east) — Johor state — without leaking into KL /
       Selangor / Pahang. The `/singapore/i` negative-guard
       keeps SG venues out of JB-mode results regardless of
       their distance.

    2. **Seen-set read moved up** (now sits above the nearby-widen
       block). Identical logic to the prior site that was at
       line 13123; the move enables the next change.

    3. **Nearby-widen gated by first-batch** (was always-on).
       Was:
       ```js
       try {
         if (!skipCacheForShuffle && !specialMode) {
           const widened = widenAndPick({ venues, cap: widenCap });
           …
           venues = widened.venues;
         }
       } catch (err) { … }
       ```
       Now:
       ```js
       const isFirstBatchForWiden = (seen.size === 0);
       try {
         if (!skipCacheForShuffle && !specialMode && isFirstBatchForWiden) {
           const widened = widenAndPick({ venues, cap: widenCap });
           …
           venues = widened.venues;
         } else if (!skipCacheForShuffle && !specialMode) {
           console.log(`[Cuisine-Search] D790 nearby-widen skipped (followUp tap, seen=${seen.size}); serving full anchor-capped pool=${venues.length}`);
         }
       } catch (err) { … }
       ```
       Effect: first 🔍 tap retains operator's "prioritize nearby"
       intent (operator's v0.61.161 spec). Subsequent taps serve
       the full anchor-capped pool, so pagination walks the wider
       tiers naturally without re-running Places. The widen
       skip path emits a new D790 log line so the operator can
       trace which mode is active per request.
