- **[INTENT]** Durian special-mode returned **< 5 stalls per city** across the belt while Google shows
  many more. Root-caused (Explore agent + code trace) to three compounding restrictions: **#1** the
  hard **rating floor ≥ 3.7** (`venue-filters.applyRatingFloor`) dropped the 2.5–3.6★ casual stalls
  Google lists; **#2** **no Malay / Indonesian local seeds** (the English `durian shop/stall` seeds
  under-recall in MY/ID/BN); **#3** the **strict name-gate** dropped stalls named only after a
  **cultivar** (e.g. "Unforgettable Musang King") because they carry no literal "durian" word.

- **[DELTA — soft 3.7 rating (operator's chosen shape)]** `index.js` (~15816): for `specialMode ===
  'durian' | 'durian-pastry'`, **skip the hard rating floor** — keep ALL stalls incl. < 3.7 and
  unrated. The trulyUnseen sort (~15850) now keys `_durianPref` FIRST (`rating ≥ 3.7 OR unrated → 0`,
  `< 3.7 → 1`) so 3.7★+/unrated stalls **page first**, lower-rated ones **fill after**. Payload gains
  **`durianRatingNotice: true`** (~16396) only when the visible page actually holds a < 3.7 stall.

- **[DELTA — local seeds]** `special-mode.js`: `LOCAL_SEED_LANG_BY_CC` adds `MY:'ms', BN:'ms',
  ID:'id'`; `LOCAL_SEEDS` adds durian `ms:['kedai durian','gerai durian','pasar durian']`,
  `id:['toko durian','warung durian','penjual durian']` and durian-pastry `ms:['kek durian','pastri
  durian']`, `id:['kue durian','pancake durian']`. English seeds kept; local seeds carry no region
  suffix (existing contract).

- **[DELTA — cultivar name-gate]** `special-mode.js` `DURIAN_CORE_TERMS` adds **only the three
  durian-EXCLUSIVE cultivars** `musang king`, `mao shan wang`, `black thorn` → a variety-only-named
  stall on an accept-type venue (food_store / meal_takeaway / fruit_*) now passes the name gate.
  **Deliberately EXCLUDED** the ambiguous cultivars (`red prawn`/`udang merah` = seafood, `golden
  phoenix` = Chinese resto, `tekka` = sushi/market) — they stay **extraction-only** in
  `DURIAN_VARIETY_TERMS` so they never false-match a non-durian stall. The
  French/Italian/Sushi-restaurant regression guards still hold (those reject by `primaryType`, not
  name).

- **[DELTA — TMA notice]** `lib/i18n.js` `special.durian.softRating` (en + fr): *"🥥 Durian stalls: we
  list 3.7★+ first, but also show lower-rated and unrated stalls — a durian stall is a durian stall."*
  `App.jsx`: `durianRatingNote` state set from `r.durianRatingNotice`, rendered as an **amber** notice
  (border-amber-500/40 — colour-blind safe, not red/green) above the result panel when the page holds a
