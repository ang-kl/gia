## New

### [HDR] v0.62.591 — Hawker: clear Telegram's fullscreen chrome on iPad + portrait zones in one row

- **[INTENT]** Operator (iPad Pro, Hawker TMA):
  1. *"In landscape mode … the frosted header and the bottom right FAB buttons cannot be seen and should
     be below the telegram system button."*
  2. *"In the portrait mode … the five zone buttons should be the same as the landscape in one row
     squeeze, and the bottom right FAB buttons cannot be seen and should be below the telegram system
     button."*

- **[ROOT CAUSE — safe area]** The layout CSS already reads `--tg-content-safe-area-inset-top/bottom`
  (top bars) — but **nothing ever set those variables** (neither Hawker's nor Cuisine's `tg.js`), so they
  fell back to `env(safe-area-inset-*)`, which is **~0 on an iPad** (no notch) and does **not** reserve
  room for Telegram's fullscreen floating system buttons. So the frosted top bar sat *under* the buttons,
  and the FAB (which only used `env(safe-area-inset-bottom)`) sat under the bottom chrome.

- **[DELTA — safe area]**
  - `web/hawker/src/tg.js` — new `safe('safe-area')` block populates
    `--tg-content-safe-area-inset-{top,bottom,left,right}` = device `safeAreaInset` **+** Telegram
    `contentSafeAreaInset` (Bot API 8.0), refreshed on `safeAreaChanged` / `contentSafeAreaChanged` /
    `fullscreenChanged` / `viewportChanged`. Only iPad-class devices go fullscreen, so phones (where the
    insets are absent) keep the `env()` fallback unchanged.
  - `web/_shared/components/FooterNav.jsx` — the FAB bottom is now
    `calc(0.75rem + max(env(safe-area-inset-bottom, 0px), var(--tg-content-safe-area-inset-bottom, 0px)))`,
    so it clears the fullscreen bottom chrome. Backward-compatible: Menu/Transport (which don't set the
    var) fall back to `env()`. The top bars already read `--tg-content-safe-area-inset-top`, so they clear
    the moment `tg.js` populates it.

- **[DELTA — portrait zones]** `web/hawker/src/App.jsx`. The portrait-tablet zone chips were a fixed
  `grid grid-cols-3` (3 + 2, added in v0.62.590 for phones). Made it responsive:
  `isWide ? 'flex flex-wrap' : 'grid grid-cols-3'` — a **wide** tablet in portrait now squeezes all five
  zones into **one row** (like the landscape top bar); phones keep the tidy 3 + 2 grid.
