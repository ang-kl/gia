- **[DELTA]**
  - **`cuisine-review-language.js`** — new
    `enrichVenuesWithTranslatedReview({ venues, cuisineSlugs,
    targetLang, redis, minRating = 3.8, capChars = 200 })` helper.
    Wraps `pickAndTranslateReview` over an array. Mutates each
    venue's `recentReview` / `recentReviewTranslatedFlag` /
    `recentReviewLanguage` / `recentReviewSourceLang` in place.
    No-op when `cuisineSlugs` has no nationality slug or `venues`
    is empty. Per-venue try/catch isolates failures.
  - **`__tests__/cuisine-review-language.test.js`** — +6 tests
    around the helper (no-op cases, mutation contract, skip-no-
    reviews, lang-mismatch / low-rating skip, capChars option,
    per-venue failure isolation). Now 37 tests total.
  - **`index.js`** — 4 call-site changes:
    1. `/api/cuisine/search` loop (was inline at v0.61.152) →
       single helper call. -28 / +12 net (~16 line reduction).
       Drops the v0.61.152 `recentReviewTranslatedRaw` debug field
       — never read anywhere; cleanup.
    2. `runFreeTextSearch` main branch (was inline at v0.61.152) →
       single helper call. ~22 line reduction.
    3. `handleMichelinSearch` — new call, inserted AFTER the
       v0.60.153 Step 5 enrichment-cache WRITE and BEFORE the
       `delete v.reviews` strip. The cache write happens FIRST so
       the Michelin enrichment cache (`michelin:enrich:<slug>`,
       7-day TTL) stays language-neutral (otherwise an EN-device
       user would poison the cache for a FR-device user). Per-
       venue translate cost stays bounded by the translate-review
       module's own language-aware Redis cache (30-day TTL).
       `cuisineSlugs` sourced from `otherCuisineSlugs` (already
       resolved upstream from `cuisines` minus the 'michelin'
       slug). `targetLang` = `csLang` (chat language already
       resolved by the handler).
    4. `runCuisineFlow` (chat `/cuisine` command) — new call
       BEFORE `deliverPicks`. Resolves `targetLang` via
       `require('./user-prefs').resolveLang(redis, chatId, null)`
       so the chat command picks up the user's saved locale
       (falls back to 'en' on any error). `cuisineSlugs` = the
       single `[cuisineType.toLowerCase()]`.
  - **`package.json`** — `0.61.153 → 0.61.154`.
  - **`doc/.serial-state.yml`** — `commit 366 → 367`, `build 156 →
    157`, `journal 354 → 355`; re-anchored 25-05 '26 20:30 SGT.
