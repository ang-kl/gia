- **[DELTA]**

  **`.vibe-journal/lib/render.mjs`** — adds `bundled-single-page` output mode. When `bundled_html` + `bundled_json` config keys are set, render.mjs emits ONE self-contained HTML (inlined CSS + JS) + ONE JSON blob `{ manifest, data: { <type>: [...] } }` instead of the multi-file `dist/`. Suits a tightly-controlled Express whitelist where only two filenames are served.

  **`.vibe-journal/templates/app.js`** — branches on `window.__VJ_JSON_URL__` (set by the inlined-script block the bundled HTML emits). Bundled mode fetches the single JSON once and reads each tab's records from the in-memory blob; multi-file mode keeps the per-tab ndjson fetch behaviour.

  **`.vibe-journal/examples/soleat-deploy/config.yaml`** — new example pointing at the gia repo via `../../../` relative paths + bundled-mode config (`bundled_html: ../../../public/doc/vibe-journal.html`, `bundled_json: ../../../public/doc/vibe-journal.json`).

  **`public/doc/vibe-journal.html`** — replaces the legacy `doc/VibeCodingRecord/` single-page output with the new 5-row tabbed bundle (17 KB; inlines CSS + JS; fetches the JSON sibling on load).

  **`public/doc/vibe-journal.json`** — new 2.9 MB JSON blob carrying 688 records across 10 doc types (PR / Register / 3rd-Party / Technical / Feature / Legal / Vault / Journal / Builder / Persona). Existing Express whitelist at `index.js:7753` already covers it.
