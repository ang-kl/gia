  **2. `web/cuisine/src/v2/components/LocationField.jsx` —
      6-second idle reminder:**

  Two parallel implementations, one in the SG/JB branch (~line
  64-83) and one in `OtherLocationPicker` (~line 538-557):

  ```js
  const [idleHintActive, setIdleHintActive] = useState(false);
  const idleTimerRef = useRef(null);
  function clearIdleHint() {
    if (idleTimerRef.current) { clearTimeout(idleTimerRef.current); idleTimerRef.current = null; }
    setIdleHintActive(false);
  }
  useEffect(() => {
    clearIdleHint();
    const trimmed = query.trim();
    if (trimmed.length < 1) return;
    idleTimerRef.current = setTimeout(() => { setIdleHintActive(true); }, 6000);
    return () => { if (idleTimerRef.current) { clearTimeout(idleTimerRef.current); idleTimerRef.current = null; } };
  }, [query /*, open in SG/JB*/]);
  ```

  When `idleHintActive` flips true, a small `animate-pulse`
  speech bubble renders below the pill at `right-2 top-full`,
  with an upward-pointing rotated-square tail anchored at
  `right-3 -top-1`. Text: `"Tap 🔍 to search"` (en) /
  `"Touchez 🔍 pour rechercher"` (fr). Same `bg-tg-accent` body +
  `rounded-2xl px-2.5 py-1 text-[10px] font-semibold` styling as
  the v0.61.241 location-suffix bubble — only the tail direction
  is flipped (up instead of down).

  `clearIdleHint()` is called from:
    - `handlePick` (SG/JB): after a suggestion is tapped/Entered
    - `handleClear` (SG/JB): when the × is tapped
    - The 🔍 button onClick (SG/JB): immediate dismissal
    - `pickResult` (OTHER): after a confirmation-list pick
    - `doSearch` (OTHER): when the 🔍 button fires
    - `cancel` (OTHER): when the user dismisses the result list

  The SG/JB branch also gates the timer on `open === true` so
  the bubble doesn't show on a resting pill the user never
  touched. The OTHER picker doesn't have an `open` flag —
  the input is always present in expanded mode — so the
  timer runs purely on `query` length.

  The expanded OTHER pill is now wrapped in a `<div className="relative">`
  parent so the absolute bubble anchors correctly (previously
  the pill had no positioned parent in this branch).

- **[KNOWN GAPS]**
  - The bubble's "right-2" anchor positions it at the pill's right
    edge, aligned under the 🔍 icon. On very narrow viewports the
    bubble may extend past the pill's right edge by a few pixels
    — visually acceptable per the FAB-hint precedent.
  - The 6 s timer is reset on every keystroke (incl. backspace).
    A user typing very slowly (one char per 5 s) might never see
    the bubble. Acceptable — the bubble's purpose is to catch
    the "I've stopped" pattern, not the "I'm typing slowly" one.
  - SG mode: the v0.61.237 auto-fire is preserved here on purpose.
    If the operator decides SG should also stop auto-firing,
    that's a one-line change (drop the `region !== 'SG'`
    condition on the SG/JB branch).
  - Menu TMA's LocationField is NOT touched in this PR — it
    has its own picker (`LocationFieldMenu.jsx`). If the
    operator wants the same idle reminder there, it's a
    follow-up.
