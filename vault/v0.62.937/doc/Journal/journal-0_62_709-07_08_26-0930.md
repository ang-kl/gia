## New

### [HDR] v0.62.709 — apply the 2026 Singapore Michelin star ceremony results to `SG-michelin.js`

- **[INTENT]** Operator, second of three independent items from one "next build" message:
  *"Singapore just staged its Michelin Bib Gourmand list release on July 28, 2026, and its full
  Michelin Star and special awards ceremony on August 4, 2026, marking the 10th edition."* Bib
  Gourmand was already applied in the prior session (v0.62.665/667); this entry closes the star
  side, which `SG-michelin.js`'s own header comment had deliberately left untouched pending this
  exact ceremony.

- **[SOURCING]** Every direct `WebFetch` attempted against `guide.michelin.com`'s two official
  full-list-2026 pages and four secondary sources (danielfooddiary.com, hungrygowhere.com,
  timeout.com, sg-cityguide.com) returned HTTP 403. The full result set was instead built from
  `WebSearch`'s synthesis across those same sources, cross-referenced name-by-name against the
  file's existing 41 `["'25"]`-only star rows to classify retained / promoted / dropped / new.
  Two addresses (1887 by André; Sushi Kimura Plus, including its correct name — the search-derived
  "Sushi Kimura +" was wrong) were supplied directly by the operator rather than guessed, matching
  this file's own governing rule against inventing data from memory. **A full classification table
  was surfaced for operator review before any diff was written**, per the approved plan's explicit
  check-in requirement for this item.

- **[RESULTS APPLIED]** 3 three-star (up from 2), 9 two-star (up from 7), 33 current one-star (up
  from 32) — 10th edition, ceremony 04 Aug 2026 at Raffles Sentosa Singapore.

  - **Three-star:** Les Amis, Odette retained. **Zén added** — but this is *not* a 2026 promotion:
    multiple sources confirm Zén has held 3 stars continuously since 2021, and the file simply
    never carried a row for it. Operator confirmed adding it now, with both `["'26", "'25"]` years,
    as a correction to a pre-existing gap rather than treating it as this year's news.
  - **Two-star:** Cloudstreet, JAAN by Kirk Westaway, Meta, Saint Pierre, Shoukouwa, Sushi Sakuta,
    Thevar retained (all 7, none dropped or promoted further). **1887 by André** debuts directly at
    two-star (operator-confirmed address: 1 Beach Road, Raffles Hotel, 189673). **Seroja promoted**
    from one-star — moved between arrays rather than edited in place, since `STARS_ONE`/`STARS_TWO`
    are separately exported and positionally concatenated into `ALL`.
  - **One-star:** 27 of the prior 32 retained (get `'26` prepended). **4 dropped from the
    selection** — Alma, Chaleur, Esora, Euphoria — kept as `["'25"]`-only historical rows, never
    deleted, per the never-delete-lapsed-award pattern (Taiwan v0.62.666 / SG Bib Gourmand
    v0.62.667). **6 new entrants**: Cherry Garden by Chef Fei, Jin Ting Wan, Loca Niru, Sushi
    Kimura Plus, Tenshima, Yong Fu.

- **[A SECOND OCCURRENCE OF THE v0.62.667 COUNT BUG, CAUGHT BEFORE SHIPPING]** The Bib Gourmand
  correction two sessions ago established that a criteria-tile description string reading
  `ARRAY.length` directly overstates the live total once lapsed-but-kept rows exist in that array.
  `STARS_ONE` now has the exact same shape (37 raw rows, 33 currently held) — `index.js`'s Michelin
  criteria tile (~line 12962) was still reading `STARS_THREE.length` / `STARS_TWO.length` /
  `STARS_ONE.length` raw. Fixed by filtering all three tiers to entries whose `awardYears` includes
  `"'26"`, matching the Bib Gourmand filter already there. `STARS_THREE`/`STARS_TWO` have no lapsed
  entries this edition so the filter is currently a no-op for them, but applying it uniformly means
  the description stays correct if either tier ever gains one.
