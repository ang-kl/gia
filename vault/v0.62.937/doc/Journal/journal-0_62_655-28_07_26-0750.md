# Journal — v0.62.655 (Cuisine's result list becomes an over-the-map drawer, opening at a measured 1.5 cards)

## New

### [HDR] v0.62.655 — the last consistency delta, and the half-card that is the whole affordance

- **[INTENT]** Operator: *"also build in the overlay drawer like Hawker TMA in Cuisine TMA in list mode. it
  should show only 1.5 card height in list mode so user knows how to scroll up and down in the drawer and use
  drawer handle to expand it"*

- **[WHAT THIS CLOSES]** The v0.62.704-audit finding: Cuisine's vertical result list had **never** been a
  drawer. It sat in **page flow below the map**, which is precisely why Cuisine was the one map app without
  the over-the-map layer Hawker and Train have had since v0.62.648. Defaults and toggles were aligned at
  v0.62.654; this aligns the **presentation**.

- **[DELTA]** (2 files)
  1. **Shared `BottomSheet` gains an optional `peekPx`** — it overrides the **collapsed (last) snap** with a
     real **pixel** height instead of a viewport fraction. This is the mechanism behind "1.5 card height":
     *1.5 cards is a fact about the card, not about the screen*, so a `vh` fraction lands right on one device
     and wrong on every other. The fraction remains the fallback when `peekPx` is null, so Hawker and Train
     are untouched.
  2. **Cuisine** —
     - the map is now **full-bleed in both modes**. `fill` no longer varies, and because it no longer varies
       the v0.62.574 framed↔full-bleed **remount** — which existed only to dodge the iPad blackout on an
       in-place canvas resize — has nothing left to guard against; the remount key is now constant.
     - the ~350-line `ResultPanel` is **wrapped in place** by a new `ResultSheetShell`, which renders a
       `BottomSheet` when list mode is active and a bare fragment otherwise. Wrapping in place rather than
       relocating the panel keeps every existing ref, scroll handler, pagination hook and flash-highlight
       wiring untouched — **the panel does not know it is inside a sheet** — and makes horizontal mode
       byte-for-byte unchanged.
     - the collapsed height is **measured from the first real rendered card** (`1.5 × cardHeight + 44 px`
       handle band), re-measured on resize and after 400 ms. The half-card cut off at the fold — the
       affordance the operator asked for — is therefore correct on every device rather than on one.

- **[BUG CAUGHT BY THE GUARD TEST]** My measurement effect's dependency array referenced `cursor`, which is

  `Cannot access 'cursor' before initialization` on every render — a white screen.
  `__tests__/tma-hook-deps-tdz.test.js` caught it before any build did. That is the **second** time that
  guard has paid for itself this session (it also caught a JSX slip at v0.62.646).
