  min"), so meaning isn't conveyed by hue alone.
- **`web/cuisine/src/v2/lib/i18n.js`** — `card.closingSoon` (base en/fr + id/zh/ja/es, mirroring
  `card.closed`'s existing locale coverage; ru/de fall back to English like `card.closed` already
  does).
