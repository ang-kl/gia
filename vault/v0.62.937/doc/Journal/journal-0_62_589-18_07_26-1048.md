# Journal — v0.62.589 (Hawker + Cuisine: one shared carousel-card ↔ pin tap flow)

_(№ 933 — 18-07 '26 10:48 SGT)_

## New

### [HDR] v0.62.589 — unify the card↔pin tap interaction across both TMAs

- **[INTENT]** Operator compared the Hawker vs Cuisine carousel-card ↔ Google-Maps-pin behaviours
  ("Hawker opens the card from the pin; Cuisine zooms, pauses, then blinks the pin… Hawker also blinks
  the card when I tap the pin"), then **locked a single shared spec** for both TMAs, both triggers
  (card tap / pin tap), both orientations (portrait list / landscape carousel):

  > pan → zoom (phone 14/15, tablet/list 17) → **0.5 s pause** → open InfoWindow anchored to the pin
  > (card-from-pin) + blink pin (`gia-pin-flash 0.5s × 5`) → matching carousel/list card gets the accent
  > ring, **keyed off the tapped id**.

- **[DELTA — shared]** New `web/_shared/lib/map-interaction.js` holds the four constants both map panels
  import: `TAP_ZOOM_WIDE = 17`, `TAP_ZOOM_PHONE = 15`, `TAP_PAUSE_MS = 500`, `BLINK_MS = 2500`.

- **[DELTA — Cuisine]** `web/cuisine/src/v2/components/MapPanel.jsx`: collapsed the focus effect so a
  **card tap and a pin tap run the identical sequence**. The pin's click handler now only calls
  `onPinTap` (sets `focusedPlaceId`); the effect does pan → zoom → 0.5 s pause → InfoWindow + blink.
  Removed `pinFocusRef` and the **v0.61.86** "pin tap = don't move the map" guard (pin taps now pan/zoom)
  and the **v0.62.141** `blinkOnly` InfoWindow suppression (the phone carousel now opens the popup;
  `blinkOnly` now only selects the phone 14/15 zoom). `ResultDrawer.jsx`: the accent **ring now keys off
  `focusedPlaceId` in both orientations** (was `activeId` on phone) — so a card tap or a pin tap lights
  the same card, and no card rings on first load; the phone opaque-centred card is preserved by passing
  an explicit `glass={placeId !== activeId}` so the opaque look is decoupled from the ring.

- **[DELTA — Hawker]** `web/hawker/src/components/HawkerMapPanel.jsx` `activateCentre` (the shared core
  both card-tap and pin-tap already funnel through): phone zoom **17 → 15** (tablet stays 17, via a live
  `matchMedia('(min-width:700px)')` read); blink **3 s → 2.5 s**; added the **0.5 s pause** before the
  popup + blink (transit pins, distance rings and the card ring stay immediate). It now blinks via a new
  `flashPin` passthrough exposed on the overlay controller (`web/hawker/src/lib/mapOverlays.js`) instead
  of `highlightLoc`, because `highlightLoc` bumps a `<16` zoom up to 16 and would clobber the phone 15.
