- **[INTENT]** Ship the **persistence + recount primitives** for
  the Periodical owner sub-menu. No chat surface, no cron — those
  land in v0.61.165 / v0.61.166. The data layer is independently
  testable (30 tests) and the chat UI lands on a known-good base.

- **[DELTA]**
  - **`count-history.js`** (NEW, ~110 lines). Redis-backed
    persistence:
    - **Schema**: `count:history:<item>` (ZSET, score = epoch ms,
      value = JSON `{n, source, notes, ts}`), capped at 12
      newest via `ZREMRANGEBYRANK 0 -13`.
    - **`HISTORY_CAP = 12`** (operator's "up to 12 versions").
    - **`ITEMS`** (frozen): `cuisines, michelin, hawker,
      healthier-eateries, buildings, bus-stops, train-stations,
      train-lines, carparks, parks, attractions, clinics,
      hospitals, police` — operator's 14.
    - **`isKnownItem(item)`** — type-checked membership test.
    - **`recordCount(redis, item, n, source, notes)`** — writes
      a new entry. `source` is `'manual' | '4-monthly' |
      'yearly' | 'revert' | <free-form>`. Caps to 12 newest.
      Returns the entry or null.
    - **`getHistory(redis, item)`** — newest-first array of
      entries (or empty array).
    - **`getCurrentCount(redis, item)`** — newest entry (or null).
    - **`revertTo(redis, item, ts)`** — writes a NEW entry with
      the prior count's `n` and `source='revert'`; the
      source-of-truth file/API stays untouched (operator Q2 (a)).
      Returns the new entry or null.
    - **`clearHistory(redis, item)`** — owner-only reset.
  - **`count-recount.js`** (NEW, ~250 lines). 14 recount fns +
    dispatcher:
    - Curated items (`cuisines`, `michelin`, `hawker`,
      `healthier-eateries`, `buildings`) read their modules /
      `data/*.json`.
    - Geo-overlay items (`parks`, `attractions`, `clinics`,
      `hospitals`, `police`) trust the `_meta.featureCount` field
      that `scripts/build-geo-overlays.js` writes (fallback:
      `features.length`).
    - `bus-stops` reads the LTA-warmed Redis `ZCARD
      lta:busstops:geo`; falls back to the curated
      `geoloc/LTABusStop.geojson`.
    - `train-stations` / `train-lines` derive from
      `data/mrt-coords.json` (lines = distinct 2-3-char prefix
      from each station code; **JB RTS Link** adds a new prefix
      once LTA exposes the stations — no code change needed).
    - `carparks` calls `carpark.allPoints()` (live LTA fetch).
    - Each fn is defensively wrapped: missing module / file /
      network error records `n=0, source='unavailable'` so the
      history view surfaces the gap without throwing.
    - `RECOUNTERS` dispatch + `recountOne(redis, item)` +
      `recountAll(redis, opts)` (parallel across all 14).
  - **`__tests__/count-history.test.js`** (NEW, 18 tests) —
    schema constants, isKnownItem, recordCount happy/edge cases,
    12-cap rotation, history newest-first ordering, defensive
    rejects, revertTo (records new entry, no source-of-truth
    mutation), clearHistory per-item isolation, closed-redis
    no-ops.
  - **`__tests__/count-recount.test.js`** (NEW, 12 tests) —
    RECOUNTERS dispatch shape (exactly 14, every ITEMS entry
    mapped, every fn is async), unknown-item null return, every
    item records a history entry (manual / unavailable), shape
    consistency, recountAll parallel + opts propagation,
    sanity-check counts (cuisines > 50, train-lines 3-20).
  - **`package.json`** — `0.61.162 → 0.61.164` (skips .163
