- **[INTENT]** Replace Chaikin's approximation with Catmull-Rom
  interpolation for the three LRT lines. Catmull-Rom is
  GUARANTEED to pass through every control point — so station
  markers stay ON the polyline, and the curve interpolates
  smoothly between them.

- **[DELTA]**
  - **`web/transport/src/data/line-paths.js`** (3 additions):
    1. **NEW `_catmullRomBlend(p0, p1, p2, p3, t)`** — uniform
       Catmull-Rom cubic blend:
       ```
       B(t) = 0.5 * (
         2 P1 +
         (-P0 + P2) t +
         (2 P0 - 5 P1 + 4 P2 - P3) t² +
         (-P0 + 3 P1 - 3 P2 + P3) t³
       )
       ```
       B(0) = P1, B(1) = P2. Anchors are preserved.
    2. **NEW `catmullRomSegment(seg, samples=12)`** — interpolates
       a dense polyline through the input control points.
       Closed loops (first === last) wrap around for proper
       tangents at the join. Open paths duplicate first/last as
       degenerate-tangent endpoints. Returns input unchanged for
       fewer than 2 points. Rounds output to 6 decimals.
    3. **NEW `CATMULL_ROM_LINES = Set('BPL', 'SLRT', 'PLRT')`** +
       updated `smoothLinePaths` dispatcher: LRT lines route
       through `catmullRomSegment(seg, 12)`; everything else
       stays on `smoothSegment(seg, 2)` (Chaikin, unchanged).
  - **`__tests__/transport-line-paths.test.js`** (+5 tests,
    1 updated, total **20 → 24**):
    - "BPL smoothed length > raw × 5" — Catmull-Rom densifies
      12 sub-samples per control-point pair.
    - "Every LRT raw control point appears in smoothed output"
      — proves the interpolation property (within 1e-5 deg).
    - `catmullRomSegment`: passes through controls, preserves
      closed loops, returns unchanged for < 2 points.
    - Existing "smoothing lengthens" assertion updated from BPL

- **[KNOWN GAPS]**
  - **Real LTA/OSM geometry remains the gold standard**. Once
    the operator runs `node scripts/fetch-mrt-lines-osm.js` (or
    the DataMall variant) and commits `data/mrt-line-paths.json`,
    `resolveLinePaths` will prefer the real track geometry over
    this Catmull-Rom approximation. The Catmull-Rom path is the
    DERIVED fallback — works without external data.
  - **12 samples per span** is a heuristic. Visually clean at
    typical zoom; if a future bug shows kinks at extreme zoom,
    we can bump to 16 or 24.
  - **Tangent control at open-path endpoints** uses point
    duplication (degenerate tangent) — slight straight-line tail
    on open lines. None of the soleat LRT lines have open ends,
    so this is theoretical.
