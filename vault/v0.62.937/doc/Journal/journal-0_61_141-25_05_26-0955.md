# Journal — soleat v0.61.141 (Cuisine TMA — Fruits / Durian / Durian Pastry as chips in "Dessert, Fruits" group; symmetric mutex with Dessert + all other cuisines)

> Operator (screenshot of the existing amber-pill Fruits/Durian row +
> a written spec): move Fruits and Durian into the catalogue grid as
> regular chips inside the "Dessert, Fruits" group, add a NEW Durian
> Pastry chip alongside, narrow Durian's criteria to "durian fruit
> only", and enforce a symmetric mutex — selecting any of the three
> specials blocks Dessert + every other cuisine, and selecting
> Dessert blocks the three specials. This PR retires the v0.61.126
> amber-pill row above the catalogue.

## New

### [HDR] #342 | 09:55 SGT 25-05-26 | v0.61.141 — Special-mode chips in catalogue + symmetric mutex | 9 files | 1 PR | 1 build |

- **[INTENT]** Operator spec:
  1. Move Fruits + Durian into the "Dessert, Fruits" group of the
     catalogue grid.
  2. Add: existing **Dessert**, **Fruits**, **Durian**, **Durian
     Pastry** (NEW).
  3. Change **Durian** criteria to "Durian fruit only".
  4. NEW **Durian Pastry** criteria = "Durian pastry only".
  5. When selecting `Fruits` / `Durian` / `Durian Pastry`, other
     cuisines (including Dessert) cannot be selected or in search
     criteria.
  6. When selecting `Dessert`, the three specials cannot be
     selected or in search criteria.
