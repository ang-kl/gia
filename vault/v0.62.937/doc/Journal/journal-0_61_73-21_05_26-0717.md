  operator's template, surface a one-tap location refresh on the Bus menu and

- **[DELTA]**
  - **`index.js`** —
    - `runTransportBus` nearest-stops block — `weatherChatFooter()` now
      *leads* the message (`lines.push(wx, '')`) instead of trailing as a
      footer; the header is `tn('transport.bus.nearestHeader', { count:
      stops.length })`. Each per-stop block now leads with the **road name**
      (`stop.roadName || stop.description`) and follows with a distance line —
      `transport.bus.stopMetaFirst` for the first stop ("… is 📍 ### away from
      current location."), `transport.bus.stopMetaRest` ("· 📍 ###") for the
      rest. One blank line after the header, two between stops. The trailing
      weather-footer block (`v0.60.220`) is removed (relocated to the lead).
      The map button is now count-aware: `tn('transport.map.busStopsBtn',
      { n: stops.length })`. (v0.61.71)
    - New `carpark:refresh-loc` callback — deletes `loc:<hashChatId(chatId)>`
      from Redis and re-runs `runCarparkCommand`, which re-prompts and
      auto-resumes the lookup on the next shared pin. `runCarparkCommand` now
      appends a `transport.menu.btn.refreshLoc` button row to the carpark
      result. `sendBusMenu` gains a "📍 Refresh location" row (reusing the
      existing `transport:refresh-loc` callback). (v0.61.72)
    - `busArrivalBand` — ETA band labels `≤5 min … >20 min` →
      `≤5 minutes … >20 minutes`. `formatBusArrivalsHtml` — arrival rows now
      lead `🚌 Bus № …` (was a bare `  № …`). (v0.61.71)
    - `registerCommandsMenu` — `/carpark` description `Nearest 5 with
      available lots` → `Nearest 5 Carpark with available lots`. (v0.61.72)
  - **`i18n.js`** (EN + FR) —
    - `transport.bus.nearestHeader` now takes `{count}` — `🚏 Nearest {count}
      bus stops`.
    - New `transport.bus.stopMetaFirst` (`🚏 Bus Stop № {code} is 📍 {dist}
      away from current location.`) and `transport.bus.stopMetaRest` (`🚏 Bus
      Stop № {code} · 📍 {dist}`).
    - `transport.map.busStopsBtn` `🚏 View bus stops` → `Show all {n} bus
      stops` (count-aware via `tn()`, icon dropped). (v0.61.73)
    - `carpark.mapAllCaption` `🗺 View all {n} carparks on one map:` →
      `Showing closest locations:`; `carpark.mapAllBtn` `🗺 View all {n} on
      map` → `Compare all {n} carparks` (icon + trailing "location" dropped).
      (v0.61.72 → .73)
    - `gmaps.openBtn` `🗺 Open in Google Maps` → `Google Map ↗`. (v0.61.72)
  - **`package.json`** — `0.61.70` → `0.61.73` (PATCH). The merge into `main`
