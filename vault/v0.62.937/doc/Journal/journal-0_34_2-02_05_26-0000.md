### [HDR] #75 | 00:00:00 SGT 02-05-26 | v0.34.2 | n/a kb | n/a lines
- **[INTENT]** Per Human Lead, two related TMA UX asks bundled:
  > "upon load, interpret the location coordinates in telegram into actual place using Google Map, if location is denials, specify that location is required, quickly offer buttons to turn on. Can we have a logo for the sole-eat? Current build is ver 0.34.1"
  
  Two improvements:
  1. **Reverse-geocode coords → place name** in the TMA Header (e.g. "Telok Blangah" instead of "1.2722, 103.8112"). Cached server-side so re-opens are free.
  2. **Denial UX:** when geolocation is denied, surface a prominent red-bordered "📍 Location required" banner with an "Enable location" button that re-triggers the Telegram WebApp `requestLocation` flow.
  3. **Logo:** ship a starter SVG brand mark (fork stem curving into a leaf — solo + sanctuary). Honest framing: this is a starter mark; a polished version should come from a designer or a Midjourney/DALL-E iteration with the prompt embedded in the SVG file.

- **[DESIGN]**
  1. **Backend `GET /api/reverse-geocode?lat=X&lng=Y`** — auth via `requireInitData`. Calls Google Geocoding API with `result_type=neighborhood|sublocality|locality` filter. Falls back to unfiltered query if no specific match. Picks the most-specific component (`neighborhood` → `sublocality_level_1` → `sublocality` → `locality` → first comma-segment of formatted_address). Cached in Redis 24 h per ~50 m grid (`revgeo:<lat4>:<lng4>` key, 4-decimal-place gridding) so repeated TMA opens at the same spot don't re-bill (~$0.005/call).
  2. **`Header.jsx` reverse-geocode integration** — `useEffect([loc.lat, loc.lng])` fires `fetchPlaceName(lat, lng)` and sets state. In-module `_placeNameCache` Map prevents re-render re-fetches. Fallback: when geocode fails, Header shows raw coords (current behaviour).
  3. **Header denial banner** — new prop `locDenied` from App.jsx. When `!loc && locDenied`, renders a red-bordered card with "Location required" copy + a full-width "📍 Enable location" button (re-triggers `requestLocation`). When `!loc && !locDenied`, shows a quiet "📍 (detecting…)" placeholder.
  4. **Logo SVG (`web/cuisine/public/soleat-logo.svg`)** — minimal viewBox 64×64. Vertical stem (fork handle) + leaf-shape fill + leaf-vein line. Hardcoded stroke `#3390ec` (Telegram blue) so it renders visibly via `<img>` tag (without inline SVG colour inheritance). Header inlines as `<img src="/app/cuisine/soleat-logo.svg" width="28" height="28">` next to the title.
  5. **Title rebrand** — Header now reads "soleat — Cuisine and Drinks" (was "Cuisine and Drinks"). Brand visibility on every TMA open.

- **[KNOWN GAPS]**
  - **Geocoding API cost** — Google charges ~$0.005/call. The 24 h Redis cache + 50 m grid keeps this near-zero for repeat users; cold-cache cost is ~$0.005/new-location. Acceptable.
  - **Place name accuracy depends on Google's neighborhood data** — works well in CBD / popular suburbs; falls through to `formatted_address[0]` (which can be a road name like "West Coast Highway") in less mapped areas. Honest fallback: still better than raw coords.
  - **SVG logo is a starter, not a brand mark.** A polished iteration should come from a designer or a generative-image tool (Midjourney prompt embedded as a comment in the SVG). The current shape (fork stem curving into a leaf) is a concept, not a finished mark.
  - **Logo only on Cuisine TMA so far.** The Menu TMA + Map TMA still show their existing headers without the logo. v0.34.x can extend if desired.
  - **Title "soleat — Cuisine and Drinks"** is longer than v0.34.1's "Cuisine and Drinks" and may truncate on narrow Telegram clients. Falls back to ellipsis via `truncate` Tailwind class.
