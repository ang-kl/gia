## New

### [HDR] v0.62.626 — make "Expand map" work in the carousel/desktop/drawer layouts

- **[INTENT]** Operator (Transport TMA, desktop): *"the 'Expand map' and 'Collapse map' buttons doesn't
  work. urgent investigation."*

- **[ROOT CAUSE]** `MrtMapPanel`'s `expanded` state only drove the map container's height in the **non-fill**
  branch (`90vh` / `70vh`). In the carousel / desktop / phone-drawer layouts the map runs in **`fill`**
  mode (`height: 100%`, sized by its bounded parent), so toggling `expanded` changed nothing — a **dead
  button**.

- **[DELTA — `web/transport/src/components/MrtMapPanel.jsx`]**
  - `expandedOverlay = expanded && fill` → in fill mode the outer wrapper becomes `fixed inset-0 z-30
    overflow-hidden bg-tg-bg`, promoting the map to a **full-viewport overlay**. The footer (`z-40`) stays
    reachable, and the nav-cluster **Collapse** button rides on the map, so the overlay is dismissable.
  - Added a `useEffect` on `[expanded]` that triggers a Google Maps **`resize`** event + **recenter** so
    the map reflows to the new size without drifting (Google Maps renders at the stale size otherwise).
  - The non-fill path (`90vh`/`70vh`) is unchanged.
