## New

### [HDR] #611 | 09:36 SGT 09-06-26 | v0.61.411 — durian-belt gate moved into the picker (chip disable) | cuisine-selection.js + CuisineDrawer.jsx + CuisineCategoryDrawer.jsx + i18n.js + test | 1 PR | 1 build |

- **[INTENT]** In **Japan** (outside the SE-Asian durian belt SG/MY/ID/TH/PH/BN) the **Durian Fruits** + **Durian Pastry** chips were still **tappable** in the picker. They must be **disabled** there.

- **[ROOT CAUSE]** v0.61.397 belt-gated durian / durian-pastry **server-side only** — a block-on-search that returns `specialModeBlocked` and shows the "only available in…" banner. But the v0.61.272 cleanup had **removed the per-slug region lock** in the picker, so the chips in `CuisineCategoryDrawer` stayed selectable everywhere. The user could pick Durian in Japan; the gate only bit *after* a 0-result search.

- **[DELTA]** (`web/cuisine/` — mirror the server gate in the picker, BEFORE the search)
  - **`src/v2/lib/cuisine-selection.js`** — new `DURIAN_BELT_COUNTRIES` = `{SG,MY,ID,TH,PH,BN}`, `BELT_GATED_SLUGS` = `{durian,durian-pastry}`, and `isSlugCountryAllowed(slug, country)`. `fruits` is **not** gated (per v0.61.402); an unknown/empty country is **not** blocked (the server still guards) so a half-resolved location never greys a chip.
  - **`src/v2/components/CuisineDrawer.jsx`** — compute `beltCountry` (SG→SG, **JB / MY-PUT → MY** since Johor *is* in the belt, OTHER→`countryPref`) and pass it to the category drawer.
  - **`src/v2/components/CuisineCategoryDrawer.jsx`** — a belt-gated chip outside the belt is `disabled` + `opacity-40 cursor-not-allowed` + `title={special.beltOnly}` + the `onClick` is guarded. An **already-selected** chip stays tappable so a stale pick can be deselected after switching country.
  - **`src/v2/lib/i18n.js`** — new `special.beltOnly` tooltip (en + fr).
  - **`__tests__/cuisine-selection.test.js`** — +8 cases pinning `isSlugCountryAllowed` (in/out of belt, fruits-everywhere, case-insensitive, unknown-country-not-blocked).
  - **`package.json`** `0.61.410 → 0.61.411`; **`doc/.serial-state.yml`** commit 623 → 624, journal 610 → 611, **build 393 → 394**; re-anchored 09:36 SGT.
