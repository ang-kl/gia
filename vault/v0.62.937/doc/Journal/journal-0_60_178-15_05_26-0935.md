  **`.vibe-journal/templates/style.css`** — full rewrite of the shell + nav rules. Highlights:
  - Sticky topbar (z-index 30); shell becomes `flex(sidebar 240px, main flex-grow)`.
  - Active nav item: 3 px left-border accent + soft-tinted background (matches Linear's pattern).
  - Mobile breakpoint `@media (max-width: 768px)`: sidebar position-fixed, transforms off-canvas; backdrop overlay; hamburger shows.
  - `<table>` `<th>` sticky offsets adjusted for the 49 px topbar.
  - Print rules: drop chrome, expand main.
  - Dark-mode + `prefers-color-scheme` colour tokens preserved.

  **`.vibe-journal/templates/app.js`** — sidebar render + drawer plumbing + URL hash:
  - Each manifest row renders as a `<div class="vj-nav-section">` containing one `<button class="vj-nav-item">` per tab. No more `|` separator markup.
  - Drawer logic: hamburger toggles `is-open` on `<aside>` + `<div class="vj-backdrop">`; backdrop click + Esc key + viewport-cross all close it.
  - URL hash deep-linking: `location.hash` honoured at boot; clicking a tab `replaceState`s the new hash; `hashchange` event re-activates if the user uses browser back/forward.
  - Selector update: `document.querySelectorAll('.vj-tab')` → `.vj-nav-item` (tracks the new shell).
