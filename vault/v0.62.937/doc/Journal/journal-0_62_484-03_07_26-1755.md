## New

### [HDR] #838 | 17:55 SGT 03-07-26 | v0.62.484 — Michelin cache v2 + lang-scope | 1 code file + 3 doc/meta | PR #(pending) |
- **[INTENT].** Make the v0.62.483 open-hours fix actually render, and make a language switch
  re-fetch the Michelin card in the new language instead of serving a stale French blob.
- **Root cause (traced — ONE cause behind BOTH symptoms).** The Michelin **Places cache**
  `michelin:place:<slug>` (`index.js` ~10014, **7-day TTL**) and the **enrich cache**
  `michelin:enrich:<slug>` (~10457, 7-day TTL) were keyed by **slug only** — no schema
  version, no language. So:
  1. **No Closed tab / 🕛 row.** Blobs cached *before* v0.62.483's FIELD_MASK gained
     `currentOpeningHours` carry no `openNow`. `ResultCard.jsx` gates the Closed corner-tab
     (`openNow === false`) and the 🕛 timing row on that strict boolean — so the v0.62.483 fix
     could not take effect until the 7-day blob expired.
  2. **Card stays French after switching to English.** A blob resolved with `languageCode: fr`
     (French `displayName` / `editorialSummary` + the narrated French dish list *"Dîner
     dégustation en 13 services"*) kept being served because the key wasn't language-scoped.
- **[DELTA] (1 code file — `index.js`).**
  - `michelin:place:<slug>` → **`michelin:place:v2:<lang>:<slug>`** (~10014).
  - `michelin:enrich:<slug>` → **`michelin:enrich:v2:<lang>:<slug>`** (~10457, keys both the
    read and the write — they share the `enrichSlugs` array).
  - `<lang> = csLang === 'fr' ? 'fr' : 'en'` — the same 2-way split the Places `languageCode`
    already uses. **`v2`** busts every stale pre-fix blob at once (so `openNow` returns
    immediately, not after a 7-day wait); the **lang** segment caches fr/en separately, so a
    language switch is a cache MISS → live re-fetch in the new language.
- **[VERIFICATION (sandbox)]** `node --check` clean on the edited `index.js`. No web build
  (server-side cache keys only; ResultCard unchanged).
- **[STATUS]** PROD — bot redeploys on merge (Railway). Verify on Telegram: a **closed**
  Michelin venue now shows the Closed tab + 🕛 row; switching device/app language to English
  re-renders the card (name / dishes / hours) in English.
- **[TEST]** Full vitest via CI.
