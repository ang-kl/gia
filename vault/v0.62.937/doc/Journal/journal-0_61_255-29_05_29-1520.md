- **[INTENT]** Three independent small UI changes:

  1. The Halal chip should read **حلال** (bold, green) instead of
     🕌 + "Halal". Underlying search keyword + i18n label stay
     "halal" Latin per operator's clarification.
  2. The "Durian" cuisine label should read **"Durian Fruits"**
     so the operator can disambiguate the fruit chip from the

     `restaurantType` line — durian is seasonal, the pastry shop
     may not always carry it.
