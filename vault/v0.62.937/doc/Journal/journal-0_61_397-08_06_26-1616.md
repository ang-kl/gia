- **[INTENT]** The **Durian / Fruits / Durian-pastry** special modes returned **wrong answers outside SE-Asia** — e.g. a Hong Kong card showed generic desserts mislabelled as durian results. The operator's decision: **block these three modes** anywhere outside the durian belt rather than keep tuning the filter. Belt = **SG, MY, ID, TH, PH, BN** (Brunei explicitly unblocked on the operator's word; "IN" read as **Indonesia/ID** per the earlier explicit list "Singapore, Indonesia, Malaysia, Thailand").

- **[SCOPE NOTE]** The operator first asked to restrict the *picker* country lists, then **corrected**: *"mistaken — I meant block durian-fruit, durian, durian-pastry for other countries and cities."* So this is a **per-mode server gate**, NOT a picker-list change. The country picker stays global; a user can still pick HK — they just can't run a durian search there.
