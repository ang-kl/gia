  Bib row (`buildInfoHtml`, `p.link` colour — parity with the bus-stop links).

  `tn('stalls.count')` which is already `🍳 {n} stalls` → a **double frying pan** (read as two
  magnifying glasses). Dropped the hard-coded prefix; now a single 🍳.
