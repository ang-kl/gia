# Journal — soleat v0.62.538 (Distance rings: 3rd "reach" train ring — #.#km (~N stops))

> Follow-up to #1548. On the live screenshot (IMG_3110.jpeg) the operator saw result pins falling
> *outside* the 2-stop train ring (2.2 km) and asked: *"there are two choices outside the train circle
> ring. Do you think we should have one more train ring include '#.#km (~# stops)'."* I recommended a
> data-driven "reach" ring; via AskUserQuestion the operator chose **size = farthest result, capped
> (~6 stops)** and **show only when a result falls beyond the 2-stop ring**.

## New

### [HDR] #894 | 10:36 SGT 15-07-26 | v0.62.538 — 3rd "reach" train ring | 4 files | PR #(pending) |

- **[INTENT].** Add a third 🚆 ring that reaches out to the farthest result pin (capped), labelled
  `#.#km (~N stops)`, so the rings visually enclose the outlying results — but only when there *is* a
  result beyond the 2-stop ring.

- **[DELTA].**
  - **`web/_shared/lib/distance-rings.js`** — NEW exported `mrtReachRadius(lat, lng, results, twoStopRadiusM)`:
    farthest result distance from the centre, **capped at `perStop * 6`** (per-stop = the 2-stop ring
    radius ÷ 2 stops). Returns null when nothing sits beyond the 2-stop ring, or when the reach ring
    would be < 1.15× it (too close to duplicate). Label = `formatDist(radius) + " (~N stops)"`, where
    `N = round(radius / perStop)` clamped to ≥ 3. `draw()` now takes an optional `results` array and
    draws the third ring iff `mrtReachRadius` is non-null; the **2-stop ring is relabelled**
    `#.#km (2 stops)` (was bare `#.#km`) for parity.
  - **`web/cuisine/src/v2/components/MapPanel.jsx`** — `syncMarkers` passes the venue pins (finite
    lat/lng) into `draw()`, so Cuisine gets the reach ring around its result set.
  - **`web/hawker/src/components/HawkerMapPanel.jsx`** — unchanged; it passes **no** results, so the
    chosen-hawker rings stay two (there's no "picks reach" concept centred on a single hawker).
  - **`__tests__/distance-rings.test.js`** — +4 tests.
  - `package.json` — 0.62.537 → **0.62.538**.
