- **[F2 — explicitPick latch misclassified auto transitions (CONFIRMED)]** The v0.61.430 effect latched `explicitPickRef=true` whenever `state.region` became OTHER/JB — **including when the 20 s device-follow callback itself or the mount auto-detect set it from raw GPS** — and nothing ever reset it. Any user physically abroad lost device-follow at boot with zero gestures; a JB-pill tap-and-back killed follow for the whole session. **Fix:** the region-watching latch is removed from the effect (the countryPref backfill stays). The latch is now set **only at genuine pick gestures**:
  1. `onLocationSelect` **committed** picks (past the cityPreview early-return — autocomplete, map, capital commit, JB focus point);
  2. the OTHER **country dropdown**;
  3. the **region pills** (latch placed in the onClick, outside the setState updater — purity);
  4. an inherited **labelled** `tryServerCache` pick (a deliberate Menu/chat choice persisted server-side) — this preserves the original v0.61.430 fix (KL pick yanked back to SG GPS); unlabelled GPS-shaped cache entries do **not** latch, so plain-GPS users keep device-follow.

- **[F10 — empty custom field saved a ≥1.0 floor (CONFIRMED)]** `Number('') === 0` is finite, so an empty Save clamped to `'1.0'` and silently disabled the rating floor. **Fix:** empty/whitespace → `null` → Save falls back to the 3.7 preset, as the function's contract always claimed.

- **[F11 — clamp contradicted /rating (CONFIRMED)]** Typing **0** (the documented "/rating 0 = any" convention) clamped to a **≥1.0 floor — the opposite**; typing 9 silently saved ≥5.0. **Fix:** `0 → 'any'`; out-of-range is **rejected** (preset fallback), matching the chat command's semantics. Comma decimals still accepted.

- **[F14 — mount seed clobbered fresher picks (CONFIRMED)]** The `fetchCountryPref` mount effect overwrote `state.countryPref` whenever the GET resolved — a slow response carrying last week's country clobbered a just-picked/backfilled one, and the backfill couldn't self-heal (it only fills empties). **Fix:** the seed now **only fills an empty slot** — never overwrites.
