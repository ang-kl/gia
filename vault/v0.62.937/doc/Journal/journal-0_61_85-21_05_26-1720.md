- **[INTENT]** (1) Default the Station Exit overlay layer OFF; (2) stop a
  venue/centre tap from auto-spraying context overlays (exit / carpark /
  bus-stop / taxi pins, the short station popup, the train-line emphasis)
  and delete the short station popup outright; (3) add the missing
  mid-zoom station-code marker state.

- **[DELTA]**
  - **`web/cuisine/src/v2/App.jsx` · `web/transport/src/App.jsx` ·
    `web/hawker/src/App.jsx`** — the `overlayLayers` `useState` default
    `exits: true` → `exits: false`. The menu toggle still flips it at
    runtime; only the first-load default changed. (#1)
  - **`web/transport/src/lib/mapOverlays.js`** (canonical copy; byte-copied
    to the cuisine + hawker copies, all three remain byte-identical) —
    - `attachAmenityPins` — the `includeStation` block (the short `🚉`
      station pill + its name/codes/Google-Map popup) and the
      `includeStation` parameter are deleted. Exit / bus / taxi / carpark
      pins are unchanged. (#2)
    - The train-line result-emphasis machinery is removed: the
      `setTrainEmphasis` controller method, the `trainEmphasis` variable,
      the `trackWindow` helper, and the emphasis branches inside the
      `applyVisibility('train')` opacity logic. The base polyline opacity
      now tracks zoom only (`detailStation` muted-base case preserved); the
      CR5 v2 selected-station segment highlight is untouched. (#2)
    - New `ZOOM_CODE_THRESHOLD = 13` (tunable). `stationPillNode` is
      refactored to share a `stationPillBase()` + `appendCodeChips()` pair
      with the new `stationCodeNode(codes, fallbackHex)` — a white pill of
      line-coloured code chips with no name. The `applyVisibility('train')`
      per-station `_mode` swap goes from two states to three:
      `square` (z < 13) → `code` (13 ≤ z < 15) → `pill` (z ≥ 15). (#3)
    - Unused `AMENITY_STATION_BG` const removed (only the deleted short
      popup used it).
  - **`web/cuisine/src/v2/components/MapPanel.jsx`** — the venue-pin tap
    handler no longer calls `drawVenueAmenities`; that function plus
    `plotAmenities` / `clearAmenities`, the `amenityMarkersRef` /
    `amenityCacheRef` refs, the `syncMarkers` `clearAmenities()` call, the
    `setTrainEmphasis` `useEffect`, and the now-unused `attachAmenityPins`
    import are all removed. (#2)
  - **`web/hawker/src/components/HawkerMapPanel.jsx`** — same removal
    pattern: `drawHawkerAmenities` + its tap-handler call, `plotAmenities` /
    `clearAmenities`, the amenity refs, and the `attachAmenityPins` import.
    (#2)
  - **`web/transport/src/components/MrtMapPanel.jsx`** — `renderAmenityPins`
    drops the now-invalid `includeStation: false` argument; Transport's
    station-detail amenity pins are otherwise unchanged.
  - **`package.json`** — `0.61.84` → `0.61.85` (PATCH).
