## New

### [HDR] #262 | 14:30:00 SGT 20-05-26 | v0.61.58 — CR5 v2 selected-station polyline emphasis | ~2 kb | 4 files | 1 PR | 1 build |

- **[INTENT]** When a train station is selected, light up the stretch of its line
  from the station before it to the station after it, and mute the rest of the
  network so that segment reads as the focus.

- **[DELTA]**
  - **`mapOverlays.js`** (byte-identical ×3) —
    - new `trackBetween(pts, aLat, aLng, bLat, bLng)` — slices a polyline between
      the vertices nearest to two points (companion to the existing `trackWindow`).
    - `buildTrain` now stores the line `code` on each polyline entry
      (`{ polyline, pts, hex, code }`) so the emphasis can match a polyline to a
      line.
    - `applyVisibility('train')`:
      - base polyline opacity gains a third branch — when `detailStation` is set,
        every base line mutes hard to `0.25 / weight 3` (was: search-emphasis 0.35,
        or zoom 0.85 / 0.5);
      - the existing search-emphasis (`trainEmphasis`) ±200 m windows are now
        suppressed while a station is selected — CR5 v2 takes precedence;
      - new block: for the selected station, on each line it serves
        (`stationsOnLine` membership by code), draw a bright overlay polyline
        (`opacity 1, weight 5`, line colour) along `trackBetween(prev, next)` — the
        prev→current→next stretch. End-of-line stations fall back to the one
        neighbour that exists. A 150 m on-segment guard skips polyline segments the
        station doesn't actually sit on.
  - **`package.json`** — `0.61.57` → `0.61.58` (PATCH).

- **[TEST]** Toggle 🚉 Train Line on, tap a station: every line dims to a faint

- **[KNOWN GAPS]**
  - The emphasis applies at all zooms (the CR5 spec framed it as a zoom-in
    behaviour, but a selected station is an explicit user action worth showing at
    any zoom). The v1 zoom-based base opacity still governs the *unselected* state.
  - `stationsOnLine` is recomputed per polyline segment per `applyVisibility` —
    cheap (≤ ~30 × 150-element sort) but un-cached.
  - Sandbox-unverified UI change. CR6 Phase 2b (first/last train) remains blocked
    on an LTA data source.
