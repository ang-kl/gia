- **[INTENT]** Give the Clinic / Pharmacy overlay layer a 💊 map pin and a proper
  tap-popup template (name, unit, building, street, telephone).

- **[DELTA]**
  - **`scripts/build-geo-overlays.js`** — the CHAS-clinic converter now emits
    **structured fields** — `unit` (`#FLOOR-UNIT`), `building`, `street`
    (`BLK_HSE_NO` + `STREET_NAME`), `postal`, `tel` (`HCI_TEL`) — instead of the single
    composed `address` string. Parsed from the same KML-style HTML Description table.
  - **`data/geo-clinics.json`** — regenerated (1193 features, structured fields).
  - **`mapOverlays.js`** (byte-identical ×3) — the clinics layer pin glyph `✚` → **`💊`**;
    new `clinicInfo()` popup builder renders the operator's template — `💊 name` /
    unit / building (when present) / street + `Singapore <postal>` / `☎ tel` / the
    standard `Google Map ↗` link (appended by `infoCard`). The old shared `poiInfo`
    helper is now police-only.
  - **`scripts/fetch-clinic-hours.js`** (new) — one-shot enricher. For each clinic
    without an `hours` field it runs one Google Places `searchText` call (New Places
    API v1), biased to the clinic's coordinates, with `regularOpeningHours` in the
    field mask; the nearest match within 140 m is accepted and its
    `weekdayDescriptions` (Mon-first, 7 strings) stored as `hours`. Idempotent +
    resumable; `--dry` / `--limit` flags; needs `GOOGLE_MAPS_API_KEY`. **G4 — paid
    Google Places calls (~1193, run by the operator with a funded key); the script
    ships here, the data run + commit happens post-merge.**
  - **`mapOverlays.js`** (×3) — `clinicInfo` renders today's opening-hours line
    (`🕒 …`) when a clinic carries the Places-sourced `hours` array; absent until
    `fetch-clinic-hours.js` has run.
  - **`package.json`** — `0.61.38` → `0.61.39` (PATCH).
