## New

### [HDR] #562 | 13:00 SGT 07-06-26 | v0.61.362 — 20 s location-sync resolves the flag beyond the SG/MY bbox | 3 code files | 1 PR | 2 builds |

- **[INTENT]** Make the 20-second "follow the device" sync flip the **country flag** for *all* the countries a TMA can show — not only Singapore / Malaysia.

- **[ROOT CAUSE]** `startLocationSync`'s `onLocation` resolved the country with **`coordsToCountry()`** — a **SG/MY-only bounding box** (`coords-to-country.js`). Outside SG/MY it returns `null`, so the Menu kept the **stale cached flag** as you moved. The richer global detector (`nearestIataCity` / `/api/cuisine/iata-snap`) ran **once on mount**, never during the follow. Compounding it on Menu: the pill flag reads **`countryPref`**, which `LocationFieldMenu` seeds from the server **once on mount** — so even updating the server mid-session wouldn't re-flag.

- **[MECHANISM]**
  - **Menu (`web/menu/src/App.jsx`)** — sync `onLocation`: SG/MY still use the cheap bbox; **otherwise** `nearestIataCity(loc).city.countryCode`, filtered to `MENU_FLAG_COUNTRIES` (= `OTHER_COUNTRIES` codes). `region` = `SG` / `JB` / `OTHER`. Persists `/api/menu/set-location` and (non-SG) `/api/cuisine/country-pref` so the picker + chat stay in step. The **mount auto-detect** `setAnchor` now also carries `country: detected.countryCode`.
  - **Menu pill (`web/menu/src/components/LocationFieldMenu.jsx`)** — the compact-pill OTHER flag now reads **`findCountry(currentAnchor.country || countryPref)`**, so the **live anchor country** (updated by the sync) drives the flag instead of the once-seeded `countryPref`.
  - **Cuisine (`web/cuisine/src/v2/App.jsx`)** — sync `onLocation`: outside SG/MY, `nearestIataCity` → `CUISINE_OTHER_CODES` → `setState({ region: 'OTHER', countryPref: cc })` + `saveCountryPref(cc)`. (The Cuisine collapsed pill shows no OTHER flag — SG/JB only — so this fixes the **region + OTHER-picker** follow.)
  - **Unsupported countries** (a country the TMA's flag list can't show) keep the prior flag rather than emitting a half-state.
