## New

### [HDR] #274 | 21:50:00 SGT 20-05-26 | v0.61.70 — map UI redesign (toggles, pins, flashes) | ~9 kb | 9 files | 1 PR | 1 build |

- **[INTENT]** Standardize and polish the in-map controls and pins across all
  three TMAs (Cuisine is the reference), per the operator's 10-item list.

- **[DELTA]**
  - **`web/transport/src/lib/mapOverlays.js`** (canonical, byte-identical ×3) —
    - `giaToggleStyle` — ON = Singapore blue `#1565C0` (white text), OFF = white
      `#FFFFFF` (the nav-button background); theme-independent. Was the CR7
      amber-on / theme-aware palette. (#2, #4)
    - **Bus-stop pin** — new `busPinNode(code, full)`: a white rounded-rect like
      the MRT-exit pins. `buildBusMarkers` carries `compact` (`🚏`) + `full`
      (`🚏 Bus Stop № <code>`); `applyVisibility('busstop')` swaps by zoom
      (`ZOOM_DETAIL_THRESHOLD`); `zoom_changed` now re-applies the bus layer.
      The CR4 focus-distance de-emphasis (`liteBusNode`, `BUS_DEEMPH_NEAR_M`,
      `focusPoints`) is removed — superseded by the zoom model. `attachAmenityPins`
      + `showStationBusStops` bus pins also use `busPinNode`. (#5, #9)
    - **Exit flash** — `stationInfoCardHtml` Exit-# links now pass the flash flag;
      `window.__giaStationFocus` closes the station card (`info.close()`) before
      panning + flashing, so the card never hides the flashed pin. (#6)
  - **`web/transport/src/components/MapControls.jsx`** (canonical, ×3) — the
    quick row is now a single **non-wrapping** row; `pillClass` font 11 → 9 px,
    tighter padding, `shrink-0`. The `⋯/⋮` menu button is a **white circle**
    (`w-7 h-7 rounded-full bg-white/70 …`) identical to the navigation buttons —
    no `giaToggleStyle`. (#1, #3, #4)
  - **`web/cuisine/src/v2/components/MapPanel.jsx`** — `cuisinePinNode(number)`:
    a green circle with a white border + drop shadow carrying the venue's
    **1-based result number**; `syncMarkers` numbers every venue by result order.
    The emoji-glyph pin (`pinGlyphFor` / `DESSERT_RX`) is removed. (#7)
  - **`web/cuisine/src/v2/App.jsx`** — new `searchFabFlash` state + a
    `useEffect([venues])` that pulses the `🔍` Search FAB for 2 s whenever a
    result set loads (warm-start or a Search-criteria run). (#10)
  - **Standardization (#8)** — `mapOverlays.js` and `MapControls.jsx` are
    byte-identical across cuisine / transport / hawker, so the toggle palette,
    `⋯` circle, and bus-stop pin are uniform; Cuisine is the reference.
  - **`package.json`** — `0.61.69` → `0.61.70` (PATCH).
