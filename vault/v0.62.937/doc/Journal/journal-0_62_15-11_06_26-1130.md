- **[INTENT]** Two linked problems: (1) JB + durian intermittently returns a **gateway 502**; (2) no
  single source of truth for how the search modes compose, so combinations are fragile. Fix the 502 and
  publish a validated decision tree.

- **[BUG — JB durian 502 (root cause)]** A 502 is a **gateway** failure — the Node route **never
  returned in time** (a hang past the proxy timeout), *not* a thrown error (the existing `catch` at
  `index.js:~16500` already degrades thrown/transient errors to a 200, so it can't help a hang). JB +
  durian **stacks sequential Places latency**: the 3-page discover (`maxPages:3`) **+** the special-mode
  widen **+** the zero-result generic fallback (`index.js:~15454`) **+** the post-search local-name /
  name-reading enrichments. The route had **no overall deadline**. Fix (3 parts):
  - **A1 — 20 s overall deadline (the core fix).** A `setTimeout` at the route head
    (`index.js:~14150`, `.unref()`'d, `res.headersSent`-guarded) returns a **degraded-200**
    (`D706 deadline-degraded`, same shape as the D705 transient path) if the body is still running.
    The gateway timeout is ~30-60 s, so a 20 s self-cap means the route **always answers first → it can
    NEVER 502**. The two real exits (success `res.json` + the `catch`) `clearTimeout` and bail on
    `res.headersSent` so we never double-send.
  - **A2 — budget guards.** The special-mode widen is skipped once `_elapsed() > 14 s`; the zero-result
    generic fallback only fires when `_elapsed() < 15 s` — so the optional extra Places passes can never
    push the request into the deadline/502 zone. Base pool + name-dedup still run.
  - **A3 — the real JB recall bug (outside the thrashed zone).** `buildSeeds` was passed
    `country: requestCountry`, which for a JB pick is often `'SG'`/null (the device anchor) — so the
    **v0.62.14 Malay seeds never got appended for JB**, and JB durian under-recalled. Now passes
    `smCountry` (already `'MY'` for JB / MY-PUT) → JB + MY-PUT get the Malay local seeds
    (`kedai/gerai/pasar durian`). This touches **seed-language only**, NOT region/country detection or
    persistence — deliberately staying clear of the "most-thrashed" location-reconciliation area.
