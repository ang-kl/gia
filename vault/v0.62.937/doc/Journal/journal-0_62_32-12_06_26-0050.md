- **[INTENT]** Arrive in a city → the TMA tells you the dishes that are genuinely *of that place*,
  with provenance you can audit (📜 fact-card cites named sources), and dish-search results that are
  honest about which eateries actually serve it. Plus the confirmed bug from the operator's Railway
  log: typed dish names were being **geocoded into place anchors** — "Ikan patin tempoyak" in
  Putrajaya jumped the search to **Yishun, SG**; "Obanzai" in Kyoto jumped to a SG izakaya.

- **[A — source of truth first (`instruction/unique_dishes.md`, v2)]** 16-section exercise before any
  code: authority hierarchy (**Tier S** government heritage — UNESCO ICH, NLB Infopedia, JKKN
  warisan registry, MAFF, Warisan Negara 2024 > **A** tourism boards > **B** TasteAtlas/Michelin —
  *cite, never scrape* > **C** Wikipedia > **D** local historians/founder shops), per-city dish rows
  with 📜 histories, a **local-language pass (ms/ja/th)** that closed 6 of 13 [TO VERIFY] rows, §17
  variant appendix (BKT Klang-vs-SG, wanton mee KL-vs-SG…), §18 fact-card UI spec, §19 honesty
  scorecard. **Remaining [TO VERIFY] rows are EXCLUDED from the data** until the operator confirms.

- **[B — `city-plates.js` (new registry)]** `CITY_PLATES` frozen object — **14 cities, 69 dish rows**
  (SG, JB, KL, Klang, George Town, Putrajaya, Bangkok, Chiang Mai, Tokyo, Kyoto, Sapporo, Brisbane,
  Sydney, Auckland; Malacca dropped — no centroid). Row:
  `{ dish, local, tier: 'city-icon'|'regional'|'national-classic', claim, history:{en,fr},
  differsFrom?, sources:[{name,url?,lang}] }` — every row carries ≥1 named source as a provenance
  comment. Helpers: `platesForCity`, `platesNear(lat,lng)` (lazy-requires
  `nearestCityForAnchor`, 25 km match, fail-open) and `allPlateDishNames()`. **Honesty model**:
  Putrajaya is `honestEmpty: true` (no city-unique dish — the regional patin tempoyak row says
  Temerloh, ~100 km); disputed origins name both claimants (pavlova AU↔NZ; BKT Klang↔SG).

- **[C — server: plate payload]** `/api/cuisine/user-location` and `/api/cuisine/set-location`
  responses now carry `plate = platesNear(lat,lng)` (try/catch, fail-open, **zero new Places spend**
  — pure in-memory lookup). No new endpoint.

- **[D — TMA Screen 1: ArrivalPlate.jsx (operator pick A)]** Collapsed one-liner under the location
  field — `🍽 What to try here: dish1, dish2… [▾]` — expands to ≥44 px rows: dish + local script +
  **tier in words** (en/fr), a **📜** button per row → dismissible fact-card bubble showing the
  **curated** `history` text + tier·claim·differsFrom + the sources line. **The bubble text comes
  from the registry only — never generated by an LLM at runtime.** `honestEmpty` cities render the
  honest notice. Collapses on city change. Tap a dish row → fires the dish search.

- **[E — Screen 2: the evidence split (operator pick E)]** On a dish search (free text matches a
  known dish), the server tags each venue `dishEvidence: 'name' | 'reviews' | null` (D790b — venue
  name contains the dish > review text mentions it, CJK-aware via the shipped v0.62.31 norm/aliases)
  and sorts confirmed-first. `ResultPanel` renders hard section headers: **"✔ Confirmed — reviews
  mention it"** above **"? Ask first — check if they serve it"** — shape + words, never colour
  alone (colour-blind safe). Off a dish search no venue carries the field → no headers, list
  renders exactly as before.

- **[F — D788 dish-name guard + D789 backstop (the Railway-log bug)]**
  `discovery-dish.isKnownDishName(text)`: lazy build-once Set (~2k names — NATION_OVERLAY
  iconicDishes incl. shared + sharedWithNeighbors, DISH_ALIASES, allPlateDishNames); match = exact
  OR contains-a-dish-with-≤1-leftover-token; script-aware floor (CJK ≥2 / Latin ≥3 chars);
  fail-open. Wired before `detectPlaceName` in the free-text anchor flow — a typed dish name can
  **never** become a geocoded place anchor (D788 log line). **D789**: even when a place IS
  detected, an anchor pivot **>300 km** from the current anchor is rejected (the cross-country
  jump class). "ramen in tiong bahru" still anchors to Tiong Bahru; "Restoran Dapur Mars patin
  tempoyak" (≥2 leftover tokens) is treated as a venue name, not blocked. Saves geocode spend too.

- **[G — the no-state-race tap]** A plate dish tap calls
  `runSearch(state, null, { freeTextOverride: dish })` — the override wins over `nlText` inside the
  request body, so the search fires on the same render without waiting for React to commit
  `setNlText` (the v0.61.237 explicit-anchor lesson applied to free text).

- **[NOT touched — deliberately]** `/s` and its router (standing rule); NATION_OVERLAY /
  COOKING_METHODS data (read-only consumers only); the location-reconciliation boot gate (no
  timers, no popups — v0.61.409 / v0.62.30 policies stand).
