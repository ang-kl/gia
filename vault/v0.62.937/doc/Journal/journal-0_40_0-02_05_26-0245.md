### [HDR] #83 | 02:45:00 SGT 02-05-26 | v0.40.0 | n/a kb | n/a lines
- **[INTENT]** Migrate the LLM provider from Gemini (`@google/generative-ai`) to Claude (`@anthropic-ai/sdk`). Per Human Lead: "switch from `GEMINI_API_KEY` to `ANTHROPIC_API_KEY`. All services in Railway have `ANTHROPIC_API_KEY`. Change the codes." Scope clarification: "Google MAP and Google New Place API remains" — preserve every Google Places, Geocoding, and Routes Matrix call; only swap the LLM SDK.
- **[DESIGN]**
  1. **NEW `llm-client.js`** — single Anthropic SDK shim used by all 12 callers. Signature mirrors the legacy Gemini call shape (`result.response.text()`) so caller diffs are minimal:
     ```js
     const result = await llm.generate({ prompt, model, system, json: true, jsonShape: 'array', maxTokens: 4096 });
     const text   = result.response.text();
     ```
     - `DEFAULT_MODEL = 'claude-opus-4-7'` (overridable via `ANTHROPIC_MODEL`).
     - `HAIKU_MODEL = 'claude-haiku-4-5-20251001'` for cheap classifiers (gatekeeper, nl-intent, vibe-summary, consultant, heritage-significance).
     - `SONNET_MODEL = 'claude-sonnet-4-6'` for the prompt-builder Stage A (mid-tier query rewriter).
     - **JSON enforcement via assistant-prefill** — the SDK has no `responseMimeType` equivalent. We seed the assistant turn with `{` (object) or `[` (array), force the model to continue inside that bracket, then re-prepend the prefill on the way out. Combined with the existing `extractJsonArray` / `extractJsonObject` helpers (kept untouched in `pipeline.js` and `surprise.js`), this handles malformed fences cleanly.
     - SDK-internal retries disabled (`maxRetries: 0`); the existing `gemini-retry.js` `withRetry` handles backoff so diagnostic logs stay readable.
  2. **`gemini-retry.js`** — filename retained for repo-churn minimisation; contents rewritten. New retryable status set adds 408 (request timeout) and 529 (Anthropic overloaded). `makeFlashFallback` is now a no-op factory returning `null` so any caller still passing it keeps compiling — Anthropic has no Pro→Flash overload class to fall back from.
  3. **Caller sweep (12 files)**:
     - `gatekeeper.js` — Haiku 4.5 (was Flash).
     - `nl-intent.js` — Haiku 4.5.
     - `vibe-summary.js` — Haiku 4.5.
     - `consultant.js` — Haiku 4.5 (review sanctuary read).
     - `heritage-significance.js` — Haiku 4.5.
     - `prompt-builder.js` — Sonnet 4.6 (Stage A meta-prompter).
     - `cuisine-search.js` — Opus 4.7 (`geminiCandidates15` legacy path).
     - `pipeline.js` — Opus 4.7 (`reason`, `reasonExecute`, `refine`).
     - `surprise.js` — Opus 4.7 (`geminiEnrich`).
     - `vibe-suggest.js` — Opus 4.7 (`geminiCandidates`).
     - `recognised-seeder.js` — Opus 4.7 (scout for award-winners; quality matters more than cost).
     - `ver.js` — `checkGemini` → `checkAnthropic`; `/ver` row label updated.
  4. **`voice-input.js` STUBBED** — `classifyVoice()` returns `null`. Anthropic's Messages API does not accept audio attachments. Telegram OGG/Opus voice notes now degrade gracefully; users see a polite fallback. Re-enabling requires a separate ASR step (Whisper / AssemblyAI / Deepgram) and is documented as Open #40D in the register.
  5. **Google Search grounding dropped** from `pipeline.reason`. Was already disabled by default since v0.31.2 (after the `tools + responseMimeType: 'application/json'` 400 regression on Pasir-Panjang), so this is a no-op behaviourally. The vault snapshot continues to anchor "newly opened" claims. If web-search reasoning is needed later, swap in Anthropic's `web_search` tool definition.
  6. **`index.js` env-var checks** — `GEMINI_API_KEY` → `ANTHROPIC_API_KEY` in `/admin/test-pipeline` trace and the `/ver`-adjacent env-presence reporter. Two single-line edits.
  7. **Version bumps**: `package.json`, `web/cuisine/package.json`, `web/menu/package.json`, `web/hawker/package.json` all bumped 0.39.3 → 0.40.0. `@google/generative-ai` removed; `@anthropic-ai/sdk` ^0.40.0 added.

- **[KNOWN GAPS / TRADE-OFFS]**
  - **No audio input** — see Open #40D. Documented; expected to remain stubbed until a dedicated ASR plumb-up is requested.
  - **No web-search grounding** — Anthropic's `web_search` tool exists but was not wired in this migration. The vault snapshot is the primary anchoring source today; web-search reasoning was already off in production since v0.31.2.
  - **Cost shift** — Opus 4.7 is materially more expensive per token than Gemini 2.5 Flash. Heavy callers (gatekeeper, nl-intent, vibe-summary, consultant, heritage-significance) were all moved to Haiku 4.5 to absorb most of the difference. Future patch can introduce prompt caching (`cache_control: { type: 'ephemeral' }`) on the GEOSPATIAL_CULINARY_ANALYST template + vault snapshot block in `pipeline.reason` for ~90% input-cost reduction on repeat queries.
  - **`responseMimeType` parity** — emulated via assistant-prefill rather than a first-class JSON-schema enforcer. Robust in practice but not as bulletproof as Gemini's hard JSON mode. Existing `extractJson*` helpers stay as the safety net.
