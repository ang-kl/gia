## New

### [HDR] v0.62.620 — five Train-TMA fixes from the IMG_3614 phone screenshot

- **[INTENT]** Operator sent **IMG_3614** (the Train TMA on a phone) with four asks:
  1. *"Extend."* — carry the v0.62.619 Inter header prototype to the **whole app body**, not just headers.
  2. *"The navigation button on the google Map — expand and default isn't working. If it is set to
     default, then the drawer should automatically open, showing the default East west line."*
  3. *"The drawer is very hard to open and half-shut and close. No drawer handle. Effect is open/close
     must be there."*
  4. *"The header with carousel scroll of All lines… East-west line without the border of the carousel."*

- **[DELTA — 5 changes]**
  1. **Inter → body.** `web/{cuisine,hawker,transport}/index.html` — `<body>` class gained `font-inter`
     (was `bg-tg-bg text-tg-text` → `… font-inter`). Inter now applies app-wide, headers and body alike.
  2. **EWL default (drawer auto-opens on the default line).** `web/transport/src/App.jsx` — the data-load
     effect changed from `if (d?.affectedCodes?.length && !focusedCode) setFocusedCode(d.affectedCodes[0])`
     to `if (!focusedCode) setFocusedCode(d?.affectedCodes?.[0] || 'EWL')`. The old guard was gated on
     `affectedCodes.length`, so an **all-clear** network (no disruptions) left **nothing focused** — no
     default line, drawer empty. Now the East-West Line (`EWL`) is the fallback focus, so the phone drawer
     always opens on a populated line.
  3. **Drawer handle — grabbable + clear open/close.** `web/_shared/components/BottomSheet.jsx` — the drag
     handle was too faint/thin to find. Wrapper `pt-2.5 pb-1.5` → `pt-3 pb-2` (bigger tap zone); bar
     `h-1.5 w-10 rounded-full bg-tg-hint/40` → `h-1.5 w-12 rounded-full bg-tg-hint/70` (wider, far more
     opaque). The tap-steps-taller + drag-to-snap behaviour was already present; this makes the affordance
     visible so the open/close effect is discoverable.
  4. **Borderless line-pills carousel.** `web/transport/src/components/AffectedTicker.jsx` — the **compact**
     variant (the "All lines / East-West line…" pill row) dropped its card chrome:
     `rounded-2xl bg-tg-bg/90 liquid-glass … px-2 py-2` → a bare `flex flex-col` (compact = `gap-0`, no
     rounded card / glass / padding). The non-compact variant keeps the card.
  5. **Map nav-cluster inset (reachable in the drawer).** `web/transport/src/components/MrtMapPanel.jsx` —
     new `navInset` prop. The floating nav cluster (`top-12`) sat under the drawer's floating header, so
     the **expand / default** controls were unreachable in the phone drawer. `App.jsx`'s `mapBlock` now
     takes `(fillMode, navInset = false)` and the **phone-drawer branch** calls `mapBlock(true, true)`;
     with `navInset` the cluster offsets to
     `calc(var(--tg-content-safe-area-inset-top, env(safe-area-inset-top, 0px)) + 7.5rem)`, clear of the
     header. Full-screen (non-drawer) map keeps `top-12`.
