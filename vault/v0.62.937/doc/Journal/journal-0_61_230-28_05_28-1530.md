## New

### [HDR] #431 | 15:30 SGT 28-05-28 | v0.61.230 — /s regionCode + suffix fix | 3 files | 1 PR | 1 build |

- **[INTENT]** When the user sets a non-SG anchor (Tokyo, Bangkok,
  KL, Kuching, …) via the v0.61.227/228 cascades, `/s` queries
  should be biased to that country's Places — not always SG.

- **[DELTA]**

  **1. `searchVenuesByDish(textQuery, cuisine, opts)`** — accepts
  new option `regionCode` (default `'SG'` for back-compat). The
  Places `searchText` body's `regionCode` field is now driven from
  this option instead of hardcoded `'SG'`.

  **2. `handleSearchTurn(chatId, userText, lang)`** (the `/s` entry
  point) — derives `regionCode` from the cached user anchor:

  ```js
  let regionCode = 'SG';
  if (loc?.country && /^[A-Z]{2}$/.test(loc.country)) regionCode = loc.country;
  else if (loc?.region === 'JB' || loc?.region === 'MY-PUT') regionCode = 'MY';
  ```

  `loc.country` is the ISO alpha-2 written by `setUserLocation`
  when the operator picked a city in the Menu / Cuisine TMA
  cascade (v0.61.227/228). JB / MY-PUT regions map to MY for
  back-compat with the existing precinct-based anchors.

  **3. Three fan-out paths get `regionCode` threaded** through:
  - `runTechniqueFanOut` — accepts `regionCode`. `ctx` now carries
    it; the variant-search textQuery suffix becomes `" restaurant
    Singapore"` only when `regionCode === 'SG'`, else just
    `" restaurant"` (Places' regionCode + locationBias do the
    geographic work).
  - `runCookingMethodFanOut` — accepts `regionCode`. The textQuery
    suffix swaps from `"Singapore restaurant"` to `"restaurant"`
    when non-SG.
  - `runNationIconicFanOut` — intentionally **NOT** updated. The
    iconic-dish overlay matches SG-only dishes (milo dinosaur,
    kaya toast, chilli crab); the textQuery's "Singapore" anchor
    is correct by design even when the user is currently in JP.

  **4. Cooking-method callback handler** (separate from `/s` entry —
  the picker tap after R.E.D / Gemini classifies the term as a
  cooking method) also derives `regionCode` from the cached anchor
  and passes it through. Parallel to `/s` logic.

  **5. `package.json`** — `0.61.229 → 0.61.230`.

  **6. `doc/.serial-state.yml`** — commit 442→443, build 232→233, journal 430→431; re-anchored 28-05 '26 15:30 SGT.
