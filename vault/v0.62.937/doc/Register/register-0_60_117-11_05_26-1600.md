## Decisions (append-only addition)

| # | Decision | Date | Rationale |
| :--- | :--- | :--- | :--- |
| D-404 | Cuisine search excludes previously-seen results per ChatID — opposite of Google Maps | 11-05 '26 | Operator: "I want to be different from Google map, to exclude previous search results." Google Maps re-shows page 1 every search; Soleat advances through an accumulating-exclusion pool. Identity = the verified Telegram `chatId` (HMAC `initData` via `twa-auth.js`) — no new identifier minted. |
| D-405 | The exclusion set is the whole session, not a time window — TTL is hygiene only | 11-05 '26 | Operator: "Fresh round should be after the last N places are listed regardless of TTL." Walks back the v0.60.116 15-min sliding window. `SEEN_SET_TTL_S` = 12 h purely so abandoned keys don't leak. Resets are: ↺ Start over (`resetSeen`), or a criteria change (different `criteriaHash`). |
| D-406 | Pool depth via Google `nextPageToken` pagination (3 pages) + query-phrasing escalation, not infinite results | 11-05 '26 | Google Places `searchText` caps at ~3 pages / 60 results per query (same ceiling Google Maps itself hits). To go deeper, escalate to alternate phrasings ("best <X> restaurant Singapore" etc.) and dedup against the accumulated seen-set — ≈100–130 distinct venues across 4 phrasings, then the genuinely-terminal ↺ Start over state. Operator's "6 pages" ⇒ this is implemented as escalation, since one query can't return 6 pages. |
| D-407 | Per-chatId pool cache for now; shared (criteria + coarse-area) cache + cron pre-warm deferred | 11-05 '26 | A shared pool keyed by criteria + ~few-km area bucket would cut Places calls ≈100–1000× and Redis ≈100× at 5000 users (the per-user freshness still lives in the per-chatId seen-set). Operator chose per-chatId for the current scale. Recorded in Deferred below. |
| D-408 | Query-variant escalation is single-cuisine only in v0.60.117 | 11-05 '26 | Multi-cuisine AND/OR has its own round-robin merge; escalating it cleanly is a larger change. Kept at v0.60.116 behaviour (plain per-chatId dedup) for now. Recorded in Deferred below. |
