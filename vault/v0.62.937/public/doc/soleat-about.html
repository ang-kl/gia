🍴 Soleat — what it is & how it thinks

“Solo eats” / “So let’s eat” — a Telegram-native dining concierge for Singapore (and beyond), read through the Observe · Interpret · Act loop, topped with Wisdom.

1 The one-paragraph picture

Soleat is a Telegram bot + five Mini-Apps + an Express server that helps a (often solo) diner decide where to eat now without a dozen browser tabs. It folds curated dining discovery, hawker culture, recognised-list pedigree, live weather, and a light transport guide into one chat surface. Every capability hangs off a single entry character — the slash /. The bot resolves your intent against your place and the moment, then hands back ranked picks and the means to get there.

3 How it thinks — the Observe · Interpret · Act loop

Every / turn runs the same cognitive loop. / is where Observe begins; the reply is where Act ends.

OBSERVE — gather
  • Who/where: location anchor (GPS · curated precinct · typed street), region (SG / JB / other)
  • Intent: the command or free-text query
  • The moment: NEA weather, LTA traffic, carpark occupancy, time-of-day meal period
  • The world: Google Places venues, reviews, ratings, hours, accessibility
INTERPRET — make sense
  • Disambiguate: R.E.D + nation-overlay + cooking-method matchers (deterministic first, LLM last)
  • Gate relevance: geofence fail-closed, per-cuisine relevance gates (no cross-border mislead)
  • Rank & narrate: Gemini ranks, picks a signature dish, writes the “why”
  • Enrich: travel time, footfall*, recognised-list pedigree, dish lists
ACT — deliver
  • Decide-for-me cards: name · dish · price · ♿ · crowd · transport
  • Maps: tap a pin / card → it blinks, shows nearby transit at the live zoom tier
  • Get there: bus / MRT / walk / drive + carpark lots
  • Carry on: Copy / share / clipboard / buddy match
Data → Information → Knowledge → Wisdom  ·  raw signals become a ranked, contextual recommendation — and the system’s judgement about what to withhold.

* footfall (BestTime) is an enrichment, currently SG-only by design — coverage abroad is thin, so it is deliberately skipped rather than mislead. Enrichment never blocks delivery.

4 The Wisdom layer — the principles under the code

Wisdom is the apex of the loop: the standing judgements about what not to do, distilled from the build’s own mistakes.

  • Honest by geography. Relevance gates fail closed — a Russian search in Putrajaya must never surface a Singapore venue 330 km away. Better no answer than a wrong one.
  • Graceful degradation. Every enrichment (travel, crowd, dishes) is best-effort; a failure logs and is skipped — the main pick still ships. A hard 20-second deadline guards against “Load failed”.
  • Deterministic before clever. Known-dish disambiguation pre-empts the LLM, so confident facts aren’t overwritten by a looser guess.
  • Authenticity over compression. The doc/ contract is append-only — removed ideas are preserved with rationale, so the build’s reasoning reads top-to-bottom (and a generated Vibe Journal makes the rework loops visible to reduce them).
  • Bilingual & private by default. Full EN / FR parity; /forgetme erases on request; identity is hashed; /doc can sit behind a key.
  • Reduce decision fatigue. The whole point of “solo eats” — collapse weather + place + pedigree + transport into one confident next step.
