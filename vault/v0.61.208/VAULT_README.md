## What this snapshot is

A faithful mirror of the repository at v0.61.208 — all source (`index.js` + ~85 root
modules, `web/<app>/src`, `scripts/`, `public/app.js`), the curated datasets (`data/`,
`data_realtime/`), the open-data sources (`geoloc/`), the `__tests__/` suite (2522 tests
green at snapshot time), and the full `doc/` documentation system through journal #409 +
the operator-supplied flag assets (`MY_Johor_flag.png`, `MY_Putrajaya_flag.PNG/.svg`).

It is bootable: a clean `npm install` reproduces the service.

## Notes

- **Rule V-1 / V-2** — `vault/v0.61.116/` is kept, not superseded. This vault captures
  the v0.61.117 → v0.61.208 delta arc (92 versions).
- **Rule V-3** — this snapshot's `doc/Journal/` will omit the self-referential journal
  addendum that documents this very vault pass (no `journal-0_61_209-*` exists yet); the
  omission is recorded in the creating PR description.
- **Region model** — at v0.61.208 the three-pill SG / JB / OTHER model is fully wired
  end-to-end: chat picker + TMA pill + region-aware Places + post-filter trust contract
  for OTHER. The OTHER region pill swaps to the Putrajaya flag PNG when the active
  anchor's precinctId is `ioi-resort-putrajaya`; otherwise it shows the generic 🌏 globe.
- **Smart label** — anchor labels now go through `smart-place-label.js` which drops bare
  Google `displayName.text` building-numbers and synthesizes `<Street/Building>, <City>,
  <State>` from `formattedAddress`. Country tail / postal codes / leading building
  numbers in the city slot are stripped.
- **Recent-locations** — `/lrecent` drawer is wired from chat `/location <text>` success
  paths (coded, SG-geocoder, non-SG Places searchText) and from
  `/api/cuisine/set-location` (TMA pick). LRU is 10-entry, 180 d TTL, deduplicated by
  coord-rounded `(lat,lng)`.
- `doc/VibeCodingRecord/` regeneration is still due (carried from prior vault).
- Operator's open follow-up at vault time: a few keyboard-nav / animation polish items
  on the custom country dropdown (Cuisine TMA + Menu TMA), and Menu TMA's OTHER picker
  could also consume the v0.61.196 `country-pref` server sync (currently only the
  Cuisine TMA reads it).
