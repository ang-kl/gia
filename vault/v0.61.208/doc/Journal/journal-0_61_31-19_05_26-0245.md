## New

### [HDR] #235 | 02:45:00 SGT 19-05-26 | v0.61.31 — "Google Map ↗" standard in every map pin popup (3 TMAs) | ~4 kb | 7 files | 1 PR | 1 build |

- **[INTENT]** Map pin info popups were inconsistent across the three Mini Apps: the
  bus-stop amenity popup ended with a `Google Map ↗` text link, but the attraction /
  exit / taxi / carpark / station-amenity popups carried no Maps link at all, and the
  Cuisine venue popup launched Google Maps from a **blue `#1a73e8` button**. The operator
  set a TMA-wide standard — every Google-map pin popup ends with a `Google Map ↗` text
  hyperlink, and the blue button is dropped.

- **[DELTA]**
  - **`web/cuisine/src/v2/lib/mapOverlays.js`** (+ byte-identical copies
    `web/transport/src/lib/mapOverlays.js`, `web/hawker/src/lib/mapOverlays.js`) — new
    `gmapsUrl()` / `gmapsLinkRow()` helpers; `infoCard(inner, gmaps)` gained an optional
    `gmaps` `{lat,lng}` arg that appends the standard link row. Every popup builder now
    passes coordinates: `nameInfo` (taxis), `exitInfo`, `carparkInfo`, `attractionInfo`,
    and the `attachAmenityPins` `openCard` (exit / taxi / carpark / station pins).
    `busInfoHtml` dropped its hand-rolled link in favour of `infoCard(h, b)`.
  - **`web/cuisine/src/v2/components/MapPanel.jsx`** — the venue InfoWindow's
    touch-only blue "Open in Google Maps" `<button>` (`background:#1a73e8`) is replaced
    by a `Google Map ↗` text hyperlink shown uniformly on touch and desktop, still
    routed through the global `window.__giaOpenMap(placeId)` handler (place-id deep
    link). The traffic-incident popup now passes `{lat,lng}` to `infoCard`.
  - **`web/transport/src/components/MrtMapPanel.jsx`** — the station popup's `linkHtml`
    label changed from `t('mrt.openInMap')` to the literal `Google Map ↗`.
  - **`web/hawker/src/components/HawkerMapPanel.jsx`** — the hawker-centre popup's
    address line is now plain text; a trailing `Google Map ↗` hyperlink (via
    `window.__giaHawkerOpenMap`) was appended so the popup ends with the standard link.
  - **`package.json`** — version `0.61.29` → `0.61.31` (PATCH; `0.61.30` reserved for
    the concurrent PR #516).
