  **`pipeline.js` — new `narrateMichelinVenues({ candidates, lang })`**
  - A narrate-only variant of `rankAndNarrate` (no re-ranking — the Michelin path already filters/sorts its curated list 3★ → 2★ → 1★ → Bib Gourmand; we just want per-venue narration). The prompt explicitly says *"add narration to EVERY one — DO NOT drop any"* and *"reference the Michelin recognition correctly (no hallucination)"*.   - Returns a placeId-keyed map `{ placeId: { vibe, signatureDish, dishes } }`. The caller merges these into its venue array. Defensive: drops hallucinated placeIds (any placeId not in the input `candidates`). `dishes` is truncated to 3.
  - Failure modes — `llm.isReady() === false`, `withRetry` throws, `JSON.parse` fails, parsed result is not an array, or no good placeIds — all return `{}`. The caller's Michelin response still ships (curated badge + review-extracted dishes + recentReview from step 1 below). **Never throws.**
  - Localised: `lang === 'fr'` adds a French-locale prompt block + iconic-SG-dish whitelist (laksa / char kway teow / kaya toast / hokkien mee / …) so French narration keeps SG dish names un-translated.
  - Exported from `pipeline.js`'s `module.exports`.

  **`index.js` — `handleMichelinSearch` (lines ~5574–6010)**
  - **FIELD_MASK** (line ~5684) gains `places.reviews` and `places.editorialSummary`. Cuisine-chip path already fetches `reviews` via `pipeline.discover`'s mask; Michelin's separate `searchText` call now matches.
  - **Venue object** (line ~5736 onward) passes the `reviews` array through (kept until cleanup below) and converts `editorialSummary.text` to `googleSummary.overview` (≤ 320 chars) — matches the cuisine-chip path's shape.
  - **Step 1 — review-derived dish extraction + recentReview** (mirrors the inline block in `/api/cuisine/search` at line ~9057; slimmed down to keep this PR's blast radius small — no shared module yet, deferred): for each Michelin venue with `Array.isArray(reviews)`, run the same two regex captures + the same TRAIL_STOPWORDS + CATEGORY_BLOCK filters + capitalisation/length heuristics.   - **Cleanup.** `delete v.reviews` on every venue before the response is sent (the heavy payload was only needed for the local dish/narrate steps). `googleSummary.overview` is small enough to ship to the TMA (parity with the cuisine-chip path).
