## New

### [HDR] #221 | 08:15:00 SGT 18-05-26 | v0.61.19 — clickable bus-stop arrivals + hawker-centre surrounding amenities | ~6 kb | 6 files | 1 PR | 1 build |

- **[INTENT]** Operator, continuing the TMA Google-map review: (1) the bus-stop amenity pins
  in the station-detail view should be tappable and show live arrivals, bucketed by ETA;
  (2) tapping a hawker centre should also drop pins for the surrounding station exits, bus
  stops, taxi stands, carparks, and the nearest MRT station — so the centre's transport
  context is visible on the map, not just in the popup text.

- **[DELTA]**
  - **`index.js`** — new `GET /api/transport/bus-arrival?code=<n>` endpoint: wraps
    `transport.busArrivals`, validates the 3–7-digit stop code, and degrades to an empty
    services list when `LTA_ACCOUNT_KEY` is unset or the LTA call fails.
  - **`web/{cuisine,hawker,transport}/src/.../lib/mapOverlays.js`** (byte-identical ×3) —
    bus-stop amenity pins are now clickable (`🚏№<code>` label, pointer cursor). A tap opens
    a popup with the stop's identity + distance, fetches `/api/transport/bus-arrival`, and
    renders the services bucketed `≤5 / ≤10 / ≤20 / 20+ min`, plus a Google Maps link.
    `amenityLabelNode` gains a `clickable` flag; `place()` in `drawAmenities` accepts an
    optional click handler.
  - **`web/hawker/src/components/HawkerMapPanel.jsx`** — tapping a hawker-centre pin now
    also fetches `/api/transport/station-context` for the centre's coords and plots the
    surrounding amenity pins (exits, bus stops, taxi/pick-up, carparks) plus a `🚉 <name>`
    pill for the nearest MRT station. Results cached per centre; pins cleared on region
    change.

  $ npx vite build  (cuisine / hawker / transport)        → all green

- **[STATUS]** DRAFT → PR (base `main`, branch `claude/review-gia4lunch-readme-3s798`).
