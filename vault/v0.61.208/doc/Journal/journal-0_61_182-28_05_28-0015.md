## New

### [HDR] #383 | 00:15 SGT 28-05-28 | v0.61.182 — TMA footer build-time chip | 3 files | 1 PR | 1 build |

- **[INTENT]** Vite's `vite.config.js` has been injecting both
  `__BUILD_VERSION__` AND `__BUILD_TIME__` constants since v0.29.0,
  but only the version is surfaced (footer, v0.60.213). Surface
  the timestamp too so a stale cached bundle is identifiable.

- **[DELTA]**
  - **`web/cuisine/src/v2/App.jsx`** (2 edits):
    - New constant `BUILD_TIME` (mirrors `BUILD_VERSION`
      pattern, defensive fallback to empty string in dev).
    - New helper `_formatBuildTimeShort(iso)` — parses an ISO
      8601 timestamp and returns `"YYYY-MM-DD HH:MM"` (strips
      the trailing `Z` + seconds; the 9pt footer can't carry
      the full ISO without wrapping).
    - Footer line: appended `· built 2026-05-28 00:15 UTC`
      after the version. Gracefully degrades when
      `BUILD_TIME` is empty (dev / SSR).
  - **`package.json`** — `0.61.181 → 0.61.182`.
  - **`doc/.serial-state.yml`** — commit 394 → 395, build 184 →
    185, journal 382 → 383; re-anchored 28-05 '26 00:15 SGT.
