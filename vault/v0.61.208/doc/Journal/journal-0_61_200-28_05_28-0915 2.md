# Journal — soleat v0.61.200 (/location country hints + restructured quick-pick)

> Two operator-flagged UX bugs:
> (a) `/location Times Square KL` resolved to a Singapore match
>     because the geocode hard-defaulted to country=SG even when
>     the query obviously named a Malaysian city.
> (b) The `/location` no-args quick-pick keyboard only listed 12
>     of the 17 precincts the Menu TMA exposes (the 5 SG region
>     buckets — CBD / West / East / North / Central — were
>     missing) and had no "Others — pick a country" affordance.
>
> Commit 413 / journal 401 / build 203, on branch
> `claude/v0.61.200-location-hints-and-quickpick` off `main` at
> v0.61.199.

## New

### [HDR] #401 | 09:15 SGT 28-05-28 | v0.61.200 — country hints + 17-entry quick-pick | 5 files | 1 PR | 1 build |

- **[INTENT]**
  1. Make `/location <text>` *infer* the country from explicit
     city/country tokens in the query (KL, Kuala Lumpur, Putrajaya,
     Bangkok, Bali, Tokyo, …) so the user doesn't have to run
     `/lcountry` first.
  2. Mirror the Menu TMA's full 17-entry precinct dropdown on the
     chat quick-pick keyboard, with an explicit "🌏 Others — pick
     a country" row.

- **[DELTA]**

  - **NEW `country-hints.js`** (~110 lines, CommonJS):
    Per-country regex arrays for the 16 OTHER countries.
    `detectCountryHint(text)` scans the text for the longest
    matching pattern (so "kuala lumpur" beats any single-word
    collision) and returns the ISO 3166-1 alpha-2 code or `null`.
    Notable omission: "nagoya" deliberately NOT in JP because
    "Nagoya Hill" is a famous shopping mall in Batam (Indonesia).
    Word-boundary anchors (`\b`) prevent false positives like
    "Skl Cafe" firing as MY.

  - **NEW `__tests__/country-hints.test.js`**: 23 tests covering
    input sanitisation, MY (operator's failure case — "Times
    Square KL", "Kuala Lumpur", "JB", "Putrajaya", "Skudai",
    "Iskandar", "Pasir Gudang", "Mersing"), TH/ID/PH/VN/JP/KR
    samples, CN/HK/TW/AU/NZ samples, longest-match priority,
    and HINTS shape integrity.

  - **`index.js`** (4 edits):
    1. **Top require** — destructures `detectCountryHint` from
       `./country-hints`.
    2. **`/location <text>` country-code resolution** — after
       reading the persistent pref (`country-pref:<chatId>`),
       scans the text for a hint. If matched and different from
       the stored pref, overrides `countryCode` for THIS query
       only (the saved pref is unchanged). New log line:
       `[/l] country-hint <text> → <CC> (override pref=<pref>)`.
    3. **`sendLocationQuickPicks`** — was using
       `precincts.getAll()` (12 entries: 10 STB + JB + IOI). Now
       uses `precincts.getMenuDropdown()` (17 entries) and groups
       them into three pair-rows sections — STB / SG region
       buckets / Malaysia — then appends a single 1-wide row:
       `🌏 Others — pick a country` (callback `locpick:others`).
       Layout per section: 5×2 STB → 3×2 SG-regions (last cell
       single) → 1×2 Malaysia → 1×1 Others.
    4. **`locpick:` callback** — NEW branch at top: when `id`
       is `'others'`, send the `/lcountry` inline keyboard (via
       `buildCountryPickerKeyboard` from `country-pref.js`)
       directly instead of resolving a precinct.

  - **`package.json`** — `0.61.199 → 0.61.200`.
  - **`doc/.serial-state.yml`** — commit 412 → 413, build 202 →
    203, journal 400 → 401; re-anchored 28-05 '26 09:15 SGT.

- **[KNOWN GAPS]**
  - The hint dictionary is a static curated list — it will miss
    less-famous places ("Klang Valley", "Putra Heights", etc.).
    Adding entries is one-line additions to `country-hints.js`.
  - The hint scan only runs in `/location <text>`. The cuisine
    TMA's OTHER picker still requires the user to pick a country
    from the flag dropdown (no auto-detection there). Symmetric
    detection in the TMA is a possible future PR but doesn't
    affect this operator complaint.
  - The 🌏 Others row sends a NEW message with the country
    picker instead of editing the quick-pick message in-place.
    That preserves the quick-pick so the user can still tap an
    SG/JB entry after seeing the country picker. Telegram's
    editMessageReplyMarkup could replace the row in-place, but
    that would lose the option to go back.
