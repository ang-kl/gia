## New

### [HDR] #267 | 18:20:00 SGT 20-05-26 | v0.61.63 — per-station nearest-bus-stop enrichment | ~9 kb | 5 files | 1 PR | 1 build |

- **[INTENT]** Produce a per-station `nearest_bus_stops` dataset (codes, coordinates,
  distances from the station centroid + nearest exit, confidence) for the CR6 card.

- **[DELTA]**
  - **`scripts/enrich-nearest-bus-stops.js`** (new, ~220 lines) — two-stage:
    - **Stage A — offline triangulation** (always runs, no network/key). Joins
      `data/stations.json` (station + exit coords) with `geoloc/LTABusStop.geojson`
      (5,166 bus stops — codes + coords, an LTA / data.gov.sg dataset). Per station:
      expanding-radius search (400 m → 800 m if < 3 found → 1000 m if 0 found);
      Haversine distance from the centroid **and** every exit; sort by distance
      from the nearest exit; keep the top 3–5; assign `high` / `medium` / `low`
      confidence.
    - **Stage B — OneMap name pass** (runs only with `ONEMAP_API_KEY`). Calls
      `getNearestBusStops` per station (3× retry, exponential backoff), fills
      `bus_stop_name` by matching the stop code. Failures → the errors file; the
      run continues. Without the key, names stay `null` + a `data_quality_note`.
    - Non-invention: codes/coords only from the GeoJSON, names only from OneMap,
      missing data → `null`.
  - **`data/stations_with_nearest_bus_stops.json`** (new, generated) — 180 stations,
    880 bus-stop entries (824 high / 44 medium / 12 low). Each record matches the
    operator's structure (`station_name`, `station_codes`, `line_codes`, `operator`,
    `station_coordinates`, `station_exits[]`, `nearest_bus_stops[]`,
    `data_quality_notes`).
  - **`data/nearest_bus_stop_errors.json`** + **`data/nearest_bus_stop_coverage_report.json`**
    (new, generated).
  - **`scripts/README-nearest-bus-stops.md`** (new) — sources, OneMap key setup,
    radius logic, confidence scoring, non-invention rules, rerun steps.
  - **`package.json`** — `0.61.62` → `0.61.63` (PATCH).
