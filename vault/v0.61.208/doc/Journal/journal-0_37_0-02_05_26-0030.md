- **[DESIGN]**
  1. **Logo polish** (`web/cuisine/public/soleat-logo.svg`) — replaces the v0.34.2 starter (fork stem + leaf) with a more refined mark: a rice bowl (gradient-filled rounded base) + steam/leaf accent + fork tine (single vertical stroke with a small split tip). Still hand-crafted SVG, hardcoded Telegram blue. Comments include the full Midjourney prompt for future designer iteration.
  2. **Footfall telemetry** — `pipeline-task.js#refineIfPossible` increments Redis counters `footfall:signal-fired:{high,medium,low,null}` plus `footfall:fetch-context-runs` per cluster ONLY when `FOOTFALL_PROXY_ENABLED === 'on'`. Fire-and-forget; never blocks refine. `index.js#runVerCommand` reads the counters and surfaces a row when the flag is on: `Footfall (A/B on, N runs): high=X · med=Y · low=Z · null=W (n=total)`. Counters live forever (no TTL — telemetry is the point); reset by deleting the keys via redis-cli.
  3. **`/recognised <category>`** — `bot.onText` regex now captures an optional second token. New `RECOGNISED_FILTER_ALIASES` map normalises `michelin`/`bib`/`asia`/`world`/`chef`/`unesco` (and full canonical names) → category. Unknown aliases respond with the valid set. When filter is set, fetch widens to 25 candidates and post-filters down to 5 (so a single-category query doesn't dead-end on the wrong-category 5).
  4. **Logo on Menu TMA** — `web/menu/public/soleat-logo.svg` (copied from cuisine TMA — same asset). `web/menu/src/App.jsx` Header gains a 28×28 inline `<img>` next to the title. Both TMAs now carry consistent branding.
  5. **Travel-time enrichment** — `runRecognisedCommand` and `runHeritageFoodCommand` now wrap the venue list with `rankByWalkingTime(lat, lng, venues)` from `vibe-suggest.js` before rendering. Each card gains `· 🚶 N min walk` next to the haversine distance. Falls back to haversine-only when Routes Matrix fails.
  6. **Inline detect error** — Header.jsx removes the `showAlert` import; replaces the modal with a small inline `<p>` below the Enable button when detect throws (lastErr state). Honest framing: "Still blocked: <reason>. Open device Settings → Privacy → Location Services and grant Telegram permission, then tap Enable again."

- **[KNOWN GAPS]**
  - **Logo iteration is still hand-crafted SVG.** Suggested next step: feed the embedded Midjourney prompt to a polished image-gen run, then export as SVG (Figma's image-trace works for high-contrast brand marks). The current asset is functional but won't beat a designer.
  - **Travel-time enrichment costs ~$0.015 per `/recognised` or `/heritage-food` call** (one Routes Matrix call). Acceptable for low-traffic chat commands; if these get spammed by buddy-shared users we'd want per-chat throttling like `pick-cache.js` does for `/cuisine`.
  - **Footfall telemetry counters are unbounded.** They never reset; they grow forever once `FOOTFALL_PROXY_ENABLED=on`. After A/B verdict, set the flag back to `off` AND `redis-cli del footfall:signal-fired:high footfall:signal-fired:medium footfall:signal-fired:low footfall:signal-fired:null footfall:fetch-context-runs` to clean up. Future patch could daily-rotate the counters into `footfall:signal-fired:high:YYYY-MM-DD` for better trend analysis.
  - **`/recognised` filter doesn't combine with category aliases.** No `/recognised michelin+bib`. If volume warrants, future patch can extend the parser.
  - **Inline detect error only fires when user taps the manual Enable button.** Auto-detect on TMA mount silently sets `locDenied` (unchanged from v0.34.2). That's correct — the banner already explains.
