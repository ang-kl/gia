    (`inRadius` / `currentRadius()` — the same set `applyVisibility`

    `frameAttractions(entry)` after `applyVisibility` when
    `name === 'attractions' && visible` — i.e. only on an explicit
    toggle-ON of the Attractions chip. cuisine edited, copied
    byte-identical to hawker + transport.
