## New

### [HDR] #166 | 21:35:00 SGT 15-05-26 | v0.60.199 — Michelin chip SG-flag label + JB-region disable | 3 files | 1 PR |

- **[INTENT]** Operator wants the ✳️ Michelin chip relabeled to surface the SG-scope (🇸🇬 flag inside the label) and disabled when the region toggle is set to JB. The curated dataset (`michelin-2025.js`) is the Singapore Michelin Guide 2025; there is no JB Michelin list to ship today.

- **[DELTA]**

  **`index.js`** — `/api/cuisine/catalogue` synthetic Michelin tile:
  - Two occurrences of `'Michelin List'` → `'🇸🇬 Michelin List'` (top-level `label` + `categoryLabel` on the single child cuisine). The chip already prefixes the emoji `✳️` via `CategoryCard`'s render path, so the visible chip becomes `✳️ 🇸🇬 Michelin List`.
  - Added `regionScope: 'SG'` to the category object. The TMA reads this; future region-scoped categories (e.g. a JB-curated list) can mirror the shape without further server change.

  **`web/cuisine/src/v2/components/CuisineDrawer.jsx`**:
  - Component signature gained a `region` prop.
  - `CategoryCard` computes `regionDisabled = cat.regionScope && region && cat.regionScope.toUpperCase() !== String(region).toUpperCase()`. When true:
    - `<button disabled aria-disabled="true">` so screen readers + browser semantics honour it.
    - `onClick` early-returns.
    - Tooltip: `Singapore only` (EN) / `Singapour uniquement` (FR).
    - Visual: `opacity-50 cursor-not-allowed` swapped in for the hover-accent styling.
  - Non-`regionScope` categories behave exactly as before.

  **`web/cuisine/src/v2/App.jsx`**:
  - `<CuisineDrawer region={state.region} … />` (line 1134).
  - Region-toggle `onClick` now strips `'michelin'` from `state.cuisines` when switching to JB — prevents a previously-selected chip from lingering as a phantom filter on the next search.
