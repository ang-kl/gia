## New

### [HDR] #204 | 12:48:00 SGT 17-05-26 | v0.61.1 — LRT station data fix + Circle Line closed loop | 4 files | PR A of 3 | 1 build |

- **[INTENT]** The three LRT lines drew wrong on the Transport Google Map and the Circle Line
  never closed into a ring. Investigation found the root cause was **corrupt station data in
  `data/mrt-coords.json`**, not just the drawing logic — the v0.60.233 geometry fix had worked
  around it for Punggol but Sengkang was still broken.

- **[DELTA]**
  - **`data/mrt-coords.json`** — Sengkang LRT was badly wrong: the SE and SW loop codes were
    **swapped**, the West Loop was **missing 3 stations** (Fernvale, Layar, Tongkang — real SW
    loop has 8, data had 5), and several coordinates were scrambled. Punggol LRT codes were
    **mis-numbered** (Teck Lee coded `PW7`, should be `PW2`; PW2–PW7 all shifted). Rebuilt all
    14 Sengkang (STC + SW1–8 + SE1–5) and all Punggol West-loop (PW1–7) station entries —
    correct codes + coordinates. Coordinates sourced offline from polygon centroids in
    `geoloc/AmendmenttoMasterPlan2019RailStationlayer.geojson` (`RAIL_TYPE:"LRT"` features),
    and Sam Kee from the averaged exits in `geoloc/LTAMRTStationExitGEOJSON.geojson`.
  - **`web/transport/src/data/line-paths.js`** — added a `LINE_SEQUENCES` entry for **CCL**: one
    closed-loop station-name sequence running the full CC arc → the CCL6 stations (Keppel /
    Cantonment / Prince Edward Road) → Marina Bay → Bayfront → back to Promenade, so the Circle
    Line draws as **one full closed ring**. Removed the now-dead `PREFIX_HEAD` CE→Promenade
    spur hack (the CE stations are folded into the CCL sequence; `LINE_SEQUENCES` short-circuits
    the code-prefix path for CCL so there is no double-draw).
  - **`__tests__/transport-line-paths.test.js`** — fixture rebuilt with corrected Punggol codes
    and the full CCL station list (incl. CC30/31/32 + CE1/2); new case asserts CCL resolves to
    one closed ring (first=Dhoby Ghaut, last=Promenade) containing the CCL6 stations and no
    detached CE spur; Punggol West-loop case updated for the corrected Teck Lee position.
  - **`package.json`** — `0.61.0 → 0.61.1` (PATCH — data + geometry bug fix).
  - With the data corrected, the existing SLRT numeric-order + STC hub-wrap logic now draws
    both Sengkang loops correctly (8 SW + 5 SE) — no further `line-paths.js` change for SLRT.
    The 3 CCL6 stations stay `status:"future"`; the CCL polyline draws solid (operator choice).

- **[STATUS]** STAGED → PROD on the next Railway deploy after PR A merges. The corrected data
  ships in `data/mrt-coords.json`; the Transport TMA bundle ships in `public/transport/`.

- **[TEST]** Post-deploy spot-check on the Transport TMA Google Map: Sengkang LRT draws as two
  proper loops (8-station West, 5-station East) off the STC hub; Punggol LRT loops with Teck Lee
  between Sam Kee and Punggol Point; the Circle Line is a closed ring running through Keppel,
  Cantonment and Prince Edward Road.

- **[KNOWN GAPS]**
  - Polylines are still straight segments between stations (no curved LTA route geometry —
    `data/mrt-line-paths.json` is absent; that fetch is blocked on data.gov.sg access).
  - Sam Kee's coordinate is the average of its two station exits (it is absent from the
    rail-station-layer GeoJSON) — accurate to ~tens of metres.
  - PR B (Healthier Choice eatery indicator) and PR C (expandable maps, overlay layers on the
    Transport TMA, live carpark) are still due — see the plan.
