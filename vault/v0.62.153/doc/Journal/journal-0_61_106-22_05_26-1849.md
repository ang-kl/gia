- **[INTENT]** `/app/map`'s Train Line layer rendered each station as a
  `🚉` emoji pin (a v0.61.100 regression); the real TMA maps draw
  coloured line-code chips. Make `/app/map` mirror the Hawker TMA's
  train-station tier algorithm.

- **[DELTA]**
  - **`public/app.js`** — `public/app.js` is a plain IIFE and cannot
    import the ES-module `mapOverlays.js`, so the Hawker train-tier
    algorithm is re-implemented compactly, ported from
    `web/cuisine/src/v2/lib/mapOverlays.js`:
    - `PREFIX_TO_LINE`, `parseCode`, `codeHex` (`LINE_HEX` was already
      present); the `CHIP` scale ladder.
    - `trainTier(zoom)` — the Hawker bands: tiny coloured square below
      z12; nearest-N line-code chips at z12-14 (nearest 5 / 10 / 15 to
      the map centre, the rest stay squares); full named pills z15+;
      line opacity 0.5 / 0.7 / 1.
    - `metresBetween`, `metresPerPixelAt`, `markerBoxPx`,
      `demoteByOverlap` (the iterative symmetric overlap-demotion
      pass); the node builders `stationPillBase` / `appendCodeChips` /
      `stationCodeNode` / `squareStationNode` / `stationPillNode` /
      `trainStationNode`.
    - `renderTrainStations` rewritten — drops the `overlayPin('🚉')`
      content and the flat z≥13 gate; resolves the tier, picks the
      nearest-N capped set, demotes overlaps, places each marker via
      `trainStationNode`, and sets the base polylines' opacity to the
      tier value. Viewport clip + ~200-marker cap kept; the station
      tap still opens the same info popup.
  - **`package.json`** — `0.61.105` → `0.61.106` (PATCH).
