## New

### [HDR] #454 | 14:45 SGT 29-05-29 | v0.61.253 — Cuisine 2-row layout | 3 files | 1 PR | 1 build |

- **[INTENT]** Today's pill packs everything onto a single row —
  `📍 <name> · <suffix> tap to change ✏️ 🔍` — which truncates the
  city name aggressively on narrow viewports. Operator wants a
  clear 2-row layout with the city name (+ a flag prefix) on row 1
  and the meta info right-aligned on row 2.

- **[DELTA]**

  **1. `web/cuisine/src/v2/components/LocationField.jsx` SG/JB pill** —
     restructured to a 2-row layout inside the same
     `rounded-md border border-tg-accent bg-tg-card` container:

     ```jsx
     <div className="rounded-md border border-tg-accent bg-tg-card px-3 py-1.5">
       <div className="flex items-center gap-2">                  {/* row 1 */}
         <span aria-hidden className="text-tg-accent">📍</span>
         <button onClick={() => setOpen(true)}
                 className="flex-1 min-w-0 text-left text-sm inline-flex items-center gap-1.5">
           {region === 'SG' && <span aria-hidden>🇸🇬</span>}
           {region === 'JB' && <img src="MY_Johor_flag.png" … />}
           <span className="truncate">{resting}</span>
         </button>
         …× / 🔍…
       </div>
       {!open && suffix && (
         <div className="text-[10px] text-tg-hint italic text-right leading-tight mt-0.5">
           {suffix} · tap to change 🔝
         </div>
       )}
     </div>
     ```

     The `🔝` lands directly below the row-1 `🔍` because both
     children align to the container's right edge (text-right on
     the meta row; flex-end on the icon button).

     `min-w-0` on the button + `truncate` on the name span lets
     long names like "SPH Media Centre Telok Blangah Cluster"
     truncate instead of pushing the 🔍 off the edge — the same
     fix idiom from v0.61.248 Menu TMA.

     Flag handling mirrors the v0.61.204 region-pill row in
     App.jsx: SG → 🇸🇬 emoji, JB → `MY_Johor_flag.png` img
     (16×11 px, `rounded-sm border-tg-border/40`).

  **2. `web/cuisine/src/v2/components/LocationField.jsx` OTHER
     compact pill** — same 2-row treatment. The row-1 trailing
     control changed from ✏️ to **🔍**, so the operator can fire
     a search at the current OTHER anchor without expanding the
     picker (consistent with the SG/JB pill). Tapping the body
     (📍 + flag + city name) still expands the picker for
     country/city changes; tapping 🔍 fires the search at the
     parent-supplied `onSearch`.

  **3. `web/cuisine/src/v2/components/LocationField.jsx`** —
     forwarded the `onSearch` prop into `OtherLocationPicker` so
     the compact pill's 🔍 can call it.

  **4. `package.json`** — `0.61.252 → 0.61.253`.

  **5. `doc/.serial-state.yml`** — commit 465→466, build 255→256,
     journal 453→454; re-anchored 29-05 '26 14:45 SGT.
