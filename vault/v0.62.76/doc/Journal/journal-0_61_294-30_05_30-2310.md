# Journal — soleat v0.61.294 (auto-warming Gemini cache extended to fruits mode)

> Operator (30-05 '26 23:05 SGT, post-PR-#799 merge): *"5"* — extend the v0.61.282 D703f auto-warming Gemini cache beyond durian / durian-pastry to the third special mode (`fruits`).
>
> Pre-v0.61.294, `/api/cuisine/search` D703e (cached-label post-filter) and D703f (inline verify-then-cache) were gated on `specialMode === 'durian' || specialMode === 'durian-pastry'`. A fruits-mode search at any location got zero Gemini quality control — even if a steak house showed up because Places ranked it for "mango" or "fresh fruit", it stayed in the result list. The cuisine drawer's "Dessert, Fruits" category exposes `fruits` as a real toggle, so this gap was user-facing.
>
> Fix in two files:
>
> 1. **`durian-gemini-verifier.js`** — `_buildPrompt` refactored from a binary `if (mode === 'durian')` to a `PROMPT_CONFIG` map keyed by mode. Adding fruits is a new map entry (`directory: 'Singapore + Malaysia fresh-fruit directory'`, broad fresh-fruit sells-clause covering mangoes / apples / oranges / mangosteen / rambutan / jackfruit / etc.). `verifyKeptVenues`'s mode-validation allow-list updated `['durian', 'durian-pastry']` → `['durian', 'durian-pastry', 'fruits']`. Existing durian + durian-pastry prompts preserve their exact substrings ("FRESH DURIAN FRUIT" / "DURIAN-FLAVORED PASTRIES") so the existing test contract stays green.
>
> 2. **`index.js D703e/D703f`** — gate widened from inline `if (specialMode === 'durian' || specialMode === 'durian-pastry')` to `if (GEMINI_CACHE_MODES.has(specialMode))` where `GEMINI_CACHE_MODES = new Set(['durian', 'durian-pastry', 'fruits'])`. Same cache lookup → inline verify → write-back flow; just a wider mode allow-list.
>
> The bot `/ver` UI still only exposes durian + durian-pastry buttons (DVG_LABEL is unchanged). **Fruits mode is auto-warming-only** — the cache builds up organically as users search.
>
> Commit 508 / journal 495 / build 297, on branch
> `claude/v0.61.294-fruits-mode-gemini-cache` off `main` at v0.61.293.
