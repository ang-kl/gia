## New

### [HDR] #331 | 06:25 SGT 25-05-26 | v0.61.130 — Cuisine TMA UI pills surface v0.61.129 O-20 + O-23 | 4 files | 1 PR | 1 build |

- **[INTENT]** Make the v0.61.129 backend additions visible to the
  Cuisine TMA user:
  - **O-20 (Tell-me place anchor)** — when the typed text is
    recognised as a Singapore place, render a pill above the result
    list saying *"📍 Searching near Tiong Bahru MRT"* (or *"📍
    Showing 'ramen' near Tiong Bahru MRT"* when the user typed a
    dish/qualifier alongside the place). Currently the result list
    shows in the right area but with no explanation — users notice
    the location pivot only by reading venue addresses.
  - **O-23 (Fruits/Durian radius widening)** — when the backend's
    radius-escalation loop fired, append *"· widened to N km"* to
    the existing amber *"Limited matches nearby"* card so users
    understand why their result list draws from a wider area than
    the slider implies.

- **[DELTA]**
  - **`web/cuisine/src/v2/App.jsx`**:
      - **Two new state hooks** (next to `specialModeNotice`):
        `placeAnchor` ({ name, kind, lat, lng, source,
        queryRemainder } | null) and `specialModeWidenedInfo`
        ({ fromM, finalM } | null).
      - **Response-handler read** (~line 720): both hooks set from
        the `r.placeAnchor` / `r.specialModeWidened*` fields with
        defensive type-narrow guards (`Number.isFinite` on lat +
        finalM; `r.placeAnchor.name` truthiness).
      - **Page-cache round-trip**: both fields are persisted onto
        `newPage` so the Back/Forward FABs replay the right pill +
        caption alongside the cached venues; the page-restore
        effect reads `p.placeAnchor` / `p.specialModeNotice` /
        `p.specialModeWidenedInfo`.
      - **Failure-path resets**: cleared in the `questionDeclined`
        branch and the top-level `catch` so a stale *"📍 Searching
        near Tiong Bahru"* doesn't sit above an empty result list
        after a network blip or a server-declined query.
      - **JSX additions** (~line 1320 / 1340):
        - The existing amber `specialModeNotice` card now appends
          a `<span className="text-tg-hint">` with `tn('special
          .widened', lang, { km: (finalM/1000).toFixed(1) })`

        - A new `placeAnchor && !loading && (...)` card with a
          `border-tg-border` (informational, not alert/amber) +
          `text-[12px] leading-snug` rendering either
          `tn('anchor.showing', lang, { query, place })` or
