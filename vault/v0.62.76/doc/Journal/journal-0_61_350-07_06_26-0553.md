- **[INTENT]** Two display bugs surfaced by the v0.61.346 multi-country wiring: (1) the result subtitle was hardcoded "Michelin Singapore 2025" for every country; (2) the curated-list hint rendered above the card instead of below the "· Michelin <country>" line.

- **[MECHANISM]**
  - **Label:** the subtitle is App.jsx's `comboLine`, built from the catalogue cuisine `name` — which is the static `'Michelin Singapore 2025'` (`index.js:11724`). The handler now computes a country-aware `michelinEditionLabel` (SG → `'Michelin Singapore 2025'`; other countries → `Michelin <CountryName>` via a `MICH_CC_NAME` map — **years omitted off-SG because editions are merged**, and the list is national, not per-city) and returns it as `michelinSummary.label`. App.jsx's `comboLine` uses `michelinRemaining.label` for the `michelin` slug instead of the static catalogue name.
  - **Hint position:** the "📚 … N more to explore … Tap 🔍 for the next batch of 12" block moved out of App.jsx (where it sat above `<ResultPanel>`) into ResultPanel as a `michelinHint` prop, rendered **full-width directly below the header** (under "Results: N" + "· Michelin <country>"), above the venue cards.
