- **[INTENT]** Operator, on the TMA Google maps: (1) tapping a station opened Google's own
  native transit info-card instead of our station-detail view; (2) the white InfoWindow
  background is hard to read, especially in dark mode — some text colours can't be read;
  (3) the expand toggle should use `⇱` (reduce) / `⇲` (expand) glyphs inside the circle;
  (4) a tapped station should go straight to the detail view without an extra popup;
  (5) add `/train` as a bot command.

- **[DELTA]**
  - **`web/hawker/src/components/HawkerMapPanel.jsx`** /
    **`web/cuisine/src/v2/components/MapPanel.jsx`** — `clickableIcons: false` on the map
    constructor, so a tap hits our overlay marker rather than Google's native POI/transit
    card (the Transport map already set this). InfoWindow content is wrapped in an off-white
    rounded card (`background:#f4f3ef;border-radius:12px`) with a pinned dark text colour, so
    every popup reads in both light and dark Telegram themes.
  - **`web/{cuisine,hawker,transport}/src/.../lib/mapOverlays.js`** (byte-identical ×3) —
    tapping a train station no longer opens an InfoWindow; the station-detail view appears
    directly. The selected station becomes a named pill (`🚉 <name>`) so it self-identifies,
    replacing the larger centre square. `stationInfoHtml` removed. Carpark / attraction /
    taxi InfoWindows wrapped in the same `infoCard` off-white card.
  - **`web/{transport,hawker,cuisine}/.../MapPanel|MrtMapPanel.jsx`** — the expand toggle
    glyphs are now `⇱` (collapse) / `⇲` (expand); the transport station InfoWindow gets the
    off-white card too.
  - **`index.js`** — `/train` added as an alias in the `/transport` command regex.
