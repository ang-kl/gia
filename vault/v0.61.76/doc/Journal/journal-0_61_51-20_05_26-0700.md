- **[INTENT]** Tidy the in-map controls and labels per the operator's CR1/2/3/7/8/9.

- **[DELTA]**
  - **CR1** — `mapOverlays.js` (×3): the exit-template popup now renders the station
    name with the `" Station"` suffix (e.g. `Somerset Station`).
  - **CR2** — quick-row / dropdown reorg on all three TMA panels:
    - row toggles: `[🚉 Train Line, 🅿️ Carpark, 🚏 Bus Stop]` (Train Line promoted,
      Attractions demoted);
    - dropdown menu: `[Exits, Taxis, ✨ Attractions, 🌳 Park, Police, Clinics,
      Hospitals, 24-hours-disabled]` — Attractions sits above Park;
    - the right-side nav cluster shifts from `top-2 → top-12` so the row has clean
      horizontal space;
    - **Taxi Stand default is now off** in all three `App.jsx` (`taxis: true → false`).
  - **CR3** — `mapOverlays.js` `buildBusMarkers`: bus-stop pin label is now
    `🚏 № <code>` (spaces inserted) — was `🚏№<code>`.
  - **CR7** — Cuisine `App.jsx`: the three floating FABs (Search, Scroll, page-Next)
    no longer use the washed-out `#7FDBDB` green. A new `fabBgFg(active)` helper
    pulls the shared `giaToggleStyle` palette so the FABs are theme-aware — Search
    FAB goes **amber when dirty**, white / dark slate otherwise; Scroll + page-Next
    are always inactive style. Also: the Search FAB's `onClick` was still calling
    `runSearch(state)` directly — corrected to `triggerSearch` (the v0.61.50 helper)
    so the loading-overlay message reflects the right state.
  - **CR8** — Colour-mode FAB on all three panels: replaces the small round icon-only
    button with a **pill that carries the state in text** — `"🎨 Colour mode"` when
    colour is on, `"🎨 Greyscale mode"` when greyscale is on. **No on/off colour
    effect** (single neutral inactive style) per operator spec.
  - **CR9** — `mapOverlays.js` `ensureGreyscaleStyle`: the rule now stacks
    `grayscale(1) contrast(0.8) brightness(0.96)` on `canvas` and `img`, so the base
    map reads as a quieter wash and custom overlays / pins pop more clearly.
  - **`giaToggleStyle`** is now theme-aware (was a single fixed amber/dark palette):
    light-mode ON `#D97706` / OFF `#FFFFFF`; dark-mode ON `#F59E0B` / OFF `#1F2937`,
    per the operator's CR7 spec — applied wherever the helper is used (MapControls
    pills + the Colour-mode FAB + the floating FABs).
  - **`i18n.js`** (×3) — new `layer.colour.on` / `layer.colour.off` keys.
  - **`package.json`** — `0.61.50` → `0.61.51` (PATCH).
