## New

### [HDR] #98 | 21:00:00 SGT 03-05-26 | v0.50.0 | n/a kb | n/a lines

- **[INTENT]** Replace the v0.49.0 PDF-based hawker vault with the human-curated `data/list-of-hawker-centres.md` file (Human Lead committed it to main as `643a79a`). Add 5-region segmentation (Central/South/East/North/West) per Human Lead's directive: "spend time to segment by north, south, east west, central. sort by alphabetic, with google url".

- **[DESIGN]**

  1. **REWRITTEN `hawker-vault.js`** — drops PDF fetch + pdf-parse + Redis cache. Reads MD file from disk at module load, parses into 122 records (107 markets + 16 new − 1 closed = 122; Bukit Timah Market is closed for redevelopment till 2029).
     - `parseMd(md)` — line-by-line pipe-table scanner. Skips header + separator + closed rows. Strips `#` footnote marker from names. Extracts postal from `S(NNNNNN)` form (takes first when slash-pair like `S(161022/162022)`).
     - Each parsed centre is enriched in-place with `region` + `mapsUrl` so consumers don't need to derive them.
     - Module-level memo cache (no TTL — file is committed, so process lifetime is enough).

  2. **5-region classifier (`regionForCentre`)** — first-match wins:
     - **Strong-signal name keywords** (~50 distinctive places per region): `bedok`, `tampines`, `pasir ris`, `marine parade`, `geylang`, `kallang` → East; `yishun`, `woodlands`, `hougang`, `sengkang`, `punggol`, `ang mo kio`, `bishan` → North (combines URA's North + Northeast); `jurong`, `clementi`, `bukit batok`, `holland`, `pasir panjang`, `queenstown` → West; `tanjong pagar`, `chinatown`, `outram`, `tiong bahru`, `bukit merah`, `telok blangah` → South; `orchard`, `newton`, `novena`, `toa payoh`, `bukit timah` → Central.
     - **Postal-sector fallback** when no keyword matches:
       - 01–10, 14–16 → South (CBD + Tiong Bahru/Bukit Merah)
       - 17–37 → Central (Orchard, Newton, Novena, Toa Payoh, Macpherson)
       - 38–52, 81–82 → East
       - 53–57, 72–80 → North
       - 11–13, 58–71 → West
     - Regex uses negative lookahead to avoid false matches (e.g. `bukit timah(?! market)` so the closed Bukit Timah Market doesn't override; `tanglin(?! halt)` to keep Tanglin Halt Market in West).

  3. **`getByRegion(region?)`** — lazy-builds the 5-region index once, sorts each region alphabetically by `name.localeCompare(en, sensitivity:base)`. Returns the full `{Central, South, East, North, West}` map when called with no arg.

  4. **`formatRegionList(region)`** — Telegram-friendly markdown output. Each centre as: `1. *Name* 🆕\n   address\n   📍 <maps_url>`. The 🆕 badge marks the 16 "new hawker centres" (Ci Yuan, Bukit Panjang, etc.). Truncates at 3800 chars to fit Telegram's 4096 ceiling.

  5. **`mapsUrlForCentre(centre)`** — uses the documented Google Maps URLs API: `?api=1&query=<encoded "Name, full address">`. The full address gives Google Maps a precise resolution target — much better than `<name> + Singapore` (v0.48.1) which often hit wrong places for generic "Blk N <street>" names.

  6. **NEW `/hawker` UI: "📋 Browse all centres by region"** button on the cleaning-info screen → opens a region picker (5 region buttons with emoji + count) → selecting a region renders the alphabetical list with maps URLs. Two callback handlers: `hawker:list:menu`, `hawker:list:region:<Region>`.

  7. **MODIFIED `nea-scrape.js#getStructuredClosures`** — vault loader is now sync (`vault.getAllCentres()` no longer takes `redis`). Same match logic at ≥0.85 confidence; vault failure still non-fatal.

  8. **DROPPED `pdf-parse` dep** — was added in v0.49.0; replaced by direct MD-file read.

- **[KNOWN GAPS / SCOPE CUTS]**
  - **Region classification is heuristic.** Some borderline centres could legitimately go either way (e.g. Holland Village = West vs Central; Adam Road = Central vs North). The keyword regex prefers consistency over perfection — Human Lead can refine `REGION_KEYWORDS` in `hawker-vault.js` directly if a specific centre lands wrong.
  - **No "South" in URA's official 5-region scheme.** URA splits SG into Central/East/North/Northeast/West. The "South" region used here groups CBD + Tiong Bahru + Bukit Merah + Telok Blangah which URA classes as Central. Used because Human Lead asked for N/S/E/W/Central explicitly.
  - **MD file is a snapshot.** When NEA publishes a new quarterly list, `data/list-of-hawker-centres.md` needs a manual update (human-readable diff in PR — much better than auto-pulling stale data). Cache is per-process so a deploy after an MD update picks it up immediately.
  - **No TMA-side region browser yet.** The `/hawker` Telegram menu has the new "Browse by region" button, but the `/app/hawker` TMA still only renders cleaning closures. TMA enhancement deferred.
  - **Bukit Timah Market is excluded.** It's "closed for redevelopment till 2029" so it has no usable address. When it reopens, the MD edit will re-add it automatically (parser detects the `closed for redevelopment` substring).
  - **`#` footnote rows kept** (Chong Pang, Old Airport, Toa Payoh Lor 5, Whampoa, etc. — managed by FairPrice on behalf of NEA). The footnote is stripped from the display name; the operator info lives in `mgmt`.
