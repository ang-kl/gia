## New

### [HDR] #257 | 09:00:00 SGT 20-05-26 | v0.61.53 — zoom-aware train layer (CR5 v1) | ~2 kb | 4 files | 1 PR | 1 build |

- **[INTENT]** At map zoom ≥ a detail threshold, every visible station becomes a
  labelled pill (`<code> <name> station`) in its line colour; the base polyline
  becomes more opaque. Below the threshold the existing compact square pins return
  and the polyline drops to 50 % opacity.

- **[DELTA]**
  - **`mapOverlays.js`** (byte-identical ×3) —
    - new `ZOOM_DETAIL_THRESHOLD = 15` constant.
    - `createOverlayController` now attaches a `zoom_changed` listener on the map and
      re-applies the `train` layer on every zoom change.
    - `applyVisibility('train')` computes `zoomedIn = map.getZoom() >= ZOOM_DETAIL_THRESHOLD`
      and:
      - sets the base polyline opacity to `0.85` when zoomed in / `0.5` when zoomed
        out (the existing emphasis mode keeps its `0.35 / 0.5` overlay logic);
      - replaces the previous "only the selected centre is a pill" rebuild with a
        unified per-station content swap — every visible station is a pill when
        zoomed in, square when zoomed out (the explicitly-selected centre stays a
        pill regardless of zoom). A `_mode` flag per station caches the current state
        so we only rebuild content on actual transitions.
    - the labelled pill uses the existing `amenityLabelNode(label, lineHex, '#fff')`
      with `label = "<code> <name> station"` (the operator's CR5 example).
  - **`package.json`** — `0.61.52` → `0.61.53` (PATCH).
