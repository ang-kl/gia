## §0.7.0 NEW CONTENT

### 1. Three-path location entry on `/eat /drink /groceries`

When no cached location exists, the bot's prompt offers three paths:

| Path | UX |
| :--- | :--- |
| **Tap to share location** | Existing 📍 reply-keyboard button. Native Telegram location share. |
| **Type a place name** | NEW. User types a building, street, or landmark; soleat geocodes via Google Places `searchText` and uses that as the search centre. Stores as 30-min cached user location for follow-ups. |
| **Default to Raffles Place** | Existing ⛔ reply-keyboard button. Falls back to 1.2839, 103.8517. |

### 2. Prompt copy update

| | |
| :--- | :--- |
| Before | "Where are you for {meal}? Tap to share once." |
| After | "Please tap to share your location, or type a place name and Gia will search within 200 m of it." |

The location handler's "Got it. Looking for X within 300m…" is updated to "within 200m" for consistency.

### 3. Walking radius — 200 m (was 300 m in v0.6.0)

`vibe-suggest.js` `SEARCH_RADIUS_M` reduced from 300 m → 200 m. Tighter "tap-friendly" radius around either the user's GPS, the typed place, or Raffles Place default.
