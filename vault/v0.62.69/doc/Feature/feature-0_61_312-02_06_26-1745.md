## C. Free-text chat pipeline

### C.1 Intent classification

The free-text path classifies each message into one of 5 intent kinds. Implementation: `nl-intent.js` + `freetext-classify.js` + `gemini-client.js` (intent classifier model call). Deterministic dictionaries (`cooking-methods.js`, `cuisine-dish-keywords.js`, `dessert-drink-keywords.js`, `dish-name.js`, `dish-types.js`, `misrepresented-dishes.js`, `nation-overlay.js`) are consulted first; on no deterministic hit, a Gemini intent classifier returns a JSON kind.

The 5 kinds:
1. **dish** — name of a specific dish (e.g. "ramen", "goulash"). Resolved via `pipeline.discover()` cuisine-fan-out.
2. **ingredient** — generic noun ("dumplings", "spicy chicken"). Same fan-out.
3. **cooking-technique** — e.g. "sous-vide", "tandoori", "sautéing". Resolves to a curated cuisine + a Gemini explainer + a representative dish, rendered with a country flag + "verify" caveat. **Render path** (resolved 02-06 '26 post-audit): chat callback at `index.js:3074` does `const cookm = require('./cooking-methods')`, calls `cookm.findCookingMethodMatches(cookText)` at `cooking-methods.js:1083` to surface candidates, then dispatches `runCookingMethodFanOut({ chatId, userText, hit, lang, center, sc, regionCode })` at `index.js:8509`. The fan-out function is the actual emitter of the cuisine + flag + Gemini explainer + dish lines. `[OK: confirmed on main @ 207f1e63 — `cooking-methods.js:1083` + `index.js:3074, 8509`]`
4. **cuisine** — name of a cuisine ("Italian", "Sichuan"). Funnels to `/cuisine` with the cuisine preselected.
5. **ambiguous** — bilingual hint suggesting the user try `/s <term>` or `/cuisine`. `[OK: confirmed pattern by `freetext-classify.js` filename + the v0.61.83 master.]`

### C.2 `/s` (alias `/search`) guided-assistance sub-menu
- `bot.onText(/^\/(?:search|s)/)` at `index.js:2538`.
- Without arguments → renders an inline-keyboard sub-menu with category buttons (the "Cooking Methods" entry was removed in v0.60.193 — see RF-1).
- With `/s <free-text>` — runs the same classifier as the free-text chat path.

### C.3 `dish-name.js` guard
- Every "Try" line emitted by a cooking-technique response carries only a genuine dish name. The guard rejects generic ingredients and freeform strings before they hit the user. `[OK: confirmed via filename + v0.61.83 master + AU-1 trace]`
