- **[INTENT]** Refine the v0.61.90 per-TMA train overlay (Cuisine only):
  revert a tapped station's marker when its info card is closed; retune
  the Cuisine zoom tiers (radius-based chip selection at z12/z13, new
  line opacities); plus enlarge the Cuisine venue droplet and turn the
  Hawker centre pins into numbered droplets, both as the map's top
  layer.

- **[DELTA]**
  - **`web/cuisine/src/v2/lib/mapOverlays.js`** (canonical; byte-copied
    to the hawker + transport copies, all three md5-identical) —
    - `closeInfo()` + the map tap-out `click` listener now call
      `exitStationDetail()` when a station is selected, so closing the
      station info card reverts that station's marker from the forced
      full pill back to its zoom-tier mode (square / code chip).
    - `trainTier()` — new `capRadius` tier kind (chip only the stations
      within N metres of the map anchor). Cuisine retuned: z<12 lines
      80%; z12 = all squares + chip within 200 m, lines 90%; z13 = all
      squares + chip within 300 m, lines 90%; z14 = chip ≤15 nearest
      (unchanged), lines 80%; z15+ emphasis 95% in-focus / 80% rest
      (was 100% / 50%). Hawker + Transport tiers unchanged from
      v0.61.90 (their `zoom < 12` row moved inside each branch).
    - `applyVisibility` train branch — the in-focus station resolver
      handles `capRadius` (a metre filter) alongside `cap` (nearest-N);
      the station-mode test accepts either; the emphasis opacities are
      0.95 / 0.80.
  - **`web/cuisine/src/v2/components/MapPanel.jsx`** — `cuisinePinNode`
    droplet 24 → 30 px, number font 12 → 14 px; the venue
    `AdvancedMarkerElement` gets `zIndex: 1000` (top layer).
  - **`web/hawker/src/components/HawkerMapPanel.jsx`** — `hawkerPinNode`
    rebuilt as a numbered droplet (26 px teardrop, 1-based list rank in
    a counter-rotated inner span; established-red / new-navy colour
    split + "NEW" badge kept, the badge on a non-rotated wrapper); the
    centre markers get a 1-based `centreNo` and `zIndex: 1000`.
  - **`package.json`** — `0.61.90` → `0.61.91` (PATCH).
