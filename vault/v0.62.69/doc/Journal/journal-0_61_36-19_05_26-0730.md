## New

### [HDR] #240 | 07:30:00 SGT 19-05-26 | v0.61.36 — unified in-map controls + working Colour toggle (3 TMAs) | ~7 kb | 13 files | 1 PR | 1 build |

- **[INTENT]** Give the Cuisine, Transport and Hawker maps one consistent in-map
  control surface, and make the 🎨 Colour toggle actually work (greyscale ↔ colour).

- **[DELTA]**
  - **`MapControls.jsx`** — rewritten, now **presentational / i18n-free** (each panel
    passes resolved `label` strings) so it is byte-identical across all three TMAs
    (`web/cuisine`, `web/transport`, `web/hawker`). Layout: a single left-aligned row —
    the "⋯/⋮" overflow menu button **first**, then the toggle pills. The menu opens a
    **checkbox dropdown** (☑️ / ☐ rows). Platform-detected glyph (`⋯` Apple / `⋮` else).
  - **Row pills** (all 3): ✨ Attractions, 🅿️ Carpark, 🚌 Bus Stop (disabled — no data),
    🎨 Colour. **Dropdown checkboxes**: 🚉 Train Line (ON), Station Exits (ON),
    🚕 Taxi Stand (ON), 🌳 Park, 👮 Police, ⚕️ Clinics, 24 hours (disabled — no data).
  - **`MapPanel.jsx` (Cuisine)** — now renders `<MapControls>` (previously the flat
    `MapLayerChips` strip) and a 4th nav button — **Reset** (`⛶⟲`). New `onOverlayChange`
    prop. `MapLayerChips.jsx` **deleted** from Cuisine (the last TMA still using it).
  - **`MrtMapPanel.jsx` / `HawkerMapPanel.jsx`** — toggle config moved in-component
    (lang-resolved labels); `<MapControls>` props updated.
  - **🎨 Colour** — tapping it applies `filter: grayscale(1)` to the map container in
    all 3 panels; tapping again restores colour.
  - **Train Line on Transport** — Transport has no `train` overlay layer (its line
    polylines are intrinsic), so the toggle now gates polyline visibility:
    `renderPolylines` honours the flag and a new effect flips `.map` on existing
    polylines. Default ON.
  - **`App.jsx` (×3)** — `overlayLayers` default state unified:
    `train` / `exits` / `taxis` default **ON**; everything else OFF.
  - **i18n (×3)** — labels updated to the operator's text (`Park`, `Taxi Stand`,
    `Station Exits`, `Train Line`, `24 hours`); Cuisine i18n gains
    `layer.busstop` / `layer.colour` / `layer.open24` / `map.reset` / `map.more`.
  - **`package.json`** — `0.61.35` → `0.61.36` (PATCH).
