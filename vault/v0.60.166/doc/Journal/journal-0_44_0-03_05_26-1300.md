## New

### [HDR] #89 | 13:00:00 SGT 03-05-26 | v0.44.0 | n/a kb | n/a lines

- **[INTENT]** Per Human Lead, add a hidden `/p` slash command that relays a free-text prompt to one of four upstream APIs. Power-user / debugging tool — useful for side-by-side comparison ("does Gemini say the same thing as Claude about this venue?"), sanity-checking creds, and quick lookups without leaving Telegram.

- **[SYNTAX (confirmed by user)]**
  ```
  /p <type> <prompt>

  type:
    c → Claude / Anthropic API   (default model claude-sonnet-4-6)
    g → Google Gemini API        (default model gemini-2.5-flash)
    s → Google Custom Search API
    m → Google Maps Places       (text search)

  /p / /p help / /p ?            → usage message
  ```

- **[DESIGN]**

  1. **NEW `prompt-query.js`** — single-purpose module exporting `runPromptQuery(rawArgs)`. ~190 lines.
     - Four handlers (`viaClaude`, `viaGemini`, `viaSearch`, `viaMaps`), each wrapped in try/catch — never throws across the module boundary.
     - Argument parser regex `/^([cgsm])(?:\s+(.+))?$/i` — case-insensitive type letter, requires whitespace + non-empty query.
     - On missing/empty/unknown args → returns the `HELP` string.
     - On missing env var → returns honest "🔴 <provider>: <ENV_VAR> not set in Railway env" message instead of crashing.
     - On API error → returns "🔴 <provider> error: <message>" (truncated to 500 chars).
     - All output capped at 3800 chars (Telegram 4096 limit minus header).
     - **No new npm dependencies.** axios + @anthropic-ai/sdk already cover all four upstreams. Gemini path uses raw HTTP because the SDK was removed in v0.40.0; re-adding it for one feature would inflate package-lock.json.

  2. **MODIFIED `index.js`** — registered `bot.onText(/^\/p.../)` near other slash-command handlers (line ~772, right after `/heritage-food`). Sends a "⏳ Querying…" tease before the actual call (skipped for HELP requests). Logs failures via pino + reports back a friendly error.

  3. **NOT registered in `setMyCommands`** — that's what makes it "hidden." The Telegram autocomplete menu won't show `/p`; the handler still responds to anyone who knows to type it.

  4. **NEW `__tests__/prompt-query.test.js`** — 13 unit tests on argument parsing + handler routing + HELP content + `MAX_OUTPUT_CHARS` constant. Skips actual API calls (would cost money + need live creds + be flaky). Tests gracefully no-op when API keys ARE set in the test env (CI-safe).

- **[REUSED]**
  - `llm.generate({ prompt, model, maxTokens })` from `llm-client.js` — same wrapper used everywhere else for Anthropic.
  - `axios` (already a top-level dep) for Gemini/Search/Maps raw HTTP.
  - Places API `searchText` field-mask shape — same pattern as `vibe-suggest.js`, `recognised-seeder.js`.
  - `safeSend` for the reply, `logger` for error logging.

- **[KNOWN GAPS / SCOPE CUTS]**
  - **Not admin-gated.** "Hidden" means not in autocomplete; no chat-ID restriction. If abuse observed, add `ADMIN_CHAT_ID` env var check in v0.44.1 (~3 lines).
  - **No rate limiting.** A user spamming `/p c <huge prompt>` could burn Anthropic quota. Mitigated by `maxTokens: 2048` cap. Add proper rate limiting if needed.
  - **Search needs CSE creds** the user may not have set. Handler returns honest message + console link.
  - **Plain text output**, no Markdown. Telegram Markdown escaping is fragile; plain text + emoji avoids the parse-mode rabbit hole.
  - **Gemini path uses raw HTTP**, not the SDK. The SDK was removed in v0.40.0; re-adding for one feature inflates lock file.
  - **No usage telemetry** (e.g. `prompt-query:metric:c-calls`). Add when needed.
  - **No model override** per-call (`/p c-opus <prompt>` to force Opus). Defer until needed.
