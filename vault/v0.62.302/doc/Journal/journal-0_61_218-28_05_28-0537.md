## New

### [HDR] #419 | 05:37 SGT 28-05-28 | v0.61.218 — city aliases + round-robin emission | 3 files | 1 PR | 1 build |

- **[INTENT]** Make `/training` with abbreviated city names actually include those cities, and make the test-cap apply evenly across all matched cities.

- **[DELTA]**

  **1. `place-search-variance.js` — CITY_ALIASES map**

  ```js
  const CITY_ALIASES = Object.freeze({
    'kl':  ['kuala lumpur'],
    'pj':  ['petaling jaya'],
    'sa':  ['shah alam'],
    'sj':  ['subang jaya'],
    'jb':  ['johor bahru'],
    'bkk': ['bangkok'],
    'kjg': ['kajang'],
    'klg': ['klang']
  });
  ```

  Tokens are lowercased + trimmed, then expanded via the map before substring/prefix match against `venue.city`.

  **2. `place-search-variance.js` — round-robin emission**

  Previously: `for (venue) { for (variant) { tests.push(...) } }` → a small cap consumed the first city fully before reaching the next.

  Now (3-step):
  - Build `venueTests[]` (per-venue variant lists, filtered by country + alias-expanded cities).
  - Group `venueTests` by city → transpose → `interleavedVenues` so cities alternate: `[KL1, PJ1, KL2, PJ2, …]`.
  - Round-robin emit by variant index across `interleavedVenues`.

  Result (cap=100):

  | Input | v0.61.217 | v0.61.218 |
  |---|---|---|
  | `KL Putrajaya` | 100/0 Putrajaya | **50 / 50** |
  | `Bali Jakarta` | 100/0 | **50 / 50** |
  | `KL PJ Putrajaya` | 100/0/0 | **40 / 40 / 20** |
  | `Osaka` (single) | 100 | 100 |

  Full sweep size unchanged at 1950.

  **3. `package.json`** — `0.61.217 → 0.61.218`.

  **4. `doc/.serial-state.yml`** — commit 430→431, build 220→221, journal 418→419; re-anchored 28-05 '26 05:37 SGT.
