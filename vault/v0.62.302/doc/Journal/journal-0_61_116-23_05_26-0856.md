# Journal — soleat v0.61.116 (Attractions / Carpark cluster engine — spec slice 2)

> Slice 2 of the operator's 2-layer Google Maps UI/UX spec (Attractions
> `⚝`, Carpark `🅿️`). Slice 1 (v0.61.115) shipped the unambiguous
> zoom-tier marker shapes and flagged four spec contradictions. The
> operator resolved all four via AskUserQuestion and answered one
> follow-up (cluster-tile size); this PR lands the resulting design.
>
> Answers, recorded for the audit trail:
>
> 1. **Cluster threshold** → per-layer: Attractions ≥ 8, Carpark ≥ 5.
> 2. **Lower-priority drop** → source-order (first-in wins, stable).
>    Subsequent markers that overlap an already-placed footprint
>    cascade label → icon → drop.
> 3. **Card layouts** → Carpark popup gains a `Google Maps ↗` link;
>    Attractions popup train-info redesign (per-line code pill(s) +
>    `‹Name› station` + line status + crowding + exits + bus stops)
>    needs new server-side data and ships in **v0.61.117 (slice 3)**.
> 4. **Carpark visibility boundary** → both at z ≥ 15. Layer fully
>    clustered below z15. At z15 unclusters straight into labels.
>
> Plus the deferred sub-decision **cluster tile size = 40 px screen
> grid** (operator picked over 60 px / 300 m radius / other).
>
> Slice-3 (v0.61.117) is scoped separately: LTA TrainServiceAlert
> fetcher, LTA platform-crowding-density fetcher, a `nearestBusStops()`
> build step in `scripts/build-geo-overlays.js`, then the attractions
> popup rewrite.
>
> This entry is commit 323 / journal 316 / build 119, off `main` at
> v0.61.115 (#607).

- **[INTENT]** Land slice 2 of the UI/UX spec: a real clustering
  engine (40 px screen-tile bucket; per-layer thresholds; carpark
  fully clustered below z15), a source-order drop cascade for
  individuals (label → icon → drop), and the Carpark popup
  `Google Maps ↗` row from the Card spec.

- **[DELTA]**

  - **`web/cuisine/src/v2/lib/mapOverlays.js`** (+ byte-identical
    copies in `web/hawker/src/lib/mapOverlays.js` and
    `web/transport/src/lib/mapOverlays.js`):

    - **`clusterLabelNode(text)`** — new pill helper that wraps
      `amenityLabelNode` with the cluster styling (white pill,
      bold 12 px). Used for the "N ⚝" / "N 🅿 here" text.
    - **`footprintOverlap(aLat, aLng, aW, aH, b, mpp)`** — new
      pure helper. Tests whether two rectangle footprints
      centred at lat/lng overlap on screen at the current zoom
      (4 px padding on each axis). Replaces the four
      copy-pasted overlap arithmetic blocks in
      `applyVisibility` with one call site each.
    - **`applyClusterAndDrop(name, e)`** — new function inside
      `createOverlayController`. Five-step pipeline:
        1. Filter `e.items` to visible candidates (radius clip
           for carpark; attractions skip the radius per v0.61.112).
        2. Bucket candidates into 40 px screen tiles using a
           `metresPerPixelAt(zoom, 1.35)`-derived `TILE_M`.
        3. Lazy-init the `e._clusters` pool, reused across
           renders.
        4. Per tile, cluster-or-cascade:
           - Cluster if `forceCluster` (carpark + z < 15) or
             `items.length >= threshold` (Carpark ≥ 5,
             Attractions ≥ 8). Cluster pill positions at the
             tile centroid; content is reused if `_text`
             matches; `gmpClickable` + a click handler zooms in
             by 2 levels capped at z18 and re-centres on the
             pill.
           - Else iterate the tile's items in source order
             through a `label → icon → drop` cascade:
             - Try a `amenityLabelNode("⚝ Name" / "🅿 Name", …)`
               if `allowLabel` (z ≥ 14 attractions, z ≥ 15
               carpark) and no overlap.
             - Else try an icon (`amenityNode('glyph', …)` for
               attractions, `dotNode(_bg, _glyph, carparkSize)`
               for carparks) if no overlap.
             - Else `it.marker.map = null` — the marker stays
               in `e.items` so the next render re-evaluates it.
        5. Hide any cluster markers from the previous render
           that this render didn't claim.
    - **`applyVisibility(name)`** — the marker branch now
      early-returns `applyClusterAndDrop(name, e)` for
      `name === 'attractions' || name === 'carpark'`. The
      slice-1 attractions `'dot' → 'glyph'` floor and the
      slice-1 carpark `z >= 15` label + size-shrink branches
      are removed (superseded by the cluster engine; the
      attractions tier logic also no longer runs through the
      shared `_tiered` branch). The remaining `_tiered`
      iteration handles only clinics / police / hospitals.
    - **`carparkInfo`** — popup gains a `gmapsLinkRow(f.lat,
      f.lng)` after the lots line. Same helper the train-
      station footer + cuisine-venue popups use, so the link
      styling matches every other card.

  - **`public/app.js`** (the standalone `/app/map` page;
    re-implements the same logic without the ES module helper
    library):

    - **`runClusterPass(items, opts)`** — new helper that
      bundles the same bucket + cluster + cascade pipeline,
      parameterised over zoom / threshold / forceCluster /
      allowLabel / clusterText / labelText /
      iconForFeature / infoFn / pool.
    - **`renderClippedLayer`** — the `key === 'carpark'`
      branch now early-returns into `runClusterPass(
      visibleCarparks, …)`. The slice-1 z ≥ 15 label gate +
      the v0.61.105 size-shrink-on-collision branch are gone.
      Bus stops keep their existing path.
    - **`renderMenuLayer`** — the `L.key === 'attractions'`
      branch now early-returns into `runClusterPass(
      visibleAttractions, …)`. Other amenity layers (parks,
      clinics, police, hospitals) keep their existing path.
    - **`carparkInfo`** — popup gains a `Google Maps ↗`
      anchor when `f.lat`/`f.lng` are finite. Mirrors the TMA
      `gmapsLinkRow`.

  - **`package.json`** — `0.61.115` → `0.61.116` (PATCH).

- **[BEHAVIOUR — what the user sees]**

  | Zoom | Layer       | Tile of N markers | Renders |
  |------|-------------|-------------------|---------|
  | < 14 | Attractions | N ≥ 8             | `N ⚝` pill |
  | < 14 | Attractions | N < 8             | source-order ⚝ glyphs; overlap → drop |
  | ≥ 14 | Attractions | N ≥ 8             | `N ⚝` pill |
  | ≥ 14 | Attractions | N < 8             | `⚝ Name` labels; overlap → ⚝ glyph; overlap again → drop |
  | < 15 | Carpark     | any (forceCluster)| `N 🅿 here` pill — single carparks render as `1 🅿 here` |
  | ≥ 15 | Carpark     | N ≥ 5             | `N 🅿 here` pill |
  | ≥ 15 | Carpark     | N < 5             | `🅿 Name` labels; overlap → 🅿 icon; overlap again → drop |

  Cluster pill click: `zoom = min(currentZoom + 2, 18); center =
  tileCentroid`.
