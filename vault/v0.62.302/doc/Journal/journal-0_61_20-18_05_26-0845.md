- **[INTENT]** Operator, reviewing the Hawker TMA map after v0.61.19 (screenshot supplied):
  (1) the map *"cannot zoom in further"* — the `+` button stops at level 16; (2) *"show only
  the surrounding 2-4 bus stop (minimum as possible)"* — the map is cluttered, *"is it too
  much information in the bus stop and car park"*; (3) the bus / carpark / pick-up / taxi /
  exit pins *"didn't pop up to show the google pin info"* — they weren't clickable. The
  operator also confirmed the same surrounding-amenity pins should appear on the **Cuisine
  eatery map**, with bus pins showing **live arrivals** and counts trimmed to
  **3 bus / 2 carpark / 2 taxi**.

- **[DELTA]**
  - **`web/{cuisine,hawker,transport}/src/.../lib/mapOverlays.js`** (byte-identical ×3) —
    `infoCard`, `busArrivalRows`, `busInfoHtml`, `openBusInfo` lifted from inside
    `createOverlayController` to module scope (`openBusInfo` now takes `map` + `infoWindow`
    explicitly); `amenityLabelNode` exported. New exported `attachAmenityPins({ maps, map,
    infoWindow, ctx, limits })` — draws clickable amenity pins (exits / bus / taxi / carpark
    / nearest-MRT pill) from a `/api/transport/station-context` payload, trims bus/carpark/
    taxi to `limits`, wires each pin's popup (bus → live arrivals, others → identity card),

    `attachAmenityPins` with `{ bus: 3, carpark: 2, taxi: 2 }`; the local `amenityNode` +
    `AMENITY_*` constants removed. The persistent `maxZoom: 16` is replaced with a cap that
    applies only to the auto-fit, released on the next `idle` so manual zoom-in works.
  - **`web/cuisine/src/v2/components/MapPanel.jsx`** — new `clearAmenities` / `plotAmenities`
    / `drawVenueAmenities`; tapping a venue now fetches `/api/transport/station-context` and
    plots the same clickable amenity pins (cached per `placeId`). Same `maxZoom`-release fix.

## Deleted

The Hawker TMA's local amenity-pin helpers, added in v0.61.19, are removed — superseded by
the shared `attachAmenityPins` / `amenityLabelNode` in `mapOverlays.js`:

```js
const AMENITY_EXIT_BG = '#5E35B1';
const AMENITY_BUS_BG = '#1565C0';
const AMENITY_TAXI_BG = '#FBC02D';
const AMENITY_CARPARK_BG = '#1565C0';
const AMENITY_STATION_BG = '#00695C';

function amenityNode(label, bg, fg) {
  const el = document.createElement('div');
  el.textContent = label;
  el.style.cssText = 'display:inline-block;padding:1px 5px;border-radius:8px;'
    + `background:${bg};color:${fg};font-size:10px;font-weight:700;line-height:1.5;`
    + 'white-space:nowrap;border:1.5px solid #fff;box-shadow:0 0 0 0.5px rgba(0,0,0,0.4);';
  return el;
}
```

The colours moved into `mapOverlays.js` (`AMENITY_STATION_BG` is new there); the node
builder is superseded by the exported `amenityLabelNode`, which also makes the pins
clickable. Preserved here per Recipe AU-5.
