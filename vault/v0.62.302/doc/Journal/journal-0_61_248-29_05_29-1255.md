## New

### [HDR] #449 | 12:55 SGT 29-05-29 | v0.61.248 — Menu TMA dropdowns + pill | 4 files | 1 PR | 1 build |

- **[INTENT]** Three Menu TMA UI bugs the operator says they've
  raised before:
  1. **Selection vanishes after pick.** `onCityPick` and
     `onPickerChange` were calling `.then(() => setX(''))` after the
     server-side `set-location` round-trip — wiping the dropdown back
     to its placeholder. The KUL pick reverted to "— —" after a beat,
     the quick-pick precinct reverted to the placeholder. Operator's
     "not baked into the selection. why. I keep asking…".
  2. **Country / city dropdowns too tall + too far apart.** The
     buttons used `px-1 py-1.5` with full borders + `bg-tg-bg`, ~2 mm
     taller than the Cuisine TMA equivalents.
  3. **🔍 icon overflows the right edge.** No pill boundary on the
     form; the input was `flex-1` with default `min-width: auto`,
     so on narrow viewports it refused to shrink → the 🔍 button got
     pushed past the right edge.

  Also touched: SG-mode form — same compact-pill treatment for
  consistency.

- **[DELTA]**

  All changes in `web/cuisine/web/menu/src/components/LocationFieldMenu.jsx`
  (~4 edit blocks).

  **1. `onCityPick` (line ~339)** — dropped the trailing
     `.then(() => setCityPick(''))`. The picked city stays
     selected in the dropdown until the user picks something else.

  **2. `onPickerChange` (line ~353)** — dropped the trailing
     `.then(() => setPickerValue(''))`. The picked precinct stays
     selected.

  **3. `CountryDropdownMenu` button (line ~167)** — class rewritten:
     ```
     - text-[13px] bg-tg-bg border border-tg-border rounded px-1 py-1.5
     + bg-transparent text-sm outline-none
     ```
     Mirrors the Cuisine TMA `CountryDropdown` (LocationField.jsx
     ~line 432). The minWidth and the flag + code + ▾ glyph layout
     are unchanged.

  **4. `CityDropdownMenu` button (line ~68)** — class rewritten:
     ```
     - text-[13px] bg-tg-bg border border-tg-border rounded px-1 py-1.5
     + text-sm bg-transparent text-tg-text border border-tg-border rounded px-1.5 py-0.5
     ```
     Mirrors the Cuisine TMA `CityDropdown` (LocationField.jsx
     ~line 333). Shorter (`py-0.5` vs `py-1.5`), slightly wider
     side padding so the 3-letter city code doesn't crowd the ▾.

  **5. OTHER form pill (line ~578)** — wrapped in
     `flex items-center gap-1.5 px-3 py-1.5 rounded-md border
     border-tg-accent bg-tg-card`. Same shape as the Cuisine TMA
     OtherLocationPicker expanded row. The pill defines the right
     boundary so the 🔍 button can never overflow.

  **6. OTHER form input** — `flex-1 bg-transparent text-sm outline-none
     placeholder:text-tg-hint min-w-0`. The **`min-w-0`** is the
     direct fix for the 🔍-off-edge symptom: flex children default
     to `min-width: auto` which prevents the input from shrinking
     below its content's intrinsic min size; that overflow pushed
     the 🔍 past the right edge.

  **7. OTHER form 🔍 button** — replaced the filled
     `bg-tg-accent text-tg-accent-text px-2.5 py-1.5 rounded` pill
     with a bare `text-tg-accent text-sm leading-none flex-shrink-0
     px-1` icon, matching Cuisine TMA. Disabled state uses
     `opacity-40` (same as Cuisine TMA).

  **8. SG-mode form** — same compact-pill treatment as the OTHER
     form (flex container + classes + min-w-0 input + bare 🔍
     button). The trailing button used to render the localised
     "Set" word; now it's a 🔍 icon for consistency across both
     modes.

  **9. `package.json`** — `0.61.247 → 0.61.248`.

  **10. `doc/.serial-state.yml`** — commit 460→461, build 250→251,
     journal 448→449; re-anchored 29-05 '26 12:55 SGT.
