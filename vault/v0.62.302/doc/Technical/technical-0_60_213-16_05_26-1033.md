## 3. Budgets

| Resource | Limit / target | Notes |
|---|---|---|
| Telegram webhook ceiling | ~30 s | hard — any handler must reply within it; LLM + Places fan-in is budgeted against it |
| Gemini call latency | ~3 s typical | Refine/explainer adds 1.5–3 s; model-fallback on timeout |
| `/cuisine` end-to-end | < 12 s p95 | 6 s fetch timeout in the TMA |
| Places billable per `/cuisine` | ~15 validates (cap = 15) | 30 s per-criteria result cache |
| Michelin per tap | top-12-fresh + a 7-day per-entry enrichment cache | cost-watch carried as DF-94 |
| Pick cache TTL | 60 s (100 m grid + sorted cuisine key) | |
| Rate limits (per chatId, 15-min fixed window) | Cuisine hot endpoints 60–200; `warm-start` 200; Tell-Gia per-endpoint | sized to "catch runaway loops, not real users" |
| Redis TTLs | location 24 h · pick cache 60 s · share tokens 7 d · recent picks 24 h · place reviews 24 h · `vibe:summary:v2` 7 d · enrichment 7 d · usage / free-text log 90 d · public holidays 90 d · Michelin seen-set 1 h idle | |
| Static TMA bundles | immutable, 1-year `max-age` | content-hashed filenames |

## 6. Architecture decisions — v0.60.158 → v0.60.213 (current state)

> A coherent summary of the catch-up arc since the last versioned Technical file. Each remains live unless the Deprecated table says otherwise.

- **T-164/165 — JB geo-fence + radius** — JB post-filter widened to `/\bjohor\b/i` (whole state); SG default radius 20 km, JB 30 km, slider max 100 km.
- **T-167 — auth chokepoint** — `requireInitDataFromBodyOrHeader` mounted once as `app.use('/api/cuisine', …)`; constant-time HMAC compare; dev bypass via `SKIP_INIT_DATA_AUTH`; the prior per-handler inline `verifyInitData` calls retained as defence-in-depth.
- **T-170 — rate-limit layer** — `rate-limit.js` `makeRateLimiter`; per-chatId Redis fixed-window (window collapsed 60 min → 15 min; caps tuned generous); wired on the Cuisine hot endpoints.
- **T-183 — Places New-API extensions** — `priceRange`, `addressComponents`, `allowsDogs` added to the discover field-mask; `currency-format.js` + Frankfurter FX (Redis 12 h); cross-handler render parity (D-183) — a new payload field must reach `formatVenueBlock` + the TMA card + Copy-All.
- **T-185/187/198/201 — Michelin walk-through** — settled, after a drop→restore pivot, on `michelin-walk.js`: a criteria-hash-scoped seen-set, 1 h idle TTL, top-12-fresh per tap, dedup keys derived from stable `name|address` fields (D-201).
- **T-204 — static cache headers** — immutable 1-year `max-age` on content-hashed TMA bundles.
- **T-205 — CI scope** — syntax-check narrowed from ~2028 to ~115 source files (vault / dist / public / `.vibe-journal` / node_modules excluded); build step split; diagnostics added.
- **T-208/209 — LLM + dish-name** — `describeCookingMethod` (Gemini one-line method explainer + representative dish); `dish-name.js` shared category-word denylist guarding every "Try" line at both extraction and render time; `vibe:summary` cache key bumped to `v2` for the 2-field Sanctuary read.
- **T-210/211 — verification + headers** — `filterTryLine` in `hidden-verify.js`; the single-query technique/ingredient header aligned to the flag-+-caveat format.
