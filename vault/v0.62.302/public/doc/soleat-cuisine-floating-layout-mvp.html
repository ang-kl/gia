3 Behaviour

  • Floating header — sticky/fixed, frosted (.glass), always on top; region pills stay reachable without scrolling.
  • Search-bar FAB — collapsed = a slim "🔍 Search · <area>" bar; tap → expands to the full search card (cuisines, filters, location, Tell-me, 🔍 run); ⌄ collapses back. Lives in the floating layer (FAB), never the static body.
  • Footer carousel — replaces the vertical list; horizontal swipe between ranked cards, the centred card expand/collapses (the v0.62.124 collapse). Selecting recenters the map (existing wiring). Sits ABOVE the search bar.
  • Map — full-bleed behind everything; the carousel no longer covers it (footer-docked), so map + cards are both visible.

4 Staged build (proposed)

  1. Move the carousel to the footer (off the map) — smallest, refines what's shipped.
  2. Floating sticky header (header + region pills).
  3. Search-bar FAB — strip the criteria/location card into a floating bar that expands/collapses.
  4. Replace the vertical list with the footer carousel as the primary result surface.

5 Open questions

  • Vertical list: remove it entirely (carousel-only), or keep it as a "scroll down for the full list" fallback below the fold?
  • Footer height: carousel ~120px + search bar — that's ~30% of a phone screen pinned at the bottom. OK, or should the carousel auto-hide until a card is tapped?
  • Search-bar FAB placement: full-width bar with the ↩/end/⤓ FABs to its right (as drawn), or a compact 🔍 circle that expands?
  • Header content: keep the region pills in the floating header (as drawn), or only the title/lang/weather, with pills in the search card?
