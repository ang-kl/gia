## What this snapshot is

A faithful mirror of the repository at v0.61.116 — all source (`index.js` + ~80 root modules, `web/<app>/src`, `scripts/`, `public/app.js`), the curated datasets (`data/`, `data_realtime/`), the open-data sources (`geoloc/`), the `__tests__/` suite, and the full `doc/` documentation system (including the v0.61.83 master document set — Feature #48 / Technical #48 / Register #116, still current).

It is bootable: a clean `npm install` reproduces the service.

## Boot instructions

```bash
cp -a vault/v0.61.116 /tmp/soleat-v0.61.116
cd /tmp/soleat-v0.61.116
npm install
npm test                                              # expect 100% green
npm run build:geo                                     # rebuild data/geo-*.json from geoloc/ (optional)
(cd web/cuisine && npm install && npx vite build)     # repeat per web/<app>/ to rebuild the TMAs
# provide a .env from .env.example, then: node index.js
```
