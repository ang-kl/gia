- **[KNOWN GAPS]**
  - **#2 — base-map station labels cannot be removed in code.** The maps are
    initialised with a `mapId` (required for `AdvancedMarkerElement` pins). Google
    Maps JS **ignores the `styles` option whenever a `mapId` is set** — base-map
    styling for a vector/cloud map must be done in the Google Cloud Console.
    To hide the `transit.station` labels: Cloud Console → Maps Platform → Map
    Styles → edit the style associated with the `MAP_ID`, set Points of Interest →
    Transit → Station → *labels* to off; ensure that styled Map ID is the `MAP_ID`
    env var on Railway. (The `DEMO_MAP_ID` fallback can't be restyled — a
    project-owned Map ID is needed.) No code change ships for this item.
  - Visual check is sandbox-blind — builds are the gate; flash + sizing verified
    by code inspection.
