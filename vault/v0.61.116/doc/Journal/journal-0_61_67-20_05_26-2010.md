- **[INTENT]** Validate `data/sg_train_timings.json` against its spec, then join it
  into `data/stations.json` and render first/last-train timings in the CR6 station
  info card.

- **[VALIDATION — `sg_train_timings.json` vs `Sg_train_timings.md`]**
  - ✅ Valid JSON; `{ metadata, lines }` top-level as specified.
  - ✅ `metadata` carries every required field (description, scraped_on, sources,
    data_completeness_notes, direction_label_conventions, active_service_adjustments).
  - ✅ 248 station entries; the 19 with null/no timings **all** carry a `note`
    (spec rule satisfied); 4 terminal-station notes.
  - ⚠️ **SK_LRT & PG_LRT deviate from the required structure** — no
    `directions`/`stations[]`; they use `departures_from_*_town_centre` arrays
    with loop-level (not per-station) timings. This reflects a real source limit
    (SBST publishes only town-centre departures for LRT loops) but means
    Sengkang/Punggol LRT stations get no per-station timings.
  - Minor: EWL airport-branch stations (CG1 Expo, CG2 Changi Airport) use
    `data_available:false` instead of the spec's null-fields-plus-note form.

- **[DELTA]**
  - **`scripts/build-station-info.js`** — new `loadTrainTimings()` reads
    `data/sg_train_timings.json`, builds a station-code → entries map (one entry
    per line+direction; verbatim timing strings; `note` carried; an active
    `service_adjustment` attached when the line is flagged). The build joins it by
    `station_code` → each record's **`first_last_train`** array (was `[]`); the
    entry's `line_code` is normalised to the stations.json convention. `_meta`
    gains `trainTimingsJoined` / `stationsWithTrainTimings` / `trainTimingsMeta`
    and a schema note; a `data_quality_note` is added for stations with no source
    timings. Entries with neither a timing value nor a note are skipped.
  - **`data/stations.json`** (regenerated) — **152 of 180 stations** now carry
    `first_last_train` (238 entries total). The 28 without are LRT-loop stations
    and stations the source does not list.
  - **`web/transport/src/lib/mapOverlays.js`** (canonical) — new
    `firstLastTrainHtml()` + `fltTimes()`/`fltHumanize()` helpers and
    `FLT_DIR_LABELS`/`FLT_DAY_LABELS` maps. `stationInfoCardHtml` renders, inside
    each per-line block, a **🚆 First / Last Train** section — one row per
    direction (`Towards Expo — First 6:00am (Mon–Sat), 6:20am (Sun/PH) · Last
    12:03am (Daily)`), null/terminal rows show their source note, and an active
    service adjustment surfaces once per line as a ⚠️ row.
  - **`web/hawker/src/lib/mapOverlays.js`** + **`web/cuisine/src/v2/lib/mapOverlays.js`**
    — byte-identical copies (`md5sum` ×3 confirmed).
  - **`package.json`** — `0.61.66` → `0.61.67` (PATCH — established CR6 cadence).
