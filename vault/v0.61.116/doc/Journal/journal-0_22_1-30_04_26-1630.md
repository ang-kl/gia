## New

### [HDR] #37 | 16:30:00 SGT 30-04-26 | v0.22.1 | n/a kb | n/a lines
- **[INTENT]** Hotfix for v0.22.0 bug surfaced by Human Lead: "TMA Cuisine Picker cannot click 'search'". Root cause: Search button was `disabled={state.loading || !state.loc}`; user opening the TMA had no detected location yet (📍 Detect was a manual tap), and the disabled style was too subtle to read as "blocked".
- **[DELTA]**
  - **`web/cuisine/src/App.jsx`** — auto-detect location on mount via `requestLocation()` inside a `useEffect`. On rejection (denial / blocked / unsupported), set `locDenied=true` and surface inline notice "Tap 📍 above to share your location." just above the Search button.
  - **Removed** `disabled={!state.loc}` from the Search button — Search is now always clickable; if `state.loc` is still null at click time, `onSearch` already shows an alert (legacy guard from v0.22.0).
  - **Header** now clears `locDenied` on successful re-detect.
