- **[INTENT]** Per Human Lead "create a 0.39.0 pull for me to merge as I have made significant changes at the code level" — diff supplied directly. Three thematic changes:
  1. **Multi-stop Google Maps container links** — every set of picks/carparks now gets a single bottom button "🗺 View all picks" / "🗺 View all carparks" that opens Google Maps with the full set as a directions route (destination + up to 4 waypoints).
  2. **Stale-location threshold tightened 15 min → 10 min** + simplified copy. Same behaviour also added to `/carpark`.
  3. **`CUISINE_DEBUG_ECHO` env / `?debug=1` query** — POST `/api/cuisine-search` echoes `{lang, cuisinesCount, preset}` in the response when enabled. Useful for client-side test scripts that want to confirm the server received the right params.

- **[DESIGN]**
  1. **`buildGoogleMapsContainerUrl(items, opts)`** — pure function. Normalises each item to either `{type: 'place', value: <placeId>}` or `{type: 'coord', value: 'lat,lng'}`. Picks first as `destination_place_id` / `destination`, next 4 as `waypoint_place_ids` / `waypoints`. Returns null when fewer than 2 items (no route to draw). Travel mode defaults to `walking` (override via `opts.travelmode`).
  2. **`sendGoogleMapsContainer(chatId, items, opts)`** — thin wrapper that builds the URL and posts a single inline-keyboard button. Caption + label both customisable via `opts.caption` / `opts.label`.
  3. **`deliverPicks` integration** — after the numbered header summary, before per-pick venue cards, render the container button. Defaults: `walking`, "🗺 View all picks". Try/catch wraps so a render failure never blocks per-pick delivery.
  4. **`runCarparkCommand` integration** — same call after the carpark list, with `travelmode: 'driving'` and "🗺 View all carparks" label. Plus a stale-location footer line when the saved location is ≥10 min old (same threshold as picks now).
  5. **Stale threshold change** — was 15 min in v0.30.2 (post-pick reminder only). Tightened to 10 min and simplified the copy (single-line, no Markdown formatting). Applied across both `deliverPicks` and `runCarparkCommand`.
  6. **Debug echo** — `process.env.CUISINE_DEBUG_ECHO === 'true'` OR `?debug=1` query enables a small `debugEcho` field in the POST response. Three fields only: `lang`, `cuisinesCount`, `preset`. Off by default.

- **[KNOWN GAPS]**
  - **Google Maps URL has a 4-waypoint cap**, so for 5-pick `/cuisine` results only the first venue (destination) + 4 waypoints render. The 5th pick is omitted from the route. The user can still tap individual venue cards' map buttons; this is a Google constraint, not ours.
  - **Mixed place/coord modes** — `buildGoogleMapsContainerUrl` picks one mode based on the FIRST waypoint's type. If picks have placeIds and coords mixed, the container drops the wrong-typed entries. In practice all v0.32+ pipeline picks have placeIds, so this rarely bites.
  - **`debugEcho` doesn't include the actual reqId trace** — only echoes back the input. Pair with `/admin/test-pipeline?nl_text=…` for full pipeline trace.
  - **Stale-location threshold 10 min** is tighter than v0.30.2's 15 min; users on slow networks may see the footer twice in quick succession if they re-trigger picks within the window. Acceptable trade-off for ambient awareness.
