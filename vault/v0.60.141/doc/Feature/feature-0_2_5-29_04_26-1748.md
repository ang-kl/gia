## 1. Active Features

### 1.1 `/start` — Greeting & command index

Returns a one-message intro listing the supported commands. Registered via `setMyCommands` so `/` autocomplete in the Telegram client surfaces both `/status` and `/lunch` without typing.

- **Trigger:** `/start` (or first contact with the bot)
- **Source:** `index.js` — `bot.onText(/^\/start(?:@\w+)?$/, …)`
- **Confirmation gate:** none

### 1.2 `/status` — CBD train pulse

Returns the most recent LTA `/TrainServiceAlerts` snapshot, cached in Redis under `lta:train_status`. Sniffer refreshes every 5 minutes. When LTA is unreachable or the key is missing, the sniffer writes a degraded/offline stub so the user never sees "Gia is still waking up."

- **Trigger:** `/status`
- **Source:** `index.js` — `updateTransitStatus()` writer + `bot.onText(/^\/status…$/)` reader
- **Redis key:** `lta:train_status` (JSON, overwritten every Pulse)
- **Refresh cadence:** 5 minutes
- **Fallback states:** `🟢 Healthy` · `🔴 Disruption` · `🟡 LTA sensor offline` · `🟡 LTA sensor degraded`

### 1.3 `/lunch` — 3 sanctuary picks (Telegram venue cards)

Returns one header text plus three `sendVenue` calls — tappable Telegram cards with embedded map pins, ⭐ rating, and "Open now" indicator. Backed by Google Places `searchNearby` centred on Raffles Place MRT (1.2839, 103.8517), 500 m radius, types `restaurant` + `cafe`, min rating 4.0, top 25 by rating, refreshed every 24 hours.

- **Trigger:** `/lunch`
- **Source:** `index.js` — `bot.onText(/^\/lunch…$/)`; `vibe.js` — `refreshVibeListings()` and `pickLunch()`
- **Redis key:** `vibe:listings` (JSON array, overwritten every refresh)
- **Refresh cadence:** 24 hours
- **Fallback:** 5-spot curated seed list (`SEED_LISTINGS` in `vibe.js`) when `GOOGLE_MAPS_API_KEY` is unset or the Places call fails.

### "Gia" user
- Profile: professional woman, mid-50s, Raffles Place.
- Goal: find a "Sanctuary" — quiet, high-vibe lunch — without crowds or weather drama.
