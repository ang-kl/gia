# Journal — Gia4lunch v0.4.0

## New

### [HDR] #3 | 22:30:00 SGT 29-04-26 | v0.4.0 | n/a kb | n/a lines
- **[INTENT]** Phase 3b + 3c shipped together. Chat-mode `/eat` (time-of-day, location-aware) + Telegram Web App (TWA) live map. `/lunch` removed; bot menu button now opens the TWA in webhook mode.
- **[DELTA]**
  - **NEW `vibe-suggest.js`** — pure-Gemini-then-Places-validation pipeline. Gemini returns 5 candidate venue names; Places `searchText` validates each within 200 m of user, drops hallucinations.
  - **NEW `location-cache.js`** — SHA-256 hashed chat-ID Redis cache. 30-min TTL on user lat/lng, 5-min TTL on pending meal markers. Documented Zero-Server Mandate breach.
  - **NEW `twa-auth.js`** — Telegram WebApp `initData` HMAC verification middleware. 24-h `auth_date` enforcement.
  - **NEW `public/index.html` + `public/app.js`** — TWA shell. Fetches `/maps-key`, dynamically loads Google Maps JS, requests browser geolocation, calls `/api/sanctuary` with `X-Telegram-Init-Data`, renders 3 numbered markers + user pin.
  - **`vibe.js`** — `fetchPlaces` now accepts `{center, radius, types}`; defaults preserved for the 24-h `vibe:listings` refresh.
  - **`index.js`** — drop `/lunch` regex handler, add `/eat`, `bot.on('location', …)`, default-button handler. Switch `setChatMenuButton` to `web_app` type when in webhook mode. Mount `/app`, `/static`, `/maps-key`, `/api/sanctuary` Express routes.
  - **`package.json`** — version → 0.4.0.
- **[RISK]** Med — three new failure modes:
  1. Gemini hallucination → mitigated by 200 m Places validation; falls back to cached `vibe:listings` if validation drops below 3.
  2. Maps JS key exposure → reused `GOOGLE_MAPS_API_KEY` is served via `/maps-key` to authenticated TWA loads only. Key restriction in Cloud Console (HTTP referrer + API allowlist) is the Human Lead's responsibility.
  3. Zero-Server breach (30-min hashed location cache) → documented; one-line rollback in Risk row of feature spec.
- **[STATUS]** BETA — pending Railway redeploy + Human Lead `@BotFather` confirmation that the menu button surfaces correctly.
- **[TEST]**
  - Local helper unit tests pass: `mealPeriodSGT` correctly maps 6 SGT hours to {breakfast, lunch, afternoon, dinner, supper, night_supper}; `hashChatId` is stable + 16 hex; `verifyInitData` rejects empty/bogus/undefined; `setUserLocation`/`getUserLocation`/`setPendingMeal`/`consumePendingMeal` round-trip correctly through Redis.
  - Sandbox cannot smoke-test the full Express server because Telegram API calls are blocked (sandbox 403 on `setWebHook`). Production behaviour is unaffected.
- **[NEXT]** Phase 4 — GrabID OAuth 2.0 PKCE for live merchant occupancy / quietness. Replaces Gemini-from-reviews "Sanctuary read" with real-time crowd data per the original README persona.
- **[ADVICE]** Pure-Gemini-then-Places is a safer hybrid than either alone. Gemini provides taste + curation; Places provides ground truth. The 200 m gate is the entire safety property.
