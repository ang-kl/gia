## Decisions

> Append-only. Quote priors verbatim before amending.

| # | Decision | Rationale | Date |
|---|---|---|---|
| Δ-101 | `/hidden` uses Gemini-with-Google-Search, not Claude with webSearch | Human Lead supplied an explicit prompt template using "Google Search grounding" terminology. Gemini's `googleSearch` / `googleSearchRetrieval` tool is the spec match; Claude's webSearch was an approximation. | 05-05 '26 06:01 SGT (PR #179) |
| Δ-102 | Drop `Criteria met:`, `Confidence:`, `Sources:` lines from `/hidden` per-result template | Human Lead — "remove these result template 3 row lines: Criteria met, Confidence, Sources". Criteria gate still enforced internally; sources still verified internally. User-facing block stays compact. | 05-05 '26 09:38 SGT (PR #185) |
| Δ-103 | "Hidden" requires C1 OR C3 in matched criteria | Human Lead reported TONSHOU (800+ reviews) qualifying via pure C2+C4 ("popular and unique"). That's `/cuisine`, not `/hidden`. Hidden means newly opened or low review count. | 05-05 '26 09:38 SGT (PR #185) |
| Δ-104 | `/hidden` default model `gemini-2.5-flash` (was `gemini-1.5-pro`) | Google retired 1.x from `v1beta` in 2025; calling it returns 404. 2.5-flash is current-gen. | 05-05 '26 09:18 SGT (PR #183) |
| Δ-105 | `thinkingConfig.thinkingBudget: 0` for all `/hidden` calls | Web-research-validated finding from Google's own dev guide. Default dynamic thinking adds many seconds before TTFT. Explained the AI Studio "10s" vs API "30-90s" gap. Single biggest user-perceived speed win. | 05-05 '26 11:22 SGT (PR #190) |
| Δ-106 | Per-attempt deadline 60 s + overall 240 s on `/hidden` | One slow model attempt (gemini-2.5-pro grounded calls take 60-120 s) was eating the whole budget on a 503 cascade. Per-attempt cut prevents that. | 05-05 '26 11:22 SGT (PR #190) |
| Δ-107 | Apartment-number sanitiser **reverted** (v0.58.40) | Human Lead — "I removed v0.58.38 from production as it is causing a loop on hidden command. remove the sanitiser". Cause not yet identified. Open as O-1. | 05-05 '26 10:05 SGT (PR #188) |
| Δ-108 | Free-text router has a deterministic noise-guard (`looksLikePlaceQuery`) | Human Lead — "Every time I type something, the bot shows 5 restaurants and ends with buddy help". Min 3 chars + emoji/punctuation gate + ~30-word chat-noise denylist. Synchronous, no LLM. | 05-05 '26 ~05:46 SGT (PR #178) |
| Δ-109 | Multi-tenant building names filtered by **shared `venue-filters.js`** across all flows | Human Lead — "Lau Pa Sat / Maxwell Food Centre / SAFRA shouldn't surface; specific stalls inside SHOULD". Start-anchored regex achieves both. | 05-05 '26 ~06:20 SGT (PR #179) |
| Δ-110 | `/cuisine` pre-resolves cached location and deep-links via `#lat&lng` | Railway evidence showed TMA firing search with `center=0.0000,0.0000`. Server-side pre-resolve avoids the bug class entirely. | 05-05 '26 ~03:00 SGT (PR #178) |
| Δ-111 | `/location current` shows only Share-pin keyboard, no cached display | Human Lead — "/location current doesn't catch current location". Bots can't auto-detect device GPS; the reply makes the action the entire conversation. | 05-05 '26 10:42 SGT (PR #189) |
| Δ-112 | `/hidden` Google Map URL must use search format only, never `place/` with hex IDs | Gemini was fabricating Place IDs (`0x9999999999999999`) and lat/lng. Real `place/` URLs require verified Place IDs; fakes route users to wrong venues. Prompt rule + post-process safety net. | 05-05 '26 11:52 SGT (PR #191) |
