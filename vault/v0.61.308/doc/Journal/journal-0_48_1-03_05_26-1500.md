- Three-bug ship: NEA URL fix + helper enrichment + share-link hyperlink + /surprise count.

- **[DESIGN]**

  1. **NEA scrape URL → `/overview`**
     - `OVERVIEW_URL = 'https://www.nea.gov.sg/our-services/hawker-management/overview'`
     - `ANNOUNCEMENTS_URL` kept as alias for back-compat references.
     - Scrape cache key bumped `v1` → `v2` so prior cached HTML from the wrong URL is never served.

  2. **Enrichment helpers (NEW in `nea-scrape.js`)** — exported so callers can structure rather than render-as-text:
     - `parseDayMonthYear('30 Mar 2026')` → `Date(UTC)`
     - `parseClosureDateRange('30 Mar 2026 to 28 Jun 2026')` → `{start, end, raw}` — handles "to", en-dash, em-dash, hyphen, and single-day ranges.
     - `classifyClosureStatus(start, end, today)` → `'ongoing' | 'upcoming' | 'recently-ended' | 'historical' | 'unknown'`. Ongoing when today ∈ [start, end]; recently-ended when end is within last 30d; historical otherwise.
     - `googleMapsSearchUrl(name)` → `https://www.google.com/maps/search/?api=1&query=<urlencode(name + ' Singapore')>`. The `query=` form (not `cid=`) renders consistently inside Google Maps and works on iOS Universal Links without redirecting to Apple Maps.
     - `enrichClosureRows(rows, today)` → array of `{name, closureType, startDate, endDate, durationDays, status, mapsUrl, raw}`. Maps Reason+Remarks to `closureType ∈ {Cleaning, R&R, Upgrading, Other}`. Drops nameless rows.
     - `sortClosuresByProximity(enriched)` → ongoing (by nearest end) → upcoming (by nearest start) → recently-ended (most recent end first). Historical dropped.
     - `formatClosureBlocks(enriched)` → numbered labeled blocks with 🔴/🟡/⚪ status emoji + `📍 <Maps URL>` per row.
     - `getStructuredClosures(redis)` — convenience wrapper: `getCachedOrFetch` → enrich → sort → return `{ok, all, ongoing, upcoming, recentlyEnded, summary, fetchedAt, cached}`.

  3. **`runHawkerClosureLive` dispatch (`index.js`)** — scrape-first:
     - Try `nea-scrape.getStructuredClosures(redis)` first (fast, free, deterministic).
     - On non-empty result, render via `formatClosureBlocks` with header summary + cache-age stamp + canonical NEA portal button.
     - On empty/error, fall back to the v0.48.0 Claude+web_search path (preserves the safety net for any future NEA layout change).
     - `runHawkerClosureLiveRefresh` now clears BOTH caches: `hawker:closures-live` (web_search fallback) AND `hawker:nea-scrape:v2` (scrape).

  4. **`/surprise` target count 12 → 5** (`pipeline-task.js#SURPRISE_TARGET_COUNT`). Human Lead's directive: "reduce the /surprise to 5 places". 5 matches the visual density of `/eat` and `/drink` cards.

  5. **Buddy share-link hyperlink** (`index.js#share:` callback handler):
     - Was: `` `<link>` `` (Markdown code block — tap-to-copy, NOT clickable as hyperlink).
     - Now: `[<link>](<link>)` (Markdown inline link — renders as a clickable hyperlink).
     - Still uses `disable_web_page_preview: true` so the chat doesn't bloom a preview card.
