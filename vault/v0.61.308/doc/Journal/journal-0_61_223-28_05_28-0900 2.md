## New

### [HDR] #424 | 09:00 SGT 28-05-28 | v0.61.223 — Menu TMA always-visible quick-pick + flag dropdown | 4 files | 1 PR | 1 build |

- **[INTENT]** Eliminate the form-mode flip in the Menu TMA's location field — both the precinct quick-pick AND the country flag dropdown stay visible in every region, and picking a quick-pick instantly updates the flag.

- **[DELTA]**

  **1. `web/menu/src/components/LocationFieldMenu.jsx`** — three changes:

  - **Always-visible precinct dropdown.** Removed the gate `currentAnchor.region === 'OTHER' || 'MY-PUT' ? null : <select…>`. The 17-precinct picker now renders in every region.
  - **Always-visible flag dropdown.** Added `CountryDropdownMenu` to the SG-mode form (previously OTHER-mode-only). Form-mode gate changed from `currentAnchor.region === 'OTHER' || 'MY-PUT'` to `countryPref !== 'SG'`. SG selected → SG mode (text + Set + autocomplete). Any non-SG → OTHER mode (flag-biased Places search).
  - **Quick-pick → flag sync.** `onPickerChange` now derives the country from the picked precinct's source (sg/sgRegion → `'SG'`; my → `'MY'`) and calls `updateCountryPref` so the flag dropdown reflects the change immediately.
  - **Anchor → flag sync (new effect).** When `currentAnchor.region` flips to `'SG'`, `'JB'`, or `'MY-PUT'` via any other route (typed-text geocode, server-side region inference), countryPref auto-syncs to `'SG'` / `'MY'`. `'OTHER'` region leaves countryPref alone (the user's explicit country pick wins).

  **2. `package.json`** — `0.61.222 → 0.61.223`.

  **3. `doc/.serial-state.yml`** — commit 435→436, build 225→226, journal 423→424; re-anchored 28-05 '26 09:00 SGT.

  **4. (this) `doc/Journal/journal-0_61_223-28_05_28-0900.md`** — new.

- **SG-no-hamper verification** — Cuisine TMA's overlay disables key on `region === 'OTHER' || jb || MY-PUT` (v0.61.219 `MapPanel.jsx`), and `countryPref` is independent of `region`. Picking SG in the new Menu-TMA flag dropdown does NOT change `region` (until the user submits a query that geocodes to SG), so no Cuisine TMA toggle is affected. Menu TMA's "tile-disable banner" (`isMy = region === 'JB' || 'MY-PUT' || 'OTHER'`) likewise stays off for SG anchors. No code change needed in Cuisine TMA.

- **Form-mode gate** — was `currentAnchor.region === 'OTHER' || 'MY-PUT' ? <other> : <sg>`. Now `countryPref !== 'SG' ? <other> : <sg>`.
- **SG-mode form** — was `text + Set` only. Now `flag + text + Set`.
- **`onPickerChange`** — now also calls `updateCountryPref('SG'|'MY')` based on the picked precinct's source.
- **New effect** — `currentAnchor.region` → countryPref auto-sync for SG/JB/MY-PUT.
