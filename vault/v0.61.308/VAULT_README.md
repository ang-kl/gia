## What this snapshot is

A faithful mirror of the repository at v0.61.308 — all source (`index.js` + ~95 root modules incl. the new `api-cost.js`, `web/<app>/src`, `scripts/`, `public/app.js`), the curated datasets (`data/`, `data_realtime/`), the open-data sources (`geoloc/`), the `__tests__/` suite (2879 tests green at snapshot time, +12 from `api-cost.test.js`), and the full `doc/` documentation system through journal #509 + the operator-supplied flag assets (`MY_Johor_flag.png`, `MY_Putrajaya_flag.PNG/.svg`).

It is bootable: a clean `npm install` reproduces the service.


## Notes

- **Rule V-1 / V-2** — `vault/v0.61.116/` and `vault/v0.61.208/` are kept, not superseded. This vault captures the v0.61.209 → v0.61.307 delta arc (99 versions).
- **Rule V-3** — this snapshot's `doc/Journal/` will omit the self-referential journal addendum that documents this very vault pass (the journal-0_61_308 entry is the creating PR's commit, not yet on disk when the rsync runs).
- **`/cost` shipped (v0.61.307)** — first owner-only API-spend visibility. Redis daily counters at `api-cost:<YYYY-MM-DD>:gemini:<model>` and `:maps:<endpoint>`; 60-day TTL. Initial instrumentation covers `place-autocomplete`, `place-resolve`, `social-profiles` only (operator-chosen "(A) tight" scope) — extend in follow-up PRs.
- **Recents-drawer pattern (v0.61.305)** — `LocationField.jsx` now flips 📍 → 🧭 on tap, replacing the input UX with a 20-entry scrollable list backed by `recent-locations.js`. Tap row → `onSelect` + auto-fire + close. The `noAutoFire: region !== 'SG'` guard from v0.61.244 was removed: drawer is the new revert affordance, so auto-fire-on-pick applies in every region.
- **Region model** — unchanged from v0.61.208 (three-pill SG / JB / OTHER end-to-end). v0.61.281 widened the SG/JB boundary's west carve-out (Legoland), and v0.61.304 added Menu TMA visibility-rehydrate so anchor changes from any TMA propagate back on viewport flips.
- **Gemini cache** — 31 cuisines / modes cached via `GEMINI_CACHE_KEYS` + `PROMPT_CONFIG` at the time of snapshot. Auto-warming `D703e` + `D703f` flow lifts out of the legacy `if (specialMode)` gate (v0.61.299) and is keyed by either `specialMode` or `cuisineMetas[0].slug`.
- **CI** — main is protected (`enforce_admins=true`); `--auto` merge requires `allow_auto_merge=true` (set v0.61.296). The 4 required checks: empty-blob guardrail (v0.61.289), syntax (`node --check` on every `.js`), vitest, TMA build (cuisine + menu + hawker + transport + oversight).
