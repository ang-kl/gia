## New

### [HDR] #201 | 23:00:00 SGT 16-05-26 | v0.60.233 — LRT closed-loop geometry + Circle Line connection + Train/Hawker map pin tweaks | 4 files | 1 PR | 1 build |

- **[INTENT]** `buildLinePaths()` (Build E 5a) orders each line's stations by the numeric
  suffix of their codes. That assumption is wrong for the Punggol LRT — **Teck Lee is PW7** but
  sits mid-loop between Sam Kee (PW1) and Punggol Point (PW2), having opened years after the
  loop — so the West loop drew with Teck Lee misplaced. The LRT lines also never closed into
  loops, and the Circle Line's CE spur drew detached from the main loop. Operator also asked
  for: Train Google Map polylines 1px thinner, station dots 1px larger; Hawker pins 1px
  smaller; and the Hawker "new centre" pin recoloured from gold to navy (operator is red/green
  colour-blind — navy reads cleanly against the red "established" pin).

- **[DELTA]**
  - **`web/transport/src/data/line-paths.js`** — `buildLinePaths` no longer derives BPL/PLRT
    order from code numbers. New `LINE_SEQUENCES` constant holds explicit operator-verified
    station-name sequences: BPL as one lollipop segment (stem + loop closing back on Bukit
    Panjang); PLRT as two closed loops off Punggol, the West loop placing Teck Lee between Sam
    Kee and Punggol Point. A `pointByName` map resolves the sequences to coordinates from the
    station list. SLRT keeps numeric order but each `SE/SW` branch now closes — wrapped with
    the STC hub at *both* ends (`HUB_CODE`/`BRANCH_PREFIXES` trimmed to SLRT-only since PLRT no
    longer needs them). New `PREFIX_HEAD = { CE: 'Promenade' }` prepends Promenade to the CCL
    `CE` spur segment so Bayfront visibly connects to the loop. Header comment + version stamp
    updated.
  - **`web/transport/src/components/MrtMapPanel.jsx`** — styling constants: `DOT_SIZE` 11→12,
    `DOT_SIZE_FUTURE` 8→9, `LINE_WEIGHT` 4→3, `LINE_WEIGHT_FOCUSED` 6→5. `stationDotNode` /
    `renderPolylines` already read these — no other change.
  - **`web/hawker/src/components/HawkerMapPanel.jsx`** — `hawkerPinNode`: pin diameter 18px →
    17px; the `isNew` pin background and the "NEW" badge background `#f5a623` (gold) → `#1e3a8a`
    (navy). Established pin stays red `#e53935`. Header comment updated.
  - **`__tests__/transport-line-paths.test.js`** — new `LRT_CCL_STATIONS` fixture (BP1–BP13,
    PTC + PW1–PW7 + PE1–PE7, a CC slice + the CE spur); +4 tests: BPL closes on Bukit Panjang,
    PLRT draws two loops each closing on Punggol, the West loop orders Teck Lee mid-loop, and
    the CE spur starts at Promenade. The SLRT test updated for the new closed-loop segment
    length.
  - `package.json` `0.60.232 → 0.60.233`; this Journal entry (#201); `doc/.serial-state.yml`
    bumped + re-anchored.
