## New

### [HDR] #34 | 15:30:00 SGT 30-04-26 | v0.21.1 | n/a kb | n/a lines
- **[INTENT]** Per Human Lead: *"Click 'open map' after searching the places, resulted in TMA pop-up instead of the map. I think can remove this option"*. Drop the **📍 Open Map** inline button under each Sanctuary read.
- **[DELTA]**
  - **`index.js deliverPicks`** — removed the `📍 Open Map` `web_app` button block. The remaining inline button under each pick is **🚗 Directions** (Google Maps `directionsUri` URL — opens the user's preferred Maps app and dispatches walking directions). The TMA at `/app` (single-pin focus) is still reachable via the menu button "🌿 soleat Map" tile, just not from the per-pick keyboard.
  - **`package.json`** — version 0.21.0 → 0.21.1.
- **[ROOT-CAUSE NOTE]** The 📍 Open Map button has been the persistent source of UX friction since v0.5.0 — it launches the TMA with a `?placeId=…` query, which on iPadOS routinely renders as a "pop-up" (Telegram's WebApp container) and fails to focus the single pin reliably. Multiple v0.4.x and v0.5.x iterations tried to fix the underlying behaviour (Place ID anchor strategy, AdvancedMarkerElement, gesture handling, install fallback). Today's instruction acknowledges that for the **per-pick** affordance, **Directions** is what users actually want — they're already on the picks message, they want to walk there. Map-browsing is the menu button's job.
- **[SAMPLE PICK INLINE KEYBOARD (v0.21.1, expected)]**
  ```
  🌿 Sanctuary read for <Venue name>
  …summary…
  💡 …generative summary…

  [🚗 Directions]
  ```
  (Down from `[📍 Open Map] [🚗 Directions]` in v0.21.0.)
- **[RISK]** Negligible. Directions URL flow is unchanged; the menu-button TMA tile is unchanged. Users who relied on tap-to-pin can still use the menu button + tap a pin from the map view.
- **[STATUS]** PROD — auto-deploys with the next Railway build.
- **[TEST]**
  1. `/eat` → share location → each Sanctuary read message has exactly one inline button: **🚗 Directions**.
  2. Tap **🚗 Directions** → opens Google Maps with walking directions to the venue (no TMA pop-up).
  3. Menu button "🌿 soleat Menu" → tile UI still works, including the Map tile.
- **[NEXT]** No follow-up needed. If Human Lead later wants a per-pick Map tap that doesn't pop up the TMA, the right shape is probably a `googleMapsLinks.placeUri` `url:` button (opens Google Maps app to the pin), not a `web_app:` button.
