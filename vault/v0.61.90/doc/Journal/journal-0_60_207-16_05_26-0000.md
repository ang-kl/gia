- **[DELTA]**

  **(1) Train TMA title** — `web/transport/src/i18n.js` `header.title`:
  - EN: `🇸🇬 Singapore Train Map and Status` → `🇸🇬 Train Map & Status`
  - FR: `🇸🇬 Carte et état du métro de Singapour` → `🇸🇬 Carte et état du métro`

  **(2) CCL6 station opening dates** — the final three Circle Line stage-6 stations (Keppel CC30, Cantonment CC31, Prince Edward Road CC32) open 12 July 2026:
  - `data/mrt-coords.json` — added `opensDate: "12 July 2026"` + `opensDateFr: "12 juillet 2026"` to the three station records (they keep `opensYear: 2026` as the fallback).
  - `index.js` `/api/transport/stations` — passes `opensDate` + `opensDateFr` through.
  - `web/transport/src/components/MrtMapPanel.jsx` — the future-station popup line now renders `opensDate || String(opensYear)`, so the three CCL6 stations read `Opens 12 July 2026` while every other future station keeps `Opens 2027/2030/…`.
  - The other three 2026-opening stations (Bedok South TE30, Sungei Bedok TE31/DT37, Xilin DT36) were NOT given a date — the operator only specified the CCL6 trio — they keep `Opens 2026`.

  **(3) Train InfoWindow dark-mode legibility** — `MrtMapPanel.jsx`: the InfoWindow root `<div>` gained `color:#1c1c1f`. The Google Maps InfoWindow bubble is always white, but Telegram's dark theme cascaded a light body colour into it, rendering the popup text near-invisible (operator screenshot). Pinning a dark colour fixes both themes.

  **(4) Cuisine free-text box dark-mode contrast** — `web/cuisine/src/v2/components/TellMePanel.jsx`: the "What are you craving?" input wrapper was `border border-tg-border` — `tg-border` (≈#2a2a2e) is near-invisible against `tg-card` (≈#1c1c1f) in dark mode. Changed to `border-2 border-tg-hint/60` — `tg-hint` is a medium-contrast colour the Telegram theme adapts for both themes; 2px width makes the field read as distinct + tappable.

  **(5a) Hawker InfoWindow — address hyperlink** — `web/hawker/src/components/HawkerMapPanel.jsx`: dropped the standalone blue "Open on Google Maps" `<button>` (it was clipped / hard to see inside the bubble — operator screenshot). The address line is now itself an `<a>` hyperlink (blue, underlined, trailing `↗`) that calls the same `window.__giaHawkerOpenMap` deep-link handler. One affordance instead of two.

  **(5b) Hawker InfoWindow — stall count** — same file: added a `🍳 {n} stalls` line (localised via `tn('stalls.count', lang)` — FR `🍳 {n} stands`) between the centre name and the address link, shown when `c.stalls` is a positive number. The InfoWindow root also gained `color:#1c1c1f` for the same dark-mode reason as (3).

  **(6) FR** — applied throughout: item 1 bilingual; item 5b localised via the existing `stalls.count` key (EN/FR both present); items 3/4 are CSS-only (no copy); item 5a's address is real-world text (untranslated by nature). See KNOWN GAPS for the one English-only remnant.
