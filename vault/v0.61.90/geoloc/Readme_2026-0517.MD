# `geoloc/` — Singapore geographic datasets

This folder holds geographic features (points, lines, polygons) and their
non-spatial attributes as **GeoJSON** — official open data from data.gov.sg,
used to draw Google Map polylines, pins and overlay layers across the project.

Keep the table below current: whenever a file is added or refreshed, update its
**Last updated** row so a stale dataset is easy to spot.

## Notes

- **Map overlay layers (v0.61.0).** `TouristAttractions`, `NParksParksandNatureReserves`
  and `LTATaxiStopGEOJSON` are converted by `scripts/build-geo-overlays.js` into slim
  `data/geo-*.json` files, served by `index.js` at `/api/geo/overlays`, and shown as
  toggleable overlay layers on the Cuisine and Hawker TMA maps. Re-run
  `npm run build:geo` after refreshing any of those three source files.
- Some data.gov.sg GeoJSON exports store feature attributes as an HTML table inside
  `properties.Description`; others (including the three overlay datasets) use flat
  `properties` keys. Converters should handle both.
