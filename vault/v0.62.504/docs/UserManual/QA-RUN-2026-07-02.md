## Patches applied

### 1. Language and food search wording

Changed internal-sounding wording from:

```text
Soleat’s food search should therefore use language as one clue...
```

to:

```text
Soleat uses language as one clue...
```

Reason: make it user-facing, not specification-style.

### 2. Practical meal wording

Changed:

```text
Soleat should support this kind of practical search...
```

to:

```text
Soleat can help with this kind of practical search...
```

Reason: avoid internal roadmap/spec language and keep it user-facing.

### 3. Station timing wording

Changed vague station timing wording from:

```text
train service timing or opening/closing context
```

to:

```text
first-train, last-train, or service-timing context
```

Reason: more precise and user-comprehensible.

### 4. `/forgetme` wording

Changed:

```text
To erase stored user data where supported...
```

to:

```text
To request removal of stored user data where supported...
```

Reason: avoid overpromising the exact storage/removal implementation.
