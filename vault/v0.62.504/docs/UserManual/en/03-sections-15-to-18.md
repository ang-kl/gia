# Soleat User Manual — Sections 15 to 18

## 15. Google Map View

Google Map View helps you understand the area around a food result.

Use it when the question is not only “Is this food good?” but also “Is this place practical to visit?”

A map view can help you compare food places with nearby context such as transport, bus stops, car parks, hawker centres, attractions, clinics, police stations, parks, and other location markers where available.

### 15.1 When to use Google Map View

Use Google Map View when location matters.

It is especially useful when you want to:

- compare several eateries in the same area;
- check whether a place is near a train station;
- check Singapore Train Station Exits where available;
- check nearby bus stops or bus information;
- check car park context;
- see whether a food stop fits into a walking route;
- plan around a mall, hotel, office, station, church, school, or attraction; or
- decide whether a place is worth saving into Sketchbook.

### 15.2 Map layers and buttons

Map layers help you show or hide nearby context.

Depending on the available feature and area, map buttons may include food results, Singapore Hawker Centres & Food Centres, train context, Singapore Train Station Exits, Singapore Bus Information, Singapore Car Parks, attractions, clinics, police stations, parks, or other practical markers.

Use layers carefully. Too many layers can make the map crowded. Turn on only the context you need for the decision.

### 15.3 Colour and monochrome view

Where available, colour and monochrome map modes help you read the map in different situations.

Use colour mode when you want stronger visual separation between features.

Use monochrome mode when you want a quieter map and want the selected results or key markers to stand out.

### 15.4 Using map view with food search

Map view is most useful after you already have possible food choices.

A practical flow is:

```text
Search food
        ↓
Open map view
        ↓
Turn on relevant layers
        ↓
Check transport, bus, car park, or nearby context
        ↓
Choose, refine, or save the place
```

### 15.5 Map tips

If the map feels crowded, hide layers you do not need.

If a result looks attractive but inconvenient, save it into Sketchbook instead of choosing it immediately.

If you are planning a trip or food trail, use the map to check whether the stops are naturally close to one another.

## 16. Recognised Venues and Curated Food Sources

Recognised Venues help you start from places with some form of recognition or curated signal.

Use this when you want a stronger starting point than ordinary search results.

Recognised results may include Michelin-listed places, Bib Gourmand places, Asia 50 / Asia 100 references, Local Produce to Table references, or other curated sources where available.

### 16.1 When to use recognised search

Use recognised search when you want to:

- explore notable food places;
- find curated options;
- compare recognised venues by location;
- look for a special meal;
- find a stronger shortlist before planning; or
- combine recognition with cuisine, map, transport, or saved planning.

### 16.2 Use `/recognised`

To start from Telegram chat, type:

```text
/recognised
```

Soleat may return recognised or curated food places depending on location, availability, and supported sources.

### 16.3 Recognition is a signal, not a guarantee

A recognised place is not automatically the best place for every user or every occasion.

Before deciding, check whether the place fits your time, budget, queue tolerance, cuisine interest, transport route, car park needs, and opening hours.

### 16.4 Using recognised venues with Sketchbook

Recognised venues are useful candidates for planning.

If you are not deciding immediately, copy useful cards into Sketchbook. You can later file them into a trip, day, time slot, event, or backup list.

## 17. Hidden Gems

Hidden Gems help you explore food places that may not appear at the top of ordinary search results.

Use this when you want discovery, not just familiar or highly visible options.

### 17.1 When to use Hidden Gems

Use Hidden Gems when you want to:

- try somewhere less obvious;
- avoid repeating the same places;
- explore a neighbourhood;
- find a possible food stop near your current location;
- plan a casual food trail;
- save new ideas into Sketchbook; or
- compare lesser-known places with recognised venues or ordinary search results.

### 17.2 Use `/hidden`

To start from Telegram chat, type:

```text
/hidden
```

You may add a place name if you want to search around a specific area.

Examples:

```text
/hidden Tanjong Pagar
/hidden Bugis
/hidden Johor Bahru
```

### 17.3 Read hidden-gem results carefully

Hidden-gem results are discovery suggestions.

Before deciding, check whether the place is open, nearby, practical to reach, and suitable for your occasion. A hidden gem may be interesting, but not always convenient.

### 17.4 Hidden Gems and planning

Hidden Gems are often useful for future planning.

If a suggestion looks interesting but does not fit the current moment, save it into Sketchbook and file it under a future trip, food trail, weekend plan, or backup drawer.

## 18. Set Meals and Practical Meal Options

Sometimes the user is not searching for a cuisine. The user is searching for a practical meal.

For example, you may want a set meal, quick lunch, solo dinner, late supper, affordable option, or something suitable before a meeting, movie, service, commute, or trip.

Soleat can help with this kind of practical search where available, but results may depend on available data, venue descriptions, dish notes, opening hours, and search context.

### 18.1 When to search for practical meal options

Use practical meal search when your need is shaped by time, budget, convenience, or occasion.

Examples:

```text
set meal near City Hall
quick lunch near Raffles Place
solo dinner near Orchard
late supper near Bugis
affordable lunch near Tanjong Pagar
```

### 18.2 Combine practical search with context

Practical meal search is more useful when combined with location and timing.

Better:

```text
set meal near City Hall before 7 PM
quick lunch near Raffles Place
late supper near Bugis MRT
```

Less useful:

```text
set meal
cheap food
```

### 18.3 Check opening hours

Opening hours matter when planning around meal slots.

If you are planning breakfast, lunch, tea break, dinner, supper, or a full-day food trail, check whether each place is likely to be open at the right time.

When saving places into Sketchbook, file them into the correct time slot so the plan remains realistic.

### 18.4 Use practical options with Sketchbook

Practical meal options are useful for planning.

For example, you can create a Sketchbook cabinet for a day outing, then add drawers such as Breakfast, Lunch, Tea Break, Dinner, Supper, and Backup Options.

Copy useful eatery cards into the right drawer so that the plan reflects real meal times.

### 18.5 Practical search tips

If results are too broad, add the area, time, cuisine, or occasion.

If results are too narrow, remove one constraint and search again.

If the app cannot confirm a set meal directly, use the result as a lead and verify the details before going.
