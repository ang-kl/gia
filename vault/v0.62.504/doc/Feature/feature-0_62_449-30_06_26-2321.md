## §2 · New / expanded features this arc (v0.62.154 → v0.62.449, PRs #1107–#1429)

### G-A · Cuisine TMA floating-dock consolidation
A multi-day rapid-iteration UI arc converged the Cuisine TMA's chrome from the v0.62.153 map-first layout into a single glassmorphism **dock**: a combined controls card (top/end row beside the free-text bar), a right 🔍 FAB that re-fires the current search rather than reopening the criteria sheet, list/vertical/Cuisine toggles on one row, a floating liquid-glass filter-pill strip above the FABs, and **folio folder-tabs** (first manila, later plain-white per operator reversal) wrapping the location, cuisine, and local-classic pickers as one connected in-flow panel. The arc closes with v0.62.190's **full redesign** — a full-bleed map with a unified glass command dock, killing the old white-margin layout — then keeps refining (squeezed-map fix, active-filters-as-text-below-search, fixed-overlay pickers restored in front of the map, folder-drawer tab↔body connection, category consolidation 14→9, Menu-hub tile/icon parity). *(#1107–#1141, #1147–#1160, #1177, #1187–#1190, #1204–#1266, wrapping through the docs catch-up at #1273)*

### G-B · Curated dish-note content pipeline
A sustained curation pass built `CUISINE_NOTES` from a handful of entries to **1,505+ verified `{local, note, sources}` dish records**: SG batch 1 (30) → SG batch 2 (+132, SG ~complete) → Vietnamese (24) → Batch 1 (203, 7 cuisines complete) → Batch 2a (98) → **L1 long-tail** (+302, then complete at 387/387 across 16 cuisines) → **L2** (+395, 17 cuisines) → **L3** (+369, long tail complete at 1,505 across 18 cuisines) → a thin-slug top-up (+15: Hainanese/Hakka/Fusion/Hunan) → cleanup passes (5 within-slug duplicates dropped, 489 truncated EN notes fixed, 888 FR accent/truncation issues fixed). Peranakan curated separately (29 entries). *(#1127, #1131, #1151, #1154, #1158, #1161, #1170, #1174, #1187, #1191, #1192, #1195; Peranakan #1134)*

### G-C · Local-classic / cuisine-plate "explain-first" UX + community grouping
The "what to try" plates (geo Local-classic and cuisine-mode) moved to an explain-first pattern: curated notes surface before "Find eateries," a dish tap no longer auto-fires a search, uncurated dishes still render a card, and "More classics" groups by meal type (Whole meals vs. Dishes & snacks). The picker settled into a top-aligned 2-column grid, later a **5-bucket split**, then a **community sub-grouping** for SG. SG local-classic taps default to hawker-centre-first results. *(#1114, #1121, #1126, #1146, #1150, #1172, #1173, #1176, #1196, #1347, #1366)*

### G-D · Eight-language i18n expansion
Chat + TMA locale coverage grew from EN/FR to **eight languages**: Indonesian (id) and then Russian (ru) + German (de) shipped as full infrastructure across Cuisine, Hawker, Transport, and Menu TMAs, followed by a 5-flag-row → compact-dropdown locale switch and cross-TMA server-side language persistence. A second wave added **Chinese (zh), Japanese (ja), and Spanish (es)** to the Cuisine TMA (open-hours labels, cuisine-card copy, picker/folio-tab cuisine names). A parallel **native-script** pass added local-script dish names in five batches — Chinese, Korean/Thai/Vietnamese, Cantonese/Sichuan/Hong-Kong, Hokkien/Teochew/Hainanese/Hakka, Shanghainese/Taiwanese/Hunan/NE/NW — plus 103 Singaporean and 6 Peranakan CJK hawker-dish names. *(#1275–#1287, #1294, #1298, #1371, #1375, #1376–#1378; native-script #1379–#1383, #1386, #1387)*

### G-E · Dish-explanation drafter + Gemini prose-translation pipeline
A **grounded, batched dish-explanation drafter** (Phase 1) generated English "what is this dish" explanations across nine sequential batches, reaching **1,643 explanations** (backfill-complete), with a length/fluff/source-quality/attribution tightening pass mid-run. Phase 2 added a **Gemini prose-translation mechanism** (`touristExplainer` → id/ru/de, later zh/ja/es) that carried through to fun-facts (72 translations) and per-dish 📜 notes (32 translations) — a frugal per-string pipeline reused across all three translated-copy surfaces, reviewed for quality at each stage, and closing with a 503-cascade fix. *(#1309–#1319 drafter batches; #1290–#1299 translation pipeline; #1320, #1324 Phase 2/3 target expansion)*

### G-F · Search Insights — anonymous demand strip
A four-PR build (`deriveInsights` pure function + tests → insight-strip UI → copy-to-chat insight line → an anonymous write-only demand counter) shipped a "what's trending nearby" signal on the Cuisine TMA, spec'd in a pre-build design brainstorm. The presentation churned heavily across the rest of the arc — dock-FAB row → tinted full-width band → neo-glass pill → short scrollable pill → wider near-square pill → borderless pill (no FAB gaps) → header-border restore → folio top-border → drop header line — settling on a **compact neo-glass pill flush to the footer**, with a full-bleed accent-bar redesign, price-range-instead-of-count, and a live crash hotfix (unmount → re-mount behind an `ErrorBoundary`) along the way. *(#1330, #1333, #1334, #1339 the 4-PR build; #1304 spec; #1335, #1343–#1363, #1368, #1369 the redesign/hardening churn)*

### G-G · Location & nearby-places overhaul
The location subsystem gained a **zone-grouped, selectable nearby-places browser** (SG MRT zones, later OTHER-cities support, street/floor/unit detail using the spare list width) after a half-baked inline "+" list was tried and reverted. Alongside: a prominent "tap to change" location box (de-duplicated to one worded affordance), reverse-geocode appending the street to a bare HDB block name, **long-press-the-map to set location**, adoption of **Telegram's native `LocationManager`** (fixing first-launch location not registering), a location-label guard so a TMA launch never shows an empty or bare-country label, dark-mode colour + 30-second static-highlight timing standardisation, and a fix stopping the location display from thrashing on an Australia→Canberra auto-reset. *(#1323, #1325, #1326, #1327, #1331, #1332, #1338, #1341, #1342, #1369, #1370, #1373, #1374, #1298)*

### G-H · Price tiers, forex, and Set Meal (Beta)
Added a **4th price tier ($$$$)** so fine-dining destinations (e.g. Manila) become filterable, fixed a deterministic-parse bug where the free-text `$` filter mis-mapped to `$$$$`, and made the price filter match what the card actually displays (dropping signal-less venues). Forex conversion now renders in the horizontal result strip. A **"Set Meal · Signature (Beta)"** button surfaces confirmed-from-website set-meal/signature-dish annotations, later trimmed to price-only (signature/popular-dish sub-copy dropped as noise). *(#1300, #1321, #1328, #1329; forex #1269; Set Meal #1270, #1272)*

### G-I · Hawker overlay ported cross-TMA
The Cuisine-TMA-only 🍚 Hawker map overlay (toggle pill, H-coded pins, zoom-tier ladder shared with Train/Bus) was ported into the **Train TMA** (default OFF) and matched 1:1 in styling between the two surfaces. Hawker-card station pills went line-coloured (parity with Cuisine's MRT chips), hawker cards adopted canonical NEA names across all TMAs, and a pin show/disappear bug from the 550 m-radius clip was fixed. *(#1136, #1145, #1148, #1244, #1247, #1248, #1252, #1253, #1261, #1267)*

### G-J · Result-card evolution
Horizontal result cards moved to collapse-by-default with a uniform size and the Michelin row promoted to position 5; a "style A" pass added icons + 2-line address wrap to cut ellipsis truncation; a **"Likely serves {dish}"** hint strip landed on result cards (with a matching copy-to-chat line) so a dish search visibly ties back to specific venues; dish cards gained a **[picture]** action pulling a region-aware Wikimedia Commons photo (fixing a Wanton Mee SG→HK cross-region mismatch), later moved into a pop-up modal with auto-close. *(#1120, #1163; #1349, #1350; #1384, #1389, #1390, #1394)*

### G-K · Sketchbook TMA v2 — chrome, cabinets, filters, archive
**Extends `feature-0_62_332-clipboard.md` (F-α…F-θ) past its #1308 cutoff.** After the operator reverted the Cuisine-TMA launcher panel (RF in the Clipboard doc), the `web/clipboard/` bundle — product-facing name **Sketchbook** — was rebuilt across five phases plus a long polish tail, per a developer-handoff spec (`UI/sketchbook/HANDOFF.md`, #1395):

- **P1 backend:** delete-to-clipboard reflow, a default cabinet seeded per user, card duplicate. *(#1397)*
- **P2 chrome:** new header + 4-tab footer + hamburger menu, replacing the original Root/CabinetGrid-only shell. *(#1398)*
- **Header filter chips** narrow the saved-card set by cuisine pick or dish keyword. *(#1399)*
- **P3:** collapsible `VenueCard` (Cuisine-TMA `ResultCard` look, reusing the venue rendered on Copy) + a vertical Clipboard list. *(#1400, #1411)*
- **P4a/P4b:** a 2-step File (drawer) creation sheet; edit pills, a default-favourite star, card duplicate, card remove. *(#1401, #1402)*
- **P5:** a dedicated Settings screen. *(#1403)*
- **Chrome parity:** soleat logo, Menu-TMA-matching hamburger icons, a footer version strip, the sample app's cobalt+ice palette (replacing Telegram-theme tokens), default first-cabinet name "My 1st Cabinet." *(#1404–#1409)*
- **Cabinets list:** badges, per-cabinet card counts, last-touched, with backend count support. *(#1410)*
- **Catch-all:** header row, sort, and **archive/restore** (new capability beyond the original Clipboard spec's ephemeral-only catch-all). *(#1415)*
- **Drawer polish:** descriptions carrying segment timing, a free-120-char description field, Edit→Duplicate/Delete relocated top-right, duplicate-card indicators, a filed cabinet/drawer label + colour strip, date-of-copy on cards, and a **📍 All-locations list** (country › city, auto-close). *(#1413, #1414, #1416, #1417, #1418)*
- **Filters:** chips as folio tabs (not a bottom sheet), richer facets (rating / price / crowd / open / Michelin), then a "professional" detached-inset dropdown that hides empty facets, following a **Cuisine folio doctrine** (no bleed, slide transition, contained grid, no edit-zoom, overlay exclusion, footer default fallback). *(#1423–#1426)*
- **Blank cards:** create/edit/delete/move a hand-authored "sketchbook" card not sourced from a Copy. *(#1427)*
- **File picker:** two-column layout with drawer chips + counts, a 33-icon cobalt file/folder icon set. *(#1428)*
- **Launch + hardening (spans the whole cycle):** `/clipboard` chat command → last-5 + "Open Sketchbook" button (with a silent-fail fix for an empty `inline_keyboard`); a Menu-TMA launch tile under Location; a bulletproof diagnostic boot; a fix for a TDZ crash that produced a black screen; an `ErrorBoundary` surfacing crashes instead of a silent black screen; raw-HTML stripped from a copied card body. *(#1352, #1365, #1367, #1388 [journal back-fill], #1406, #1419, #1421, #1422)*

The Redis schema, 16 `/api/clipboard/*` endpoints, TTL/cascade-delete rules, and share/fork mechanics documented in the Clipboard doc's Architecture appendix are **unchanged** by this rebuild — G-K is a chrome/UX layer on top of that same backend, plus the new archive capability noted above.
