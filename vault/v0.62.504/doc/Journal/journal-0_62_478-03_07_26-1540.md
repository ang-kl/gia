### [HDR] #832 | 15:40 SGT 03-07-26 | v0.62.478 — Cuisine TMA back FAB (layers 2/3), English-only "Back" word | 1 file | PR #(pending) |
- **[INTENT].** Give the drilled-in cuisine picker an easy thumb-reach "back" affordance
  stacked directly **above** the Search FAB, appearing only on the 2nd/3rd drill layers,
  and — per 2b — showing the word "Back" **only** in English (emoji-only 🔙 elsewhere).
- **Where the layers live.** The Cuisine picker is a nest: **layer 1** = the inline folio
  category grid (`cuisinePickOpen`, in the header — has its own ✕ + folio tab); **layer 2**
  = `CuisineCategoryDrawer` (the sub-cuisine modal, `fixed inset-0 z-30`, opened from inside
  `CuisineDrawer`); **layer 3** = the dish pop-ups inside that drawer (`dishModal` z-40,
  `dishDetail` z-50). Layers 2 + 3 all live inside `CuisineCategoryDrawer`, which already
  owns their state and close handlers — so the FAB was added there, one file, no state
  lifting across App ↔ CuisineDrawer ↔ CuisineCategoryDrawer.
- **[DELTA] `web/cuisine/src/v2/components/CuisineCategoryDrawer.jsx` (1 file).**
  - `goBack` is a **derived** value (no new state): `dishDetail ? closeDetail : dishModal ?
    closeModal : onClose` — it always pops the **topmost** open layer only. Layer 3b→3a→2→(close→1).
  - A `fixed z-[60]` back FAB, rendered whenever the drawer is mounted (i.e. layer ≥ 2). z-[60]
    floats it above the category scrim (z-30) and both dish pop-ups (z-40/z-50).
  - **Alignment is by construction, not guessed.** It reuses App.jsx's bottom-cluster geometry:
    `right: 0.625rem` (container `px-2` 0.5rem + row `px-0.5` 0.125rem = the Search FAB's right
    edge) and `bottom: calc(0.15rem + env(safe-area-inset-bottom,0px)*0.5 + 2.5rem + 0.375rem)`
    (base padding + one 40px FAB height + the 6px row gap) → it lands exactly one row above 🔍.
  - **2b.** The visible `<span>Back</span>` renders only when `lang === 'en'`; every other locale
    is the 🔙 circle. `aria-label` always carries the localised word (`Retour / Kembali / Назад /
    Zurück / 返回 / 戻る / Atrás`) so screen readers announce it in all 8 locales.
  - Styling mirrors the sibling 💬 FAB (`bg-tg-card border-2 border-tg-hint/60 shadow-lg`, `h-10`)
    so it reads as part of the same FAB system rather than competing with the accent Search button.
- **[VERIFICATION (sandbox)]** `esbuild --format=esm` parse of `CuisineCategoryDrawer.jsx` clean
  (exit 0). No behavioural change to layer 1 or to any existing close control (the ✕ buttons and
