## Investigation before implementation

names, and native-script terms are **identity, not copy** — Gemini is instructed to keep them
**verbatim**. This matches how the Cuisine TMA already renders dishes everywhere (English name +
native script, never a translated name). Operator confirmed: keep names verbatim, translate
**descriptions** only.
