  - **NEW** `web/cuisine/src/components/OtherCuisineInput.jsx` — free-text input "e.g. kaiseki, nasi padang, smashburger", comma-tolerant; appended to cuisines payload at search time.
  - **NEW** `web/cuisine/src/components/PromptPreview.jsx` — collapsible `<details>`-style strip below presets that re-renders the actual Gemini prompt as the user changes any control. `buildClientPreviewPrompt` mirrors `cuisine-search.js#buildPrompt` shape so users (and the dev) can see what's about to be sent.
  - **REWRITE** `web/cuisine/src/state/useCuisineState.js` — adds `radius` (200–5000), `recencyDays` (5–180), `queueMaxMin` (5–60), `otherCuisine` (string). Toggling any control clears `preset` (so the active preset doesn't lie about what's being searched). `MAX_CUISINE_SELECTIONS` enforced in the reducer.
  - **REWRITE** `web/cuisine/src/App.jsx` — assembles three RangeSliders + ModeDropdown + TimeDropdown + CuisineAccordion + OtherCuisineInput + PresetCombos + PromptPreview. Search payload now `{lat, lng, cuisines, radius, recencyDays, queueMaxMin, mode, when, preset}`. The `cuisinesPayload` merges accordion selections with comma-split free-text values.
  - **REWRITE** `web/cuisine/src/components/VenueCard.jsx` — adds `⏱ ~N min queue (est)` chip + `📅 Booking advised` chip when applicable.
  - **DELETE** `web/cuisine/src/components/CuisineChips.jsx` — superseded by `CuisineAccordion`.
  - **DELETE** `web/cuisine/src/components/RadiusToggle.jsx` — superseded by `RangeSlider`.
  - **`cuisine-search.js`** —
    - Removed `ALLOWED_RADIUS = new Set([250, 1000])`. Replaced with `clamp(200..5000)` for radius, `clamp(5..180)` for recency, `clamp(5..60)` for queue.
    - Gemini schema now asks for `queue_min_estimate` (integer minutes) + `booking_required` (bool). Both surfaced on the validated venue.
    - `buildPrompt` now includes radius m, recency-window line, and a queue-tolerance line that asks Gemini to estimate honestly even if the result will be filtered out.
    - Post-validate filter drops venues with `queueMinEstimate > queueMaxMin` (null estimates pass through).
    - `searchCuisine` signature gains `recencyDays`, `queueMaxMin`. Returned payload echoes both for the client.
  - **`index.js`** — `POST /api/cuisine-search` route now plumbs `recencyDays`, `queueMaxMin`. Cuisines slice cap raised from 9 to 10 (chip max 5 + free-text headroom).

- **[KNOWN GAPS]**
  - Queue estimate is Gemini knowledge, not a real-time queue feed. Labelled `~N min (est)` so users don't mistake it for an SLA. Documented as Decision Rule #44 below.
  - Larger radius (3–5 km) substantially expands the Places search billable area. Cost is bounded by the 15-validate cap, but per-call $$ is roughly linear in radius for places that match the cuisine prompt at distance.
  - Accordion doesn't remember open/closed state across tabs of the TMA (no persistence). Acceptable for a one-screen TMA.
