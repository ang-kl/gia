## §0.9.0 NEW CONTENT

### Redis Vault — curated places, geo-indexed, queried first

A user-curated corpus of places lives in Redis as a geospatial index plus per-place metadata hashes. `/eat` and `/drink` consult the Vault before falling through to the broad Gemini → Places pipeline.

### 1. Schema

| Key | Type | Purpose |
| :--- | :--- | :--- |
| `gia:vault` | Sorted set (geo) | `GEOADD <lng> <lat> <place_id>` — one member per Vault entry. |
| `gia:place:<place_id>` | Hash | `name`, `address`, `primaryType`, `hours` (JSON), `businessStatus`. No expiry. |
| `gia:vault:cleanup` | List | Skipped/closed venues from sync runs (`{timestamp} {url} {reason}`). |

### 2. Sync workflow (`sync-vault.js`)

One-shot importer. Run locally with Railway env vars (`railway run node sync-vault.js`) or with a populated `.env`. Behaviour:

1. Concurrency 5, exponential backoff on 429 / 503 / ETIMEDOUT (max 3 retries).
2. For each Google Maps short URL:
   - Follow redirect (up to 5 hops) to expanded `https://www.google.com/maps/place/<name>/@<lat>,<lng>/...` URL.
   - Parse name + coords from the URL path.
   - `places:searchText` with `<name> Singapore` + 100 m `locationBias` → `place_id`.
   - `Place Details` with FieldMask `id,businessStatus,regularOpeningHours,location,displayName,formattedAddress,primaryType`.
   - **Operational Gate:** `business_status !== 'OPERATIONAL'` → log to `gia:vault:cleanup` list + console, skip.
   - Else `GEOADD gia:vault <lng> <lat> <place_id>` + `HSET gia:place:<place_id> ...`.
3. Console summary at end: imported / skipped (closed) / failed (resolve or fetch error) / current vault size.

### 3. Runtime priority (`/eat` and `/drink`)

`runFlow(chatId, lat, lng, category)` — Vault-first decision tree:

```
if category in ['food', 'drink']:
    GEOSEARCH gia:vault FROMLONLAT <lng> <lat> BYRADIUS 300 m
    for each hit (sorted by distance):
        Place Details → currentOpeningHours.openNow + businessStatus
        if OPERATIONAL && openNow !== false: keep
    if 3 open hits → deliverPicks(vault picks)
    else → fall through to pickValidated (broad Places + Gemini)

if category == 'groceries':
    pickValidated  (Vault skipped intentionally — different corpus)
```

`/groceries` deliberately does NOT consult the Vault: the curated 14 URLs are food/drink-oriented and surfacing them as "groceries" would be wrong.
