- **[INTENT]** Operator, reviewing the TMA maps: *"Remove nearby to details as it doesn't
  work. Add 'taxi' button in all tma beside exit button. Upon tap 'taxi', it will shows
  taxi and pickup related to the stations in view … if train is tap, it will shows … the
  station before and after it. Tap taxi button will show the taxi stands of these three
  stations. tap 'exit' button shows the exits of these three stations."* Two operator
  decisions clarified the build: **reuse the existing 🚆 Exits / 🚕 Taxis chips** (not new
  buttons), and in the station-detail view **drop the bus-stop + carpark pins** — only the
  chip-driven exits / taxis show.

- **[DELTA]**
  - **`web/{transport,hawker,cuisine}/src/.../lib/mapOverlays.js`** (byte-identical ×3) —
    - Removed the Nearby↔Details slider: `OVERLAY_RADIUS {nearby,details}` → one fixed
      `OVERLAY_RADIUS_M = 550`; `currentRadius()` returns it; dropped `attractionsMode`
      state + the `setAttractionsMode` public API.
    - New `STATION_AMENITY_RADIUS_M = 400` + `detailStations` (the 3 visible stations'
      coords, rebuilt in `applyVisibility('train')`). In the marker branch, when a
      station-detail view is active the `exits` / `taxis` layers clip to within 400 m of
      any of the 3 stations instead of the anchor radius — so the chips show those
      stations' amenities.
    - New `syncDetailAmenityLayers()` re-applies the Exits / Taxis layers when the detail
      view is entered / cleared (`handleStationTap`, `exitStationDetail`, train-off).
    - Removed the station-context amenity path — `loadAmenities` / `drawAmenities` /
      `clearAmenities` / `detailAmenities` / `stationCtxCache`. Station-detail no longer
      auto-draws exits/bus/taxi/carpark from `/api/transport/station-context`; the chips
      do it (bus + carpark are no longer shown in the detail view). `attachAmenityPins`
      stays — still used by the panels' venue / hawker-centre taps.
  - **`MapLayerChips.jsx` ×3** — Taxis chip moved next to Exits; removed the slider markup
    + `attractionsMode` / `onAttractionsModeChange` props.
  - **`App.jsx` ×3** — removed the `attractionsMode` state + prop threading.
  - **`MrtMapPanel.jsx` / `HawkerMapPanel.jsx` / `MapPanel.jsx`** — removed the
    `attractionsMode` prop + the `setAttractionsMode` useEffect.
  - **`i18n.js` ×3** — removed the now-unused `layer.nearby` / `layer.details` keys.
