## New

### [HDR] #273 | 21:15:00 SGT 20-05-26 | v0.61.69 — 24-hour places fetch pipeline | ~7 kb | 4 files | 1 PR | 1 build |

- **[INTENT]** A reproducible pipeline that fetches Singapore places open 24 hours,
  grouped by the operator's 8 types, into `data/sg_24hr_places.json` — without
  inventing any place data.

- **[DELTA]**
  - **`scripts/fetch-24hr-places.js`** (new, ~190 lines) — Google Places API
    (New) `places:searchText`. Per type, a text query + `includedType` narrows
    the search; results are paginated (≤3 pages) and **filtered to API-confirmed
    24-hour places** (`isOpen24()`: a single `regularOpeningHours` period opening
    day 0 / 00:00 with no close, or all `weekdayDescriptions` reading "Open 24
    hours"). Each kept place → `{ type, name, address, tel, google_maps_url,
    place_id }`, all verbatim from the API (missing → `null`). Deduped by
    `place_id` across type queries. 3× retry with exponential backoff; failures
    recorded in `metadata.errors[]`, the run continues. Key read from
    `GOOGLE_PLACES_API_KEY` (env only, never committed); no key → exit with a
    message.
  - **`data/sg_24hr_places.json`** (new) — committed **scaffold**: `metadata`
    (description, source, the 24-hour rule, the 8 types, non-invention note,
    counts, errors, `status`) + empty `places: []`. The operator's run overwrites
    it with real data.
  - **`scripts/README-24hr-places.md`** (new) — source, key setup, the 24-hour
    rule, the type→query table, non-invention rules, output schema, rerun steps,
    and the Places API caching-policy note.
  - **`package.json`** — new `fetch:24hr-places` script; `0.61.68` → `0.61.69`
    (PATCH — data-pipeline addition, established cadence).
