# Journal — soleat v0.60.160

> Operator-reported precision bug on Cuisine TMA: searching with cuisine chip **"Portuguese"** returned a mix of Spanish, Seafood, Eurasian, Cantonese (Macanese) — even Wagyu via prior-clip noise — not just Portuguese. Two genuine Portuguese hits (Lusitano, Vera Portuguese Seafood JB) shipped alongside ~10 unrelated venues. Root cause: the v0.57.13 gated-category post-filter at `index.js:9366` accepted any venue whose **review text** mentioned the cuisine word — for "Portuguese", reviews on Spanish, Eurasian, Macanese, Wagyu venues mention Portuguese as a cultural-influence flavour reference, so they all passed the gate. Fix: split the filter's haystack — bare cuisine-name + multi-word matches run against a STRONG haystack (name + area + primaryType + editorial summary) only; dish-keyword matches keep using the FULL haystack (reviews included) since dish names are specific enough to be reliable signals. Applied to both the TMA path (`index.js:9366`) and the NL chat-path twin (`:9988`).

- **[DELTA]**

  **`index.js` `/api/cuisine/search` gated-category filter (~line 9366)** — was:

  ```js
  const haystack = [
    v.name || '', v.area || '', v.primaryType || '',
    v.googleSummary?.overview || '',
    reviewText                                  // ← review text in the bare-name match
  ].join(' ').toLowerCase();
  for (const name of gatedNames) {
    const lower = name.toLowerCase();
    if (haystack.includes(lower)) return true;  // ← review mentions kept the venue
    …
    const words = lower.split(/\s+/).filter((w) => w.length >= 4);
    if (words.length >= 2 && words.every((w) => haystack.includes(w))) return true;
    const dishKeywords = require('./cuisine-dish-keywords').getDishKeywords(name);
    for (const kw of dishKeywords) {
      if (haystack.includes(kw)) return true;
    }
  }
  ```

  Now:

  ```js
  const strongHaystack = [
    v.name || '', v.area || '', v.primaryType || '',
    v.googleSummary?.overview || ''
  ].join(' ').toLowerCase();
  const fullHaystack = (strongHaystack + ' ' + reviewText).toLowerCase();
  for (const name of gatedNames) {
    const lower = name.toLowerCase();
    if (strongHaystack.includes(lower)) return true;            // bare match → STRONG only
    if (v.primaryType === `${slugForType}_restaurant`) return true;
    if (words.length >= 2 && words.every((w) => strongHaystack.includes(w))) return true;  // multi-word → STRONG only
    for (const kw of dishKeywords) {
      if (fullHaystack.includes(kw)) return true;               // dish keywords → FULL (reviews OK)
    }
  }
  ```
