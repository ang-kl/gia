### [HDR] #441 | 21:20 SGT 28-05-28 | v0.61.240 — Combo line + pill bg | 4 files | 1 PR | 1 build |

- **[INTENT]** Surface the active combo so the user always sees what they're searching, and visually mark the selected category cards so picks register at a glance.

- **[DELTA]**

  **1. `web/cuisine/src/v2/App.jsx`** — new computed `comboLine` prop passed to ResultPanel:
  ```js
  comboLine={(() => {
    const parts = [];
    /* cuisine display names from catalogue */
    /* filter labels (Halal / Vegetarian / Open now / Home-based / Pet-friendly / Newly opened) when true */
    /* price range "$" repeated min-times, "–" + max-times when range */
    return parts.length ? parts.join(' · ') : '';
  })()}
  ```
  Example outputs:
  - cuisine = ['japanese'] + filters.halal → `Japanese · Halal`
  - cuisine = ['japanese'] + filters.prices=[2,3] → `Japanese · $$–$$$`
  - no cuisine/filter → empty string (line doesn't render)

  **2. `web/cuisine/src/v2/components/ResultPanel.jsx`** — new `comboLine` prop. Rendered as the third title line, `text-[10px] text-tg-hint italic font-normal leading-tight mt-0.5`, prefixed with `· `.

  **3. `web/cuisine/src/v2/components/CuisineDrawer.jsx`** — `CategoryCard` className flips to a selected style when `selectedInCat > 0` OR (single-item category) `isOnlySelected`:
  ```
  bg-[#DCEBFF] border-tg-accent text-[#0c2540]
  ```
  vs default `bg-tg-card border-tg-border`. Region-disabled (Michelin in JB) keeps its grey style independent of selection.

  **4. `package.json`** — `0.61.239 → 0.61.240`.
