### [HDR] #560 | 11:45 SGT 07-06-26 | v0.61.360 — USD-pivot FX table (Alpha Vantage + Frankfurter), markup + "≈" | 1 code file + 1 test | 1 PR | 0 build |

- **[INTENT]** The "rigid in Malaysia" complaint traced to the FX source, not Malaysia: the old Frankfurter-only path (ECB, ~33 majors) **omits TWD / VND / MOP / BND**, so those picker countries silently fell back to no-conversion. Replace it with a **USD-pivot rate table** that converts *any* picker currency, fetched once per 15 days, and present the converted value as an **honest traveller estimate** (markup + round-up + "≈").

- **[MECHANISM]**
  - **`usdRate(cur, redis)`** (NEW) — USD per 1 unit of `cur`. **Primary** Alpha Vantage `CURRENCY_EXCHANGE_RATE&from_currency=<cur>&to_currency=USD&apikey=$ALPHAVANTAGE_API_KEY` → `["Realtime Currency Exchange Rate"]["5. Exchange Rate"]`; the free-tier throttle envelope (`Information` / `Note` / `Error Message`) is treated as a **miss**. **Fallback** Frankfurter `?from=<cur>&to=USD`. `USD` short-circuits to `1.0`. Result cached in Redis at **`fx:usd:<CUR>`** for **15 days** (`15*24*3600` s) — long TTL keeps us inside Alpha Vantage's 25-req/day free tier and satisfies "once … 15 days".
  - **`fetchFxRate(a, b, redis)`** (REWRITTEN) — now `usdRate(a) / usdRate(b)`, i.e. a USD-pivot **cross-rate** (how many `b` per 1 `a`). Identical currencies short-circuit to `1.0`; any failed leg → `null` (caller drops the parenthetical). This is what fixes the rigid-currency gap: even when one leg is TWD/VND/MOP/BND, the pivot still resolves via Alpha Vantage.
  - **`convAmount(n, userCurrency)`** (NEW) + **`FX_MARKUP = 1.028`** + **`NO_CENTS`** set — multiply by 1.028 (operator's +2.8 %), then **round UP**: `Math.ceil` to a whole number for no-cents currencies (operator-named JPY/KRW/VND/IDR + the ISO-4217 zero-decimal set), else `Math.ceil(m*100)/100` to 2 dp. Applied to the **converted (parenthetical) value only** — the native menu price is never marked up.
  - **`formatPriceRangeForVenue`** — the parenthetical now reads **`(≈<prefix><lo>–<hi>)`**, e.g. `M$50–80 (≈S$14.91–23.85)`, `S$25–40 (≈US$19.02–30.43)`, `S$25–40 (≈¥2839–4542)`.
