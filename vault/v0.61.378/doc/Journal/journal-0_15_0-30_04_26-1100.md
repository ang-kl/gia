- **[DELTA]**
  - **`ver.js`** — error-note slice 80 → 250 chars. Next `/ver` should show the full Gemini error message instead of truncating at the URL.
  - **`vault.js`** — `DEFAULT_RADIUS_M` 300 → **500** m (with existing 50 m FUZZY_BUFFER → 550 m effective).
  - **`consultant.js`** — `RADIUS_M` 300 → **2000** m for Hidden Sanctuary "Near-Miss" analysis.
  - **`index.js`** — `runFlow` Vault check radius arg 300 → 500.
  - **`sync-vault.js`** — full rewrite. Now resolves inputs from (priority order):
    1. `--json=<path>` CLI flag (Saved Places.json schema)
    2. `--html=<path>` CLI flag (cheerio)
    3. `--kmz=<path>` CLI flag (single KMZ unzip + KML parse)
    4. **Auto-scan** `data/Saved Places.json` + `data/My Maps/*.kmz`
    5. Hardcoded URL fallback list (the original 14 URLs from earlier spec)
  - **Singapore geo-fence** by default (`lat 1.15–1.50, lng 103.55–104.10`). Drops out-of-region pins (Tokyo, Malaysia, Indonesia, USA — found in user's actual data). CLI flag `--no-fence` disables.
  - **Fence is two-stage**: file-level coords filtered first; canonical Place location re-checked after Place Details fetch (catches venues whose file-level coords are off but which resolve to a Singapore Place).
  - **`migration_audit.log`** — file-based audit log per spec (`fs.appendFileSync` per skip, plus `gia:vault:cleanup` Redis list). FS may be ephemeral on Railway but persists if run locally with `railway run`.
  - **JSON parser** also handles entries with `[0,0]` coords by recovering lat/lng from the `google_maps_url` `?q=lat,lng` query (Google Takeout Saved Places have many of these).
  - **KMZ parser** uses `adm-zip` to unzip; cheerio `xmlMode: true` to parse `doc.kml`. Extracts `<Placemark>` name + description + Point coordinates.
  - **`package.json`** — version → 0.15.0; + `adm-zip` dep.
- **[RISK]** Med —
  - **Singapore fence hardcoded.** Disabled with `--no-fence`. If you ever want a Tokyo soleat variant, the bounds would need to widen.
  - **JSON `[0,0]` coord recovery** is best-effort. Some entries have only `&ftid=...` not `?q=lat,lng`; those still log to audit as `place_id_unresolved`.
  - **KMZ corpus mostly out-of-region.** Of 13 KMZ files in `data/My Maps`, only "Map of the Thomson-East Coast Line" is Singapore-related (and it's an MRT line map, not venues). The fence will drop most KMZ pins. That's correct behaviour but means KMZ contribution to the Vault will be small.
  - **`adm-zip` is widely used** but synchronous; for thousands of KMZ entries we'd want streaming. At 13 files this is fine.
  - **2 km Hidden Sanctuary radius** is wide for an SG-CBD walk recommendation. The walk-time annotation (v0.8.0) keeps it honest by surfacing how far a 2 km candidate actually is.
- **[STATUS]** PROD — code auto-deploys with the next Railway build. Vault contents stay empty until you run sync-vault.
