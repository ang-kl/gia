## What this snapshot is

A faithful mirror of the repository at v0.61.378 — all source (`index.js` + ~100 root modules,
`web/<app>/src`, `scripts/`, `public/app.js`), the curated datasets (`data/`, `data_realtime/`),
the open-data sources (`geoloc/`), the `__tests__/` suite (**3055 tests green**, 110 files at
snapshot time), and the full `doc/` documentation system through journal **#578**.

It is bootable: a clean `npm install` reproduces the service.

## Exclusions (per `doc/CLAUDE-FULL.md` §16.1 — strict)

Produced via `git archive HEAD | tar -x` (tracked files only) minus the nested `vault/`, which
inherently applies the standard exclusion set:

| Excluded | Reason |
|---|---|
| `node_modules/` (root + every `web/*/node_modules`, `.vibe-journal/node_modules`) | Reinstalled by `npm install` |
| `.git/` | History lives in the parent repository |
| `vault/` | Nested vaults forbidden (recursion) |
| `dist/`, `web/*/dist/`, `public/{cuisine,menu,hawker,transport,oversight}/` | Vite build artefacts — gitignored, regenerated by `npm run build` |
| `*.log`, `.env`, `tmp/`, `.claude/settings.local.json` | Transient / secret / local-only (gitignored) |

`public/app.js`, `public/index.html`, `public/doc/` are kept (not build output).
`geoloc/*.geojson` (LTA/URA/NParks/STB/NLB/HPB open data) IS kept — source input to
`scripts/build-geo-overlays.js`.
