## New

### [HDR] #420 | 06:30 SGT 28-05-28 | v0.61.219 — OTHER-region disable + "Closed now" | 5 files | 1 PR | 1 build |

- **[INTENT]** Make the Cuisine TMA layer toggles honestly reflect data availability outside SG, and remove the misleading "Closed today" prefix on venues that re-open later the same day.

- **[DELTA]**

  **1. `web/cuisine/src/v2/components/MapPanel.jsx`** — adds an `isOther` flag (`region === 'OTHER'`) alongside the existing `isNonSg` (JB / MY-PUT). All 9 overlay toggle items get `disabled: isNonSg || isOther`; **carpark** specifically gets `disabled: isOther` (JB and MY-PUT keep their Places-fallback carpark layer; OTHER's country-level anchors are too coarse for that to be useful). `effectiveLayers` also force-zeroes every layer (including carpark) when `isOther` is true, so the controller stops emitting stale pins after the region flips.

  Cuisine TMA only — `hawker` and `transport` MapPanel.jsx files left untouched per operator scope.

  **2. `open-hours.js — closedTodayString`** — prefix now depends on `nextOpenString`'s return value:

  ```js
  const prefix = next.startsWith('Opens today ') ? 'Closed now' : 'Closed today';
  return `${prefix} · ${next}`;
  ```

  Result:

  | Scenario | Before | After |
  |---|---|---|
  | Mon 09:30, opens 11:30 today | `Closed today · Opens today 11:30 AM` | **`Closed now · Opens today 11:30 AM`** |
  | Mon 23:00, opens Tue 11:00 | `Closed today · Opens tomorrow 11:00 AM` | _unchanged_ |
  | Mon afternoon, opens Thu noon | `Closed today · Opens Thu 12:00 PM` | _unchanged_ |
  | No periods | `Closed` | _unchanged_ |

  **3. `__tests__/open-hours.test.js`** — added a "later today" case asserting the `Closed now` prefix.

  **4. `package.json`** — `0.61.218 → 0.61.219`.

  **5. `doc/.serial-state.yml`** — commit 431→432, build 221→222, journal 419→420; re-anchored 28-05 '26 06:30 SGT.
