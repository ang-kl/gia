## New

### [HDR] #196 | 19:55:00 SGT 16-05-26 | v0.60.228 — Free-text: silence guard on the decline path + transport-query redirect to /transport | 4 files | 1 PR | 0 builds |

- **[INTENT]** Two operator-reported free-text chat issues. (1) When a query is ambiguous / off-topic, the user sometimes gets **no reply at all** — the `bot.on('message')` free-text handler's outer `catch` only `console.error`s, so any throw between the entry gates and `runFreeTextSearch` ends in silence. (2) A transport query ("how to get to Changi", "MRT to Bugis", "bus 174") has no `transport` intent, so it reaches `classifySearchIntent`, comes back `ambiguous`, and gets the food-nudge decline instead of being directed to the existing `/transport` tool. Issue (3) — geo-bounding Gemini to Singapore/Johor — the operator chose not to action it; logged as out-of-scope.

- **[DELTA]**
  - **`freetext-classify.js` — new `looksLikeTransport(text)`** (exported). Deterministic, conservative: trips only on whole-word transport nouns (`mrt`, `lrt`, `train(s)`, `subway`, `metro`, `bus(es)`, `taxi`, `cab`, `checkpoint`, `causeway`) or explicit phrases (`how to get to`, `how do i get`, `directions to`, `route to`, `fastest way to`, `fare(s) to`, …). Header bumped `v0.60.131 → v0.60.228`.
  - **`index.js` — transport gate** in the `bot.on('message')` free-text path, placed BEFORE the `looksLikeQuestion` guard (a "how to get to …" query also reads as a question). On a hit it logs the term (`transport-redirect`) and `safeSend`s the new pointer message, then `return`s.
  - **`index.js` — silence guard.** A new `let committedToFreeText = false;` is declared on the handler (outside the `try`); it flips `true` once the path is past every non-search gate. The outer `catch` now, when `committedToFreeText` is set, sends `bot.error.freetext` so a throw before `runFreeTextSearch` produces a visible error nudge instead of silence. (`runFreeTextSearch` already surfaces its own errors via its internal `catch`.)
  - **`i18n.js` — new key `freetext.transportRedirect`** (en + fr): "🚆 For trains, buses, and getting around Singapore, tap /transport. This chat searches for food and eateries."
  - `package.json` `0.60.226 → 0.60.228` (0.60.227 is held by the in-flight PR #479); this Journal entry (#196); `doc/.serial-state.yml` (`journal 194→196`, `commit 201→203`, `chat_counter 20→22`, `build 10→11`; re-anchored 19:55 SGT — counters sequenced to clear the concurrent v0.60.227 PR #479, per the existing concurrent-PR precedent noted in `.serial-state.yml`).
