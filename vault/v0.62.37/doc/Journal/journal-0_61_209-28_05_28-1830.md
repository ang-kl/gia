### [HDR] #410 | 18:30 SGT 28-05-28 | v0.61.209 — Menu TMA pref sync + WP abbreviation | 4 files | 1 PR | 1 build |

- **[INTENT]**
  1. Make the Menu TMA's OTHER picker open on the user's last
     chosen country (set via /lcountry or the Cuisine TMA's OTHER
     dropdown) instead of always defaulting to 🇲🇾.
  2. Stop showing the full "Wilayah Persekutuan Kuala Lumpur"
     tail at the end of every KL anchor label.

- **[DELTA]**

  **`web/menu/src/components/LocationFieldMenu.jsx`** (~50 lines):
  - **NEW mount-only `useEffect`** fetches `/api/cuisine/country-
    pref` via the `X-Telegram-Init-Data` header. On a non-SG
    response, calls `setCountryPref` (idempotent — short-circuits
    when state already matches). The `'SG'` value is intentionally
    skipped because the SG region pill has its own anchor and the
    OTHER picker's `countryPref` slot is dedicated to non-SG.
    Network failures / 401s fall back silently to
    `DEFAULT_OTHER_COUNTRY`.
  - **NEW `updateCountryPref(code)` helper** wraps the
    `setCountryPref(code)` call with a fire-and-forget
    `fetch('/api/cuisine/country-pref', { method: 'POST', … })`.
    Mirrors the Cuisine TMA's `saveCountryPref` shape.
  - **`<CountryDropdownMenu>` `onChange`** updated to call
    `updateCountryPref` instead of bare `setCountryPref`.

  **`smart-place-label.js`** (~10 lines added inside the state-
  tail handling block):
  ```js
  state = state
    .replace(/^Wilayah\s+Persekutuan\s+Kuala\s+Lumpur$/i, 'WP KL')
    .replace(/^Federal\s+Territory\s+of\s+Kuala\s+Lumpur$/i, 'WP KL')
    .replace(/^Wilayah\s+Persekutuan\s+/i, 'WP ')
    .replace(/^Federal\s+Territory\s+of\s+/i, 'WP ');
  ```
  - KL gets the strongest abbreviation (`WP KL`) because it's the
    most frequent / longest.
  - Putrajaya + Labuan get the partial collapse (`WP Putrajaya`,
    `WP Labuan`) — the territory name is short enough to keep.
  - Both Malay (`Wilayah Persekutuan …`) and English (`Federal
    Territory of …`) forms covered, since Places may return
    either.

  **`__tests__/smart-place-label.test.js`** — 2 existing tests
  updated (Imbi/KL + named-venue cases now expect `"WP KL"`); +2
  NEW tests for Putrajaya + Federal-Territory-English forms. 9
  → 11 tests, all green.

  - **`package.json`** — `0.61.208 → 0.61.209`.
  - **`doc/.serial-state.yml`** — commit 421 → 422, build 211 →
