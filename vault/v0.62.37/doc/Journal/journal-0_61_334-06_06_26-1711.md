The loader (`michelin-data.js`) uses each `entry.id` verbatim (it does NOT re-synthesise ids), validates that every venue's `city` resolves in `CITY_IATA`, and asserts the per-(country,year) manifest once the table is non-empty. The data uses 16 distinct cities; Bangkok / Phuket / Chiang Mai were already mapped, the other 13 are added. One subtlety: the data uses `Ko Samui` (distinct string from the pre-existing `Koh Samui` entry) — both spellings now resolve to `USM`.
