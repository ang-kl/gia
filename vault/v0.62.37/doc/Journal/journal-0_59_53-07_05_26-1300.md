- **[ADVICE]** The cuisine-search rotation arc is a textbook "fix-after-fix landed but the real bug was downstream" case study. v0.59.42 added `lightShuffle`. v0.59.43 added cache-skip. v0.59.46 ungated distance-sort. v0.59.47 made shuffle non-tiered. v0.59.52 routed empty path through searchText. Each fix addressed a real problem; the user reporting "same 3 venues" persisted because the *next* layer downstream was still deterministic. The lesson: when a bug "still persists" after a fix, audit ALL transforms between source and response, not just the one closest to the source.
