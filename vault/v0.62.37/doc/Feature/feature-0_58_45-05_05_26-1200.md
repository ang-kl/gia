## 2. Per-Feature Detail

### F-2 — `/hidden` Hidden Gems (Gemini-grounded)

- **Surface:** `/hidden` chat command
- **Introduced:** v0.58.28 (rewrite from v0.58.22 deterministic + Claude path)
- **Last amended:** v0.58.45 (forbid fabricated Place URLs + scrub criteria-letter leaks)
- **Behaviour:**
  1. Read cached user location. Reverse-geocode to a place name. Reject "Singapore" / catchment / reservoir / park / VivoCity-style names → re-prompt the user to type a place name (pending-meal flow re-fires `/hidden` after geocode).
  2. Send "🔍 Searching hidden gems near {anchor}… please wait." plus up to 10 progress pulses every 12 s.
  3. Build the Gemini prompt from `HIDDEN_GEMS_PROMPT_TEMPLATE` with `{{ANCHOR_NAME}}`, `{{GOOGLE_MAPS_URL}}`, `{{TODAY_SGT}}` substituted.
  4. Call Gemini via `gemini-client.generateGroundedHiddenGems({ anchor, todayIsoSGT })`. Up to 5 attempts (user model × 2 tool variants → fallback chain). Each attempt has a 60 s deadline; overall 240 s.
  5. `thinkingConfig.thinkingBudget: 0` disables the thinking phase for low TTFT (~10 s vs 30+ s).
  6. Post-process: `stripMarkdown` → `stripCriteriaLeak` (removes "meets C3 and C4" prose) → `rewriteFabricatedPlaceUrls` (replaces fake `/maps/place/` URLs with `/maps/search/?api=1&query=…`).
  7. Chunk on numbered-heading boundaries (`/(?=\n\d+\.\s+\S)/`) and send each chunk to chat.
- **Inputs:** cached lat/lng, today's SGT date.
- **Outputs:** up to 5 picks in plain text. Each block: numbered heading "N. NAME - primary type", Address line with walking distance + direction, Opening hours, Google rating + review count, Latest review signal date, Why a gem (one concrete sentence), Order this (signature item), Google Map URL (search format only).
- **Failure modes:**
  - 401 GEMINI_API_KEY unset → diagnostic error to user
  - 503 high demand on every fallback model → "Gemini is overloaded, retry in a minute"
  - Overall 240 s timeout → "/hidden timed out after 4 minutes"
  - Single attempt error → next fallback in chain (or opposite tool name on same model on first 503)
- **Cost:** 1 Gemini grounded call per `/hidden` (with up to 5 fallback attempts on failure). ~$0.005-0.015 per successful call at gemini-2.5-flash pricing. Reverse-geocode adds 1 Google Geocoding call (~$0.005), cached 1 h.
- **Diagnostic codes:** `[/hidden]`, `[gemini-client] attempt N/M`, `[gemini-client] degraded — fell back to <model>`, `[gemini-client] 503 transient on <model>; retrying after 2s`.

### F-12 — Free-text place search (with noise-guard)

- **Surface:** `bot.on('message')` for any non-command, non-keyboard text.
- **Introduced:** v0.57.27 (LLM-free design); v0.58.27 noise-guard added.
- **Behaviour:**
  1. `looksLikePlaceQuery(text)` — synchronous deterministic gate. Min 3 chars, must contain letter or digit, not pure punctuation/emoji, not in a ~30-word chat-noise denylist (`hi`, `ok`, `thanks`, `lol`, …). Returns false → silently skip.
  2. Verbatim text becomes the `searchText` query for `pipeline.discover` (Google Places).
  3. `filterFreeTextResults` applies `passesVenueFilter` (drops chains, multi-tenant buildings) + SG-only gate + distance sort + cap to 5.
  4. `deliverPicks` to chat.
- **Inputs:** user's chat message text + cached location.
- **Outputs:** up to 5 places with name, rating, walking distance, dishes, brief snippet.
- **Failure modes:** No location cached → `setPendingMeal(redis, chatId, "freetext:<text>")` + Share-pin keyboard prompt. After share, location-handler resumes.
- **Cost:** 1 Google Places searchText call. ~$0.005 per query.

### F-13 — Tell-Gia cuisine NL

- **Surface:** Cuisine TMA Tell-Me panel (`/api/cuisine/nl-query`).
- **Introduced:** v0.30+ (Claude-classifier era); v0.58.32 brand-passthrough.
- **Behaviour:**
  1. `tellGia.inferTellGia({ text })` — Claude with strict JSON output extracts `cuisines[]` (slugs from cuisines-vault), `filters` (newlyOpened, openNow, halal, vegetarian, homeBased, prices), `location_override` (geocoded SG location string).
  2. Brand-name passthrough: if user's text is 3-40 chars / ≤ 4 words / has letters, prepend it as the first cuisineQuery before the inferred cuisines. Lets "sushi tei" hit Sushi Tei first, then Japanese fallback.
  3. `pipeline.discover` with combined cuisineQueries → post-filter via `passesVenueFilter` → distance gate → openNow / price / homeBased filters → top 12.
- **Cost:** 1 Claude call (~$0.001) + 1 Google Places call (~$0.005).
- **Rate limit:** 60 LLM calls per chat per epoch hour (Redis INCR + EXPIRE).
