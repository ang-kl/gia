## Note

This fix has the same shape as the v0.62.667 / v0.62.709 stale-count bugs, just in a different
dimension: a piece of infrastructure (`DEFAULT_MODEL`, an env-var-driven constant) existed and was
even documented as general-purpose ("GEMINI_MODEL env var still overrides" — no qualifier), but only
one of five call sites actually used it. The comment was accurate about what `DEFAULT_MODEL` does; it
was silent about which functions read it. Worth noting as a recurring failure mode this session: a
mechanism built once, generalized in a comment, but not actually wired to every place the comment's
phrasing implies.
