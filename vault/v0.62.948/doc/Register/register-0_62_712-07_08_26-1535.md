## Decisions (new this entry)

| # | Decision | Rationale |
| :--- | :--- | :--- |
| D-95 | **When an operator's stated scope conflicts with reality and the decision is delegated, use the complete, correct set — not an arbitrary subset with no principled basis for what to cut.** China's 5 real autonomous regions (vs. the operator's originally-stated "3") were all included once the operator delegated the specific list to this session, rather than picking 3 with no defensible reason to exclude the other 2. | v0.62.712 |
| D-96 | **Before restructuring the order of a data array, grep every direct index-access call site.** `App.jsx`'s boot-anchor fallback reads `CITIES_BY_COUNTRY[cc][0]` as the country's national-capital default. A plan-literal "Popular provinces first, in the stated order" would have silently moved China's `[0]` element from Beijing to Guangzhou. Found by grepping `CITIES_BY_COUNTRY[` across `web/` before writing the new data, not after — fixed by reordering the Popular manifest (Beijing first) rather than touching the `[0]`-dependent code. | v0.62.712 |
| D-97 | **A latent bug that's inert today can still be a real bug — fix it before the change that activates it ships, not after.** `collapsedStates`'s `useState(() => new Set())` initializer never reseeds on a `countryCode` prop change, because `CityDropdown`/`CityDropdownMenu` are not remounted on a country switch. Harmless while only AU carried a `state` field (switching to any other country just rendered flat); would have silently broken China's "non-Popular starts collapsed" seeding the moment this entry's own generalization shipped, on the very next country switch after AU. Fixed proactively with a `useEffect` reseed, found by reasoning about the mechanism's own effect on itself rather than discovered on device after shipping. | v0.62.712 |

the change's effect on itself and on its neighbours, rather than by a test failure or a device report
— the discipline this session has repeatedly needed (see also № 186's note on C-192/C-194/C-196's
shared shape) is to trace a change's full blast radius outward before trusting a locally-obvious
implementation.
