## F-68.1 — Every GIA surface now speaks the user's language to assistive tech

Switching to any of the 8 locales now updates the document's language metadata in all five localized
apps — screen readers switch voice/phonetics, browsers apply correct hyphenation/font rules. Previously
every session was announced as English regardless of the chosen locale.

## F-68.2 — GIA is now keyboard-operable end to end

Every modal, sheet, drawer and popup traps Tab, closes on Escape, and returns focus to where the user
was. Draggable handles, tappable cards, and every "looks like a button" element respond to Enter/Space.
Language menus and location dropdowns walk with arrow keys. A single theme-aware focus ring appears for
keyboard users only — touch users see nothing new.

## F-68.3 — Motion respects the user's system preference everywhere

All seven surfaces now honour reduced-motion: infinite blinks/pulses stop (including the JS-driven clock
colon that CSS could not reach), transitions collapse to instants, and nothing conveys state by motion
alone.

## F-68.4 — Every control has a name; every input has a label; small targets have big hit areas

Icon-only buttons (✕, ⋮, ↻, ⇧⇩, ✍️, ★, chevrons…) are named and localized; switches/toggles announce
their state; search fields are labelled, not placeholder-only. The ~45 smallest tap targets gained
invisible extended hit areas — the compact visible design is pixel-identical.
