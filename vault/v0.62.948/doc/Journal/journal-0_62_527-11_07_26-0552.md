- **[FINDINGS SUMMARY].**
  - **TMA frontends: ~6,900–7,200 duplicated LOC.** Dominated by `web/{cuisine,hawker,transport}/
    src/lib/mapOverlays.js` (near-identical, ~2,400–2,760 lines each, ~70% of the frontend total

    and copy-pasted-but-comment-acknowledged build config (`vite.config.js`, `tailwind.config.js`).
  - **Server-side modules: ~855–1,040 duplicated LOC** (excluding an unsized Places-normalization
    opportunity). Largest single item: **no canonical Gemini client** — `gemini-client.js` exists
    but reimplements its own model-chain factory 5 times internally, and `translate-name.js`,
    `translate-review.js`, `durian-gemini-verifier.js`, plus one `index.js:13985` site, each
    construct their own `GoogleGenerativeAI` + model-chain + retry from scratch instead of using
    it. Also: no shared Redis get/set helper (15+ raw call sites), copy-pasted batch-pipeline
    scaffolding across 4 `scripts/*.mjs` files, near-identical GitHub Actions workflow shape
    across 4 `workflow_dispatch` YAMLs, and internally-repetitive (but correctly single-file)
    overlay-merge logic in `nation-overlay.js`.
  - **Bot slash-commands: mostly already well-centralized.** `resolveLang` (56 call sites),
    `getUserLocation` (~34), `isSgOnlyCommandAllowed` (3), `escapeHtmlForTelegram` (59), and the
    single `callback_query` dispatcher are all correctly shared helpers with no reimplementation
    found. The only real duplication is cosmetic — `require('./user-prefs')` re-declared inline in
    ~56 handlers instead of once at file top (~60 LOC, zero-risk to hoist). A `registerCommand()`
    wrapper is flagged as a **medium-risk** opportunity (divergent per-command regex signatures;
    a careless generic try/catch could mask the exact "silent return" / "error-swallowing catch"
    failure modes `gia-preflight` already watches for).

- **[TWO EXPLICIT "DO NOT BLIND-MERGE" FLAGS — the most important finding in the report].**
  1. `web/hawker/src/tg.js` still uses a `window.history.length > 1` back/close heuristic that at
     least one sibling TMA (transport, per the frontend audit) already removed as buggy
     (`history.length` only ever grows across a session — it doesn't reflect "can I go back").
     A naive shared-`tg.js` extraction would silently reintroduce the bug into TMAs that already
     fixed it.
  2. The same pattern repeats in `BackFab.jsx` — `web/menu/src/components/BackFab.jsx` explicitly
     reverted the identical heuristic (its own comment records it as buggy); `web/hawker/src/
     components/BackFab.jsx` still has it.
  3. (Server-side, same category.) `translate-name.js`'s CJK-detection regex range and
     `local-name.js`'s independently-defined range **already disagree** at the boundary (one
     starts at U+3000, the other at U+3040) — consolidating requires picking a canonical range
     first, not just merging files.
  These are recorded so that IF a future consolidation pass happens, it resolves the divergence
  as a deliberate decision rather than mechanically merging and silently picking a winner.
