### [HDR] #812 | 13:45 SGT 01-07-26 | v0.62.458 — initData on 3 raw fetches | 4 files | PR #(pending) |
- **Root cause:** `/api/cuisine/*` is **auth-gated** (requires the `X-Telegram-Init-Data` header;
  the TMA's `getJson` helper always sends it). Three raw `fetch()` calls I added recently did **not**
  send it → the server returns **401 `{"error":"invalid initData"}`** → `r.ok` false → empty list.
  Confirmed by curling `soleat.net/api/cuisine/dishes` → `invalid initData`.
- **Fix — added `headers: { Accept, 'X-Telegram-Init-Data': initData() || '' }` to all three:**
  1. **`web/cuisine/src/v2/components/CuisineCategoryDrawer.jsx`** — `openDishes` → `/api/cuisine/dishes`
     (the reported "No dishes"). `initData` imported from `../../api/tg.js`.
  2. **`web/clipboard/src/App.jsx`** — `/api/cuisine/catalogue` (v0.62.451; the Sketchbook cuisine
     picker was silently empty) **and** `/api/cuisine/plate` (v0.62.452; Pick-local-classic silently
     fell back to saved-dish chips). `initData` imported from `./lib/tg.js`.
