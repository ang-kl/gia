- **[DELTA]**

  **1. `web/menu/src/components/LocationFieldMenu.jsx`** — state
     init for `expanded`:

     ```js
     // Was (v0.61.254):
     const [expanded, setExpanded] = useState(!currentAnchor);

     // Now (v0.61.256):
     const [expanded, setExpanded] = useState(false);
     useEffect(() => {
       if (currentAnchor && Number.isFinite(currentAnchor.lat)
           && Number.isFinite(currentAnchor.lng)) {
         setExpanded(false);
       } else {
         setExpanded(true);
       }
     }, [currentAnchor?.lat, currentAnchor?.lng]);
     ```

     The v0.61.254 `useState(!currentAnchor)` captured `currentAnchor`
     at FIRST render — async, null at that point — so `expanded`
     locked at `true`. The new useEffect tracks anchor changes and
     keeps `expanded` in sync.

  **2. `web/menu/src/cities.js`** — wholesale sync to the v0.61.242
     `web/cuisine/src/v2/lib/cities.js` audit. Identical content; the

     header. Carries forward all 39 invented-code corrections (DAJ →

     subdistricts → BWN, etc.).

  **3. `web/menu/src/components/LocationFieldMenu.jsx`
