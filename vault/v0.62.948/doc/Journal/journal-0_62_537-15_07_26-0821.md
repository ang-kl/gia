## New

### [HDR] #893 | 08:21 SGT 15-07-26 | v0.62.537 — distance-ring overlay | 6 files | PR #(pending) |

- **[INTENT].** On the two TMAs that show map results, draw concentric dashed distance rings centred on
  the reference point — a **750 m walkable** ring and a **2-MRT-stops** ring — each labelled with a
  mode icon + distance, matching the operator's reference image.

- **[DESIGN].**
  - **Centre differs by TMA** (per the spec): Cuisine = the **set-location** (`searchCenter || userLoc`,
    the blue anchor pin); Hawker = the **chosen hawker** (the tapped pin).
  - **Two rings, one shared line style** (neutral grey `#5f6368`, 2 px). Google's `Circle` strokes
    **solid only**, so — to honour the reference's dashed look — each ring is a **`Polyline` circle**
    (72 segments) with a repeating dash `Symbol` via `icons`. A small north-edge pill label carries
    `🚶 750m` / `🚆 #.#km`.
  - **2-MRT-stops radius is COMPUTED** (operator choice): find the operational station nearest the
    centre, step **±2 positions** along each of its lines' operational order (a line code is
    prefix + sequence number, so index ±2 in the per-line sorted list is exactly two stops and
    non-operational gaps are skipped), and take the **mean** straight-line distance from the centre to
    those 2-stops-away stations. Suppressed when the nearest station is **> 2000 m** away (so Cuisine's
    non-SG regions show only the walk ring), and only drawn when meaningfully larger than the walk ring.
