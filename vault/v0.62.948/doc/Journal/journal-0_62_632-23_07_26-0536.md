## New

### [HDR] v0.62.632 — iPad-mini station cards: uniform collapsible tiles + multi-triangle folds + dense grid + select-pop

- **[INTENT]** Operator (iPad mini, `IMG_1180` portrait LIST + `IMG_1181` landscape CAROUSEL, v0.62.631):
  *"Yeo columns for iPad mini Train TMA … the carousel cards looks weird, why is the share above.
  Standardised all card height same height using cuisine TMA carousel card, use multiple triangle
  (collapse/expand) per card to expand multiple lines in each station card and also within each line if the
  information is too much, I should be able to see four per row in portrait mode of iPad mini and 6 for
  landscape mode. And when station is selected, I thought we have the card effect and zoom in like the iPhone
  standard effect for selecting card in carousel or the pin."*

- **[DECISION]** Started an `AskUserQuestion` (grid-layout / card-default / select-effect); the operator
  **interrupted** it — read as "build, don't ask". Decided sensibly and matched what the screenshots + text
  already specified: keep the map-anchored LIST (IMG_1180) but make it a dense grid; every card a uniform
  collapsible tile; the selected card pops + centres + zooms (Cuisine/iPhone effect).

- **[DELTA]** (2 files)
  - `web/transport/src/components/StationCard.jsx` — new **`collapsible` TILE mode**:
    - The **name strip** + a **one-line summary** (per-line status dot + crowd + distance) are **always**
      shown → every collapsed tile is the **SAME height** (fixes the uneven-height "why is the share above"
      look, because the Directions/Save/Share action row now lives **inside** the folded body).
    - The heavy body (action row, per-line trains, Around-the-station) folds behind a **card-level ▾**.
    - **"Multiple triangle per card"**: each **LINE** sub-card now owns its **own ▾** (was one card-level
      "Train times" toggle driving every line at once) — collapsed shows a today first/last summary, expanded
      shows the full per-direction detail; **"Around the station"** folds behind **its own ▾**.
    - **Select pop**: the active/selected card gets `scale-[1.02]` + `ring-2 ring-tg-accent` + `shadow-xl` +
      `z-10`, and **auto-expands** its body and its lines (a `useEffect` on `active`) — the iPhone/Cuisine
      "selected card blooms" effect.
  - `web/transport/src/App.jsx` —
    - LIST-mode station grid is now **CSS multi-column**: `columns-4` portrait / `columns-6` landscape /
      `columns-1` phone (driven by `useViewport` orientation), each tile `break-inside-avoid` so an expanding
      tile grows only its **own column**, never blowing out a whole row into empty space.
    - `renderStationCard` gains a `collapsible` arg (passed **true** for BOTH the list grid and the bottom
      carousel).
    - `StationCarousel` gains `activeIndex` + a `scrollIntoView({ inline: 'center' })` effect that **centres
      the selected card** — parity with the Cuisine `ResultCarousel`.
    - The map's pan/zoom-to-station on select was already wired (`onStationSelect → focusedStation →
      MrtMapPanel`), so "zoom in on select" comes for free.
