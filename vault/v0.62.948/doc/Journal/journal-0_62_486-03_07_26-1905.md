## New

### [HDR] #840 | 19:05 SGT 03-07-26 | v0.62.486 — empty-array fallback in the open-hours label pass | 2 code files + 3 doc/meta | PR #(pending) |

- **[INTENT].** Make the 🕛 timing row carry real information again: an **open** venue shows
  "Open · Closes HH:MM", a **closed** venue shows "Closed · Opens HH:MM" (its next opening) —
  instead of a bare "Open"/"Closed".

- **Root cause (traced — ONE empty-array falsy trap, present at 3 sites).**
  The open-hours label pass computed its schedule as
  `const periods = v.currentPeriods || v.regularPeriods;`.
  Google's **Places New** frequently returns `currentOpeningHours.periods` as an **empty array
  `[]`** (the real weekly schedule lives in `regularOpeningHours.periods`). An empty array is
  **truthy**, so `[] || regularPeriods` evaluated to `[]` — the fallback never fired. The rich
  helpers in `open-hours.js` (`currentOpenString` / `closedTodayString` / `minutesUntilClose`)
  were then handed an **empty period list**, so they returned their **bare fallback**
  ("Open" / "Closed") with no closing time and no next-opening time. That is exactly the
  KwonSookSoo card: `openNow === true`, `openClosingLabel` empty → `ResultCard.jsx` renders
  `openClosingLabel || tr('card.open')` → bare **"Open"**.
  Upstream the field is normalised to `[]` **or** `null`
  (`Array.isArray(...) ? [...] : null`), so an explicit `.length` guard is both safe and clear.

- **[DELTA] (2 code files — `index.js`, `cuisine-enrich.js`).**
  Replaced the truthy-`||` with a length-guarded fallback at all **3 sites**:
  ```js
  const periods = (Array.isArray(v.currentPeriods) && v.currentPeriods.length)
    ? v.currentPeriods
    : v.regularPeriods;
  ```
  - `cuisine-enrich.js:105` — the **normal** cuisine-search path (most cards).
  - `index.js:10210` — the **Michelin** path (`handleMichelinSearch`).
  - `index.js:18036` — the **near-location** path (`periodsNL`).
  This directly delivers operator ask **#1** (closed → next opening time) and **#3** (Korea bare
  "Open" → now shows closing time). It also fixes the identical latent bug on the normal +
  near-location paths, surfaced by consistency.

- **[VERIFICATION (sandbox)]** `node --check` clean on the edited `index.js` and
  `cuisine-enrich.js`. No web build — **server-only**; `ResultCard.jsx` reads the same
  `openClosingLabel` / `closedTodayLabel` / `closingSoonMinutes` fields (unchanged).
