- **[DELTA]** (Train TMA, 5 files + 2 tests)
  1. **Pasir Ris "missing" — diagnosed: NOT the JSON update.** A pre-existing `mrt-coords.json` quirk: a stop
     that will gain a future interchange has **two** records sharing the same on-line code — the operational
     one and a future "… CRL" shadow (Pasir Ris/EW1 + Pasir Ris CRL/EW1; also Boon Lay, Ang Mo Kio, Hougang,
     Bright Hill). The line listed **two** cards, and in the carousel the operational Pasir Ris sat clipped at
     the far-left edge, so it *looked* gone. `web/transport/src/data/line-paths.js` `lineStationsFull` now
     **de-dupes by the on-line code**, keeping the operational record (it sorts before the future one) → one
     card per stop.
  2. **Carpark details.** `station-context` already returned `carparks` (≤400 m) but the card never rendered
     them. `StationCard.jsx` now shows `context.carparks` (🅿️ name · N m) in "Around the station".
  3. **Open-now + health + hours.** `station-card-utils.js` gains `parseClock()` / `stationOpenNow()` /
     `stationHours()` (after-midnight-aware). The card shows a service-status **health dot** + **"Open now /
     Closed now"** + **"🕑 Operating hours: first – last"** at the top of the body.
  4. **Action row to the BOTTOM** (operator: *"why the share … at the top"* — 3rd time). Directions / Save /
     Share moved below everything, behind a top border. New card order:
     status/open/health → hours → **Around** (exits · bus stops + descriptions · **carparks** · taxis ·
     hawker) → per-line status sub-cards → actions.
  5. **Zoom.** `MrtMapPanel.jsx` `maxZoom` **20 → 23**; a selected station now `setCenter` + `setZoom(18)`
     (was `fitBounds`, which zoomed **out** to frame every amenity pin, landing ~z15-16). Exits / bus stops /
     carparks still render; the user can zoom out to 7 or in to 23.
  - i18n: added `mrt.openNow` / `mrt.closedNow` / `mrt.hours` (en + fr; English fallback for the other
    locales).
