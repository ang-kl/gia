# Journal — v0.62.622 (fix: narrow Telegram-Desktop window mis-classified as a wide tablet — Cuisine "cards look weird")

_(№ 966 — 21-07 '26 15:25 SGT)_

## New

### [HDR] v0.62.622 — guard the tablet classifier on the live width (not just the physical screen)

- **[INTENT]** Operator (Cuisine TMA on **Telegram Desktop**, screenshot): *"the cuisine TMA stuck at
  expand mode but size and card looks weird."* The cards showed the **wide** tablet layout — a big centred
  card with a peeking side card — crammed into a narrow (~500 px) window.

- **[DIAGNOSIS]** A **Playwright probe** of the shared `readViewport()` classifier reproduced it: a
  narrow Telegram-Desktop mini-app window (`w = 500`) on a **touchscreen laptop** reads `pointer: coarse`,
  and the physical monitor's short edge is ≥ 700, so the **`screenMin >= 700` fallback** (added v0.62.612
  for partial-height iPad webviews) promoted it to `deviceClass = 'tablet'` → `isWide = true` → the wide
  layout in a phone-width window. `tdesktop` also fires `requestFullscreen` (the "expand mode").

  ```
  narrow-desktop-touch   {w:500,h:730,coarse:true,screenMin:1080}  cur:'tablet'  → weird
  ipad-mini-partialheight{w:744,h:420,coarse:true,screenMin:744}   cur:'tablet'  (correct — keep)
  ```

- **[DELTA]**
  1. **NEW** `web/_shared/lib/classify-viewport.js` — the pure, React-free classifier
     (`classifyViewport({ w, h, coarse, screenMin })` + `TABLET_MIN_EDGE`), split out so it is
     unit-testable from the repo-root (node) Vitest context (which can't import `react`). The
     screen-short-edge tablet fallback is now **gated on the live width also being ≥ 700** — so a real
     tablet collapsed to partial **height** (its **width** stays wide) still classifies `tablet`, while a
     phone-narrow desktop window stays `mobile`.
  2. `web/_shared/lib/use-viewport.js` — `readViewport()` now measures the four signals and delegates to
     `classifyViewport`; it re-exports `TABLET_MIN_EDGE`. The `react` import stays (for the hook only).
  3. `__tests__/classify-viewport.test.js` — **+8** tests (narrow-desktop-touch → mobile,
     iPad-partial-height → tablet, full tablet, desktop, phones, orientation, empty-input, edge constant).

- **[VERIFICATION (sandbox)]** Playwright probe confirmed the fix flips **narrow-desktop-touch** from
  `tablet` → `mobile` while **iPad mini partial-height** (744 wide) and **iPad landscape** (1080 wide)
