- **[INTENT]** Operator: *"Train TMA google Map default size follows Hawker TMA … have the carousel near
  the footer area similar to how Cuisine TMA behaves in phone aspect ratio … the Train TMA starts with
  carousel like phone/tablet/desktop."* When asked *what fills the carousel on first load*, the operator

  - **LIST (toggle)** — the two-panel view (fixed `h-40vh` fill map + a scrolling station-card grid +
    the `LineStatusPanel` / `LocationCard` secondary panels).

    `🗺 Schematic` map-*type* toggle). The **⇡/⇣** scroll button now scrolls the **list panel**
    (new `listScrollRef` + `onListScroll` + `listAtBottom`) and shows **only in list mode** (the
    carousel has no vertical scroll).
  - i18n: `+layout.list` / `+layout.map` (en/fr).
