# Journal — soleat / Gia4lunch v0.62.718

## New

### [HDR] v0.62.718 — a temporary Cloud Translation route, because the pipeline had no runner

- **[INTENT]** The operator, choosing between two unblocks: *"A"* — build the endpoint.

  v0.62.717 shipped 36 job files holding 1,590 seeded translation items, and every one of
  them sat at `google_translation: null`. The Gemini audit step is the operator's to run in
  their own Gemini Pro account, but it audits a translation that must already exist, and
  nothing could produce one: no CLI on the operator's machine, service-account key creation
  blocked for their account, and this sandbox has no Google credentials at all (checked —
  zero matching env vars). The API key does exist, in Railway. So the call has to originate
  from the server.

  Earlier in the same session the operator asked *"have you complete the translations, i
  thought you want me to do in gemini pro account"* — a fair question about a split this
  session had explained badly. There are two machine steps, not one. Cloud Translation fills
  `google_translation`; Gemini fills `gemini_audit`. Only the second is theirs.

- **[DELTA]**
  - **`i18n-translate.js` (new).** `fillJob()` reads a parsed job object, translates every
    item still missing a `google_translation`, and returns the filled job plus a report
    (`filled` / `chars` / `damaged` / `alreadyFilled`). Items already carrying a translation
    are skipped, so a re-run after a partial failure only pays for what is missing.
  - **Masking, which is the substance of the module.** Machine translation reliably destroys
    two things in these strings: placeholders (`{cap}` → `{上限}`, substitution silently stops
    working) and slash commands (`/hidden` → `/oculto`, the command is dead). Both render as
    fluent text and survive casual review. Cloud Translation's supported escape hatch is
    `format=html` plus `<span translate="no">…</span>`, so every placeholder, slash command,
    backtick span and Telegram HTML tag is wrapped before sending and unwrapped after.
    `protectedRunsIntact()` then verifies each run actually survived, and any item that failed
    gets a warning prepended to its `gemini_audit.notes` so the auditor sees it.
  - **`index.js` — one temporary route**, `GET /api/i18n-translate?lang=&batch=&token=`.
    32 lines. Reads one job file from `scripts/i18n-audit-jobs/`, fills it, returns it as a
    download. To be deleted once the six languages are through.
  - **`api-cost.js`** — `translate: 20 / 1e6` added to `PRICES.maps`. Billed per character,
    so the call site passes a character count, mirroring how `routes` passes an element count
    rather than a request count.
  - **`__tests__/i18n-translate.test.js`** — 20 tests.

- **[GATE — deliberately not `isOwnerChat`]** The route is gated on a dedicated
  `I18N_TRANSLATE_TOKEN` and **fails closed** when that var is unset (503, no translation).
  `isOwnerChat` was the obvious choice and is the wrong one here: it returns `true` for
  everyone when `TELEGRAM_OWNER_CHAT_ID` is missing (Register O-185, still unverified against
  the deployed environment). Fail-open is a defensible default for a read; it is not one for
  a route that spends money on every call.

- **[VERIFICATION (sandbox)]**
  - `node --check` on `index.js`, `i18n-translate.js`, `api-cost.js` — all clean.
  - `npx vitest run` — **170 files / 4,164 tests, 0 failures, 0 errors.**
  - `package.json` 0.62.717 → 0.62.718. No `web/` change, so no TMA build.
  - Route body scanned for bare module references — none.

- **[TWO BUGS THE TESTS CAUGHT, both of which would have shipped]**
  - **`replace()` passes the match offset as the second callback argument when the pattern
    has no capture group.** `mask()` checked `if (captured)`, which is truthy for any non-zero
    offset, so `Top {n} eateries` masked to `Top <span translate="no">4</span> eateries` —
    the placeholder replaced by its own offset. Every protected run in every string would
    have been silently corrupted, and the output would still have looked like well-formed
    HTML. Fixed to `typeof captured === 'string'`.
  - **`recordMapsCall` is async, so a synchronous `try/catch` does not contain its
    rejection.** The hostile-Redis test raised an unhandled promise rejection: the cost
    recording was not actually fail-open, it just looked it. In production a Redis blip during
    translation would have produced an unhandled rejection. Fixed with an explicit
    `Promise.resolve(...).catch(...)`.

  Neither is visible to `node --check`, and the first is invisible to review — the masked
  output is syntactically perfect and semantically destroyed.

- **[TEST]** Set `I18N_TRANSLATE_TOKEN` in Railway to any random string, then open
  `https://soleat.net/api/i18n-translate?lang=zh&batch=1&token=<that>`. Expect a downloaded
  `i18n-audit-zh-01.json` with all 50 `google_translation` fields populated, and a Railway log
  line `[i18n-translate] zh/01 filled=50 chars=… damaged=0`. Spot-check that `{n}`, `/transport`
  and `<b>` survived byte-identical. Wrong token → 403; unset var → 503; `lang=xx` → 400.
  Re-running the same URL should report `filled=0` for an already-filled file.

- **[KNOWN GAPS]**
  - **Never run against the real API.** Every test mocks `axios`. The masking round-trip is
    verified against strings this session wrote, not against what Cloud Translation actually
    returns. `damaged` may be non-zero on first contact.
  - **`$20/M characters` is a list price**, and the free tier (500k chars/month) likely absorbs
    this workload entirely — so `/cost` will show a translate line that probably overstates the
    real bill. Same class of estimate as O-172's Routes figure.
  - **The route reads job files from the deployed image**, so it can only serve what was in the
    repo at build time. Regenerating jobs requires a redeploy.
  - **Nothing deletes this route.** It is scaffolding with no expiry; if it is still in
    `index.js` a month from now that is a small standing liability, not a feature.
  - **The audit step is still entirely unrun** — this unblocks it, it does not perform it.
  - **Copy-all is still broken in production** and unrelated to this change.
  - **`/cost` has still never been read against the deployed build** (O-175).
