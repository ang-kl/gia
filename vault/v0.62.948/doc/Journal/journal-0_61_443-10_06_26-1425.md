## Amendment (v0.61.444 — geographic scoping REDESIGN, supersedes the pure refactor; same PR #959)

After reviewing the four geo filters, the operator chose to **redesign** scoping rather than ship
the faithful copy (so #959 becomes a deliberate behaviour change, smoked before merge).

- **[INTENT]** *"(1) does the 120 km gate apply to SG/JB only? (2) does JB cover Pontian→Desaru?
  (3) OTHER should not be gated — we have per-city boundaries. (4) SG should use a concentric
  circle from the set location."* Findings: (1) the 120 km gate applied to ALL regions; (2) JB's
  ≤60 km intent was clipped by the trailing SG ≤30 km re-filter (far-Johor silently dropped);
  (3) the OTHER country-keyword filter is belt-and-braces only and caused the `cc=VN 59→0 → FLOOR`
  churn; (4) SG used a fixed centroid, not the set location.

- **[DECISIONS — locked]** JB reach = ≤60 km of set location **OR** any "Johor"-addressed venue
  (≤120 km backstop). Cross-border = keep a light text exclusion (JB drops `singapore`; SG drops
  `johor`). Sequencing = **convert #959** into this redesign.

- **[DELTA]**
  - **`cuisine-geo-scope.js`** rewritten — ONE rule per region keyed on **`v.distanceM` from the
    set location**, bounded by the per-city **`anchorCap`** (density-tiered radiusM; falls back to
    `searchRadius`, then SG 30 km / OTHER 40 km). Removed the fixed `SG_CENTROID`/`JB_CENTROID`
    + local haversine. SG = `≤cap AND NOT johor`; JB = `NOT singapore AND (≤60 km OR (johor AND
    ≤120 km))` + the JB→OTHER fallback (now guarded against a throwing `isFarFromJB`); OTHER =
    `≤cap`. Each region floored by the shared `demoteNeverEmpty` (min 1, nearest-first) — subsumes
    the old OTHER stale-pref floor. New `D703s` (SG) log alongside `D703b`/`D703d`.
  - **`index.js`** call site — drop the `resolveCtxCountry` + `countryTextMatch` injects; pass
    `anchorCap` + `searchRadius`. `country-text-match.js` is no longer required by the search path
    (module left in place for any other reference).
  - **`__tests__/cuisine-geo-scope.test.js`** rewritten (15 cases): SG cap + johor-bleed + cap
    precedence; JB ≤60 km / johor-text-rescue-at-90 km / singapore-drop / fallback; OTHER pure
    distance (no keyword) + never-empty floor + 40 km default; defensive (null venues, null
    distance, thrown `isFarFromJB`).
  - **`package.json`** `0.61.443 → 0.61.444`; **`doc/.serial-state.yml`** commit 657 → 658,
    re-anchored. Server-only (no build).

- **[VERIFICATION]** `node --check` clean. Full suite **3238/3238** green.
