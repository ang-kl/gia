## T-68.1 — The audit's biggest finding was distributional, not inventive

Nearly every missing pattern already had a correct implementation somewhere in this repo: the vanilla
`bottom-sheet.js` had the full dialog contract (trap/Escape/restore/:focus-visible/reduced-motion),
hawker had the reduced-motion net, `CountryDropdown` had the arrow-key model, several controls had
`min-h-[44px]`. Phase 1 is therefore mostly PROPAGATION — `use-dialog.js` lifts the vanilla contract
into a hook; the RM block was pasted; the dropdown model was cloned to its siblings. No Material Web
import was needed or added; the "Material discipline" was achievable with what GIA had already written.

## T-68.2 — A keyboard-only focus ring can be global precisely because it is `:focus-visible`

One `:where(...):focus-visible { outline: … !important }` rule per app beats per-site fixes: equal-or-
lower specificity selectors keep it overridable in principle, the `!important` keeps `focus:outline-none`
utilities from silently re-removing it, and because it only fires on keyboard-driven focus it cannot
change what a touch user sees — which is what made a GLOBAL rule safe in a repo this visual. Verified in
the BUILT css of all six apps, because this repo's history (Register D-22/23/24) says a rule that isn't
in the bundle looks exactly like a rule that works.

## T-68.3 — Invisible hit areas need directional discipline

A transparent `::after` extends a control's interactive box without moving a pixel — but in tight
clusters, naive 44px extension makes neighbours steal each other's taps (the extension of the LATER
element wins the overlap). Hence three utilities: `.gia-hit` (isolated controls, ±8px), `.gia-hit-x`
(stacked columns: wide sideways, minimal vertical), `.gia-hit-y` (packed rows: tall, minimal sideways),
plus a small symmetric `.gia-hit-s` for grids packed in both axes where the honest maximum is the 24px
floor, not 44px. The rule generalises: extend into empty space only.

## T-68.4 — Dialog naming: point at the visible heading, never duplicate it

Every dialog that had a name carried it as an `aria-label` string DUPLICATING its visible `<h2>` — two
copies that can (and in an 8-locale app, will) drift. The contract is now `aria-labelledby` → the
heading's id everywhere a visible heading exists; `aria-label` only where there is genuinely no heading.
One source of truth per name.
