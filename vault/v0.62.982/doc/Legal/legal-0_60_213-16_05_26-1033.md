## 3. Jurisdiction & Privacy

- **Jurisdiction:** Singapore. The bot serves SG-specific data sets and complies with Singapore-side terms (LTA / NEA data licences, HDB carpark licence). Default coverage is Singapore; selecting the "Johor Bahru" region extends search across the state of Johor, Malaysia, where data quality relies on Google Places' own coverage.
- **Governance alignment:** the IMDA Model AI Governance Framework is followed. No automated decisions are made about individuals.
- **Personal data:** Telegram chat IDs (numeric), Telegram user IDs (numeric), language code, and geolocation (only when shared by the user). No persistent identity binding beyond Telegram's own user record.
- **Storage:** Redis only (no SQL database). TTLs — location 24 h, pick cache 60 s, share tokens 7 d, recent picks 24 h, place reviews 24 h, vibe-summary 7 d, enrichment 7 d, usage / free-text log 90 d, public holidays 90 d.
- **Aggregate usage:** usage counts (totals, daily-active, popular cuisines / filters / search terms) are kept only as aggregate numbers; per-user entries are one-way sha256 hashes used solely to de-duplicate those counts, removed on `/forgetme` and expiring after 90 days.
- **Retention posture:** no off-platform export; no analytics SDK; no third-party cookies; no advertising IDs; no cross-bot profiling; no sharing with marketers.

## 4. Retention summary (canonical surface: `/privacy`)

Stored data expires automatically; the longest retention window is **90 days** of inactivity (search / selection / usage records, the free-text log, and the hashed aggregate counters). Location is cached 24 h; recent picks 24 h; share tokens 7 d. A manual erasure (`/forgetme`) removes the user's stored data immediately. These windows match the Redis TTLs documented in §3.

## 5. AI provider terms summary

AI-generated content is produced via the Gemini API (Google). Use is subject to Google's Generative AI / Gemini API terms. The bot sends no personal data to the model beyond the user's free-text query and venue/location context needed to answer it. AI output is **best-effort enrichment** — it never gates a core reply, and is server-verified where it makes factual claims (e.g. `/hidden` venues are checked against Google Places before display).
