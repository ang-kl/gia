## Decisions (new this entry)

| # | Decision | Rationale | Where recorded |
| :--- | :--- | :--- | :--- |
| D-22 | **Assert on computed style or built output, never only on a class string.** | All three silent-drop failures this arc were caught by something measuring what the browser did; none by a unit test asserting on source. | Technical T-61.1c |
| D-23 | **A Tailwind colour function must treat `opacityValue` as an arbitrary CSS token, not a number.** | Tailwind passes `'var(--tw-bg-opacity)'` for bare utilities; `Number()` of it is `NaN`. | Technical T-61.1a; `__tests__/tg-colors.test.js` |
| D-24 | **Never interpolate into a Tailwind class string in a scanned file — not even in a comment.** | Disables the whole arbitrary-variant family across every stylesheet, silently. | Technical T-61.1b; `__tests__/viewport-breakpoints.test.js` |
| D-25 | **CSS breakpoints agree with `TABLET_MIN_EDGE`, not Tailwind defaults.** | The iPad mini is 744 px; `md` (768) silently drops it to two columns. | Technical T-61.2a |
| D-26 | **Where a platform emits an event, subscribe to it; timers are a fallback, never the mechanism.** | The auto-expand timers were a guess at what Telegram announces exactly. | Technical T-61.4a |
| D-27 | **Wrap in place rather than relocate**, when retrofitting a large component. | Cuisine's 350-line panel became a drawer with every ref and handler intact and the alternate path byte-identical. | Technical T-61.6 |
