## 2. Lessons that changed the method (from this arc)

| # | Lesson | Evidence |
|---|---|---|
| L-1 | **A write chained behind a step that can fail silently produces a commit that looks complete.** `read … && cat >>` skipped two journal entries; found only by checking records against `origin/main` | `[AMD-255]` correction |
| L-2 | **A builder that rewrites more than its input changed can delete enrichment.** The overlay builder would drop opening hours from 1,059 clinics | `technical-0_62_948` H-1 |
| L-3 | **Upstream ids are not content.** LTA and NParks renumber `OBJECTID` on every publish; diff by natural key | `technical-0_62_948` §4 |
| L-4 | **A blank output is not a verdict.** Mutation results are read from exit codes, not from the last line of output | `[AMD-256]` |
| L-5 | **Never put a real identifier in a test fixture**; use an obviously synthetic one and run the guard after `git add` | `legal-0_62_948` §3 |
