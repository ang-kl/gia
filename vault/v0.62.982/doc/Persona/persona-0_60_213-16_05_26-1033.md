## 0. Profile in brief

The Human Lead is the **sole operator, product owner, and director** of Soleat / Gia4lunch — a production Telegram bot + five Mini Apps serving Singapore F&B discovery, transport, and logistics. Across ~190 numbered versions and ~460 pull requests the operator has carried the project end-to-end: domain dataset curation, product and UX direction, architecture decisions, security hardening, a self-designed eight-folder documentation contract, bilingual (EN/FR) content, and release operations on Railway — working through AI-assisted development as the directing intelligence.

The profile below is evidence-oriented: every rating is anchored to a verifiable artifact in the repository (a Journal entry, a Register decision, an operator-quoted instruction, a shipped PR).
