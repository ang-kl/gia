## §H-A · Distance-ring overlay (Hawker + Cuisine TMA maps)

**What the user sees.** When map results are shown, dashed concentric distance rings are drawn around a
reference point, each with a small edge pill (mode icon + distance). The centre is the **chosen hawker**
(Hawker TMA — drawn on a hawker pin tap, cleared on tap-out) or the **set-location** (Cuisine TMA — drawn
while results are on the map, centred on the search anchor).

**Rings.**
- **Ring 1 — 🚶 750 m walk** — always, both in and outside Singapore.
- **In Singapore:**
  - Ring 2 — 🚆 **computed 2-MRT-stops**: nearest operational station to the centre, stepped ±2 along each
    line's operational order (line code = prefix + sequence, so index ±2 = two stops; gaps skipped), mean
    straight-line distance from the centre. Labelled `#.#km (2 stops)`. Suppressed when the centre is
    > 2 km from any station.
  - Ring 3 — 🚆 **capped "reach"** (`#.#km (~N stops)`): the farthest result, capped at ~6 stops, drawn only
    when a result falls beyond ring 2.
- **Outside Singapore** (no MRT network; the bundled station list is SG-only):
  - Ring 2 — a plain **2 km** ring (no glyph).
  - Ring 3 — a plain ring at the **farthest result** (no glyph), drawn only when result(s) fall outside the
    2 km ring; the results bound it. On a new search the map auto-frames to the ring's extent so all three
    rings are visible.
- **Big-ring readability:** a ring wider than **8 km** carries its distance label on all four sides
  (N/E/S/W), not just north.
- **Units:** labels are km by default, **miles** (`#.#mi` / `###ft`) for road-distance imperial countries
  (US, UK, Myanmar, Liberia), keyed to the **searched** country (`state.countryPref`), not the device locale.

## §H-B · Cuisine result-pin colour-coding + card fix

- **Pin colours** (Cuisine map result droplets) — closed → **grey**, closing within the hour → **pink**,
  Michelin star/Bib → **red** (Michelin macaron red), open → **green**. Precedence grey > pink > red > green
  (availability/urgency before prestige); the card still carries the word ("Closed"/"Closing in N min") + the
  ✳️ Michelin row, so colour is a scan aid, never the sole signal.
- **Result-card name fix** — the focused horizontal card's name row had rendered white-on-white over its
  forced-white background (a latent bug since v0.62.285); restored so every centered card shows its name.
