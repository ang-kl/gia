- **[KNOWN GAPS]**
  - **Asset format inconsistency** — `johor-flag.png` /
    `soleat-icon.png` are PNGs; the cuisine TMA's only JPEG is
    now `durian.jpeg`. Vite handles either format transparently
    (just static-copies), and modern browsers render both
    indistinguishably; the format is just whichever the operator
    sourced. If a future asset cleanup wants to standardise on
    one format (PNG for transparency support, or JPEG for
    photographic textures), it's a per-file conversion + map
    update, not a system-level change.
  - **JPEG transparency** — JPEGs don't support an alpha
    channel, so the durian artwork's background (if not white)
    will render against the chip's `bg-tg-card`. The operator's
    upload is a photograph-style flat-background JPEG; no
    transparency expected. If the chip looks like it has a
    square background bleed, swapping to a PNG with alpha would
    address it — easy follow-up.
  - **`data/IMG_2180.jpeg`** removed from the index; the blob
    is preserved in git history at the operator's upload
    commit `fc8822d`. Same pattern as v0.61.142's
    `data/IMG_2177.png` cleanup.
