# Journal — soleat v0.61.20 → v0.61.21 (amenity pins appear on every station tap)

> Operator: tapping a station on the Train TMA and the Cuisine TMA does not show the
> surrounding amenity pins (exits / bus / taxi / carpark). Root cause: three divergent
> amenity-rendering paths; this PR unifies them on the proven shared helper.

## New

### [HDR] #223 | 13:10:00 SGT 18-05-26 | v0.61.21 — unify amenity rendering on attachAmenityPins | ~4 kb | 4 files | 1 PR | 1 build |

- **[INTENT]** Operator: *"in the Train TMA or Cuisine TMA, tap on the station doesn't show
  the surroundings amenities (carpark, station exit, bus stop, taxi/pickup)"* — the Hawker
  centre tap works, the two station-tap paths do not.

- **[DELTA]** Before this PR there were three separate amenity-rendering implementations:
  `MrtMapPanel.renderAmenityPins` (Transport — its own code, pins had no click handlers),
  `mapOverlays.drawAmenities` (Cuisine/Hawker train-overlay station-detail — gated each pin
  on `layers.train.visible` via `m.map = show ? map : null`), and the shared
  `attachAmenityPins` (added v0.61.20, used by the Hawker/Cuisine venue taps, attaches
  markers to the map directly). The last is the path that demonstrably works; this PR
  routes the other two through it.
  - **`web/{cuisine,hawker,transport}/src/.../lib/mapOverlays.js`** (byte-identical ×3) —
    `attachAmenityPins` gains an `includeStation` option (default `true`); station-detail
    callers pass `false` so the `🚉` pill doesn't overlap the tapped station's own centre
    marker. `drawAmenities` rewritten to delegate to `attachAmenityPins({ …, includeStation:
    false })`, storing the returned markers in `detailAmenities`; the train-layer
    visibility honouring is kept (`applyVisibility('train')` still re-syncs them).
  - **`web/transport/src/components/MrtMapPanel.jsx`** — `renderAmenityPins`, the local
    `amenityPinNode`, and the `AMENITY_*` colour constants removed; `renderAmenityPins` now
    calls `attachAmenityPins` (clickable popups for the first time on the Transport map).
    New `amenityMarkersRef` keeps the pins separate from the station dots and is torn down
    with them in `renderPins`.
