## New

### [HDR] #197 | 21:00:00 SGT 16-05-26 | v0.60.229 — Cuisine/Hawker map pins → 18px dots + curated directory-building filter | 5 files | 1 PR | 2 builds |

- **[INTENT]** Three operator asks. (1) The Cuisine TMA map used Google's `PinElement` teardrops; the operator wants plain **18px round dots**, with Michelin/Pet/dessert venues showing the icon **inside** the circle. (2) The Hawker TMA pins (just set to 25px in PR #479) should drop to **18px** to match. (3) Multi-eatery "directory" buildings — food halls, food courts, markets that Google Maps lists with many tenants inside ("Old Airport Road Food Centre", "Lau Pa Sat", "Food Opera") — must never be returned as a venue, across the Cuisine TMA, free-text chat search, and `/s`.

- **[DELTA]**
  - **`web/cuisine/src/v2/components/MapPanel.jsx`** — new `cuisinePinNode(glyph, focused)` builds an 18px round `<div>` dot (modeled on the Hawker TMA's `hawkerPinNode`): green normal / orange + 24px focused (preserving the v0.60.224 focus treatment); glyph venues get a white circle with the emoji centred **inside**. The venue-loop `new PinElement(...)` is replaced by `cuisinePinNode(...)`. `PinElement` is still imported — the user-anchor "you are here" pin still uses it.
  - **`web/hawker/src/components/HawkerMapPanel.jsx`** — `hawkerPinNode` circle `25px → 18px`. The "NEW" badge is `position:absolute` off the marker's top edge, so it re-anchors unchanged at any pin size.
  - **`data/directory-buildings.json`** — NEW curated list of distinctive multi-tenant food-hall / food-court / market names the start-anchored `BUILDING_NAME_PATTERNS` regex misses (food-court chain brands: Food Opera, Food Republic, Food Junction, Food Fare, Koufu, Kopitiam, Rasapura Masters, Malaysian Food Street; plus Lau Pa Sat / Telok Ayer Market / Old Airport Road Food Centre). Kept deliberately conservative — distinctive names only — so a real stall is never dropped.
  - **`venue-filters.js`** — loads `data/directory-buildings.json` (defensive `require`, mirrors the free-text-search.js idiom) into a normalized `Set`; new `isDirectoryBuilding(cleaned)` matches a name exactly or as a start-anchored building name followed by a location qualifier ("Food Opera @ ION Orchard"); `isBuildingItself` calls it before the regex pass. Header `v0.58.31 → v0.60.229`.
  - **`index.js` — `searchVenuesByDish` (the `/s` technique/dish fan-out)** now applies `passesVenueFilter` after the result `.map(...)` and logs how many directory/non-food results were dropped. This closes a long-standing gap: the `/s` fan-out never filtered, so directory buildings leaked into `/s` while the Cuisine TMA (`/api/cuisine/search`) and free-text (`filterFreeTextResults`) already filtered.
  - **`__tests__/venue-filters.test.js`** — new `describe('curated directory-buildings list')`: food-court chains rejected, location-qualifier variants rejected, case-insensitive + ", Singapore <postcode>" tolerant, specific stalls still kept, `passesVenueFilter` end-to-end.
  - `package.json` `0.60.228 → 0.60.229`; this Journal entry (#197); `doc/.serial-state.yml` (`journal 196→197`, `commit 203→204`, `chat_counter 22→23`, `build 11→12`; re-anchored 21:00 SGT).
