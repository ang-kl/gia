# Journal — soleat v0.61.318 (/hidden: tighten newness to 3 months, rating floor 3.9, Places review-time refute)

> Operator (05-06 '26, while reviewing how `/hidden` decides a "hidden gem"):
> - *"3 months or less are new"* — the C1 newness window was 4 months; tighten to 3.
> - *"rating be 3.9 and above"* — the rating floor was 4.0; lower to 3.9.
> - Plus the sketch the operator approved: use the one real date Google exposes — Places
>   `reviews[].publishTime` — to *refute* false "newly opened" claims that Gemini infers from
>   the open web (there is no opening-date field in any Places API call).
>
> Context: `/hidden`'s C1 ("opened in the last 4 months") is a Gemini web-grounded guess, the
> weakest signal in the gate. A venue with 300+ Google reviews can only survive the
> "300+ reviews UNLESS newly opened" exclusion via that C1 exception — so a hallucinated "new"
> claim lets a widely-known place through. A Google review can only be posted *after* a venue
> opens, so the OLDEST review Places returns is a sound one-directional check: it can refute
> newness (old review ⇒ not new) but cannot confirm it (Places returns ≤5 reviews).
>
