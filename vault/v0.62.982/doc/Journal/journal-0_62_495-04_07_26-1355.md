### [HDR] #849 | 13:55 SGT 04-07-26 | v0.62.495 — horizontal card meta separator glued to the distance unit | 1 web file + 3 doc/meta | PR #(pending) |

- **[INTENT].** On the **horizontal** ResultCard the meta line is allowed to wrap over two lines
  (`line-clamp-2`). The distance unit `distMeta` is built NON-BREAKING (all internal spaces are
  ` `, since v0.62.216) so `📍 ~1.3 km away` moves to line 2 as one unit. Side effect: the plain
  `" · "` join BETWEEN the clock/reopen text and that non-breaking unit became the **only** breakable
  point, so when the pin wrapped, a lone **`·`** was stranded at the end of line 1 (visible in IMG_2685).

- **[DELTA] (1 code file).**
  - `web/cuisine/src/v2/components/ResultCard.jsx` — replaced the horizontal meta build with a
    `clockSeg`-based join: `` `${clockSeg} · ${distMeta}` `` — a **breakable** space BEFORE the
    `·` and a **non-breaking** space AFTER it. The whole `"· 📍 …away"` chunk now travels to line 2
    together; no bare separator can end a line. The **vertical** card is unchanged — it stays a single
    truncated line `[rating, price, open, distMeta].filter(Boolean).join(' · ')`.

  `react` + `./tg.js` resolve-warnings — not syntax errors). No behavioural change to the vertical path.
