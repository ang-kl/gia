- **[INTENT]** Per the locked plan: PR #3 is the "Clipboard TMA bundle" — new

- **[DELTA]**

  - **NEW `web/clipboard/` Vite app** (12 files + 13 component/lib modules):
    - `package.json` (own version 0.62.330; deps mirror cuisine: React 18 + Vite 5 +
      Tailwind 3); `vite.config.js` (base `/app/clipboard/`, output `public/clipboard`,
      reads version from root package.json same as cuisine); `index.html`;
      `postcss.config.js`; `tailwind.config.js` (Telegram theme tokens + 4 slot
      super-group accents `g-morning/midday/evening/night`); `src/styles.css` (sheet
      scrim + drag-ghost + slot left-border accents).
    - `src/main.jsx` — boot guard for non-Telegram opens (mirrors cuisine TMA's
      `hasInitData()`); renders `App`.
    - `src/App.jsx` — hash router with 3 top-level routes (Root / CabinetView /
      SharedView). Threads the `useDrag` hook through `CatchAllStrip`'s cards into
      every drop target so a long-press drag lands cards in cabinets or drawers via
      the `placeCard` endpoint. Hosts all 4 sheets (CreateCabinet / AddDrawer /
      AmendCard / ShareDrawer) above whichever route is active.
    - `src/lib/tg.js` — slim copy of the cuisine TMA's tg.js (initData,
      applyTelegramTheme, getLanguage, openTelegramLink, haptic). Keeping it small
      avoids dragging the cuisine TMA's bootstrap edge cases into a brand-new bundle.
    - `src/lib/api.js` — 16 endpoint wrappers around `/api/clipboard/*`. Stuffs
      `initData` inline on every authed call (matches the cuisine TMA's `postJson`
      pattern) so the server gate verifies via either header or body.
    - `src/lib/state.js` — useReducer-based store. Hash-driven routing. Loads
      `catchAllCards` from `/state` directly (PR #2's `/state` was extended in this
      same PR — additive — to return up to 50 cards in full alongside the count).
    - `src/lib/i18n.js` — **32 keys × 5 langs = 160 strings** (en/fr/id/ru/de).
      Covers: chrome (back/close/save/cancel/delete/loading), root (catchAll +
      cabinets + new + cap), cabinet (create/fields/drawers/empty/deleteConfirm),
      drawer (add/segment/dayTag/location/capReached/empty/deleteConfirm), card
      (amend/name/note/favourite/moveTo), share + fork, segment display labels × 11.
      Nullish fallback `entry[l] ?? entry.en ?? key` per the v0.62.280 cuisine fix.
    - `src/lib/segments.js` — 11-segment catalog (`dayBreak / breakfast / brunch /
      lunch / lateLunch / teaBreak / earlyDinner / dinner / supper / nightSnack /
      wholeDay`) with emoji + English time-range + super-group classification
      (morning/midday/evening/night drives the left-border accent colour).
    - `src/lib/dnd.js` — pointer-event drag with a **280ms long-press threshold**.
      Renders a floating `.drag-ghost` element tracking the pointer; highlights
      drop-targets (`[data-clipboard-drop]` attribute) via `elementFromPoint` +
      `.dropzone` class; fires haptic feedback on drag-start (light) + drop
      (success). No DnD library — keeps the bundle flat.
    - `src/components/`:
      - `VenueCard.jsx` — read-only card; accepts dragProps from the dnd hook
      - `CatchAllStrip.jsx` — horizontal scroll of catch-all cards
      - `CabinetGrid.jsx` — root cabinets grid + "+ New cabinet" tile
      - `CabinetCard.jsx` — one grid tile; doubles as a drop target
      - `CabinetView.jsx` — header + drawer list + "+ Add drawer" + ⋯ menu
      - `DrawerRow.jsx` — collapsible drawer with cards + drop-target attribute
      - `SharedView.jsx` — read-only public view + Fork CTA
      - `sheets.jsx` — 5 bottom sheets co-located: CreateCabinetSheet,
        AddDrawerSheet (11-segment picker grid), AmendCardSheet (name/note/
        favourite + Move-to picker + Delete), ShareDrawerSheet (URL + copy +
        share-to-Telegram), ForkSheet (cabinet picker)

  - **SURGICAL EXTENSION of `clipboard-routes.js`** (PR #2 territory, additive only,
    no breaking change): `/state` now returns `catchAllCards` (up to 50) alongside

  - **CUISINE TMA — bordered Sketchbook / Clipboard panel** (`web/cuisine/src/v2/

      `Telegram.WebApp.openTelegramLink('https://t.me/<bot>/clipboard?startapp=root')`.
