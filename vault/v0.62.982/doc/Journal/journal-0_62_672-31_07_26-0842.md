## New

### [HDR] v0.62.672 — building the ruler; nothing measured with it yet

- **[INTENT]** Operator, after the Tier 0 recap: **"Okay. tier 1"** — proceed with defining the shared
  shape/elevation/motion/spacing vocabulary from the M3 audit, on the understanding (per D-46, this arc)
  that Tier 1 is zero-visible-change by construction since nothing consumes it yet, distinct from Tier 2
  (applying it to real controls), which still requires a per-item decision round.

- **[DELTA]** (single commit `5cb06d0`)
  - New `web/_shared/lib/m3-tokens.js`: `m3Radius` (the M3 shape scale — 0/4/8/12/16/28/9999px, named
    `none/xs/sm/md/lg/xl/full`), `m3Duration` (short1-4/medium1-4/long1-4, 50-600ms — the extra-long tier
    was dropped as irrelevant to this UI's transition needs), `m3Easing` (standard + its accelerate/
    decelerate variants + emphasized-accelerate/decelerate; `emphasized` itself omitted since the
    material-web source resolves it to the identical curve as `standard`), `m3StateLayer` (hover/focus/
    pressed/dragged opacities), `m3TouchTarget` (48px, for a future decision on raising Phase 1's 44px
    floor). All values cited to `tokens/versions/v0_192/_md-sys-*.scss` in the cloned
    `material-components/material-web` source (tag v2.5.0) — not recalled from general M3 knowledge.
  - `m3Radius` spread additively into all six apps' `tailwind.config.js` under `theme.extend.borderRadius`,
    using `m3-`-prefixed keys specifically so they cannot collide with or reinterpret any of Tailwind's
    own `rounded-{sm,md,lg,xl,2xl,3xl,full}` utilities already in use across the suite. Clipboard's
    config (which has no `tg-colors.js` import, since its palette is fixed per D-37) imports only
    `m3Radius` — its colours are untouched.
  - **Deliberately NOT included**: any elevation-tier naming (deferred to Tier 2, since it requires
    deciding whether cuisine's glass system and hawker/transport/menu's skeuomorphic system merge or
    stay named separately — a design call, not vocabulary) and any spacing/padding role naming (deferred
    for the same reason — naming "chip padding" requires picking WHICH of the ~11 existing ad-hoc combos
    wins, which is Tier 2's job).
