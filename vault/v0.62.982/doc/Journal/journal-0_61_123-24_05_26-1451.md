## New

### [HDR] #324 | 14:51 SGT 24-05-26 | v0.61.123 — Menu TMA location anchor field + disable SG-only tiles on MY anchor | ~12 kb | 7 files | 1 PR | 1 build |

- **[INTENT]** Add the location-anchor picker to the Menu TMA hub
  below the PLAN section heading (above `TrainPanel`). Two input
  modes: a grouped dropdown of 17 curated precincts (10 STB + 5 SG
  region buckets + 2 Malaysia anchors) and a free-text input that
  server-geocodes. When the resolved anchor's region is `'JB'` or
  `'MY-PUT'`, SG-only tiles (Hawker, Incidents, Bus stops, Weather)
  and the TrainPanel flip to a disabled state with the
  `Singapore only — switch anchor to use this.` tooltip.

- **[DELTA]**
  - **`precincts.js`** — adds 5 SG region buckets (CBD, Western,
    Eastern, North, Central) with operator-curated centroids:
    - Singapore CBD (1.2845, 103.8519) — Raffles Place / Tanjong Pagar
    - Singapore Western (1.3329, 103.7426) — Jurong East MRT
    - Singapore Eastern (1.3236, 103.9273) — Bedok MRT
    - Singapore North (1.4304, 103.8354) — Yishun MRT
    - Singapore Central (1.3503, 103.8485) — Bishan / Toa Payoh axis
    New `getSgRegionBuckets()` export + new `getMenuDropdown()`
    export (10 STB + 5 region + 2 MY = 17 entries) for the Menu TMA.
    Chat `getAll()` stays at 12 entries (no change to /location
    keyboard). `getById()` searches the full menu dropdown so
    server endpoints accept the new ids.
  - **`+ web/menu/src/components/LocationFieldMenu.jsx`** (~150 lines,
    new component). Free-text input + Set button (POSTs `{ text }`
    to `/api/menu/set-location`, server geocodes) + grouped `<select>`
    with three optgroups (Singapore — STB precincts /
    Singapore — region / Malaysia, the MY entries showing
    `(30 km)` / `(15 km)` caps). Submit uses `keepalive: true` so
    the request survives the WebApp closing. Anchor-summary line at
    top reads `Anchored at <label>.` or `Anchored at <label> · 15 km cap.`
    when present.
  - **`web/menu/src/components/Tile.jsx`** — optional `disabled` +
    `disabledTooltip` props. Disabled state: opacity 0.4, cursor
    not-allowed, click surfaces the tooltip via Telegram WebApp's
    native `showAlert` (fallback `window.alert`) instead of running
    the tile's `onClick`. Visually-only change; no impact on
    existing call sites (props default to false/'').
  - **`web/menu/src/App.jsx`**
    - Imports `LocationFieldMenu`, fetches the cached anchor at mount
      via `/api/cuisine/user-location` (existing initData-gated
      endpoint).
    - Renders `LocationFieldMenu` inside the PLAN section ABOVE
      `TrainPanel`, with `TrainPanel` wrapped in an opacity overlay
      (`opacity: 0.4, pointerEvents: 'none'`) + the disabled
      tooltip via `title` when `isMy`.
    - New `SG_ONLY_TILES = new Set(['hawker', 'incidents', 'busnearest', 'weather'])`
      — passed to `Tile` as `disabled={isMy && SG_ONLY_TILES.has(tile.id)}`.
    - `isMy = anchor && (anchor.region === 'JB' || anchor.region === 'MY-PUT')`.
  - **`index.js`** — two new Express endpoints:
    - `GET /api/menu/precincts` — public; returns the 17-entry
      dropdown (id/label/region/country/lat/lng/source/radiusCapM).
      In-memory cache after first call.
    - `POST /api/menu/set-location` — initData-gated; accepts
      `{ precinctId }` (resolves via `precincts.getById`, stamps
      full anchor metadata) or `{ text }` (geocodes via
      `geocodeQuery`, stamps label only). Reuses v0.61.122
      `setUserLocation(opts)`. Returns the resolved anchor.
  - **`web/menu/src/i18n.js`** — 12 new keys en+fr:
    `location.fieldLabel`, `location.currentNone`,
    `location.currentSet`, `location.capNote`,
    `location.dropdownLabel`, `location.dropdownGroupSg`,
    `location.dropdownGroupSgReg`, `location.dropdownGroupMy`,
    `location.searchPlaceholder`, `location.searchSubmit`,
    `location.setOk`, `location.setErr`, `tile.disabledMy`.
  - **`package.json`** — `0.61.122 → 0.61.123` (PATCH).
