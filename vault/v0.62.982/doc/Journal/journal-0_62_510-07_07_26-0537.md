- **[INTENT].** Operator: *"1. do for the footer"* — apply a liquid-glass treatment to the
  Cuisine TMA's bottom command dock. Result cards stay solid (standing rule: frosted cards read
  as broken). Header deferred to a later pass.

- **[WHY CSS, NOT liquidGL].** The linked lib does true refraction via **html2canvas** snapshot →
  WebGL shader. The footer band is `fixed inset-x-0 bottom-0` **over the live map** (`MapPanel`).
  html2canvas **cannot** capture a live Leaflet/tile map or moving React content, so liquidGL
  would refract a **blank/stale** image — and it's heavy for a Telegram mobile webview. CSS
  `backdrop-filter` is **liquidGL's own documented fallback**; it refracts the live map natively,
  GPU-composited, zero new deps. The app already standardises glass on `.liquid-glass`.
