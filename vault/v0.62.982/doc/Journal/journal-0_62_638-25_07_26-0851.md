- **[ROOT CAUSE — headers]** The fixed-shell headers read `--tg-content-safe-area-inset-top` for their top
  padding, but **only** `web/hawker/src/tg.js` ever **set** that var — Transport / Cuisine / Menu / Oversight
  had **zero** safe-area wiring, so they fell back to `env(safe-area-inset-top)` ≈ 0 on an iPad (no notch) and
  the header stuck to y=0 **under** Telegram's floating Back / ⌄ / ··· buttons. And even Hawker's *reported*
  content-safe-area top was smaller than the visible floating-button band, so its header overlapped too.

- **[DELTA — headers, 6 files]**
  - **NEW** `web/_shared/lib/safe-area.js` `wireSafeAreaInsets(w)` — sets all four
    `--tg-content-safe-area-inset-*` from the Bot API 8.0 `safeAreaInset` + `contentSafeAreaInset`, **and
    enforces a 64 px MINIMUM top clearance while `w.isFullscreen`** (0 otherwise — phones aren't fullscreen,
    so no floating buttons and no wasted gap). Re-runs on `safeAreaChanged` / `contentSafeAreaChanged` /
    `fullscreenChanged` / `viewportChanged`; toggles a `tg-fullscreen` class on `<html>`.
  - Wired into **all 5** apps' `tg.js`: Transport / Cuisine (`api/tg.js`) / Menu / Oversight **add** the
    import + `safe('safe-area', () => wireSafeAreaInsets(w))`; Hawker's inline v0.62.591 block was
    **refactored** to the shared helper (gaining the min-clearance). Because every header padding already
    reads that var, the 64 px min flows through with **no per-layout edits**.

- **[DELTA — Train carousel = Hawker parity, `web/transport/src/App.jsx`]** The `StationCarousel` card wrapper
  now uses Hawker's **exact** dimensions — `basis-[82%] md:basis-[44%] min-[1180px]:basis-[30%]` +
  `max-h-[46vh]` + `rounded-lg` (was `basis-[86%]`/`sm:48%`/`32%` + `max-h-[44vh]` + `rounded-xl`) — and the
  carousel now renders **full** cards (`renderStationCard(…, compact=true, collapsible=FALSE)`) instead of the
  collapsed strip tile, so a Train card carries the same content weight as a Hawker centre card. The
  collapsible 4/6-per-row **tile** mode stays **only** in the LIST/grid view.
