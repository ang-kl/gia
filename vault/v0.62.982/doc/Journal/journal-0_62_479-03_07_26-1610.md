### [HDR] #833 | 16:10 SGT 03-07-26 | v0.62.479 — back FAB lifted into the App FAB cluster; English emoji-only, non-English small localised word | 4 files | PR #(pending) |
- **[INTENT].** Fix the v0.62.478 regression (the 🔙 pill painted **behind** the 🔍 Search
  FAB and overlapped it) and flip the label rule per the operator's clarification.
- **Root cause (two bugs).**
  1. **Stacking-context trap.** v0.62.478 rendered the FAB *inside* `CuisineCategoryDrawer`,
     whose root is `fixed inset-0 z-30` — a self-contained stacking context. The child's
     `z-[60]` only elevates *within* that context; the App bottom FAB cluster (also z-30, but
     painted **later** in the DOM) covered it. z-index cannot cross stacking contexts.
  2. **Wrong position anchor.** The hardcoded `bottom: calc(…)` assumed the Search FAB was
     anchored to the viewport bottom. It isn't — it floats *above* a variable-height band
     (the "hide results · list · top · end" row + version tag), so the FAB landed too low,
     right on top of 🔍.
- **[DELTA] — lift the FAB into the App FAB cluster (4 files).**
  - `web/cuisine/src/v2/components/CuisineCategoryDrawer.jsx` — removed the in-drawer FAB.
    Now reports `{ drillDepth (1=sub-cuisine drawer, 2=dish list, 3=dish detail), topmost
    goBack }` **up** via a new `onDrillChange` prop (effect keyed on depth; a `goBackRef`
    keeps App calling the latest handler). The reporting hook sits **before** the
    `if (!category) return null` early-return (Rules of Hooks).
  - `web/cuisine/src/v2/components/CuisineDrawer.jsx` — accepts + forwards `onDrillChange`.
  - `web/cuisine/src/v2/App.jsx` — holds `drillDepth` + `drillBackRef` (with a `useCallback`
    `onDrillChange`), passes it to `CuisineDrawer`, and renders the 🔙 FAB as the **top row**
    of the bottom FAB `flex-col`. Being the first flex child, it sits one row **above** 🔍 by
    construction — correct stacking, correct position, no fixed-offset math.
  - **Label rule (operator clarification).** English = **emoji-only** (the 🔙 glyph already
    renders "BACK"); every other locale appends the localised word in a **small hint font**
    (`text-[10px]`): Retour / Kembali / Назад / Zurück / 返回 / 戻る / Atrás. `aria-label`
    always carries the localised word so screen readers announce it in all 8 locales.
- **[VERIFICATION (sandbox)]** `esbuild --format=esm` parse clean on all three JSX files
  (exit 0). The FAB now shares the App cluster's stacking context and flex-col order.
