### [HDR] v0.62.641 — why Cuisine's card fits and Train's didn't, and the four fixes that close the gap

- **[SELF-AUDIT — why Cuisine fits and Train didn't]** The Cuisine `ResultCard` is a **flat text card**: one
  line per fact at `text-[12px]`, and its only affordance is a small inline *"details, review & links"* text
  toggle. The Train `StationCard` instead carried heavy **chrome**:
  1. three **36 px circular** action buttons, **each with a caption underneath** (the v0.62.621 Google-Maps
     place-details styling) — a whole band of height for three actions;
  2. nested bordered per-line sub-cards; and
  3. the real killer, visible in `IMG_1206`: the v0.62.640 always-visible summary **duplicated** the expanded
     body — status / open-now / crowd / hours printed **twice** — so an expanded card was ~2× taller than the
     information warranted.

- **[DELTA]** (Train, 2 files)
  1. **Action buttons** — `ActionButton` rewritten from a 36 px circle + caption into a flat **Cuisine-style
     pill** (`text-[11px] px-2 py-0.5 rounded-full border`, icon + word on **one** line); action row `pt-2` →
     `pt-1`.
  2. **No duplicated meta** — the status/open/crowd/hours block in the expanded body is now gated
     `{!collapsible && (…)}`. A collapsible card already shows that in its summary row, so its expanded body
     starts at **Around the station → line sub-cards → action pills**.
  3. **Walk removed** — the 🚶 walk/distance is gone from **both** the summary row and the body; the
     `distM`/`walkMin` derivation and the `haversineM`/`walkMinutes` imports are deleted from `StationCard`,
     **and** the one-shot `navigator.geolocation` request in `App.jsx` is removed — nothing consumes a user
     fix any more, so the Mini App no longer raises a location prompt it cannot justify. `userLoc` stays wired
     as a permanently-null prop so `StationCard`'s contract is unchanged; `haversineM` / `walkMinutes` remain
     exported + unit-tested for other callers.
  4. **Tap now zooms** — the name strip used to **be** the collapse toggle and called `stopPropagation`,
     swallowing the tap so it never reached the card's `onTap` → the map never focused/zoomed the station. The
     strip no longer toggles; the tap bubbles to `onTap` → `handleSelectStation` → `focusedStation` →
     `MrtMapPanel`'s detail branch `setCenter` + `setZoom(18)` (v0.62.634). **Only the ▾ button collapses.**
     Strip padding `px-3 py-2` → `px-2 py-1.5`.
