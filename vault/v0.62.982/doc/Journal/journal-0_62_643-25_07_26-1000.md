- **[DIAGNOSIS from the screenshots]** The collapsed cards read **"NS1 EW24 Ju… `[Interchange]` ▾"**,

- **[DELTA]** (Train, 1 file — `web/transport/src/components/StationCard.jsx`)
  1. **Name** — the category chip ("MRT station" / "Interchange") is **removed** from the name strip; it was
     redundant, since two line-code chips already say "interchange". The name goes **14 px → 16 px** (the
     operator's "+2 px") and takes the full remaining width; `truncate` stays only as a last resort for the
     longest names on the narrowest card.
  2. **Summary** — the two rows collapse into **one** that actually uses the width: health dot + status +
     Open-now + crowd on the left, **🕑 first–last** pushed right with `ml-auto`.
  3. **Line sub-card** — the collapsed times row now carries the **"Station info ↗"** link on its right
     (`ml-auto`) instead of a row of its own — saving a row **per line**. The standalone link still renders
     when there is no times row, so the Codex-P2 CGL/SLRT/PLRT case is preserved (guarded by
     `!(hasDetail && !open && summary)`).
