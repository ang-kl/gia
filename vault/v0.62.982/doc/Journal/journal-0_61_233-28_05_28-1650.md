- **Why the input was getting squeezed:**

  Phone viewport ≈ 22 rem. Previous layout:
  - country flag (~5 rem) + city select (10 rem) + input (flex-1)
    + 🔍 button (~3 rem) → input fits in ~4 rem. Too narrow to
    type meaningfully → operator perceived as "removed".

  v0.61.233 layout:
  - country flag (~5 rem) + city code (~3.5 rem) + input (flex-1)
    + 🔍 button (~3 rem) → input fits in ~10.5 rem. Comfortable.
