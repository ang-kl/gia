- **[PRESET COMBO LOGIC GATES (concrete)]**
  | Preset | Pre-fills | Server-side |
  |---|---|---|
  | Transit Efficiency | radius=1 km, mode=transit, when=now | `minRating ≥ 4.2`, prompt "low-profile high-rating hidden gems near MRT" |
  | After-Hours | radius=1 km, mode=walk, when=now → `forceMeal='supper'` | `requireOpenNow=true`, prompt "open after 22:00, suitable for late-night supper" |

- **[RISK / KNOWN GAPS]**
  - 15-pick search cost: 15 Place Details validates + 1×15 Routes Matrix per Search tap → ~$0.05/search. Mitigation deferred to a Phase 2 60 s per-chat cache.

  - Older Telegram clients without WebApp support cannot open the TMA — they get the inline button but tapping it does nothing. Documented; defer fallback to v0.22.1 if reports come in.
