## New

### [HDR] #148 | 10:40:00 SGT 15-05-26 | v0.60.181 `/s` assistance sub-menu — Cooking Methods / Authentic Dishes / Others + dish-type heuristic | 3 files (1 new), ~280 LOC | 1 PR |

- **[INTENT]** Replace bare `/s`'s text-instruction prompt with a `/transport`-style 3-button inline keyboard, drilling into per-cuisine method + iconic-dish lists with succinct course/protein tags. `/s <text>` flow unchanged.

- **[DELTA]**

  **`dish-types.js`** (NEW, ~85 LOC) — heuristic classifier `classifyDishType(name, cuisineSlug)` returning `{ course, overlay, tags }`. Two regex-pattern arrays:
  - **`COURSE_PATTERNS`** — `dessert | drink | starter | side | main` buckets. Order-sensitive; longer/specific patterns first.
  - **`PROTEIN_PATTERNS`** — `fish | meat | vege` overlay applied on top of course.
  - Emoji per bucket (🥩 meat, 🐟 fish, 🥕 vege, 🍰 dessert, 🥤 drink, 🥟 starter, 🍛 main, 🥗 side).
  - Drink + dessert short-circuit the overlay (they're self-describing).
  - Smoke-tested against Nepalese sample (momos, dal bhat, sel roti, thukpa, juju dhau, sukuti, yomari, chatamari, kheer, lassi, sweet lassi, kopi, samosa, jhol momo) — all classify correctly after two heuristic refinements (plural `momos?` matching; `lassi` removed from dessert; `jhol momo` removed from fish — it's a saucing technique, not a fish dish).

  **`index.js`** — five new handlers + callback dispatch:
  1. `sendSearchAssistMenu(chatId, lang)` — 3-button inline keyboard (Cooking Methods / Authentic Dishes / Others). Bare `/s` now calls this instead of dumping the v0.60.110/111 instruction text.
  2. `_buildCuisinePicker(source, lang)` — shared picker. Groups cuisines by `cuisines-vault.js` `categoryLabel` (Common in SG / Southeast Asian / East Asian / South Asian / Middle Eastern / European / etc.), 2 per row, with `── Category ──` separator rows. Only cuisines that have data in the chosen source (cooking-methods OR nation-overlay) appear; cuisines without either are skipped.
  3. `sendSearchMethodsPicker` / `sendSearchMethodsFor(chatId, slug, lang)` — drill-down. `sendSearchMethodsFor` lists all `cooking-methods.COOKING_METHODS[slug]` entries with succinct line per item; back-button row to picker / menu. Operator-curated explainers per method are DF-70.
  4. `sendSearchDishesPicker` / `sendSearchDishesFor(chatId, slug, sort, lang)` — drill-down. Pulls `nation-overlay.NATION_OVERLAY[slug].iconicDishes`, decorates each with dish-type tags from `dish-types.classifyDishType`, sorts by `nationality` (solo-cuisine first, shared dishes last) OR `type` (course/protein order). Sort toggle in the keyboard footer.
  5. `sendSearchOthersPrompt(chatId, lang)` — preserves the v0.60.110/111 free-text instruction text in EN + FR. Back-button to menu.
  - Callback dispatch added before the transport block: `s:menu | s:methods | s:methods:<slug> | s:dishes | s:dishes:<slug>[:type|:nationality] | s:others | s:noop`. `s:noop` swallows the category-header label callbacks so they no-op cleanly.
  - `runSearchCommand` (line ~4519) — the bare-arg branch now calls `sendSearchAssistMenu(chatId, lang)` instead of `safeSend(chatId, helpText)`. Conversation state (`sc.startConversation`) still primes so the user can type `/s <text>` immediately as a free-text follow-up.
