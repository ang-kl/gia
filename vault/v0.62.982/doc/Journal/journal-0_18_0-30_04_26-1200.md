## New

### [HDR] #26 | 12:00:00 SGT 30-04-26 | v0.18.0 | n/a kb | n/a lines
- **[INTENT]** Per Human Lead spec: build a Durger-King-style menu in the TMA, plus add 5 new commands (`/cuisine`, `/weather`, `/transport`, `/carpark`, `/grocery`). Single coherent navigation surface.
- **[DELTA]**
  - **`weather.js`** (new) — NEA `api.data.gov.sg` integration. `summary(lat, lng)` calls `/2-hour-weather-forecast` and `/air-temperature` in parallel; returns nearest area forecast + nearest station temperature. No API key required (sovereign-Singapore public endpoint).
  - **`carpark.js`** (new) — LTA `/CarParkAvailabilityv2` paged fetch. `nearest(lat, lng, count = 5)` returns the closest 5 carparks with `> 0` available lots, with distance in metres. Reuses existing `LTA_ACCOUNT_KEY`.
  - **`vibe-suggest.js`** — `CATEGORIES` extended with `cuisine`. `pickValidated` accepts `opts.cuisineType`; when set, composes the Gemini hint as `"<type> restaurants and cafés serving authentic <type> food, suitable for a solo diner"`.
  - **`index.js`** —
    - + `/grocery` regex alias of `/groceries` (one regex `/^\/(?:groceries|grocery)…/`).
    - + `/cuisine` handler — accepts `<type>` argument; encodes pending state as `cuisine:<type>` so the location-share path knows to route via the new `runCuisineFlow`.
    - + `runCuisineFlow(chatId, lat, lng, type)` — wraps the v0.10.0 lock + Vault-or-pickValidated flow with cuisine-specific Gemini hint. Hidden Sanctuary fallback wording adjusted: *"I couldn't find a strictly Italian sanctuary, but I've identified a 'Hidden Sanctuary' at … "*.
    - + `/weather`, `/transport`, `/carpark` slash-command handlers (each thin wrapper around `runWeatherCommand` / `runTransportCommand` / `runCarparkCommand`).
    - + `routeMenuCommand(chatId, raw, payload)` — single dispatcher used by deep links (`/start <cmd>`) AND TMA tile taps (`web_app_data`). Routes `eat / drink / grocery / groceries / cuisine / weather / transport / status / carpark / ver`.
    - + `resolvePending(pending)` — centralises pending-state parsing (now distinguishes sanctuary categories from cuisine types).
    - **Free-text handler** (`bot.on('message')`) now also handles `msg.web_app_data.data` — parses the JSON `{cmd, type?}` payload from menu tile taps and routes via `routeMenuCommand`.
    - **Default-button handler** (`⛔ Use Raffles Place default`) now routes to `runCuisineFlow` when pending is a cuisine.
    - **Location handler** (`bot.on('location')`) same.
    - **Typed-place branch** same.
    - **`/start`** regex now accepts a parameter: `/^\/start(?:@\w+)?(?:\s+(\w+))?$/`. When invoked with a param (e.g. via `t.me/<bot>?start=eat` deep link), routes through `routeMenuCommand` before the greeting fallback.
    - **`/start` greeting** updated to list all 9 commands.
  - **`public/menu.html`** (new) — Durger-King-style tile grid (8 tiles): Eat / Drink / Grocery / Cuisine / Weather / Transport / Carpark / Map. Cuisine tile opens a bottom-sheet modal with 9 cuisine-type buttons (Japanese / Korean / Chinese / Italian / Indian / Thai / Vietnamese / Malay / Western). Theme variables read from `--tg-theme-*` CSS variables for native Telegram light/dark consistency.
  - **`public/menu.js`** (new) — tile click → `tg.sendData(JSON.stringify({cmd, type?}))`. Telegram dismisses the TMA automatically after `sendData`. Map tile uses `tg.openLink('/app/map')` (separate page).
  - **`index.js` Express routes** —
    - `GET /app` and `GET /app/menu` → `public/menu.html` (the new default — chat menu button lands here).
    - `GET /app/map` → `public/index.html` (the legacy v0.4.0 sanctuary map; still available).
  - **`setMyCommands`** updated to include all 9 commands.
  - **Menu button** label changed from "🌿 soleat Map" → "🌿 soleat Menu". URL → `/app/menu`.
  - **`package.json`** — version → 0.18.0.
- **[RISK]** Med —
  - **TMA `web_app_data` flow.** Requires Telegram Bot API 6.4+ (April 2023). All current Telegram clients (Desktop, iOS, Android, Web) support this. Older clients will simply not see the menu button or won't be able to send data.
  - **Carpark API quota.** LTA DataMall is free; no quota concern at single-user scale. The `fetchAll` paginates up to 10 pages × 500 = 5000 records max (current real count is ~2000) — safe upper bound.
  - **Weather API.** `api.data.gov.sg` is public and free, no key. Stable for years.
  - **Cuisine type free-text.** `/cuisine asdf` will produce a Gemini-driven search for "asdf cuisine" — likely empty. The Hidden Sanctuary fallback fires gracefully. Worth iterating into a closed list later, but the open form is more flexible for niche cuisines.
- **[STATUS]** PROD — auto-deploys with the next Railway build.
