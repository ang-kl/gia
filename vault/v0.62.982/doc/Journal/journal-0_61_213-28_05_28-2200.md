  | Mode | Rows | Cost | ETA |

  | Smoke | 50 | ~$2.50 | ~30 s |
  | MY only | 500 | ~$25 | ~3 min |

  **Flow:**
  1. `/ver` → admin keyboard now includes a row `[🧪 Place-search variance]`.
  2. Tap → `ownerPlaceSearchVarianceMenu` shows last result summary (if any) + the three Run options + Close.
  3. Tap a Run option → confirm dialog (`psv:run-<mode>` → `ownerPlaceSearchVarianceConfirm`) with cost + ETA + ↩ Cancel.
  4. Tap `▶️ Run … now` → `psv:go-<mode>` fires `ownerPlaceSearchVarianceRun`. Posts "starting" message; ~30 s progress pings; final summary.
  5. Summary stored at `psv:latest` (60 d TTL) so the menu can re-render it next time.
