- **[DELTA — DEFECT 1 (fixed)]** `web/cuisine/src/v2/App.jsx`. The pink "Closing in N min" and red
  "Closed" card status strips (`ResultCard.jsx` L305/L309, styled `relative z-10`) **bled over** the
  sticky portrait two-panel map: the map wrapper was **also** `z-10`, so at equal z-index the
  later-in-DOM card strip painted **over** the map as a card scrolled up behind it. Raised the opaque
  sticky map wrapper `z-10` → **`z-20`** (still below the `z-30` header + folio pickers), so it covers
  the `z-10` strips.

- **[DEFECT 2 — NOT yet fixed, awaiting operator clarification]** Verified numerically that the folio
  **tabs** (`folio-tabs` + `pickerWidthCls` = `max-w-md`, left-aligned) and the fixed picker

  left-aligned positioning at the **same** md gutter (~24 px) — so it is **not** a horizontal offset.
  Likely candidates: the **right** tab ("Pick local classic") dropdown opening left-aligned (not under
  its own tab); a vertical gap/overlap at `top: headerBottom`; or the narrow left column reading
  unbalanced in the narrower portrait width. Asked the operator which one before touching it (a wrong
