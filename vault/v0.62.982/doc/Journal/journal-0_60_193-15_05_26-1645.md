  Two sibling helpers added to `michelin-2025.js`:
  - `appendMichelinAnnotation(lines, venue, logTag)` — pushes the formatted line; consumed by `formatVenueBlock` + `formatTechniqueVenueBlock`.

Idempotent — short-circuits when `venue.michelinCategory` is already set (handleMichelinSearch populates it upstream).

  Both helpers swallow exceptions with a `console.warn` keyed by `logTag`, so the three call sites stay differentiable in Railway logs.
