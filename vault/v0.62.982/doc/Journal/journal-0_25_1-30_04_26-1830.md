    | Code | Step |
    |------|------|
    | D100 | TMA mounted |
    | D110 | Pre-selected cuisine from `?cuisine=` deep link |
    | D200 | Geolocation requested |
    | D201 | Got browser location |
    | D202 | Geolocation rejected (denied / blocked) |
    | D203 | `navigator.geolocation` undefined |
    | D300 | initData present (length logged) |
    | D301 | initData empty (auth header will be blank) |
    | D302 | `Telegram.WebApp` not present (running outside TG) |
    | D400 | onSearch invoked |
    | D401 | Payload built (cuisines count, radius, preset) |
    | D402 | POST /api/cuisine-search dispatched |
    | D403 | HTTP 2xx |
    | D404 | HTTP 4xx (server reports `diag` field, captured here) |
    | D405 | HTTP 5xx |
    | D406 | Network/fetch threw before HTTP response |
    | D500 | Response parsed |
    | D501 | venues array empty after server filtering |
    | D502 | venues received (count logged) |
    | D900 | Catastrophic / unhandled |
  - **`index.js#POST /api/cuisine-search`** — server-side instrumentation:
    | Code | Step |
    |------|------|
    | D700 | request received (lat, lng, radius, preset, n_cuisines logged) |

    | D702 | success (elapsed ms + venues count logged) |
    | D703 | error during searchCuisine — 500 with `{error, diag:'D703'}` |
