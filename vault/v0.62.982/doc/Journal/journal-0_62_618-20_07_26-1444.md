## New

### [HDR] v0.62.618 — the shared-component Tailwind purge (root cause of the missing map buttons), NEA footer-left, nav audit

- **[INTENT]** Operator: *"NEA link: footer-left. fix #2. Also audit all nav cluster buttons ensure they
  are not there for show."*

- **[#2 ROOT CAUSE — important, my slice-B miss]** Each TMA's `tailwind.config.js` `content` glob was
  `['./index.html', './src/**/*.{js,jsx}']` — it **did not scan `web/_shared/`**. When slice B
  (v0.62.615) moved `MapControls` → `web/_shared/components/` (and `BottomSheet` earlier, v0.62.608/609),
  Tailwind **purged every class used only in those shared components**. `MapControls`' **`top-2`** (the
  framed non-fill map's top offset) was purged → `top: auto` → the quick-toggle row (⋮ / Colour / 🚉 Train
  / 🅿 Carpark / 🚌 Bus Stop) fell to its **in-flow position** = below the 560 px map = **the map's bottom
  (y=648)**. That's "where are the quick buttons." (My slice-B "no regression" check verified the DOM
  *text* was present but not its *position*/purged classes — hence the miss.)

- **[#2 FIX]** Added **`'../_shared/**/*.{js,jsx}'`** to the `content` glob of the **4 TMAs that import
  shared components** — `cuisine`, `hawker`, `menu`, `transport`. This regenerates their CSS with the
  previously-purged classes, and also repairs any purged **`BottomSheet`** drawer classes
  (`rounded-t-2xl`, the up-cast shadow, the `h-1.5 w-10` handle) and `FooterNav`.
  **Verified:** a Playwright bounding-box probe shows the Hawker tablet toggle row moved **y=648 → y=96**
  (top of the map, full width 704 px) — visually confirmed (`⋮ Monochrome Train Carpark Bus Stop` at the
  top).

- **[#1 — NEA footer-left]** `web/hawker/src/App.jsx` `FooterDock`: the NEA ↗ own-line row `justify-end` →
  **`justify-start`** (footer-left, per the operator).

- **[NAV-CLUSTER AUDIT — Hawker + Train]** Result: **all buttons are wired to real map actions; none are
  decorative.** Reset (`setCenter`+`setZoom`), Zoom ± (`setZoom±1`), Centre (`panTo`), Expand
  (`toggleExpand` / `setExpanded`), Train **Overview** (`toggleOverview`), and the `MapControls` layer
  pills (`onToggleLayer` → `onOverlayChange`; 19 `overlayLayers` consumers in `MrtMapPanel`) + the Colour
  toggle. The only inactive states are the **intentionally-greyed** Expand/Overview when the action isn't
  available (a visual "not now", not a dead button).
