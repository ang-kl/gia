  1. **P1-a (`36d85cd`)** — `document.documentElement.lang` synced with the active locale in all 5 i18n
     modules (boot + CustomEvent + cross-tab storage). Previously every non-English session was announced
     with English phonetics in all 8 locales.
  2. **P1-b (`81eda2c`)** — hawker's `prefers-reduced-motion` CSS net ported to cuisine/menu/clipboard/
     oversight; cuisine's infinite `.animate-blink` loading dots go static under RM; transport's JS-driven

     toggle).
  3. **P1-c (`d7596af`)** — one theme-aware accent `:focus-visible` ring per app (`!important` so
     `focus:outline-none` utilities can't silently re-remove it; keyboard-only — touch/mouse users see
     nothing; clipboard's ring uses its fixed palette accent per the recorded Sketchbook decision).
     Presence verified in all six BUILT css bundles (the repo's known silent-drop failure class).
  4. **P1-d (`782168d`, `5590d4a`)** — new shared `web/_shared/lib/use-dialog.js` (initial focus, Tab
     containment, Escape, focus restore — lifted from the vanilla bottom-sheet; respects pre-existing
     autoFocus) applied to ~20 dialog/sheet/popup surfaces across all six apps; keyboard operation for the
     BottomSheet drag handle (Enter/Space/arrows/Home/End), transport StationCard, hawker centre card,
     clipboard VenueCard, ResultPanel's city-jump; all four LocaleToggles converted from broken
     `listbox`-of-buttons to the menu-button pattern (menuitemradio + roving arrows + Escape-to-trigger);
     the three menu location dropdowns + cuisine CityDropdown gain the arrow-key model their sibling
     already had. Bonus: removed a pre-existing double-close bug (CuisineCategoryDrawer's document-level
     Escape closed the root drawer underneath the dish pop-ups).
  5. **P1-e (`bcb4736`, `3a55d45`)** — accessible-name + label sweep: every audited icon-only control
     named (localized via existing keys where possible; new keys added to ALL locale tables a file
     carries); switches named by their visible labels (aria-labelledby); disclosures gain `aria-expanded`;
     toggles gain `aria-pressed`; clipboard's `field()` helper now genuinely associates label↔control
     (htmlFor/id); every placeholder-only input gains an aria-label reusing its placeholder key; the
     rating radiogroup becomes a single tab stop with roving arrows and its fourth (custom) choice joins
     the group; ResultCard's details toggle gains `aria-controls`. New i18n keys: cuisine
     `sheet.dragHandle`/`localeToggle.language`/`localeToggle.close`; hawker those + `link.neaAria`;
     transport `sheet.dragHandle` (8-locale) + `mrt.close`/`locale.language` (en/fr per that file's own
     convention); clipboard `sort.asc`/`sort.desc`/`a11y.expand`/`chrome.menu`/`chrome.refresh`/
     `cabinet.field.dateEnd`; menu none (reused existing keys); oversight plain English by design.
  6. **P1-f (`81a5015`, `e37e326`)** — `.gia-hit/.gia-hit-x/.gia-hit-y` (+ transport-only `.gia-hit-s`)
     utilities: a transparent `::after` grows the INTERACTIVE box while the visible control keeps its
     exact pixels; directional variants stop neighbouring extended areas from overlapping in tight
