- **[INTENT]** Make `/about` visually scannable instead of a wall of text, and clean up the Safari rendering bug the operator's screenshot surfaced.

- **[DELTA]**

  **1. `public/about.html`** — three changes:

  **a) Comparison list overlap fix** (CSS):
  - Was: `.compare__list li { display: grid; grid-template-columns: 24px 1fr; … }` + `::before { grid-column: 1; }`. On Safari, the raw text node inside `<li>` does NOT auto-place into column 2; it falls back to column-1 overlap with the `::before` marker. Operator screenshot confirms.
  - Now: `.compare__list li { display: flex; gap: var(--sp-3); … }` + `::before { flex-shrink: 0; width: 16px; }`. Flex containers wrap raw text into anonymous flex items, so marker and content sit side-by-side cleanly. Same visual result on Chrome / Firefox / Safari.

  **b) Picture placeholder system** (CSS + HTML):
  - New `.placeholder` class — dashed accent border, repeating-stripe + linear-gradient background, `aspect-ratio` reservation so layout doesn't jump when real image drops in. Each placeholder has a `data-slot="<id>"` attribute, a corner `<span class="placeholder__slot">` label, an emoji icon, a human label, and a hint line (dimensions + content description).
  - Variants: `.placeholder--hero` (4 : 3), `.placeholder--phone` (9 : 16, max-width 280 px), `.placeholder--wide` (16 : 9).
  - Hidden via `@media print { .placeholder { display: none; } }`.

  **c) Layout integration** — five placeholder slots inserted:
