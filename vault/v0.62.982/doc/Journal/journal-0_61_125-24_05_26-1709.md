- **[DELTA]**
  - **`vibe-suggest.js`** — new `geocodeQueryRegion(text, { region, biasCenter })`.
    The prior `geocodeQuery` hardcoded `" Singapore"` in the Places
    API (New) `textQuery`, so any namesake hotel in SG outranked the
    genuine JB hotel. The new helper:
      - swaps the suffix per region (` Singapore` / ` Johor Bahru, Malaysia`
        / ` Putrajaya, Malaysia`),
      - sends a Places `locationBias` circle around the user's
        existing anchor (25 km SG / 50 km JB / 15 km Putrajaya),
      - filters out hits outside the expected country bbox so a stray
        SG fallback can't bleed into a JB result.
    Default `geocodeQuery` preserved for back-compat.
  - **`index.js`** (`/api/menu/set-location` text path) — reads the
    cached location's region BEFORE geocoding, passes it +
    `biasCenter` to `geocodeQueryRegion`. When the resolved point
    stays in the same region as the cached anchor, the prior
    `region` + `radiusCapM` are preserved (so picking another JB
    place keeps the 30 km cap). The client can also pass an explicit
    `body.region` override.
  - **`web/menu/src/App.jsx`** — new `location` entry in the
    `SECTIONS` array; `LocationFieldMenu` moved out of the PLAN
    section's render branch into its own `section.id === 'location'`
    branch (no tile grid, just the field). Text-size classes bumped
    one step throughout the hero / section headings / footer chip /
    footer tag / scroll FAB.
  - **`web/menu/src/i18n.js`** — new `section.location` key (en+fr).
  - **`web/menu/src/components/Tile.jsx`** — icon `text-lg` → `text-xl`,
    label `text-[13px]` → `text-sm`.
  - **`web/menu/src/components/TrainPanel.jsx`** — icon `text-base`
    → `text-lg`, title `[12px]` → `[13px]`, sub `[10px]` → `[11px]`,
    buttons `[11px]` → `[12px]`.
  - **`web/menu/src/components/LocaleToggle.jsx`** — `[10px]` → `[11px]`.
  - **`web/menu/src/components/BackFab.jsx`** — `[10px]` → `[11px]`.
  - **`web/menu/src/components/LocationFieldMenu.jsx`** — summary
    split into `summaryMain` at `text-[13px]` (the bigger
