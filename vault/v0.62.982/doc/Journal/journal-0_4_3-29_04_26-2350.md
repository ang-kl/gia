## New

### [HDR] #6 | 23:50:00 SGT 29-04-26 | v0.4.3 | n/a kb | n/a lines
- **[INTENT]** Detect whether Google Maps app is installed on iOS/iPadOS, and route the TWA "Open in Google Maps" action accordingly. v0.4.2 fixed the URL format but still relied on Universal Links picking the right destination — Human Lead's requirement is "Google Maps must be installed; detect if not."
- **[ROOT CAUSE recap]** iOS does not expose an "is X app installed?" check to webviews for privacy reasons. The standard pattern is to attempt the app's URL scheme (here `comgooglemaps://…`) and watch for the page-hidden visibility signal — if the page stays visible after a short timeout, the app didn't open.
- **[DELTA]**
  - **`public/app.js`** — full rewrite of the InfoWindow link handler:
    - New helpers `isIOS()`, `externalOpen(url)`, `ask(message, callback)`, `openMapsForVenue(v)`.
    - On iOS: sets `window.location.href = 'comgooglemaps://?q=<name>&center=<lat>,<lng>&zoom=17'` and listens for `visibilitychange`. If the page goes hidden within 1500 ms, Google Maps opened — exit silently. If still visible afterwards, Google Maps app is not installed → prompt the user via `tg.showConfirm` (or `window.confirm` fallback) with two paths:
      - **OK** — open the App Store install page `https://apps.apple.com/app/google-maps/id585027354`.
      - **Cancel** — open the documented Google Maps Search-action URL `…/maps/search/?api=1&query=<name>&query_place_id=<id>` in the system browser.
    - On non-iOS: bypass the probe and open the HTTPS URL via `tg.openLink()`.
    - Click handler attached via Google Maps `info.addListener('domready', …)` per InfoWindow render — replaces the previous `domready`-querySelector pattern with a deterministic per-venue `linkId`.
  - **`package.json`** — version → 0.4.3.
- **[RISK]** Low–Medium —
  - The visibility-detection trick is well-established but can produce false negatives if iPadOS animation timing varies. Conservative 1500 ms timeout chosen.
  - `tg.showConfirm` requires Telegram WebApp 6.2+; older clients fall back to `window.confirm`, which inside a Mini App may show as a system alert (less polished but functional).
  - `comgooglemaps://` is Google Maps' documented iOS URL scheme. If they ever change it, the probe silently fails and we fall through to the install prompt — not catastrophic.
- **[STATUS]** PROD — auto-deploys with the next Railway build.
- **[TEST]** Human Lead on iPadOS:
  1. With Google Maps installed → tap "Open in Google Maps" → app opens directly to the named Place.
  2. (Optional, if the user has a second device without Google Maps) → tap link → install prompt appears → Cancel opens the named Place in browser.
- **[NEXT]** Phase 4 — GrabID PKCE for live quietness signal.
- **[ADVICE]** iOS Universal Links and URL schemes overlap awkwardly. Universal Links favour the OS-default Maps app (Apple Maps); URL schemes are app-specific. The hybrid here — try scheme first, fall back to documented HTTPS — is the most reliable cross-state behaviour you can get from a webview.
