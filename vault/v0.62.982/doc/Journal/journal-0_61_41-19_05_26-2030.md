### [HDR] #245 | 20:30:00 SGT 19-05-26 | v0.61.41 — clinic "+" pin · colour-toggle default + semantics · quick-toggle palette | ~4 kb | 13 files | (PR #526) | 1 build |

- **[INTENT]** Re-shape the clinic pin to a red "+" rectangle, make the map `colour`
  toggle default-ON with corrected semantics (ON = colour, OFF = greyscale) across all
  three TMAs, and restyle the in-map quick-toggle buttons to the operator's palette.

- **[DELTA]**
  - **`mapOverlays.js`** (byte-identical ×3) —
    - new `rectPinNode(bg, text)` — a square-cornered (2 px radius) pin tag, bold white
      text on a solid background with a white outline; `buildMarkers` gains an optional
      `makeNode` arg, and the **clinics** layer now renders `rectPinNode('#C62828', '+')`
      instead of the round `dotNode('#C62828', '💊')`.
    - new exported `giaToggleStyle(on, disabled)` — the operator's quick-toggle palette
      (ON `#F59E0B` / `#111827` / `#FCD34D`; OFF `#1F2937` / `#D1D5DB` / `#374151`;
      shadow `rgba(0,0,0,0.45)`; disabled → 0.5 opacity). Light + dark identical.
    - `ensureGreyscaleStyle` CSS now carries `!important` so the base-map greyscale
      filter cannot be overridden.
  - **`MapControls.jsx`** (byte-identical ×3) — `pillClass` is now layout-only; the
    overflow-menu button and the row toggle pills take their colours from the inline
    `toggleStyle()` (the `giaToggleStyle` palette).
  - **`MrtMapPanel.jsx` / `HawkerMapPanel.jsx` / `MapPanel.jsx`** — the greyscale class
    now applies when `colour === false` (was: when `colour` truthy — inverted); the 🎨
    Colour nav button takes the `giaToggleStyle` palette and `aria-pressed` reflects
    `colour !== false`.
  - **`App.jsx`** (×3) — `overlayLayers` initial state `colour: false` → **`colour: true`**
    (the map opens in colour; toggling the button off switches to greyscale).
  - **`package.json`** — `0.61.40` → `0.61.41` (PATCH).
