- **[INTENT]** Close two carry-forward items from the v0.61.130
  KNOWN GAPS list:
  - **Pill reorder** — the place-anchor pill (v0.61.130) currently
    renders AFTER the `misrepNote` + amber `specialModeNotice`
    cards in the result-list info-card stack. The "Where am I
    searching" context outranks the dish-name aside and the
    limited-matches card semantically: it explains WHERE the
    visible results come from, whereas the other two qualify the
    WHAT/WHY of those same results. Move the pill JSX block to
    render FIRST.
  - **Inline unit tests for the v0.61.129 backend** — O-20 (place-
    anchor detection wiring) and O-23 (Fruits/Durian progressive
    radius widening) were both shipped as inline blocks in
    `index.js`. The v0.61.129 journal flagged: *"the widening loop
    is testable in principle … but extracting either into a unit-
    friendly helper would enlarge the diff"*. The diff is enlarged
    now; tests follow.

- **[DELTA]**
  - **`web/cuisine/src/v2/App.jsx`** — the `{placeAnchor && !loading
    && (...)}` block moved UP, now rendered before `misrepNote`
    and `specialModeNotice`. JSX otherwise identical to v0.61.130.
    No state-shape change.
  - **`cuisine-tellme-anchor.js`** (NEW, 65 lines) — extracted the
    v0.61.129 O-20 logic into a pure helper:
    `async detectAnchorFromFreeText({ text, isJB, detectPlaceName,
    nearbyRadiusM, anchorCap }) → { anchor, queryRemainder,
    searchCenter, searchRadius } | null`. Also exports
    `PLACE_SPLIT_RE` (the `<query> in/near/around/at <place>`
    pattern) so the regex itself is unit-testable. `detectPlaceName`
    is injected so tests can stub the place-detector ladder
    (which calls mrt-coords.json + hawker-vault + Google Places)
    without spinning anything up.
  - **`cuisine-special-mode-widen.js`** (NEW, 110 lines) — extracted
    the v0.61.129 O-23 loop:
    `async widenSpecialMode({ specialMode, venues, seeds,
    searchCenter, searchRegionCode, lang, startRadius, anchorCap,
    target, hardCapM, discoverFn, passesVenueFilter, filterByMode,
    logger }) → { venues, widened, widenedFromM, finalRadiusM }`.
    All IO injected. Exports `DEFAULT_TARGET` (8) +
    `DEFAULT_HARD_CAP_M` (30000) so the handler doesn't carry
    its own copies.
  - **`index.js`** — the two v0.61.129 inline blocks
    (~50 lines + ~75 lines) replaced by single calls to the
    helpers. Net `−68` lines in the `/api/cuisine/search` handler;

  - **`__tests__/cuisine-tellme-anchor.test.js`** (NEW, 17 tests
