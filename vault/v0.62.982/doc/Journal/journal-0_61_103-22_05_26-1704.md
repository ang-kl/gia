## New

### [HDR] #303 | 17:04 SGT 22-05-26 | v0.61.103 — monochrome lines fix | ~2 kb | 5 files | 1 PR | 1 build |

- **[INTENT]** In monochrome mode the train lines render grey — the
  v0.61.95 coloured-line overlay isn't visible. Make the lines show in
  colour as intended.

- **[DELTA]**
  - **Root cause** — v0.61.95 kept the base `google.maps` Polylines on
    the map and layered the coloured SVG overlay on top. But the base
    polylines composite into a canvas the greyscale CSS filter
    desaturates, and that greyed canvas sits over the SVG overlay
    (both in the `overlayLayer` pane) — so the grey base hid the
    coloured SVG.
  - **`web/cuisine/src/v2/lib/mapOverlays.js`** (+ the byte-identical
    Hawker / Transport copies) — in `applyVisibility('train')` the
    base train polylines and the detail-highlight polyline take
    `strokeOpacity 0` while monochrome is on; `colourSegs` (fed to the
    SVG overlay) keeps the real opacity so the SVG draws at full
    strength. The greyed canvas is then transparent where the lines
    were, so the coloured SVG shows through.
  - **`web/transport/src/components/MrtMapPanel.jsx`** —
    `renderPolylines` builds the line polylines at `strokeOpacity 0`
    in monochrome (still `clickable`); the Colour-toggle `useEffect`
    now also re-renders the pins so the polylines pick up a monochrome
    toggle.
  - **`package.json`** — `0.61.102` → `0.61.103` (PATCH).
