- **[INTENT]** When the user moves their anchor back to SG (e.g. Geylang via `/location`), reopening the Cuisine TMA should land on the SG region, not the stale OTHER state from the previous session.

- **[DELTA]**

  **`web/cuisine/src/v2/App.jsx — tryServerCache()`** had auto-flip branches for JB and OTHER/MY-PUT, but no SG branch. So when:
  - state.region was previously OTHER (sticky from session), and
  - server cache now returns `r.region === 'SG'`,

  nothing flipped state.region back to 'SG'. The OTHER pill stayed selected.

  Added the SG branch (mirrors the visibility-refresh handler at line 620 which already had it from v0.61.206):

  ```js
  } else if (r.region === 'SG') {
    setState((s) => (s.region === 'SG' ? s : { ...s, region: 'SG' }));
    console.log('[Cuisine-TMA-v2] tryServerCache: auto-flip region → SG');
  }
  ```
