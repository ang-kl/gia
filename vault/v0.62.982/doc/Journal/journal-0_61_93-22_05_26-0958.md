## New

### [HDR] #293 | 09:58 SGT 22-05-26 | v0.61.93 — map zoom + /l codes | ~7 kb | 5 files | 1 PR | 1 build |

- **[INTENT]** Stop the embedded maps re-framing themselves (zooming
  out) on every data reload; turn the zoom readout into a white
  circular button that, on Cuisine, recenters on the saved location
  (the separate floating pin button goes away); let `/l` accept an MRT
  station code, a bus-stop number or a station exit as the location;
  and fix the `/s` → `/search` copy in the location-saved message.

- **[DELTA]**
  - **`web/cuisine/src/v2/components/MapPanel.jsx`,
    `web/hawker/src/components/HawkerMapPanel.jsx`,
    `web/transport/src/components/MrtMapPanel.jsx`** —
    - **Auto-zoom-out stopped.** Each map gains a `firstFitRef`: the
      `fitBounds` auto-frame runs only on the first data load; later
      loads keep the user's zoom and recenter (`panTo`) only. Transport
      also keeps a `lastFocusRef` so it still re-frames on a focused-
      line / station / Overview change but not on an incidental
      re-render (crowd refresh, locale). The detail-view fit + the
      Overview fit + the Reset button are unchanged (user actions).
    - **Zoom readout → white circular button.** Cuisine: the readout
      becomes the recenter control (`handleRecenterClick`, pans to the
      saved location); the separate floating 📍 button is removed.
      Hawker + Transport have no user location, so their circle is a
      display-only readout (Transport's stacked above the Overview
      button to avoid a collision).
  - **`index.js`** —
    - New module-scope `resolveCodedLocation(text)` + cached loaders
      `mrtCoordsLite` / `stationExitsLite` / `busStopsLite` (the richer
      `loadMrtCoords` / `exitsForStation` live inside the server block,
      out of the `/l` handler's scope). The `/l` handler tries it
      before geocoding: a 5-digit string → bus stop
      (`data_realtime/BusStops.json`), `<station> exit <id>` → that
      exit (`data/station-exits.json`), a bare MRT/LRT code → the
      station (`data/mrt-coords.json`). The whole attempt is wrapped in
      try/catch so a failure falls through to the geocoder.
    - The GPS location-saved message: `/cuisine, /s, /carpark` →
      `/cuisine, /search, /carpark` (EN + FR).
  - **`package.json`** — `0.61.92` → `0.61.93` (PATCH).
