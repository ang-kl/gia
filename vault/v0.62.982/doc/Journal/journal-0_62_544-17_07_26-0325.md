- **[DELTA].**
  - **NEW `web/_shared/lib/use-viewport.js`** — shared hook: `deviceClass` (`mobile`/`tablet`/`desktop`,
    from coarse-pointer + short-edge ≥ 768 / fine-pointer ≥ 1024), `orientation`, `isWide`; debounced via
    rAF on resize/orientationchange. Plus `viewportTag(vp)` → `"(tablet · landscape)"` / `"(tablet)"` /
    `"(desktop · landscape)"` / `""` (portrait drops "landscape" per operator; empty on phones).
  - **`web/hawker/src/components/HawkerMapPanel.jsx`** — new `fill` prop: `absolute inset-0` full-bleed
    background (fills its relative parent) vs the framed fixed-height inline card.
  - **`web/hawker/src/App.jsx`** — `useViewport()` gates the layout. **`isWide`** (tablet/desktop):
    outer becomes `fixed inset-0`; the map renders `fill` as the background; the header + region chips +
    list ride a translucent **left glass panel** (`bg-tg-bg/75 backdrop-blur`, `w-[64%] max-w-[920px]`
    landscape / `w-[88%]` portrait, own scroll). The list container is a **grid** — `grid-cols-2` portrait,
    `repeat(auto-fit, minmax(min(200px,100%), 1fr))` landscape (→ 3–4 cols). **Mobile is unchanged**: the
    panel wrapper is `display:contents` (transparent to layout) and the inline map + single-column list
    render exactly as before. Footer shows `… · v{VERSION}{footerTag}`.
