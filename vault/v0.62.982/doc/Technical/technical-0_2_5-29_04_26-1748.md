## 2. Update Transport

```
WEBHOOK_DOMAIN || RAILWAY_PUBLIC_DOMAIN  set?
                │
        yes ────┴──── no
         │            │
   webhook mode    polling fallback
   POST /webhook   getUpdates (long-poll)
   verified by    Used for local dev
   X-Telegram-    only.
   Bot-Api-
   Secret-Token
```

Webhook mode eliminates the recurring 409 polling conflict structurally — there is no `getUpdates` call to conflict over.

## 6. Build Constraints

- **Single bot polling lock.** Telegram allows only one `getUpdates` consumer per token. Webhook mode bypasses this; polling mode requires `numReplicas == 1`.
- **Places API quota.** Free tier: $200/month credit. At our usage (1 `searchNearby` every 24 h, no detail follow-ups), monthly cost ≈ $0.
- **LTA DataMall rate limit.** No published cap; we call once every 5 min (288/day). Well under any reasonable threshold.
- **Redis key cap.** Two keys total in v0.2.5; nowhere near concern.
