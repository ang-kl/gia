## §0.8.0 NEW CONTENT

### 1. New external API integration

**Google Routes API — `distanceMatrix/v2:computeRouteMatrix`** (the modern successor to Distance Matrix API). Used to compute walking duration + distance from one origin (user) to N destinations (validated picks).

| Property | Value |
| :--- | :--- |
| Endpoint | `https://routes.googleapis.com/distanceMatrix/v2:computeRouteMatrix` |
| Method | POST |
| Auth | `X-Goog-Api-Key` (reuses `GOOGLE_MAPS_API_KEY`) |
| Field mask | `originIndex,destinationIndex,duration,distanceMeters,condition` (tight; no leg geometry) |
| Travel mode | `WALK` |
| Cost | ~$0.005 per element. 1 origin × 3 destinations = 3 elements ≈ $0.015 per `/eat /drink /groceries` invocation. |
| Timeout | 8 s |

### 3. API response handling

The Routes API returns a JSON **array** of route-matrix elements (not an object), each shaped like:

```json
{
  "originIndex": 0,
  "destinationIndex": 1,
  "status": {},
  "condition": "ROUTE_EXISTS",
  "distanceMeters": 320,
  "duration": "240s"
}
```

`duration` is a Google Duration string (always with trailing `s`). Parsed via `parseInt(String(elem.duration).replace(/s$/, ''), 10)`. If the parse fails for any element, that venue retains no `walkMinutes` and falls to the bottom of the sort.

### 4. Cost / quota notes

- Routes API has its own SKU separate from Places API. Both billable on the same Google Maps Platform account.
- At single-user scale: ~$0.015 per pick session. At 100 users × 5 sessions/day = ~$7.50/month. Documented for monitoring.
- The single-call-per-`/eat` pattern (one origin, N destinations in one request) is intentional — N parallel calls would be N× the cost AND multiply the quota burn.
