|---|---|---|---|

## 6. Build constraints

- **Node.js 20+** required (engines pin in package.json).
- **No top-level fetch dependency** beyond `axios` and the SDKs — keeps cold-start under 2 s on Railway.
- **`@google/generative-ai` 0.24.1 is EOL** as of 2025-11-30. Continued use is technical debt; migration to `@google/genai` planned (Register O-2). The current SDK still functions for our call shape (`getGenerativeModel({ model, tools, generationConfig }).generateContent(prompt)`).
- **TMA build must complete in CI** before merge. The cuisine TMA's React tree imports must resolve cleanly under Vite — failures here block deploys.
- **No third-party Telegram libraries** beyond `node-telegram-bot-api`. Inline keyboards / `web_app` buttons / `request_location` keyboards are the only UX surfaces; we don't use stickers, polls, or live-location streaming.
