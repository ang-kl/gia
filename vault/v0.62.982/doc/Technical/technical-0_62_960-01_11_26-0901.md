## 5. Map controller structure

The three `mapOverlays.js` copies (Cuisine, Hawker, Transport) received identical edits **inside
`createOverlayController` only** in v0.62.956-958. So the copies census in `map-overlays-copies.test.js`
(87 / 71 / 63 bindings) did not move. New shared logic goes to `web/_shared/lib/` and is imported, never
copied into a controller.

## 6. Locale handling

Word order and spacing in composed strings follow the **script** of the joined words, never a list of
locales. `NON_LATIN` is imported from `sg-place-text.js`. The locale allow-list census forbids literal
narrow locale arrays; it caught one in `poi-i18n.js` during v0.62.958.
