## 6. Vault mechanics (v0.62.948)

- A current snapshot is the tracked tree of one commit minus the §16.1 exclusions, **staged from that
  commit's own blobs** (`git ls-tree -r` → `git update-index --index-info` under `vault/<v>/`), so every file
  keeps its object id and mode and Git stores no new content.
- `scripts/verify-vault-archives.mjs` now exports `CURRENT_SNAPSHOTS` (v0.62.937 and v0.62.948, each with
  source commit and pinned folder tree) and `versionFolders()` (29). `--verify` fails on a changed snapshot
  tree or an extra folder; both proved by mutation on 29-10 '26.
- `vault-verify.yml` fetches each pinned source, runs each snapshot's `VAULT_VERIFY.mjs`, and restore-builds
  each in isolation.
- **Deploy cost:** Railway copies `vault/` into every image; each current snapshot adds about 245 MB
  (operator accepted, spec A1).
