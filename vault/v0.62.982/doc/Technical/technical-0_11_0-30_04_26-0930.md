### 2. Radial expansion mechanics

```
pickValidated(lat, lng, count, _, opts):
    candidates = geminiCandidates(meal, lat, lng)   ← 5 names
    if !candidates: return {meal, venues: []}

    first = null
    activeRadius = 200
    for r in [200, 500, 1000]:
        first = validateWithPlaces(candidates[0], {lat, lng}, r)
        if first: { activeRadius = r; break }
    if !first: return {meal, venues: []}     ← Hidden Sanctuary takes over upstream

    validated = [first]
    for i in 1..candidates.length while validated.length < count:
        v = validateWithPlaces(candidates[i], {lat, lng}, activeRadius)
        if v: validated.push(v)

    ranked = rankByWalkingTime(lat, lng, validated.slice(0, count))
    return {meal, venues: ranked, activeRadius}
```

Worst-case Places searchText calls per `/eat`:
- 3 (radial expansion attempts on candidate 0) + 4 (candidates 1–4 at active radius) = **7**
- Plus 1 Place Details per validated candidate for review-keyword screen.
- Plus 1 Routes Matrix.

### 3. Vault buffer mechanics

```
queryVault(redis, lat, lng, radiusM):
    effectiveRadius = radiusM + 50
    GEOSEARCH gia:vault FROMLONLAT lng lat BYRADIUS effectiveRadius m ASC WITHCOORD WITHDIST
    ← per-hit HGETALL gia:place:<id>
```

User-facing radius unchanged at 300 m. Internal GEOSEARCH spans 350 m to absorb GPS drift.

### 4. sync-vault.js input resolution

```
resolveUrlSet():
    if --html=<path> in argv:
        return parseHtmlForMapUrls(path)
    if exists data/Saved Places.html:
        return parseHtmlForMapUrls('data/Saved Places.html')
    return HARDCODED_URLS    ← original 14 URLs from spec
```

`parseHtmlForMapUrls(file)` uses cheerio's `$('a[href]')` selector and matches four URL patterns (short, legacy goo.gl, full Google Maps, maps.google.*).
