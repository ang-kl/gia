## 3. Budgets / cost notes (this arc)

- **Places negative-cache** for failed Michelin lookups + 7-day success TTL (#989) — caps repeated paid lookups on misses.
- **FX**: Alpha Vantage + Frankfurter, 15-day cache (#875) — minimises FX API calls; +2.8 % markup baked in.
- **Cuisine corpus removed** (#973) — the 165k-restaurant Bangkok foundation (#972) was reverted as "too heavy / won't scale": a deliberate decision NOT to carry a large local corpus.
- `/cost` owner-gated API-spend tracker added (#813).

## 4. Build Constraints (this arc)

- `michelin-meta.json` is a large tracked snapshot regenerated by the refresh tooling; geo-guard must run on refresh (wrong-country rows otherwise leak — #963 fixed 33→0).
- Progressive NDJSON streaming is **opt-in** (a base→patch→done contract); non-streaming clients still get the final batch.
- Native-script names + Gemini romanisation add a foreign-name line on every card surface — keep the romanisation keyed to device language (#897, #900).
