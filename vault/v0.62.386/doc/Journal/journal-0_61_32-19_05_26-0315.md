## New

### [HDR] #236 | 03:15:00 SGT 19-05-26 | v0.61.32 — Clinics + Police overlay layers (3 TMAs) | ~6 kb + 2 data files | 16 files | 1 PR | 1 build |

- **[INTENT]** The map-controls redesign adds new POI overlay layers. Phase A converts
  two operator-supplied `geoloc/` datasets — `CHASClinics.geojson` (MOH CHAS clinics) and
  `SingaporePoliceForceEstablishments.geojson` (SPF establishment points) — into slim
  `data/geo-*.json` files; Phase B serves them and renders them as toggleable map overlay
  layers on all three TMA maps. (Police = establishment points only; the NPC boundary
  polygons are deliberately not drawn. 24 hrs / Bus Stop layers are separate later work.)

- **[DELTA]**
  - **`scripts/build-geo-overlays.js`** — `CONFIG` gains `clinics` (`CHASClinics.geojson`)
    and `police` (`SingaporePoliceForceEstablishments.geojson`). New `parseKmlDescription()`
    helper reads the data.gov.sg KML-style HTML `<table>` of `<th>KEY</th><td>VALUE</td>`
    rows (CHAS clinics store their attributes there); new `joinAddress()` composes a
    readable block/street/building/postal address. `convertPoint()` gains `clinics` (name
    = `HCI_NAME`, address from the parsed table) and `police` (name = `DEPARTMENT`,
    address from flat properties) branches.
  - **`data/geo-clinics.json`** (new, 1193 features) + **`data/geo-police.json`** (new,
    128 features) — generated, committed (static artefacts, like the other `geo-*.json`).
  - **`geoloc/Readme_2026-0517.MD`** — dataset-table rows for the two new sources.
  - **`index.js`** — `loadGeoOverlays()` reads `geo-clinics.json` + `geo-police.json`;
    `/api/geo/overlays` now returns `clinics` and `police`.
  - **`mapOverlays.js`** (byte-identical ×3) — `ensureLayer()` branches build the two
    marker layers via `buildMarkers()` (clinics `✚` on `#C62828`, police `👮` on
    `#1A237E`); new shared `poiInfo()` popup builder (glyph + name + 📇 address +
    the v0.61.31 `Google Map ↗` link). `fetchOverlays()` fallback extended.
  - **`MapLayerChips.jsx`** (×3) — `Clinics` + `Police` chips added to `LAYERS`.
  - **`App.jsx`** (×3) — `overlayLayers` state gains `clinics` / `police` keys (off).
  - **`MapPanel.jsx` / `MrtMapPanel.jsx` / `HawkerMapPanel.jsx`** — `applyOverlayLayers`
    calls `ctrl.setLayer('clinics' | 'police', …)`.
  - **i18n** (×3) — `layer.clinics` / `layer.police` (EN + FR).
  - **`package.json`** — `0.61.31` → `0.61.32` (PATCH).
