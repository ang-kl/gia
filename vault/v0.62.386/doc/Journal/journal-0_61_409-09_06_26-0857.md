- **[ROOT CAUSE]**
  - **Popup still showed** because v0.61.407 only neutered **one** of three detectors (`anchorMismatch`). The screenshot's *"Keep MY"* popup is **`coherenceMismatch`** (`App.jsx:912` / text `:2279`); `regionMismatch` (`:1007`) is a third — both were still live.
  - **Auto-loaded behind the popup (race):** the boot gate (`:1089`) is meant to hold the load while a modal is up (`modalPendingRef`), but `tryServerCache` loads the saved country/anchor **async**. If the device GPS resolves first, the gate opens and fires the boot load **before** the saved country lands → then coherence raises the modal. Screenshot = **0 results + hourglass + popup at once**.
  - **Architecture note (the over-compression):** `userLoc` resolves from **one** source in a priority chain (hash → initData → **serverCache** → gps → centroid); serverCache and gps are **mutually exclusive**, so in the saved-location path `userLoc` **is** the saved location (no separate device read). The "mismatch" is really **saved-internal incoherence** (saved coords SG "Bukit Merah" vs saved countryPref MY), not device-vs-saved.
