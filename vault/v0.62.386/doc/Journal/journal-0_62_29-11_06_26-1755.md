- **[INTENT / GAP]** The TMA card's 🍲 Try line is fed only by **review-mined** dishes
  (`cuisine-enrich.js extractDishes`); when reviews yield nothing the line is **empty** — precisely on
  unfamiliar cuisines where a foodie most needs "what do I order?". The curated tables were unused in
  this path (only `/s` reads them).

- **[DELTA — `discovery-dish.js` (new)]**
  - `iconicDishesFor(slug)` — from `NATION_OVERLAY[slug].iconicDishes`: **food**-kind entries with **no
    `sharedWith` claimants** only (shared/ambiguous dishes like laksa stay in the `/s` disambiguation
    flow, never a one-line claim). E.g. french → boeuf bourguignon/coq au vin; african → jollof
    rice/suya; moroccan → tagine.
  - `famousMethodsFor(slug)` — COOKING_METHODS terms (secondary).
  - **`findVerifiedDish(venue, slug)` — the answer to "how would you know":** the curated dish is
    claimed **ONLY when the venue's OWN text** (its Places `reviews[]` + `googleSummary`/editorial
    overview) **mentions it** — diacritic **and ligature** folded (a review's "bœuf bourguignon" matches
    the curated "boeuf bourguignon"). No mention → `null` → **no claim**. Same pattern as the durian
    review-mention counter. Returns `{ dish, source: 'curated-verified' | 'method-verified' }`.

- **[DELTA — `cuisine-family.js`]** `COUNTRY_LOCAL_FAMILIES` — the cuisine families "local /
  everyday-safe" per supported search country (SG/MY = SE-Asian + East-Asian + South-Asian trio;
  CN/TW/HK/MO/JP/KR = East-Asian; ID/TH/PH/VN/BN = SE-Asian; AU/NZ = European + American). 15 countries
  = exactly SG/MY + the OTHER picker list. `isUnfamiliar(slug, cc)` — true only when both sides resolve
  and the family isn't local (**never guesses**: unknown family/country → false). This is the
  set-location-as-home-cuisine signal the operator chose.

- **[DELTA — `index.js` wiring (post-`enrichFast`, ~16156)]** Single-cuisine, non-special searches only
  (the slug is unambiguous; durian/fruits have their own flows; Michelin early-returns before here).
  **Reviews-first:** venues whose review-mined `dishes` came back empty AND have no `signatureDish` get
  `v.signatureDish = findVerifiedDish(...)` + `v.dishSource`. Log: `D786 curated-try slug=… country=…
  unfamiliar=… filled=n/N`. The payload passes whole venue objects (`venues: dedupedTop`) and
  `ResultCard.jsx` already renders `signatureDish` → **zero client change, no build bump**.
