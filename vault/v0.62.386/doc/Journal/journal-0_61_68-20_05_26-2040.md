- **[DELTA]**
  - **`web/transport/src/lib/mapOverlays.js`** (canonical) —
    - New `showStationBusStops(rec)` / `clearStationBusStops()` + a
      `stationBusPins[]` controller field. On a station tap, `openStationCard`
      now draws the station's per-exit `nearest_bus_stop` set as 🚏 map pins

      overlay is off** (when on, that layer already shows them).

      toggled on (`setLayer` busstop+visible) to avoid duplicate pins.

      so the 2 s flash reads as a highlight over the now-visible real bus-stop
      pin rather than a duplicate.

    row reorders: **Colour pill first**, then Train Line / Carpark / Bus Stop,
