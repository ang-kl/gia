  1. **Wrong country (primary).** `handleMichelinSearch`'s `michelinCountry` arrived **null** for an OTHER search with no body `countryCode` → handler treated empty as **SG**, loaded the **Singapore** list, queried SG names near a KL/Hanoi anchor → **0**.

  4. **Region-pill strip.** Tapping any non-SG pill dropped `'michelin'` (old SG-only logic).
