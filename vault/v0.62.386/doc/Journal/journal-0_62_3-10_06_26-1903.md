## New

### [HDR] #647 | 19:03 SGT 10-06-26 | v0.62.3 — first-ever location share is confirmed back (Yes / set-manually) + desktop nudge on later shares | index.js + i18n.js | 1 PR | 0 builds |

- **[INVESTIGATION — read-only trace]** *"Muzium Negara" is NOT in the codebase* (grep-confirmed) —
  it is the point **Telegram Desktop** sent. Telegram Desktop (macOS) has **no GPS**: its
  `request_location` button is a **map-pick** that defaults to an IP / last-used point. Our
  `bot.on('location')` (`index.js:~3820`) faithfully saves whatever Telegram delivers. The code
  already documents this (`index.js:2204` *"Bots can't read device GPS unsolicited"*). **Gap:** the
  existing drift prompt (`index.js:~3854`) only fires when a *new* share drifts OUTSIDE a registered
  spot — on **first load there is no prior location, so nothing confirms the (possibly wrong) pick.**

- **[DELTA — `index.js`]**
  - **First-share detection** (`bot.on('location')`): read `getUserLocation` **before**
    `setUserLocation` → `hadPriorLocation`.
  - **First-ever bare share** (`!pending` path): instead of the silent "Location saved", send a
    **confirmation** — reverse-geocoded place + *"On desktop, Telegram shares a map-pinned point, not
    live GPS … Is this where you are?"* + inline **[✅ Yes, use it] / [✏️ No, set manually]**. The
    resolved label is stashed (`locconf:<chat>`, 10 min TTL) for the callback ack.
  - **Subsequent bare shares** keep the "Location saved" message **plus a desktop nudge line** so a
    wrong map-pick stays correctable.
  - **New callback** `locconf:ok` / `locconf:fix` (mirrors the `drift:` handler): *ok* confirms the
    place + clears the inline buttons; *fix* prompts *"Type your area — e.g. `/l Orchard Road` …"*
    (typing is the reliable path on desktop). The location is left saved (their next `/l <place>`
    overwrites) — no auto-clear, to avoid leaving them location-less mid-flow.

- **[DELTA — `i18n.js`]** 6 new keys, **en + fr**: `loc.confirm.firstShare`, `loc.confirm.yes`,
  `loc.confirm.no`, `loc.confirm.okAck`, `loc.confirm.fixPrompt`, `loc.desktopNudge`.
