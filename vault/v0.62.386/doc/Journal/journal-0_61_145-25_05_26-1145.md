- **[INTENT]**
  1. Stop the durian result list from showing the same chain name
     multiple times. Root cause: Google Places returns separate
     placeIds per OUTLET of a multi-location chain (Golden Moments
     Durian has many outlets across SG, each tagged separately).
     The v0.61.126 placeId-based dedup lets all outlets through.
     For special modes the operator wants ONE card per chain-name.
  2. Replace the three default-🍽️ chip fall-throughs in the
     "Dessert, Fruits" group with the operator-chosen emoji:
     Dessert → 🍨 (shaved-ice ice cream); Fruits → 🍉 (watermelon);
     Durian Pastry → 🥮 (moon cake). Durian also gets a 🥥 emoji
     fallback for the v0.61.142 PNG's `onError` path.

- **[KNOWN GAPS]**
  - **Dedup is post-widening** — the v0.61.129 widening loop sees
    the FULL pool (incl. duplicates) when computing whether to
    escalate radius. Means a "8-target" pool of 10 venues with 5
    duplicate names triggers no widening (count ≥ 8), but the
    user sees only 5 unique cards. Better would be: dedup
    per-pass inside `widenSpecialMode` so the widening sees the
    deduplicated count. Easy follow-up via the existing helper;
    deferred so this PR ships the operator's regression fix fast.
  - **Name-only dedup** is heuristic — "Golden Moments" vs
    "Golden Moments Durian Cafe" would NOT dedup (different
    strings). The operator's screenshot showed identically-named
    cards, so this catches the common case; fancier
    normalisation (drop suffixes like "Cafe" / "Stall" /
    "Shop" / "Specialist") could land in a follow-up if the
    operator surfaces near-dupes.
  - **No new tests** — the dedup is a tiny inline `Set`-based
    filter; behaviour-obvious. The emoji change is a data-only
    delta inside an existing tested data structure
    (`FLAG_BY_SLUG`).
  - **Durian PNG fallback** — when the operator's `durian.png`
    fails to load (chaos test from PR #643), the chip now falls
    back to 🥥 (per the new `FLAG_BY_SLUG['durian']`) instead of
    the default 🍽️. Minor improvement piggybacked on this PR.
